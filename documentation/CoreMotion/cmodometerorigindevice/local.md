# CMOdometerOriginDevice.local

**Framework**: Core Motion  
**Kind**: case  
**Role**: Case

The origin of the odometer sample comes from the same device that requests the sample.

**Availability**:
- iOS 15.4+
- iPadOS 15.4+
- Mac Catalyst 15.4+
- macOS 10.15+
- visionOS 1.0+
- watchOS 8.4+
