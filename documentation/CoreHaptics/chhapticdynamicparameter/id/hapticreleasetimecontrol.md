# hapticReleaseTimeControl

**Framework**: Core Haptics  
**Kind**: property  
**Role**: Type Property

A dynamic parameter to change the time at which to begin fading the haptic pattern.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- macOS 10.15+
- tvOS 14.0+
- visionOS 1.0+
