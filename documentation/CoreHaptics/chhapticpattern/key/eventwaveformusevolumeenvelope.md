# eventWaveformUseVolumeEnvelope

**Framework**: Core Haptics  
**Kind**: property  
**Role**: Type Property

A key that identifies whether audio file playback fades in and out using an envelope.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
