# defaultValue

**Framework**: Core Haptics  
**Kind**: property  
**Role**: Instance Property  
**Required**: Yes

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- macOS 10.15+
- tvOS 14.0+

## Declaration

```swift
var defaultValue: Float { get }
```

```objc
@property (readonly) float defaultValue;
```

The parameter assumes this default value when initialized.
