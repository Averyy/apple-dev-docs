# CGRectGetMinX(_:)

**Framework**: Core Graphics  
**Kind**: func  
**Role**: Function

Returns the smallest value for the x-coordinate of the rectangle.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- macOS 10.0+
- tvOS
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
func CGRectGetMinX(_ rect: CGRect) -> CGFloat
```

```c
extern CGFloat CGRectGetMinX(CGRect rect);
```

## Return Value

The smallest value for the x-coordinate of the rectangle.

## Parameters

- `rect`: The rectangle to examine.
