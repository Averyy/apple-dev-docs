# CGPointEqualToPoint

**Framework**: Core Graphics  
**Kind**: macro  
**Role**: Macro

Returns whether two points are equal.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```c
#define CGPointEqualToPoint
```

## Return Value

[`true`](../Swift/true.md) if the two specified points are the same; otherwise, [`false`](../Swift/false.md).

## Parameters

- `point1`: The first point to examine.
- `point2`: The second point to examine.
