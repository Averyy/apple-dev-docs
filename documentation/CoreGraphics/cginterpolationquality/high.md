# CGInterpolationQuality.high

**Framework**: Core Graphics  
**Kind**: case  
**Role**: Case

A high level of interpolation quality. This setting may slow down image rendering.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

```swift
case high
```
