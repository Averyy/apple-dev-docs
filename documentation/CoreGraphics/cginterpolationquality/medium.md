# CGInterpolationQuality.medium

**Framework**: Core Graphics  
**Kind**: case  
**Role**: Case

A medium level of interpolation quality. This setting is slower than the low setting but faster than the high setting.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS
