# CGSizeEqualToSize

**Framework**: Core Graphics  
**Kind**: macro  
**Role**: Macro

Returns whether two sizes are equal.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```c
#define CGSizeEqualToSize
```

## Return Value

[`true`](../Swift/true.md) if the two specified sizes are equal; otherwise, [`false`](../Swift/false.md).

## Parameters

- `size1`: The first size to examine.
- `size2`: The second size to examine.
