# alphaInfoMask

**Framework**: Core Graphics  
**Kind**: property  
**Role**: Type Property

The alpha information mask. Use this to extract alpha information that specifies whether a bitmap contains an alpha channel and how the alpha channel is generated.

**Availability**:
- iOS 7.0+ - Deprecated in 27.2
- iPadOS 7.0+ - Deprecated in 27.2
- Mac Catalyst 7.0+ - Deprecated in 27.2
- macOS 10.9+ - Deprecated in 27.2
- tvOS 9.0+ - Deprecated in 27.2
