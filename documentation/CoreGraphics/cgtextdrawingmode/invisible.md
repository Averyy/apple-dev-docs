# CGTextDrawingMode.invisible

**Framework**: Core Graphics  
**Kind**: case  
**Role**: Case

Do not draw the text, but do update the text position.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS
