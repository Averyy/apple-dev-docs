# outputOffsetX

**Framework**: MetalFX  
**Kind**: property  
**Required**: Yes

The horizontal offset, in pixels, of the region within the output texture to write results. For regions outside the contents of the colorTexture are copied.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
