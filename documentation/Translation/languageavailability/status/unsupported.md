# LanguageAvailability.Status.unsupported

**Framework**: Translation  
**Kind**: case  
**Role**: Case

The framework doesn’t support the language or language pairing.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 26.0+
- macOS 15.0+

```swift
case unsupported
```
