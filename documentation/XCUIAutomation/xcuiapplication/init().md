# init()

**Framework**: XCUIAutomation  
**Kind**: init  
**Role**: Initializer

Creates a proxy for the application that’s configured as the Target Application in Xcode’s target settings.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS
- Xcode 16.3+
