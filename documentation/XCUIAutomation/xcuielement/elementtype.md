# XCUIElement.ElementType

**Framework**: XCUIAutomation  
**Kind**: enum  
**Role**: Enumeration

The types of UI elements that you find, inspect, and interact with in a UI test.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS
- Xcode 16.3+
