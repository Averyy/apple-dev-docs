# swipeUp(withVelocity:)

**Framework**: XCUIAutomation  
**Kind**: method  
**Role**: Instance Method

Sends a swipe-up gesture with a velocity you specify.

**Availability**:
- watchOS
- Xcode 16.3+

> **Deprecated**: Use [`swipeUp(velocity:)`](./swipeup%28velocity%29.md) instead.

## Declaration

```swift
@MainActor
@nonobjc @preconcurrency func swipeUp(withVelocity velocity: XCUIGestureVelocity)
```

## Parameters

- `velocity`: The speed at which to perform the swipe-up gesture, expressed in pixels per second.
