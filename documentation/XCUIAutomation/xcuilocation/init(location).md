# init(location:)

**Framework**: XCUIAutomation  
**Kind**: init  
**Role**: Initializer

Initializes a proxy that simulates latitude, longitude, and course information based on the location object you provide.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS
- Xcode 16.3+

## Declaration

```swift
init(location: CLLocation)
```

```objc
- (instancetype) initWithLocation:(CLLocation *) location;
```

## Parameters

- `location`: The [`CLLocation`](../../CoreLocation/cllocation.md) object that contains the latitude, longitude, and course information for this proxy.
