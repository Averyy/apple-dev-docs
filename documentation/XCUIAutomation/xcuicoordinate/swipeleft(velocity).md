# swipeLeft(velocity:)

**Framework**: XCUIAutomation  
**Kind**: method  
**Role**: Instance Method

Sends a swipe-left gesture with a velocity you specify.

**Availability**:
- macOS
- Xcode 16.3+

## Declaration

```swift
func swipeLeft(velocity: XCUIGestureVelocity)
```

```objc
- (void) swipeLeftWithVelocity:(XCUIGestureVelocity) velocity;
```

## Parameters

- `velocity`: The speed at which to perform the swipe-left gesture, in pixels per second.
