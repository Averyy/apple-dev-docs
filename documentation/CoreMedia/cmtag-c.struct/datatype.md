# dataType

**Framework**: Core Media  
**Kind**: property  
**Role**: Instance Property

**Availability**:

- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+

