# kCMTagCollectionError_ExhaustedBufferSize

**Framework**: Core Media  
**Kind**: case  
**Role**: Enumeration Case

Indicates that a buffer was smaller than the number of requested tags.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```c
kCMTagCollectionError_ExhaustedBufferSize
```
