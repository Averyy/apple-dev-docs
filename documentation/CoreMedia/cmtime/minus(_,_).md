# -(_:_:)

**Framework**: Core Media  
**Kind**: op  
**Role**: Operator

Returns a new time that represents the difference between two times.

**Availability**:
- iOS 4.0+
- iPadOS 4.0+
- Mac Catalyst 4.0+
- macOS 10.7+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 6.0+

## Declaration

```swift
static func - (minuend: CMTime, subtrahend: CMTime) -> CMTime
```

#### Return Value

A time value that represents the result of the operation.

## Parameters

- `minuend`: A time value.
- `subtrahend`: A time value to subtract from the minuend.
