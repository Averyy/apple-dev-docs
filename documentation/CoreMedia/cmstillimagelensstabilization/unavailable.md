# CMStillImageLensStabilization.unavailable

**Framework**: Core Media  
**Kind**: case

The lens stabilization module was unavailable for use.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst ?+
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- watchOS 27.0+ (Beta)

## Declaration

```swift
case unavailable
```

#### Discussion

The value of kCMSampleBufferAttachmentKey_StillImageLensStabilizationInfo if the lens stabilization module is unavailable to compensate for the motion of the device. The module may be available at a later time.
