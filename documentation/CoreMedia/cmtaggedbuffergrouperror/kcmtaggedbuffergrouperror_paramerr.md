# kCMTaggedBufferGroupError_ParamErr

**Framework**: Core Media  
**Kind**: case  
**Role**: Enumeration Case

Indicates a parameter to a function was of the wrong type or didn’t meet a necessary condition.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
