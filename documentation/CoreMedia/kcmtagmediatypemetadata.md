# kCMTagMediaTypeMetadata

**Framework**: Core Media  
**Kind**: var  
**Role**: Global Variable

A value for associating a tag’s media type with metadata.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```c
extern const CMTag kCMTagMediaTypeMetadata;
```

#### Discussion

This value is for use in tags with the [`kCMTagCategory_MediaType`](./cmtagcategory/kcmtagcategory_mediatype.md) category.
