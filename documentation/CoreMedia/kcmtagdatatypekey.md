# kCMTagDataTypeKey

**Framework**: Core Media  
**Kind**: var  
**Role**: Global Variable

A constant for use as a key during tag creation from a dictionary, whose value is the tag’s data type.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```c
extern CFStringRef const kCMTagDataTypeKey;
```
