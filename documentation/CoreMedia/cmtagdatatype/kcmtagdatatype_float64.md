# kCMTagDataType_Float64

**Framework**: Core Media  
**Kind**: case  
**Role**: Enumeration Case

The tag value is a 64-bit floating point number.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+
