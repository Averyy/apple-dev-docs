# FormatFlagIsFloat

**Framework**: AudioDriverKit  
**Kind**: case  
**Role**: Enumeration Case

A flag to indicate whether samples are floating-point values.

**Availability**:
- DriverKit 21.0+

## Declaration

```c
FormatFlagIsFloat
```

#### Discussion

Set this flag for floating-point samples; clear it for integers.
