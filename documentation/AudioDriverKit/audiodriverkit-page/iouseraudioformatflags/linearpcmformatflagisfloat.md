# LinearPCMFormatFlagIsFloat

**Framework**: AudioDriverKit  
**Kind**: case  
**Role**: Enumeration Case

A flag to indicate whether PCM samples are floating-point values.

**Availability**:
- DriverKit 21.0+

## Declaration

```c
LinearPCMFormatFlagIsFloat
```
