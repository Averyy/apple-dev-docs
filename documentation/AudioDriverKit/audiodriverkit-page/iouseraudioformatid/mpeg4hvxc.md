# MPEG4HVXC

**Framework**: AudioDriverKit  
**Kind**: case  
**Role**: Enumeration Case

The MPEG-4 Harmonic Vector eXcitation Coding (HVXC) audio object format.

**Availability**:
- DriverKit 21.0+

## Declaration

```c
MPEG4HVXC
```

#### Discussion

This format uses no flags.
