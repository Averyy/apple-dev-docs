# AppleIMA4

**Framework**: AudioDriverKit  
**Kind**: case  
**Role**: Enumeration Case

The Apple implementation of IMA 4:1 Adaptive Differential Pulse-Code Modulation (ADPCM) format.

**Availability**:
- DriverKit 21.0+

## Declaration

```c
AppleIMA4
```

#### Discussion

This format uses no flags.
