# AudioSessionPropertyID

**Framework**: Audio Toolbox  
**Kind**: typealias  
**Role**: Type Alias

The data type for an audio session property identifier.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- visionOS

> **Deprecated**: Deprecated in iOS 7.0.

## Declaration

```swift
typealias AudioSessionPropertyID = UInt32
```

```c
typedef UInt32 AudioSessionPropertyID;
```

## Discussion

Each Audio Session property has a four-character identifier. The properties are listed in [Audio Session Property Identifiers](./api-1618455-audio-session-property-identifie.md).
