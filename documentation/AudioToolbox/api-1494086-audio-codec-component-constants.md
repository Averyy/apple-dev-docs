# Audio Codec Component Constants

**Framework**: Audio Toolbox  
**Role**: API Collection

Audio codec component types.

#### Overview

Some possible audio codec component subtypes are listed in the format IDs enumeration in the CoreAudioTypes.h header file (see [Core Audio Data Types](../CoreAudio/core-audio-data-types.md)).

## Topics

### Constants
- [var kAudioDecoderComponentType: UInt32](./kaudiodecodercomponenttype.md)
  A codec that translates data in some other format into linear PCM.
- [var kAudioEncoderComponentType: UInt32](./kaudioencodercomponenttype.md)
  A codec that translates linear PCM data into some other format
- [var kAudioUnityCodecComponentType: UInt32](./kaudiounitycodeccomponenttype.md)
