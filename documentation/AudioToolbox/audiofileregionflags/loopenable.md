# loopEnable

**Framework**: Audio Toolbox  
**Kind**: property  
**Role**: Type Property

If set, the region is looped. You must set one or both of the remaining flags must also be set for the region to be looped.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
