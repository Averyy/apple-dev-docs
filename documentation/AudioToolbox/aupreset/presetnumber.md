# presetNumber

**Framework**: Audio Toolbox  
**Kind**: property  
**Role**: Instance Property

If less than `0`, then the preset is a user preset. If greater than or equal to `0`, then this field is used to select a factory preset.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
