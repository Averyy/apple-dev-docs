# init()

**Framework**: GameplayKit  
**Kind**: init  
**Role**: Initializer

Initializes a state object.

**Availability**:
- iOS 9.0+
- iPadOS 9.0+
- Mac Catalyst 13.1+
- macOS 10.11+
- tvOS 9.0+
- visionOS 1.0+

## Declaration

```swift
init()
```


A state object.

Override this method to perform custom initialization in your state classes.
