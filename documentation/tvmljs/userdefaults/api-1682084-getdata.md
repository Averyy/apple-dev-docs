# getData

**Framework**: TVMLKit JS  
**Kind**: instm  
**Role**: Instance Method

Returns the data associated with a particular key.

**Availability**:
- tvOS 10.0+

## Declaration

```
String getData(
    in String key
);
```

#### Return Value

The retrieved data.

## Parameters

- `key`: The key for data to be retrieved.
