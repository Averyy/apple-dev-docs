# removeData

**Framework**: TVMLKit JS  
**Kind**: instm  
**Role**: Instance Method

Removes the data associated with a particular key.

**Availability**:
- tvOS 10.0+

## Declaration

```
void removeData(
    in String key
);
```

## Parameters

- `key`: The key for the data to be removed.
