# clear

**Framework**: TVMLKit JS  
**Kind**: instm  
**Role**: Instance Method

Removes all instances of key-value pairs from the storage list.

**Availability**:
- tvOS 9.0+
- Safari Desktop 4.0+
- Safari Mobile 3.0+

## Declaration

```
void clear();
```
