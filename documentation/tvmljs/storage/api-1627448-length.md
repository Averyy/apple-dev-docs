# length

**Framework**: TVMLKit JS  
**Kind**: instp  
**Role**: Instance Property

The number of key-value pairs currently in the storage list.

**Availability**:
- tvOS 9.0+
- Safari Desktop 10.0+
- Safari Mobile 10.0+

## Declaration

*tvOS*

```
readonly attribute int length;
```

*Safari Desktop, Safari Mobile*

```
readonly attribute unsigned long length;
```
