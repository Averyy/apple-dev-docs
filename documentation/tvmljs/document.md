# Document

**Framework**: TVMLKit JS  
**Kind**: cl  
**Role**: Class

These additions to the `Document` class are used to create touch event objects on iOS and control full-screen mode on the desktop.

**Availability**:
- tvOS 13.0+
- Safari Desktop 10.0+
- Safari Mobile 1.0+

## Declaration

```
interface Document
```
