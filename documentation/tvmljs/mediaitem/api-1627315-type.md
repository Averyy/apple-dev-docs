# type

**Framework**: TVMLKit JS  
**Kind**: instp  
**Role**: Instance Property

The type of media item.

**Availability**:
- tvOS 9.0+

## Declaration

```
attribute String type;
```

#### Discussion

The valid values for this attribute are `audio` and `video`.
