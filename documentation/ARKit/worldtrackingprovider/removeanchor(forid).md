# removeAnchor(forID:)

**Framework**: ARKit  
**Kind**: method  
**Role**: Instance Method

Removes a world anchor from a world-tracking provider based on its ID.

**Availability**:
- visionOS 1.0+

## Declaration

```swift
final func removeAnchor(forID id: UUID) async throws
```

## Parameters

- `id`: The unique ID of the world anchor to remove.
