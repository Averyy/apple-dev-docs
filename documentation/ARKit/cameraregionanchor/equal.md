# ==(_:_:)

**Framework**: ARKit  
**Kind**: op

Returns a Boolean value indicating whether two camera region anchors are equal.

**Availability**:
- visionOS 26.0+

## Declaration

```swift
static func == (lhs: CameraRegionAnchor, rhs: CameraRegionAnchor) -> Bool
```

#### Return Value

`true` if the two camera region anchors are equal; otherwise, `false`.

## Parameters

- `lhs`: The left-hand side camera region anchor to compare.
- `rhs`: The right-hand side camera region anchor to compare.
