# isEnvironmentTexturingEnabled

**Framework**: ARKit  
**Kind**: property

Enable or disable environment texturing.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)

## Declaration

```swift
var isEnvironmentTexturingEnabled: Bool { get set }
```

#### Discussion

When enabled, the system automatically generates and updates the environment texture at the device position. Disabled by default.
