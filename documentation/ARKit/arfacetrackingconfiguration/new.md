# new

**Framework**: ARKit  
**Kind**: method  
**Role**: Type Method

Allocates and initializes a new face-tracking configuration.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+

## Declaration

```objc
+ (instancetype) new;
```

## Discussion

To use the configuration in an AR session, pass it to the [`ARSession`](../arsession.md) [`run(_:options:)`](../arsession/run%28_,options%29.md) method.
