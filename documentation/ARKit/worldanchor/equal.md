# ==(_:_:)

**Framework**: ARKit  
**Kind**: op

Returns a Boolean value indicating whether two world anchors are equal.

**Availability**:
- visionOS 2.0+

## Declaration

```swift
static func == (lhs: WorldAnchor, rhs: WorldAnchor) -> Bool
```

#### Return Value

`true` if the two world anchors are equal; otherwise, `false`.

## Parameters

- `lhs`: The left-hand side world anchor to compare.
- `rhs`: The right-hand side world anchor to compare.
