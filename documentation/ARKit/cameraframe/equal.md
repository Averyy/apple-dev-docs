# ==(_:_:)

**Framework**: ARKit  
**Kind**: op

Returns a Boolean value indicating whether two camera frames are equal.

**Availability**:
- visionOS 2.0+

## Declaration

```swift
static func == (lhs: CameraFrame, rhs: CameraFrame) -> Bool
```

#### Return Value

`true` if the two camera frames are equal; otherwise, `false`.

## Parameters

- `lhs`: The left-hand side camera frame to compare.
- `rhs`: The right-hand side camera frame to compare.
