# init()

**Framework**: ARKit  
**Kind**: init  
**Role**: Initializer

Initializes a new geotracking configuration.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+

## Declaration

```swift
init()
```

```objc
- (instancetype) init;
```

#### Discussion

To use the configuration in an AR experience, pass it as an argument to your app’s [`run(_:options:)`](../arsession/run%28_,options%29.md) function.
