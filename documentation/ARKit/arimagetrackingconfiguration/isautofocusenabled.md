# isAutoFocusEnabled

**Framework**: ARKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that determines whether the device camera uses fixed focus or autofocus behavior.

**Availability**:
- iOS 12.0+
- iPadOS 12.0+
