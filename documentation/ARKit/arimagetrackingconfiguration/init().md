# init()

**Framework**: ARKit  
**Kind**: init  
**Role**: Initializer

Initializes a new image-tracking configuration.

**Availability**:
- iOS 12.0+
- iPadOS 12.0+

## Declaration

```swift
init()
```

```objc
- (instancetype) init;
```

## Discussion

To use the configuration in an AR session, pass it to the [`ARSession`](../arsession.md) [`run(_:options:)`](../arsession/run%28_,options%29.md) method.
