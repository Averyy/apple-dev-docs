# init(from:)

**Framework**: ARKit  
**Kind**: init

Creates a reference object from a URL you provide.

**Availability**:
- visionOS 2.0+

## Declaration

```swift
init(from url: URL) async throws
```

## Parameters

- `url`: Local path to the reference object model.
