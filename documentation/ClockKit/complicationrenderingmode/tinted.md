# ComplicationRenderingMode.tinted

**Framework**: ClockKit  
**Kind**: case  
**Role**: Case

The system renders the complication as a tinted complication.

**Availability**:
- watchOS 7.0+ - Deprecated in 27.2

> **Deprecated**: On watchOS 9.0 or later, use WidgetKit instead

## Declaration

case tinted
