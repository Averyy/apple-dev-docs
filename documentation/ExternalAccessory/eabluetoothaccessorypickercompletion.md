# EABluetoothAccessoryPickerCompletion

**Framework**: External Accessory  
**Kind**: typealias  
**Role**: Type Alias

The completion block for the Bluetooth picker.

**Availability**:
- iOS 3.0+
- iPadOS 3.0+
- Mac Catalyst 13.0+
- macOS 10.13+
- tvOS 10.0+
- visionOS 1.0+

## Declaration

```swift
typealias EABluetoothAccessoryPickerCompletion = ((any Error)?) -> Void
```

```c
typedef void (^)(NSError *) EABluetoothAccessoryPickerCompletion;
```

#### Discussion

You use this block to process results generated by the [`showBluetoothAccessoryPicker(withNameFilter:completion:)`](./eaaccessorymanager/showbluetoothaccessorypicker%28withnamefilter,completion%29.md) method. The block receives an [`NSError`](../Foundation/nserror.md) object as its only parameter. If no error occurred, this parameter is set to `nil`.
