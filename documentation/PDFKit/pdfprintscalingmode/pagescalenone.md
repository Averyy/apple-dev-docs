# PDFPrintScalingMode.pageScaleNone

**Framework**: PDFKit  
**Kind**: case  
**Role**: Case

Do not apply scaling to the page when printing.

**Availability**:
- macOS 10.4+

## Declaration

```swift
case pageScaleNone
```

```c
kPDFPrintPageScaleNone
```
