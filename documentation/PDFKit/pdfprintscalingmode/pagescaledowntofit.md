# PDFPrintScalingMode.pageScaleDownToFit

**Framework**: PDFKit  
**Kind**: case  
**Role**: Case

Scale large pages down to fit the paper size (smaller pages do not get scaled up).

**Availability**:
- macOS 10.4+

## Declaration

```swift
case pageScaleDownToFit
```

```c
kPDFPrintPageScaleDownToFit
```

### Enumeration Cases

- [PDFPrintScalingMode.pageScaleToFit](./pagescaletofit.md)
