# isOpen()

**Framework**: PDFKit  
**Kind**: method  
**Role**: Instance Method

Returns a Boolean value indicating whether the pop-up is open.

**Availability**:
- macOS 10.5+ - Deprecated in 10.12

## Declaration

```swift
func isOpen() -> Bool
```

```objc
- (BOOL) isOpen;
```

#### Return Value

[`true`](../../Swift/true.md) if the pop-up is open; [`false`](../../Swift/false.md) otherwise.
