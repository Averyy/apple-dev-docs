# PDFDisplayMode.twoUp

**Framework**: PDFKit  
**Kind**: case  
**Role**: Case

A display mode where the document displays two pages side-by-side.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- Mac Catalyst 13.1+
- macOS 10.4+
- tvOS 11.0+
- visionOS 1.0+

## Declaration

```swift
case twoUp
```

```c
kPDFDisplayTwoUp
```

#### Discussion

Vertical and horizontal scrolling apply only to the pair of displayed pages.
