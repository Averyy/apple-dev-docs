# fontColor()

**Framework**: PDFKit  
**Kind**: method  
**Role**: Instance Method

Returns the font color used for the annotation’s text field.

**Availability**:
- macOS 10.4+ - Deprecated in 10.12

## Declaration

```swift
func fontColor() -> NSColor!
```

```objc
- (NSColor *) fontColor;
```

## Return Value

The font color used for text in the annotation’s text field.
