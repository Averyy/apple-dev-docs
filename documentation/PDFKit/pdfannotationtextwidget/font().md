# font()

**Framework**: PDFKit  
**Kind**: method  
**Role**: Instance Method

Returns the font used for the annotation’s text field.

**Availability**:
- macOS 10.4+ - Deprecated in 10.12

## Declaration

```swift
func font() -> NSFont!
```

```objc
- (NSFont *) font;
```

#### Return Value

The font used for text in the annotation’s text field.
