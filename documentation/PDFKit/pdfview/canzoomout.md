# canZoomOut

**Framework**: PDFKit  
**Kind**: property  
**Role**: Instance Property

Returns a Boolean value indicating whether the user can view an expanded area and zoom out.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- Mac Catalyst 13.1+
- macOS 10.4+
- tvOS 11.0+
- visionOS 1.0+

```swift
var canZoomOut: Bool { get }
```

```objc
@property (nonatomic, readonly) BOOL canZoomOut;
```
