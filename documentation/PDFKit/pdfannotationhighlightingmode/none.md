# none

**Framework**: PDFKit  
**Kind**: property  
**Role**: Type Property

A highlight mode that doesn’t change the appearance of the annotation.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- Mac Catalyst 13.1+
- macOS 10.13+
- tvOS 11.0+
- visionOS 1.0+
