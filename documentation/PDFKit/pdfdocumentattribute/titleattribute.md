# titleAttribute

**Framework**: PDFKit  
**Kind**: property  
**Role**: Type Property

An optional text string containing the title of the document.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- Mac Catalyst 13.1+
- macOS 10.4+
- tvOS 11.0+
- visionOS 1.0+
