# values

**Framework**: PDFKit  
**Kind**: property  
**Role**: Instance Property

An array of strings that specifies the export values for items in a list or a pop-up menu.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- Mac Catalyst 11.0+
- macOS 10.4+
- tvOS
- visionOS 1.0+
