# quadPoints

**Framework**: PDFKit  
**Kind**: property  
**Role**: Type Property

An array of floating point values that specifies a rectangular region of a page.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- Mac Catalyst 13.1+
- macOS 10.13+
- tvOS 11.0+
- visionOS 1.0+
