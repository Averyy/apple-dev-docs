# setFont(_:)

**Framework**: PDFKit  
**Kind**: method  
**Role**: Instance Method

Sets the font of the control’s label.

**Availability**:
- macOS 10.4+ - Deprecated in 10.12

## Declaration

```swift
func setFont(_ font: NSFont!)
```

```objc
- (void) setFont:(NSFont *) font;
```

## Parameters

- `font`: The desired font for the control’s label.
