# pdfView

**Framework**: PDFKit  
**Kind**: property  
**Role**: Instance Property

Returns the `PDFView` object associated with the thumbnail view.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- Mac Catalyst 13.1+
- macOS 10.5+
- tvOS 11.0+
- visionOS 1.0+

## Declaration

```swift
weak var pdfView: PDFView? { get set }
```

```objc
@property (nonatomic, weak, nullable) PDFView * PDFView;
```

## Return Value

The PDF view object associated with the thumbnail view.
