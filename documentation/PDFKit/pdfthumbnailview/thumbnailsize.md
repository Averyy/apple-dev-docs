# thumbnailSize

**Framework**: PDFKit  
**Kind**: property  
**Role**: Instance Property

Returns the maximum width and height of the thumbnails in the thumbnail view.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- Mac Catalyst 13.1+
- macOS 10.5+
- tvOS 11.0+
- visionOS 1.0+

## Declaration

*iOS, iPadOS, Mac Catalyst, tvOS, visionOS*

```swift
var thumbnailSize: CGSize { get set }
```

*macOS*

```swift
var thumbnailSize: NSSize { get set }
```

*iOS, iPadOS, Mac Catalyst, tvOS, visionOS*

```objc
@property (nonatomic) CGSize thumbnailSize;
```

*macOS*

```objc
@property (nonatomic) NSSize thumbnailSize;
```

## Return Value

The maximum width and height of the thumbnails in the thumbnail view.
