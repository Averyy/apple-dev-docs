# simd_equal

**Framework**: simd  
**Kind**: func  
**Role**: Function

Returns true if every element in a matrix is exactly equal to the corresponding element in a second matrix.

## Declaration

```c
static simd_bool simd_equal(simd_double2x2 __x, simd_double2x2 __y);
```
