# sinpi(_:)

**Framework**: simd  
**Kind**: func  
**Role**: Function

Returns the sine of each element in a vector multiplied by pi.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
