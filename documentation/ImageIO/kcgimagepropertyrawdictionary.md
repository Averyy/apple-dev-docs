# kCGImagePropertyRawDictionary

**Framework**: Image I/O  
**Kind**: var  
**Role**: Global Variable

A dictionary of key-value pairs for an image that contains minimally processed, or raw, data.

**Availability**:
- iOS 4.0+
- iPadOS 4.0+
- Mac Catalyst 13.1+
- macOS 10.4+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
let kCGImagePropertyRawDictionary: CFString
```

```c
extern CFStringRef const kCGImagePropertyRawDictionary;
```
