# kCGImagePropertyDNGBaselineExposure

**Framework**: Image I/O  
**Kind**: var  
**Role**: Global Variable

The amount by which to adjust the zero point of the exposure, specified in EV units.

**Availability**:
- iOS 10.0+
- iPadOS 10.0+
- Mac Catalyst 13.1+
- macOS 10.12+
- tvOS 10.0+
- visionOS 1.0+
