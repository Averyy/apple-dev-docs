# CGImageMetadataErrors.prefixConflict

**Framework**: Image I/O  
**Kind**: case  
**Role**: Case

An error that indicates an attempt to register a namespace with a prefix that is different than the namespace’s existing prefix.

**Availability**:
- iOS 4.0+
- iPadOS 4.0+
- Mac Catalyst 13.0+
- macOS 10.8+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+
