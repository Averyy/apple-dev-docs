# BrandsReportingAdGroup.PricingModel

**Framework**: Apple Ads Platform API  
**Kind**: typealias

The unit of ad delivery the ad group is charged for, as captured at report time.

**Availability**:
- apple-ads-platform-api 1.0+

## Declaration

```swift
string BrandsReportingAdGroup.PricingModel
```

#### Discussion

`pricingModel` reflects the ad group’s charge unit at the time the system generated the report row. See [`ReportingPricingModel`](reportingpricingmodel.md) for additional context.
