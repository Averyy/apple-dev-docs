# ReportingBidStrategy.BidStrategyType

**Framework**: Apple Ads Platform API  
**Kind**: typealias

Auction participation approach applied to the campaign or ad group at report time.

**Availability**:
- apple-ads-platform-api 1.0+

## Declaration

```swift
string ReportingBidStrategy.BidStrategyType
```

#### Discussion

`MANUAL_CPT` and `MANUAL_CPM` are manual bidding strategies with a fixed bid. `MAX_CONVERSIONS` and `MAX_ENGAGEMENTS` are automated strategies that adjust bids to maximize conversions or engagements.
