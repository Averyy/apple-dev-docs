# AdAccount.Currency

**Framework**: Apple Ads Platform API  
**Kind**: typealias

The currency for the ad account.

**Availability**:
- apple-ads-platform-api 1.0+

## Declaration

```swift
string AdAccount.Currency
```

#### Discussion

The `AdAccount` currency is inherited from the parent org at creation.
