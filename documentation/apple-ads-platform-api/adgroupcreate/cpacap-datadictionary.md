# AdGroupCreate.CpaCap

**Framework**: Apple Ads Platform API  
**Kind**: dictionary

**Availability**:

## Declaration

Deprecated. Use `bidStrategy` with `MAX_CONVERSIONS` instead.

See [`CPAGoalCreate`](cpagoalcreate.md) for the full field reference.
