# SCNSceneSourceAssetUnitMeterKey

**Framework**: SceneKit  
**Kind**: var  
**Role**: Global Variable

The conversion factor from the unit used in the scene file to the SI meter.

**Availability**:
- iOS 8.0+ - Deprecated in 26.0
- iPadOS 8.0+ - Deprecated in 26.0
- Mac Catalyst 13.1+ - Deprecated in 26.0
- macOS 10.8+ - Deprecated in 26.0
- tvOS 9.0+ - Deprecated in 26.0
- visionOS 1.0+ - Deprecated in 26.0
- watchOS 3.0+ - Deprecated in 26.0

## Declaration

```swift
let SCNSceneSourceAssetUnitMeterKey: String
```

```c
extern NSString * const SCNSceneSourceAssetUnitMeterKey;
```

#### Discussion

The value for this key is an [`NSNumber`](../Foundation/nsnumber.md) object whose floating-point value is the number of SI meters for each unit in the scene file.
