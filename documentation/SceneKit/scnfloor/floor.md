# floor

**Framework**: SceneKit  
**Kind**: method

## Declaration

```objc
+ (instancetype) floor;
```

#### Return Value

A new floor geometry.

#### Discussion

A floor extends infinitely in the x- and z-axis dimensions of its local coordinate space, and is located in the plane whose y-coordinate is zero.
