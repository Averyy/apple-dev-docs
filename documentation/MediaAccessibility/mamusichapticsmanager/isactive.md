# isActive

**Framework**: Media Accessibility  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the system setting for Music Haptics is on.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- macOS 15.0+
- tvOS 18.0+
- visionOS 2.0+
