# Table.CellFormat.DurationFormat.Unit

**Framework**: Keynote Interchange Format  
**Kind**: typealias  
**Role**: Type

A duration unit.

**Availability**:
- Keynote Interchange Format 1.0+ (Beta)

## Declaration

```
string Table.CellFormat.DurationFormat.Unit
```

## Discussion

This value takes one of the following forms:

- `day`: Days
- `hour`: Hours
- `millisecond`: Milliseconds
- `minute`: Minutes
- `none`: No unit
- `second`: Seconds
- `week`: Weeks
