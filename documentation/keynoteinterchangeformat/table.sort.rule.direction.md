# Table.Sort.Rule.Direction

**Framework**: Keynote Interchange Format  
**Kind**: typealias  
**Role**: Type

A sort direction.

**Availability**:
- Keynote Interchange Format 1.0+ (Beta)

## Declaration

```
string Table.Sort.Rule.Direction
```

## Discussion

This value takes one of the following forms:

- `ascending`: Smallest or earliest first.
- `descending`: Largest or latest first.
