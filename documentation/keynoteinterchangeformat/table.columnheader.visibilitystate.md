# Table.ColumnHeader.VisibilityState

**Framework**: Keynote Interchange Format  
**Kind**: typealias  
**Role**: Type

A string that indicates whether a column is visible.

**Availability**:
- Keynote Interchange Format 1.0+ (Beta)

## Declaration

```
string Table.ColumnHeader.VisibilityState
```

## Discussion

This value takes one of the following forms:

- `user_hidden`: The user hid the with the Hide Column command.
- `visible`: The column is shown.
