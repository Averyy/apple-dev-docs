# Table.Predicate.Qualifier

**Framework**: Keynote Interchange Format  
**Kind**: typealias  
**Role**: Type

A qualifier for text-matching predicates.

**Availability**:
- Keynote Interchange Format 1.0+ (Beta)

## Declaration

```
string Table.Predicate.Qualifier
```

## Discussion

This value takes one of the following forms:

- `case_insensitive`: Match is case insensitive.
- `case_sensitive`: Match is case sensitive.
