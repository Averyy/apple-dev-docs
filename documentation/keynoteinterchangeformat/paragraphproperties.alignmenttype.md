# ParagraphProperties.AlignmentType

**Framework**: Keynote Interchange Format  
**Kind**: typealias  
**Role**: Type

The horizontal alignment of a paragraph.

**Availability**:
- Keynote Interchange Format 1.0+ (Beta)

## Declaration

```
string ParagraphProperties.AlignmentType
```

## Discussion

This value takes one of the following forms:

- `center`
- `justified`
- `left`
- `natural`: In a table cell, aligns text to the leading edge and numbers to the trailing edge. Shown in Keynote as Auto-Align Table Cell.
- `right`
