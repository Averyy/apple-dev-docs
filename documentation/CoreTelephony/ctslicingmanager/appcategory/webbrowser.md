# CTSlicingManager.AppCategory.webBrowser

**Framework**: Core Telephony  
**Kind**: case

An application category for web browsing traffic.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)

## Declaration

```swift
case webBrowser
```

#### Discussion

Browser slices provide optimized routing for web browsing traffic, enabling consistent performance for loading web pages and web-based content. Use this category for web browsers and apps that primarily deliver web content.
