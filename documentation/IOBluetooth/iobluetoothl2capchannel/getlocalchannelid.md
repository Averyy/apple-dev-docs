# getLocalChannelID

**Framework**: IOBluetooth  
**Kind**: method  
**Role**: Instance Method

Returns the local L2CAP channel ID for the target L2CAP channel.

**Availability**:
- macOS 10.0+ - Deprecated in 10.7

## Declaration

```objc
- (BluetoothL2CAPChannelID) getLocalChannelID;
```

## Return Value

Returns the local L2CAP channel ID for the target L2CAP channel.
