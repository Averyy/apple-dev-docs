# getRemoteChannelID

**Framework**: IOBluetooth  
**Kind**: method  
**Role**: Instance Method

Returns the remote L2CAP channel ID for the target L2CAP channel.

**Availability**:
- macOS 10.0+ - Deprecated in 10.7

## Declaration

```objc
- (BluetoothL2CAPChannelID) getRemoteChannelID;
```

#### Return Value

Returns the remote L2CAP channel ID for the target L2CAP channel.
