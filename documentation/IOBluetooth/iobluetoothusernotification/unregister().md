# unregister()

**Framework**: IOBluetooth  
**Kind**: method  
**Role**: Instance Method

Called to unregister the target notification.

**Availability**:
- macOS

## Declaration

```swift
func unregister()
```

```objc
- (void) unregister;
```

#### Discussion

Once this method has completed, the target IOBluetoothUserNotification will no longer be valid.
