# mean()

**Framework**: Create ML  
**Kind**: method  
**Role**: Instance Method

Returns the arithmetic mean of the elements in a column of integers.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 10.14+
- tvOS 16.0+
- visionOS 1.0+

## Declaration

```swift
func mean() -> Double?
```

Available when `Element` is `Int`.

**Other overloads**:

```swift
func mean() -> Double?
```

## Return Value

A [`Double`](../../Swift/double.md); otherwise `nil` if the column is invalid.
