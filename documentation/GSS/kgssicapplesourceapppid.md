# kGSSICAppleSourceAppPID

**Framework**: GSS  
**Kind**: var  
**Role**: Global Variable

A number that indicates the process ID of the app.

**Availability**:
- iOS 5.0+
- iPadOS 5.0+
- Mac Catalyst 13.0+
- macOS 10.14+
- visionOS 1.0+
