# DTLS.PeerAuthentication.optional

**Framework**: Network  
**Kind**: case

Requests the peer certificate, but if none is provided, proceed with the connection.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+
- watchOS 27.0+

## Declaration

```swift
case optional
```

#### Discussion

This is for servers. Clients will ignore this option.
