# userAppend

**Framework**: System  
**Kind**: property

Writes to the file may only append.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- watchOS 27.0+ (Beta)

## Declaration

```swift
static var userAppend: FileFlags { get }
```

#### Discussion

The corresponding C constant is `UF_APPEND`.

> **Note**: This flag may be changed by the file owner or superuser.
