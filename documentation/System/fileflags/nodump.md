# noDump

**Framework**: System  
**Kind**: property

Do not dump the file during backups.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- watchOS 27.0+ (Beta)

## Declaration

```swift
static var noDump: FileFlags { get }
```

#### Discussion

The corresponding C constant is `UF_NODUMP`.

> **Note**: This flag may be changed by the file owner or superuser.
