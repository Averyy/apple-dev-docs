# tracked

**Framework**: System  
**Kind**: property

File is tracked for the purpose of document IDs.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+
- watchOS 27.0+

## Declaration

```swift
static var tracked: FileFlags { get }
```

#### Discussion

The corresponding C constant is `UF_TRACKED`.

> **Note**: This flag may be changed by the file owner or superuser.
