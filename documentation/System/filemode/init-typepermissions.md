# init(type:permissions:)

**Framework**: System  
**Kind**: init

Creates a `FileMode` from the given file type and permissions.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+
- watchOS 27.0+

## Declaration

```swift
init(type: FileType, permissions: FilePermissions)
```

#### Discussion

> **Note**: This initializer masks the inputs with their respective bit masks.
