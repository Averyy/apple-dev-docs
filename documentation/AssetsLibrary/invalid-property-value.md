# Invalid Property Value

**Framework**: Assets Library  
**Role**: API Collection

A constant to indicate that a property accessed by `ALAsset/value(forProperty:)` is invalid.

## Topics

### Constants
- [ALErrorInvalidProperty](./alerrorinvalidproperty.md)
  Value returned by `ALAsset/value(forProperty:)` if the property you tried to access is invalid.
