# ALAssetsGroupPhotoStream

**Framework**: Assets Library  
**Kind**: case

The PhotoStream album.

## Declaration

```swift
ALAssetsGroupPhotoStream
```

#### Discussion

In iOS 6.0 and later, this also includes Shared Streams.
