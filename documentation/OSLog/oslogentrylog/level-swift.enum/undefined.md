# OSLogEntryLog.Level.undefined

**Framework**: OSLog  
**Kind**: case  
**Role**: Case

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 10.15+
- tvOS 15.0+
- visionOS 1.0+

#### Discussion

You should never encounter an undefined log level.
