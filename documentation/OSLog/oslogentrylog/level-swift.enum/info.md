# OSLogEntryLog.Level.info

**Framework**: OSLog  
**Kind**: case  
**Role**: Case

The log level that captures additional information.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 10.15+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
case info
```

```c
OSLogEntryLogLevelInfo
```

## Discussion

This log level captures information that may be helpful but isn’t essential for troubleshooting errors.
