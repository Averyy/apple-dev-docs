# placeholder

**Framework**: OSLog  
**Kind**: property  
**Role**: Instance Property

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 10.15+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
var placeholder: String { get }
```

```objc
@property (nonatomic, readonly) NSString * placeholder;
```

#### Discussion

The `placeholder` property holds an empty value when it is the last component.
