# audio-role-source

**Framework**: Professional-Video-Applications  
**Role**: Article

Defines an audio component by its role.

## Overview

Based on the audio roles assigned in a compound clip or a multicam clip, the `audio-role-source` element defines an audio component for `ref-clip` and `mc-clip` elements. For more information on audio component configuration in `mc-clip` and `ref-clip` elements, see [Audio Components and Multicam](./audio-components-and-multicam.md) and [Audio Components in Compound Clips](./audio-components-in-compound-clips.md)).
