# Professional Video Applications Data Types

**Framework**: Professional-Video-Applications  
**Role**: API Collection

## Topics

### Data Types
- [typealias FxImageOrigin](../professional_video_applications/fximageorigin.md)
  These constants define the orientation of an image’s coordinate system. Images in Motion have a bottom-left origin. Images in Final Cut have a top-left origin.
- [typealias FxPathStyle](../professional_video_applications/fxpathstyle.md)
  The style of the path, which is linear, bezier, or b-spline.
- [typealias FxPixelTransformSupport](../professional_video_applications/fxpixeltransformsupport.md)
  Constants that define the support for pixel transforms.
