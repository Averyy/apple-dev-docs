# title

**Framework**: Professional-Video-Applications

Represents a title with one or more text blocks.

#### Overview

A `title` element contains one or more `text` elements, each of which describes a block of text with custom styles.

## Topics

### Text and Style Elements
- [text](./text.md)
  Describes a block of text that appears in a title or caption on a timeline.
- [text-style](./text-style.md)
  Describes text style for a segment of text.
