# asset

**Framework**: Professional-Video-Applications

Define file-based media managed in a Final Cut Pro library.

#### Overview

Use the `asset` element to define a file-based media. A file-based media can have an original media representation and a proxy media representation. Describe those using the `media-rep` element along with file URLs for the media files.

##### Asset Element Attributes

| Attribute | Description |
| --- | --- |
| `uid` | The unique identifier of a media. By default, Final Cut Pro assigns a unique value. Third-party tools may assign their unique identifiers for media managed by their tool when importing the media into a Final Cut Pro library. Use a UUID or a string with a reverse DNS prefix to ensure uniqueness. ![](https://developer.apple.com/tutorials/images/com.apple.professionalvideoapplications/spacer.png) **Note**: Final Cut Pro reserves strings that contain only uppercase hexadecimal characters for internal identifiers. A third-party tool must not use these strings when assigning its own asset identifiers. |

> **Note**:  FCPXML 1.7 added support for asset identifiers assigned by third parties.

Use the `uid` attribute to reference the same asset in a subsequent XML import, even if the media representation is in a different location. Final Cut Pro locates the asset using the `uid` attribute value and relinks the media to the media file at the new location.

The `uid` attribute enables a workflow where the media initially imports as offline with its media file missing, and subsequently relinks to the media file when it becomes available. Start by importing XML with the original media with missing media file and the proxy media with a file existing at the specified location. This allows an editor to start working without waiting for the original media file to become available. When the high-resolution media file becomes available for the original media, you can perform a second XML import, that includes the high-resolution media file location, to replace the original media that was initially offline. The proxy and the original high-resolution media must be compatible, meaning their frame rates match, and the high-resolution media covers the time range of the proxy media. You can switch which media representation to view in the Final Cut viewer.

It is possible that an importing XML may include a media asset with its unique identifier assigned by a third-party tool, but the media asset has already been imported manually into Final Cut Pro by the user. In such situations, Final Cut Pro finds the asset through the URL specified by the `src` attribute of the `media-rep` element and assigns the unique identifier from the importing XML to the asset, overriding the unique identifier generated by Final Cut Pro. This is only possible when the media asset imported has a unique identifier assigned by Final Cut Pro.

> **Note**:  In FCPXML 1.8 or earlier the `asset` element directly specifies the original media file URL through its `src` attribute.

##### Implied Asset Attributes

Some `asset` element attributes are optional (or implied), because Final Cut Pro derives their values from the respective media file. However, the asset file may be offline when Final Cut Pro tries to access it; therefore, it is recommended that you specify the attributes listed below for all assets.

| Attribute | Description |
| --- | --- |
| `hasVideo` | Specifies whether the asset has video. |
| `hasAudio` | Specifies whether the asset has audio. |
| `audioSources` | The number of audio sources, or tracks, in the asset. |
| `audioChannels` | The number of audio channels in an audio source, or track. |
| `audioRate` | The asset’s audio rate. |
| `videoSources` | The number of video sources in the asset. ![](https://developer.apple.com/tutorials/images/com.apple.professionalvideoapplications/spacer.png) This attribute captures the number of PSD layers, especially when you import the media offline. Final Cut Pro needs to establish the respective number of media components. You can omit the attribute for a normal video where there is only one video source. |
| `auxVideoFlags` | Specifies the asset’s auxiliary video flags. |

##### Override Attributes

Use the asset element override attributes to override the information in the media file:

| Attribute | Description |
| --- | --- |
| `customLUTOverride` | Specifies a combination of color primaries and transfer functions that are unique for a specific camera manufacturer. ![](https://developer.apple.com/tutorials/images/com.apple.professionalvideoapplications/spacer.png) The override value can be one of the following: ![](https://developer.apple.com/tutorials/images/com.apple.professionalvideoapplications/spacer.png) A built-in custom camera Log or processing mode. For example, `64 (Panasonic_VLog_VGamut)`. ![](https://developer.apple.com/tutorials/images/com.apple.professionalvideoapplications/spacer.png) A custom LUT. For example, `LUT:f9814a42eb75c58d9d9dc2a5344bd423 (FilmConvert-Justine-3D-LUT)`. |
| `colorSpaceOverride` | Specifies the color space to use. Describe color space in terms of its three components shown under [Well-Known Color Space Triplets](./asset.md#Well-Known-Color-Space-Triplets). ![](https://developer.apple.com/tutorials/images/com.apple.professionalvideoapplications/spacer.png) For still images, the value can be sRGB IEC61966-2.1 or Adobe RGB (1998), in addition to those described in terms of components. |
| `projectionOverride` | Specifies the projection type for the asset. ![](https://developer.apple.com/tutorials/images/com.apple.professionalvideoapplications/spacer.png) Valid values are `none, equirectangular, cubic, fisheye, and back-to-back fisheye.` |
| `stereoscopicOverride` | Specifies the stereoscopic mode for the asset.  ![](https://developer.apple.com/tutorials/images/com.apple.professionalvideoapplications/spacer.png) Valid values are `mono`, `side by side`, and `over under`. |

##### Well-Known Color Space Triplets

FCPXML 1.7 and later use the following triplets for well-known color spaces:

| Triplet | Name |
| --- | --- |
| 1-1-1 | Rec. 709 |
| 6-1-6 | Rec. 601 NTSC |
| 5-1-6 | Rec. 601 PAL |
| 9-1-9 | Rec. 2020 |
| 9-16-9 | Rec. 2020 PQ |
| 9-18-9 | Rec. 2020 HLG |
