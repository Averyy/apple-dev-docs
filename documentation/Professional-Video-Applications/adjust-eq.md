# adjust-EQ

**Framework**: Professional-Video-Applications  
**Role**: Article

Specifies the equalization to apply to a clip.

## Overview

The valid values for equalization to apply can be one of the following:

- `flat`
- `voice_enhance`
- `music_enhance`
- `loudness`
- `hum_reduction`
- `bass_boost`
- `bass_reduce`
- `treble_boost`
- `treble_reduce`
