# AgeRangeService.Error.declinedOnboarding

**Framework**: Declared Age Range  
**Kind**: case

Indicates the person declined the age range onboarding flow.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+

## Declaration

```swift
case declinedOnboarding
```

#### Discussion

You receive this error when the person dismisses or opts out of the system onboarding interface required to set up age range sharing.
