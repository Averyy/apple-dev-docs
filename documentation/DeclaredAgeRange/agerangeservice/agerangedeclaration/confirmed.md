# AgeRangeService.AgeRangeDeclaration.confirmed

**Framework**: Declared Age Range  
**Kind**: case

Indicates a user’s age range was set using a scrutinized method, like a credit card or government ID.

**Availability**:
- iOS 26.5+
- iPadOS 26.5+
