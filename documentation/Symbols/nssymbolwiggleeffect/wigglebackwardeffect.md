# wiggleBackwardEffect

**Framework**: Symbols  
**Kind**: method  
**Role**: Type Method

Convenience initializer for a wiggle effect that moves back and forth horizontally based on the current locale, starting by moving backward.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- macOS 15.0+
- tvOS 18.0+
- visionOS 2.0+
