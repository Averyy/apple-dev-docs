# bounceUpEffect

**Framework**: Symbols  
**Kind**: method  
**Role**: Type Method

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```objc
+ (instancetype) bounceUpEffect;
```

## Return Value

A new instance of the bounce effect options that bounces the symbol upward.
