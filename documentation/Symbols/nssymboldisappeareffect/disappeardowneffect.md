# disappearDownEffect

**Framework**: Symbols  
**Kind**: method  
**Role**: Type Method

An effect that scales the symbol down as it disappears.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```objc
+ (instancetype) disappearDownEffect;
```

#### Return Value

A new instance of the disappear effect options that makes the symbol scale down as it disappears.
