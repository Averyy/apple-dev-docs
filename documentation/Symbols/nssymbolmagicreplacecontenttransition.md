# NSSymbolMagicReplaceContentTransition

**Framework**: Symbols  
**Kind**: class  
**Role**: Class

A symbol effect applies the MagicReplace animation to symbol images.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- macOS 15.0+
- tvOS 18.0+
- visionOS 2.0+
- watchOS 11.0+

## Declaration

```objc
@interface NSSymbolMagicReplaceContentTransition : NSSymbolContentTransition
```

#### Overview

The MagicReplace effect animates common elements across symbol images.
