# effect

**Framework**: Symbols  
**Kind**: method  
**Role**: Type Method

An animation that scales the layers in a symbol-based image separately or as a whole.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```objc
+ (instancetype) effect;
```

#### Return Value

A new instance of the scale effect options.
