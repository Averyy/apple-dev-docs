# scaleUpEffect

**Framework**: Symbols  
**Kind**: method  
**Role**: Type Method

An effect that scales the symbol up.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```objc
+ (instancetype) scaleUpEffect;
```

#### Return Value

A new instance of the scale effect options that scales up the symbol.
