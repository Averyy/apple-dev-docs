# appearUpEffect

**Framework**: Symbols  
**Kind**: method  
**Role**: Type Method

An effect that makes the symbol scale up as it appears.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```objc
+ (instancetype) appearUpEffect;
```

#### Return Value

A new instance of the appear effect options that makes the symbol scale up as it appears.
