# dimInactiveLayers

**Framework**: Symbols  
**Kind**: property  
**Role**: Instance Property

An effect that dims inactive layers in a symbol-based image.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```swift
var dimInactiveLayers: VariableColorSymbolEffect { get }
```

## Discussion

This effect draws inactive layers with reduced, but nonzero, opacity.
