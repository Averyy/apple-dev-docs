# transition

**Framework**: Symbols  
**Kind**: method  
**Role**: Type Method

An effect that replaces the layers of one symbol-based image with those of another.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```objc
+ (instancetype) transition;
```

#### Return Value

A new instance of the replace transition.
