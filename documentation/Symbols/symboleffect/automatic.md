# automatic

**Framework**: Symbols  
**Kind**: property  
**Role**: Type Property

A transition that applies the default animation to a symbol-based image in a context-sensitive manner.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```swift
static var automatic: AutomaticSymbolEffect { get }
```

Available when `Self` is `AutomaticSymbolEffect`.
