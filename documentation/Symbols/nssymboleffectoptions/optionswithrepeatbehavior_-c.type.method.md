# optionsWithRepeatBehavior:

**Framework**: Symbols  
**Kind**: method  
**Role**: Type Method

Convenience initializer setting a preferred repeat behavior.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- macOS 15.0+
- tvOS 18.0+
- visionOS 2.0+
- watchOS 11.0+

## Declaration

```objc
+ (instancetype) optionsWithRepeatBehavior:(NSSymbolEffectOptionsRepeatBehavior *) behavior;
```

## Return Value

A new options object with the preferred repeat behavior.

## Parameters

- `behavior`: The preferred behavior when the effect is repeated.
