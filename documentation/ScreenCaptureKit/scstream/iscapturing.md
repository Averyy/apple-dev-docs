# isCapturing

**Framework**: ScreenCaptureKit  
**Kind**: property

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
var isCapturing: Bool { get }
```

#### Discussion

Indicates whether this stream is currently capturing screen content

Returns YES if the stream has been started and is actively capturing, NO otherwise.
