# SCStreamError.Code.noCaptureSource

**Framework**: ScreenCaptureKit  
**Kind**: case  
**Role**: Case

An error message that indicates a stream doesn’t have a source to capture.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 18.2+
