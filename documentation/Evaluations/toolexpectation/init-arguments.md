# init(_:arguments:)

**Framework**: Evaluations  
**Kind**: init

Creates a new tool expectation.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- visionOS 27.0+
- watchOS 27.0+
- Xcode 27.0+

## Declaration

```swift
init(_ name: String, arguments: [ArgumentMatcher] = [])
```

## Parameters

- `name`: The name of the tool.
- `arguments`: The argument matchers to validate against the tool call.
