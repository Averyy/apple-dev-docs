# aggregateValue(_:)

**Framework**: Evaluations  
**Kind**: method

Returns the first aggregate value matching the given operation, or `-1` if not found.

**Availability**:

- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)

```swift

```

## Parameters

- `operation`: The aggregation operation to match.
