# hiddenPreviewsShowTitle

**Framework**: User Notifications  
**Kind**: property  
**Role**: Type Property

Show the notification’s title, even if the user has disabled notification previews for the app.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- Mac Catalyst 13.1+
- macOS 10.14+
- visionOS 1.0+
