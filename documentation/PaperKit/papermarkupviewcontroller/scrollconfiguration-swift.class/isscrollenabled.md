# isScrollEnabled

**Framework**: PaperKit  
**Kind**: property

A Boolean value that determines whether scrolling is enabled.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
final var isScrollEnabled: Bool { get set }
```

#### Discussion

When `false`, the scroll view disables dragging temporarily. Default is `true`.
