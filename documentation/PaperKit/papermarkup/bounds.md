# bounds

**Framework**: PaperKit  
**Kind**: property

The bounds of the paper.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- macOS 26.0+
- visionOS 26.0+

## Declaration

```swift
var bounds: CGRect { get set }
```

#### Discussion

The contents of the paper are positioned relative to its bounds.
