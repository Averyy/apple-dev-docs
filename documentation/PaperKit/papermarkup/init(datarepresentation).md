# init(dataRepresentation:)

**Framework**: PaperKit  
**Kind**: init  
**Role**: Initializer

Initializes and returns a new paper model from the specified data.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- visionOS 26.0+

## Declaration

```swift
init(dataRepresentation: Data) throws
```

## Parameters

- `dataRepresentation`: The data containing the serialized paper model.
