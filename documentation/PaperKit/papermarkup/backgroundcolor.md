# backgroundColor

**Framework**: PaperKit  
**Kind**: property

The background color of the paper.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
var backgroundColor: CGColor? { get set }
```

#### Discussion

Default is `nil`, which uses a default color based on the current user interface style.
