# init(bounds:)

**Framework**: PaperKit  
**Kind**: init

Initializes and returns a new paper model with the specified bounds.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- visionOS 26.0+

## Declaration

```swift
init(bounds: CGRect)
```

## Parameters

- `bounds`: The bounds of the markup container.
