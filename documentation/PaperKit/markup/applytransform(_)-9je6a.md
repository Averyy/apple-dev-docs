# applyTransform(_:)

**Framework**: PaperKit  
**Kind**: method  
**Role**: Instance Method

Transforms this element with the specified transform.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- visionOS 27.0+

## Declaration

```swift
mutating func applyTransform(_ transform: CGAffineTransform)
```

## Parameters

- `transform`: The transform applied to the element. Skew is ignored.
