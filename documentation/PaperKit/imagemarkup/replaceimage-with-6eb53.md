# replaceImage(with:)

**Framework**: PaperKit  
**Kind**: method

Replaces the contents of this image markup with a `CGImage`.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
mutating func replaceImage(with image: CGImage)
```

#### Discussion

Image content is shown scaled to fill.

## Parameters

- `image`: The new image to display.
