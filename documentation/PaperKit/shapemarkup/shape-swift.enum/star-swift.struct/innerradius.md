# innerRadius

**Framework**: PaperKit  
**Kind**: property

The radius of inner points relative to outer points, in unit coordinate space (0.0 to 1.0).

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
var innerRadius: CGFloat
```

#### Discussion

A value of `0.5` creates inner points halfway to the center.
