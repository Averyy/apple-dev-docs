# init(tailLocation:tailAngle:)

**Framework**: PaperKit  
**Kind**: init

Create an new speech bubble with a tail pointing to a specific location.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init(tailLocation: CGPoint, tailAngle: CGFloat)
```

## Parameters

- `tailLocation`: The position of the tail tip in unit coordinate space.
- `tailAngle`: The angle of the tail in radians.
