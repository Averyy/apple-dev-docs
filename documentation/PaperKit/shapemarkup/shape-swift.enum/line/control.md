# control

**Framework**: PaperKit  
**Kind**: property

The control point that defines the curve in unit coordinate space.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
var control: CGPoint?
```

#### Discussion

If `nil` this is a straight line without a middle control point.
