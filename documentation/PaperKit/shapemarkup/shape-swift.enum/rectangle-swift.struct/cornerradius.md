# cornerRadius

**Framework**: PaperKit  
**Kind**: property

The radius of the rounded rectangle’s corners.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
var cornerRadius: CGFloat?
```

#### Discussion

If `nil` the rectangle does not have a corner radius UI control point.
