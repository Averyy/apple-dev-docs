# autoresizing

**Framework**: PaperKit  
**Kind**: property

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration


#### Discussion

Controls whether the markup automatically adjusts its dimensions to fit content changes.
