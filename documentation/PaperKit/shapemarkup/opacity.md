# opacity

**Framework**: PaperKit  
**Kind**: property

The opacity of the shape.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
var opacity: CGFloat { get set }
```

#### Discussion

Ranges from `0.0` (fully transparent) to `1.0` (fully opaque). Defaults to `1.0`.
