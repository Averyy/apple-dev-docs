# strokeColor

**Framework**: PaperKit  
**Kind**: property

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- visionOS 27.0+

## Declaration

```swift
var strokeColor: CGColor? { get set }
```

#### Discussion
