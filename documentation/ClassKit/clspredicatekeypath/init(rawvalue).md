# init(rawValue:)

**Framework**: ClassKit  
**Kind**: init  
**Role**: Initializer

**Availability**:

- iPadOS 11.3+
- Mac Catalyst 11.3+
- macOS 11.0+
- visionOS 1.0+

## Declaration

