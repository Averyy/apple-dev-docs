# MediaDevice.DeviceType

**Framework**: Now Playing  
**Kind**: enum  
**Role**: Enumeration

The type of device that plays media.

**Availability**:
- iOS 27.0+
- iOS App Extension 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+

## Declaration

```swift
enum DeviceType
```

## Overview

Use this enumeration to specify the type of playback device in a remote session. The system uses the device type to display an appropriate icon in the Now Playing interface.
