# isExcludedFromSuggestions

**Framework**: Now Playing  
**Kind**: property  
**Required**: Yes

A Boolean value that indicates whether to exclude this content from media suggestions.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+
- watchOS 27.0+

## Declaration

```swift
var isExcludedFromSuggestions: Bool? { get set }
```

#### Discussion

Defaults to `false`.
