# isrc

**Framework**: Now Playing  
**Kind**: property

The International Standard Recording Code (ISRC) for this content.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+
- watchOS 27.0+

## Declaration

```swift
var isrc: String?
```

#### Discussion

ISRC is an industry-standard identifier for sound recordings. The system uses this value to integrate with the Music Haptics accessibility feature.
