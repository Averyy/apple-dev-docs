# init(extension:)

**Framework**: Now Playing  
**Kind**: init

Creates a new configuration with the specified extension instance.

**Availability**:
- iOS 27.0+ (Beta)
- iOS App Extension 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)

## Declaration

```swift
@MainActor
init(extension: Extension)
```

## Parameters

- `extension`: The extension that provides remote sessions.
