# resultsLimit

**Framework**: CKTool JS  
**Kind**: property  
**Role**: Instance Property

The maximum number of records to fetch.

**Availability**:
- CKTool JS 1.2.15+

## Declaration

```
attribute Int32? resultsLimit;
```

## Discussion

`resultsLimit` can be between 1 and 200, inclusive.
