# resultsLimit

**Framework**: CKTool JS  
**Kind**: property  
**Role**: Instance Property

The maximum number of records to delete.

**Availability**:
- CKTool JS 1.2.15+

## Declaration

```
attribute Int32? resultsLimit;
```

#### Discussion

`resultsLimit` can be from 1 to 200, inclusive.
