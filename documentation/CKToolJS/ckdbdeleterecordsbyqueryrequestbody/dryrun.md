# dryRun

**Framework**: CKTool JS  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether to delete matching records.

**Availability**:
- CKTool JS 1.2.15+

## Declaration

```
attribute boolean? dryRun;
```

## Discussion

If `dryRun` is set to `true`, the server won’t delete records.
