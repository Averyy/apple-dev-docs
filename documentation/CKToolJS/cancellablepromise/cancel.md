# cancel

**Framework**: CKTool JS  
**Kind**: method  
**Role**: Instance Method

Stops any work the promise is doing.

**Availability**:
- CKTool JS 1.2.15+

## Declaration

```
void cancel();
```

## Discussion

When called, it throws a `CancelledError`.
