# local

**Framework**: GameKit  
**Kind**: property  
**Role**: Type Property

The shared instance of the local player.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- macOS 10.15+
- tvOS 13.0+
- visionOS 1.0+

## Declaration

```objc
@property (class, readonly, nonnull) GKLocalPlayer * local;
```

#### Discussion

You never directly create a local player object. Instead, use this property to get the shared instance.
