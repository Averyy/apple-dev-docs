# GKError.Code.restrictedToAutomatch

**Framework**: GameKit  
**Kind**: case  
**Role**: Case

The system can’t complete the requested operation because the player is using automatch.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- macOS 10.15+
- tvOS 13.0+
- visionOS 1.0+
