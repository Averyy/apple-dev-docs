# GKError.Code.apiObsolete

**Framework**: GameKit  
**Kind**: case  
**Role**: Case

The system can’t complete the requested operation because Apple deprecated the API.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 7.0+
