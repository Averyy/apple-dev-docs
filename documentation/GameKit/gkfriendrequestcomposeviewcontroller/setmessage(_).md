# setMessage(_:)

**Framework**: GameKit  
**Kind**: method  
**Role**: Instance Method

Sets the text message included in the friend invitation.

**Availability**:
- iOS 4.2+ - Deprecated in 10.0
- iPadOS 4.2+ - Deprecated in 10.0
- Mac Catalyst 13.1+ - Deprecated in 13.1
- macOS 10.8+ - Deprecated in 10.12
- visionOS 1.0+ - Deprecated in 1.0

> **Deprecated**: No longer supported.

## Declaration

```swift
func setMessage(_ message: String?)
```

```objc
- (void) setMessage:(NSString *) message;
```

#### Discussion

If you do not set a text message, GameKit sets a default text message.

## Parameters

- `message`: The text message.
