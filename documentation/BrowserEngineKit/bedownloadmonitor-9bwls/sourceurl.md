# sourceURL

**Framework**: BrowserEngineKit  
**Kind**: property  
**Role**: Instance Property

**Availability**:
- iOS 18.2+
- iPadOS 18.2+

## Declaration

```swift
@objc
final let sourceURL: URL
```

#### Discussion
