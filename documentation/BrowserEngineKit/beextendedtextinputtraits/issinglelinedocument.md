# isSingleLineDocument

**Framework**: BrowserEngineKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that represents whether the active web input field is a single line document.

**Availability**:
- iOS 17.4+
- iPadOS 17.4+
- tvOS 17.4+
- visionOS 1.1+
