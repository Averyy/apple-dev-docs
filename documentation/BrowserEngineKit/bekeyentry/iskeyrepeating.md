# isKeyRepeating

**Framework**: BrowserEngineKit  
**Kind**: property

A Boolean value that indicates whether the person holds a key down to repeat its key event.

**Availability**:
- iOS 17.4+
- iPadOS 17.4+
- tvOS 17.4+
- visionOS 1.1+
