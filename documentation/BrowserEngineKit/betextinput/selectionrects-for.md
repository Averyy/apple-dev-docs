# selectionRects(for:)

**Framework**: BrowserEngineKit  
**Kind**: method  
**Required**: Yes

Returns an array of selection rectangles corresponding to the given text range.

**Availability**:
- iOS 17.4+
- iPadOS 17.4+
- tvOS 17.4+
- visionOS 1.1+
