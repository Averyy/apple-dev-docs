# caretRect(for:)

**Framework**: BrowserEngineKit  
**Kind**: method  
**Required**: Yes

Returns a rectangle in which the system can draw the text-selection caret.

**Availability**:
- iOS 17.4+
- iPadOS 17.4+
- tvOS 17.4+
- visionOS 1.1+

## Declaration

```swift
func caretRect(for position: UITextPosition) -> CGRect
```
