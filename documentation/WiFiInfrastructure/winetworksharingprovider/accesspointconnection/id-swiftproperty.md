# id

**Framework**: Wi-Fi Infrastructure  
**Kind**: property

A stable per-access point ID that can be used to uniquely identify this access point. ID will be stable for the lifetime of a given App launch.

**Availability**:
- iOS 26.4+
- iPadOS 26.4+
- Mac Catalyst 26.4+
