# IntelligenceSettingsApps_SafariObject

**Framework**: Device Management  
**Kind**: dictionary

**Availability**:
- iOS 26.4+
- iPadOS 26.4+
- Mac Catalyst 26.4+
- macOS 26.4+
- visionOS 26.4+
