# Get In-App Purchases

**Framework**: Device Management  
**Kind**: httpRequest

## Endpoint

`GET https://vpp.itunes.apple.com/mdm/x-hidden-/v2/inapps`

## Parameters

- `adamId` ([int64])
- `cursor` (string)
- `parentAdamId` ([int64])
