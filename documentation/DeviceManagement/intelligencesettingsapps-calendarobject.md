# IntelligenceSettingsApps_CalendarObject

**Framework**: Device Management  
**Kind**: dictionary

If present, configures Calendar and Reminders Intelligence features.

**Availability**:
- iOS 26.4+
- iPadOS 26.4+
- Mac Catalyst 26.4+
- macOS 26.4+
- visionOS 26.4+

## Declaration

```swift
object IntelligenceSettingsApps_CalendarObject
```

## Properties

- `AllowNaturalLanguageEditing` (boolean): If `false`, disables Natural Language Editing in Calendar and Reminders.
