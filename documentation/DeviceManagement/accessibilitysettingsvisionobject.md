# AccessibilitySettingsVisionObject

**Framework**: Device Management  
**Kind**: dictionary

If present, configures vision accessibility settings.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
object AccessibilitySettingsVisionObject
```

## Properties

- `AllowLiveRecognition` (boolean): If `false`, disables the Live Recognition accessibility feature.
