# DeviceInformationResponse.QueryResponses.AutoSetupAdminAccountsItem

**Framework**: Device Management  
**Kind**: dictionary  
**Role**: Device Management Command

**Availability**:
- macOS 10.11+

## Declaration

```
object DeviceInformationResponse.QueryResponses.AutoSetupAdminAccountsItem
```

## Properties
