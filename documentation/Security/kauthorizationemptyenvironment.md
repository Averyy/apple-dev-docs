# kAuthorizationEmptyEnvironment

**Framework**: Security  
**Kind**: macro  
**Role**: Macro

A constant you use in functions with an environment parameter if you have no environment data to provide.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
#define kAuthorizationEmptyEnvironment
```
