# SecCredentialType.noUI

**Framework**: Security  
**Kind**: case  
**Role**: Case

Keychain operations on keys that have this credential are not allowed to present UI, and will fail if UI is required.

**Availability**:
- macOS 10.3+ - Deprecated in 12.0

> **Deprecated**: No longer supported
