# kSecTransformErrorInvalidAlgorithm

**Framework**: Security  
**Kind**: var  
**Role**: Global Variable

A transform that needs an algorithm as an attribute received an invalid algorithm.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.7+ - Deprecated in 13.0
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
var kSecTransformErrorInvalidAlgorithm: CFIndex { get }
```

```c
kSecTransformErrorInvalidAlgorithm
```

## Discussion

This error applies to the sign and verify transforms.
