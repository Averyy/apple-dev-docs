# AuthorizationPluginId

**Framework**: Security  
**Kind**: typealias  
**Role**: Type Alias

An unused identifier for a plug-in.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.4+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```c
typedef AuthorizationString const AuthorizationPluginId;
```

#### Discussion

This identifier is not used by plugin writers. Loaded plugins are identified by their name instead.
