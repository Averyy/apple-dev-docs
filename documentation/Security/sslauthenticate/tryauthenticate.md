# SSLAuthenticate.tryAuthenticate

**Framework**: Security  
**Kind**: case  
**Role**: Case

Indicates that client-side authentication should be attempted. There is no error if the client doesn’t have a certificate.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+
