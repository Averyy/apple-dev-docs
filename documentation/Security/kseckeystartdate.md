# kSecKeyStartDate

**Framework**: Security  
**Kind**: var

Type `CSSM_DATE`.  Earliest date at which this key may be used.  If the value is all zeros or not present, no restriction applies.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.3+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+
