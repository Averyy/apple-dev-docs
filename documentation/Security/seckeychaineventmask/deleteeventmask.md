# deleteEventMask

**Framework**: Security  
**Kind**: property  
**Role**: Type Property

If the bit specified by this mask is set, your callback function is invoked when an item is deleted from a keychain.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+
