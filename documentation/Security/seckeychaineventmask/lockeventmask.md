# lockEventMask

**Framework**: Security  
**Kind**: property  
**Role**: Type Property

If the bit specified by this mask is set, your callback function is invoked when a keychain is locked.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+
