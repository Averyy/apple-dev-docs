# SecTransformMetaAttributeType.requiresOutboundConnection

**Framework**: Security  
**Kind**: case  
**Role**: Case

The attribute requires an outbound connection.

**Availability**:
- macOS 10.7+ - Deprecated in 13.0

> **Deprecated**: SecTransform is no longer supported

## Declaration

```swift
case requiresOutboundConnection
```

```c
kSecTransformMetaAttributeRequiresOutboundConnection
```

## Discussion

This metadata has a default value of [`true`](../../Swift/true.md) for the output attribute but is [`false`](../../Swift/false.md) for all other attributes.
