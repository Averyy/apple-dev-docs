# kSecCFErrorArchitecture

**Framework**: Security  
**Kind**: var  
**Role**: Global Variable

A key whose value is a string containing the name of the architecture that is causing the problem.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+
