# kAuthorizationFlagDefaults

**Framework**: Security  
**Kind**: case  
**Role**: Enumeration Case

An empty flag set that you use as a placeholder when you don’t want any of the other flags.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 16.0+
- macOS 10.0+
- tvOS 9.0+
