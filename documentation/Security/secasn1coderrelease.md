# SecAsn1CoderRelease

**Framework**: Security  
**Kind**: func  
**Role**: Function

Destroys an ASN.1 coder object and releases all of its memory.

**Availability**:
- macOS 10.0+ - Deprecated in 12.0

## Declaration

```c
OSStatus SecAsn1CoderRelease(SecAsn1CoderRef coder);
```
