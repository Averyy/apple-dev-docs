# PresentationCommand.shotFlip(_:)

**Framework**: Immersive Media Support  
**Kind**: case

A value that represents a command that mirrors a whole frame vertically for the duration of the command.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- visionOS 27.0+

## Declaration

```swift
case shotFlip(ShotFlipCommand)
```

#### Discussion

> **Note**: The renderer only honors this command on visionOS 27, macOS 27, or later. Earlier runtimes ignore it during playback.
