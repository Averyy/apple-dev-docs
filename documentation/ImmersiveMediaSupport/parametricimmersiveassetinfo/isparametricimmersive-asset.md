# isParametricImmersive(asset:)

**Framework**: Immersive Media Support  
**Kind**: method

Checks asynchronously whether the asset is already in the parametric immersive format.

**Availability**:
- iOS 26.4+ (Beta)
- iPadOS 26.4+ (Beta)
- Mac Catalyst 26.4+ (Beta)
