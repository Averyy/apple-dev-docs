# isShotFlipped

**Framework**: Immersive Media Support  
**Kind**: property

A Boolean value that indicates whether to vertically flip the video frame for the PTS specified in the last call to the update method.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
