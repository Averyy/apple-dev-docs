# People-Picker Event Kinds

**Framework**: Address Book  
**Role**: API Collection

Constants used by [`ABPickerAttributes`](./abpickerattributes.md) to specify People Picker event types.

## Topics

### Constants
- [kEventABPeoplePickerGroupSelectionChanged](./keventabpeoplepickergroupselectionchanged.md)
  The selection in the group list changed.
- [kEventABPeoplePickerNameSelectionChanged](./keventabpeoplepickernameselectionchanged.md)
  The selection in the name list changed.
- [kEventABPeoplePickerValueSelectionChanged](./keventabpeoplepickervalueselectionchanged.md)
  The selection in a multi-value property changed.
- [kEventABPeoplePickerDisplayedPropertyChanged](./keventabpeoplepickerdisplayedpropertychanged.md)
  The displayed property in the record list changed.
- [kEventABPeoplePickerGroupDoubleClicked](./keventabpeoplepickergroupdoubleclicked.md)
  A group in the group list was double-clicked.
- [kEventABPeoplePickerNameDoubleClicked](./keventabpeoplepickernamedoubleclicked.md)
  A record in the record list was double-clicked.
