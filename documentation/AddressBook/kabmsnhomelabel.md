# kABMSNHomeLabel

**Framework**: Address Book  
**Kind**: var  
**Role**: Global Variable

Home MSN instant messaging ID.

**Availability**:
- macOS 10.0+ - Deprecated in 10.7

> **Deprecated**: Use the multivalue property [`kABInstantMessageProperty`](./kabinstantmessageproperty.md) with a label of [`kABHomeLabel`](./kabhomelabel.md) and an instant message service of [`kABInstantMessageServiceMSN`](./kabinstantmessageservicemsn.md) instead.
