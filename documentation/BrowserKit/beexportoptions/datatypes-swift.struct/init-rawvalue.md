# init(rawValue:)

**Framework**: BrowserKit  
**Kind**: init

Initializes a browser data export option with a value that represents the underlying type.

**Availability**:
- iOS 26.4+
- iPadOS 26.4+

## Declaration


## Parameters

- `rawValue`: An instance of the structure’s underlying type.
