# init(windowScene:)

**Framework**: BrowserKit  
**Kind**: init

Initializes an import manager for a window scene.

**Availability**:
- iOS 26.4+ (Beta)
- iPadOS 26.4+ (Beta)

## Declaration

```swift
@MainActor
init(windowScene: UIWindowScene?)
```

## Parameters

- `windowScene`: Your app’s window scene. The manager presents the import sheet in this window.
