# init(coder:)

**Framework**: BrowserKit  
**Kind**: init  
**Role**: Initializer

Initializes browser data from a decoder.

**Availability**:
- iOS 26.4+
- iPadOS 26.4+

## Declaration

```swift
init?(coder: NSCoder)
```

## Parameters

- `coder`: The decoder from which to read data.
