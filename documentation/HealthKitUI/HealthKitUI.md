# HealthKitUI

**Framework**: HealthKitUI  
**Kind**: module  
**Role**: Framework

Display user interface that enables a person to view and interact with their health data.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 10.0+
- visionOS 1.0+
- watchOS 2.0+

## Overview

HealthKitUI defines user interface for the [HealthKit](../HealthKit/HealthKit.md) framework.

## Topics

### Essentials
- [class HKActivityRingView](./hkactivityringview.md)
  A view that uses the Move, Exercise, and Stand activity rings to display data from a HealthKit activity summary object.
