# IMKServerInput

**Framework**: InputMethodKit

`IMKServerInput` is an informal protocol that defines methods for receiving text events. This is intentionally not a formal protocol because there are three ways to receive events. An input method chooses one of the following approaches and implements the appropriate methods:

#### Overview

- Key binding. In this approach the system tries to map each key-down event to an action method that the input method has implemented.  If successful (action method found), the system calls `didCommandBySelector:client:`.  If unsuccessful (action method not found), the system calls `inputText:client:`.  For this approach you need to implement [`inputText(_:client:)`](../ObjectiveC/nsobject-swift.class/inputtext%28_,client%29.md) and [`didCommand(by:client:)`](../ObjectiveC/nsobject-swift.class/didcommand%28by,client%29.md).
- Text data only. In this approach, you opt to receive all key events without the key binding, and then unpack  the relevant text data.   Key events are broken down into the Unicodes, the key code that generated them, and modifier flags.  This data is then sent to the [`inputText(_:key:modifiers:client:)`](../ObjectiveC/nsobject-swift.class/inputtext%28_,key,modifiers,client%29.md) method, which you need to implement.
- Handle all events. In this approach, you receive events directly from the Text Services Manager as [`NSEvent`](../AppKit/nsevent.md) objects. You must implement [`handle(_:client:)`](../ObjectiveC/nsobject-swift.class/handle%28_,client%29.md) method.

## Topics

### Supporting Key Binding
- [func inputText(String!, client: Any!) -> Bool](../ObjectiveC/nsobject-swift.class/inputtext%28_,client%29.md)
  Handles key down events that do not map to an action method.
- [func didCommand(by: Selector!, client: Any!) -> Bool](../ObjectiveC/nsobject-swift.class/didcommand%28by,client%29.md)
  Processes a command  generated by user action such as typing certain keys or pressing the mouse button.
### Unpacking Text Data
- [func inputText(String!, key: Int, modifiers: Int, client: Any!) -> Bool](../ObjectiveC/nsobject-swift.class/inputtext%28_,key,modifiers,client%29.md)
  Receives Unicode, the key code that generated it, and any modifier flags.
### Receiving Events Directly from the Text Services Manager
- [func handle(NSEvent!, client: Any!) -> Bool](../ObjectiveC/nsobject-swift.class/handle%28_,client%29.md)
  Handles key down and mouse events.
### Committing a Composition
- [func commitComposition(Any!)](../ObjectiveC/nsobject-swift.class/commitcomposition%28_%29.md)
  Informs the controller that the composition should be committed.
### Getting Input Strings and Candidates
- [func composedString(Any!) -> Any!](../ObjectiveC/nsobject-swift.class/composedstring%28_%29.md)
  Return the current composed string.
- [func originalString(Any!) -> NSAttributedString!](../ObjectiveC/nsobject-swift.class/originalstring%28_%29.md)
  Return the string that consists of the precomposed Unicode characters.
- [func candidates(Any!) -> [Any]!](../ObjectiveC/nsobject-swift.class/candidates%28_%29.md)
  Returns an array of candidates.
