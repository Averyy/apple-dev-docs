# IMKCandidatesOpacityAttributeName

**Framework**: InputMethodKit  
**Kind**: var  
**Role**: Global Variable

The opacity level for a candidates window.

**Availability**:
- macOS 10.5+

## Declaration

```swift
let IMKCandidatesOpacityAttributeName: String
```

```c
extern const NSString * IMKCandidatesOpacityAttributeName;
```

## Discussion

The associated value must be an `NSNumber` object that represents a value from 0 to 1.
