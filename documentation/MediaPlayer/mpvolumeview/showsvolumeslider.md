# showsVolumeSlider

**Framework**: Media Player  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates the volume slider is visible in the volume view.

**Availability**:
- iOS 4.2+
- iPadOS 4.2+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+

## Declaration

```swift
var showsVolumeSlider: Bool { get set }
```

```objc
@property (nonatomic) BOOL showsVolumeSlider;
```

## Discussion

The volume slider is visible by default. To hide the volume slider, set this property’s value to [`false`](../../Swift/false.md).
