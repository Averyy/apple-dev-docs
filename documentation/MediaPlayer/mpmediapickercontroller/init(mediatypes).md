# init(mediaTypes:)

**Framework**: Media Player  
**Kind**: init  
**Role**: Initializer

Initializes a media item picker for specified media types.

**Availability**:
- iOS 3.0+
- iPadOS 3.0+
- Mac Catalyst 13.1+

## Declaration

```swift
init(mediaTypes: MPMediaType)
```

```objc
- (instancetype) initWithMediaTypes:(MPMediaType) mediaTypes;
```

#### Return Value

A new media item picker.

## Parameters

- `mediaTypes`: A set representing the media types for the media item picker. See the [`MPMediaType`](../mpmediatype.md) enumeration.
