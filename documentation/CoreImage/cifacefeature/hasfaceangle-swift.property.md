# hasFaceAngle

**Framework**: Core Image  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether information about face rotation is available.

**Availability**:

- iPadOS 5.0+
- Mac Catalyst 13.1+
- macOS 10.7+
