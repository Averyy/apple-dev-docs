# LAf

**Framework**: Core Image  
**Kind**: property  
**Role**: Type Property

A 64-bit-per-pixel, full-width floating-point pixel format with 32-bit luminance and alpha components.

**Availability**:
- iOS 10.0+
- iPadOS 10.0+
- Mac Catalyst 13.1+
- macOS 10.12+
- tvOS 10.0+
- visionOS 1.0+
