# intensity

**Framework**: Core Image  
**Kind**: property  
**Role**: Instance Property  
**Required**: Yes

The intensity of the effect.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS

## Declaration

```swift
var intensity: Float { get set }
```

```objc
@property (nonatomic) float intensity;
```

#### Discussion

A value of 0.0 is no effect. A value of 1.0 is the maximum effect.
