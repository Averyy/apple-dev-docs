# intensity

**Framework**: Core Image  
**Kind**: property  
**Role**: Instance Property  
**Required**: Yes

The intensity of the sepia effect.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS

## Declaration

```swift
var intensity: Float { get set }
```

```objc
@property (nonatomic) float intensity;
```

#### Discussion

A value of 1.0 creates a monochrome sepia image. A value of 0.0 has no effect on the image.
