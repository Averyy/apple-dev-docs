# scale

**Framework**: Core Image  
**Kind**: property  
**Role**: Instance Property  
**Required**: Yes

A value that determines whether the ripple starts as a bulge (a higher value) or a dimple (a lower value).

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
