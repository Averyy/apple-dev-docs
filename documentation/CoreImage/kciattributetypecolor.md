# kCIAttributeTypeColor

**Framework**: Core Image  
**Kind**: var  
**Role**: Global Variable

A Core Image color ([`CIColor`](./cicolor.md) object) that specifies red, green, and blue component values.

**Availability**:

- iPadOS 5.0+
- Mac Catalyst 13.1+
- macOS 10.11+
- tvOS
