# roundedMarkers

**Framework**: Core Image  
**Kind**: property  
**Role**: Instance Property  
**Required**: Yes

If 1, then the Finder Patterns in the QRCode should have a rounded appearance. If 2, then the Alignment Patterns will also be rounded

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
