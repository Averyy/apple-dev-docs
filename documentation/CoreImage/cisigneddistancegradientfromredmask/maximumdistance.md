# maximumDistance

**Framework**: Core Image  
**Kind**: property  
**Role**: Instance Property  
**Required**: Yes

Determines the maximum distance to the mask that can be measured. Distances between zero and the maximum will be normalized to negative one and one.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
