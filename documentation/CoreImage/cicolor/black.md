# black

**Framework**: Core Image  
**Kind**: property  
**Role**: Type Property

Returns a singleton Core Image color instance in the sRGB color space with RGB values `0,0,0` and alpha value `1`.

**Availability**:
- iOS 10.0+
- iPadOS 10.0+
- Mac Catalyst 13.1+
- macOS 10.12+
- tvOS 10.0+
- visionOS 1.0+

## Declaration

```swift
class var black: CIColor { get }
```

```objc
@property (class, strong, readonly) CIColor * blackColor;
```
