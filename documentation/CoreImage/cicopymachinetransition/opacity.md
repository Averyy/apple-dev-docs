# opacity

**Framework**: Core Image  
**Kind**: property  
**Role**: Instance Property  
**Required**: Yes

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS

## Declaration

```swift
var opacity: Float { get set }
```


## Discussion

A value of 0.0 is transparent. A value of 1.0 is opaque.
