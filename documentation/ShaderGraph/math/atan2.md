# Atan2

**Framework**: ShaderGraph  
**Kind**: subscript  
**Role**: ShaderGraph Node

The arctangent of the expression (iny/inx) in radians.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 26.0+
- visionOS 1.0+
