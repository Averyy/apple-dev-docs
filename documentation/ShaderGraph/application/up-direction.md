# Up Direction

**Framework**: ShaderGraph  
**Kind**: subscript  
**Role**: ShaderGraph Node

The direction of the up vector.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 26.0+
- visionOS 1.0+

## Parameter Types

| Input | Type |
| --- | --- |
| `Space` | String |

| Output | Type |
| --- | --- |
| `Out` | Vector3f |

## Parameter description

- **`Space`**: The space for which the node returns the up vector; the default is `world`.
