# isEqualToHandle:

**Framework**: CallKit  
**Kind**: method  
**Role**: Instance Method

Returns a Boolean value that indicates whether a given handle is equal to the receiver.

**Availability**:
- iOS 10.0+
- iPadOS 10.0+
- Mac Catalyst 13.0+
- visionOS 1.0+
- watchOS 9.0+

## Declaration

```objc
- (BOOL) isEqualToHandle:(CXHandle *) handle;
```

#### Return Value

[`true`](../../Swift/true.md) if `handle` is equal to the receiver, otherwise [`false`](../../Swift/false.md).

## Parameters

- `handle`: The handle with which to compare the receiver.
