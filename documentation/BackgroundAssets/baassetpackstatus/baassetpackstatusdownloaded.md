# BAAssetPackStatusDownloaded

**Framework**: Background Assets  
**Kind**: case  
**Role**: Enumeration Case

A status value that indicates that the system finished downloading the asset pack.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- tvOS 26.0+
- visionOS 26.0+
