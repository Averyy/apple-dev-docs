# userInfo

**Framework**: Background Assets  
**Kind**: property  
**Role**: Instance Property

**Availability**:

- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+

- visionOS 26.0+

## Declaration

```objc
@property (copy, readonly, nullable) NSData * userInfo;
```

## Discussion

This property is `nil` for Apple-hosted asset packs.
