# userInfo

**Framework**: Background Assets  
**Kind**: property  
**Role**: Instance Property

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+

- tvOS 26.0+
- visionOS 26.0+

## Declaration


#### Discussion

This property is `nil` for Apple-hosted asset packs.
