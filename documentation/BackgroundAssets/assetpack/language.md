# language

**Framework**: Background Assets  
**Kind**: property

The language for which this asset pack is localized.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
let language: Locale.Language?
```

#### Discussion

This property is `nil` if the asset pack isn’t localized and therefore isn’t language-specific.
