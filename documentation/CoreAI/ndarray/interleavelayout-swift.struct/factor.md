# factor

**Framework**: Core AI  
**Kind**: property

The number of elements from the interleaved dimension stored contiguously per block. Adjacent elements within a block have stride 1 in memory.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
