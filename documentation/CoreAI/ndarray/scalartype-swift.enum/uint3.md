# NDArray.ScalarType.uint3

**Framework**: Core AI  
**Kind**: case

A 3-bit unsigned integer.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- watchOS 27.0+ (Beta)

## Declaration

```swift
case uint3
```

#### Discussion

Three-bit unsigned integers can represent values in the range [0, 7]. This type is used for quantization and in lookup tables.
