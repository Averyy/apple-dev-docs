# NDArray.ScalarType.uint6

**Framework**: Core AI  
**Kind**: case  
**Role**: Case

A 6-bit unsigned integer.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- tvOS 27.0+
- visionOS 27.0+
- watchOS 27.0+

## Declaration

```swift
case uint6
```

## Discussion

Six-bit unsigned integers can represent values in the range [0, 63]. This type is used for quantization and in lookup tables.
