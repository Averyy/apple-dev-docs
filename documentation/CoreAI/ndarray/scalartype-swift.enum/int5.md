# NDArray.ScalarType.int5

**Framework**: Core AI  
**Kind**: case  
**Role**: Case

A 5-bit signed integer.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- tvOS 27.0+
- visionOS 27.0+
- watchOS 27.0+

## Declaration

```swift
case int5
```

## Discussion

Five-bit signed integers can represent values in the range [-16, 15]. This type is used for quantization.
