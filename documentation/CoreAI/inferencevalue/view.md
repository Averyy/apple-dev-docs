# InferenceValue.View

**Framework**: Core AI  
**Kind**: struct

A borrowed, read-only view of an inference value.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- watchOS 27.0+ (Beta)

## Declaration

```swift
struct View
```

#### Overview

Use views to pass input values to [`InferenceFunction.Inputs`](inferencefunction/inputs.md) without transferring ownership.
