# HomeAccessoryRangeSetting.SliderStyle.stepped

**Framework**: HomeExtensions  
**Kind**: case  
**Role**: Case

A slider that moves in discrete steps and displays tick marks.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+

## Declaration

```swift
case stepped
```

#### Discussion

The step size is the setting’s `step` value, or 1 if you don’t provide one. Without a `step` value, the slider doesn’t display tick labels.
