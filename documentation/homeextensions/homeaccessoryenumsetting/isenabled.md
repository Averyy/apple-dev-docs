# isEnabled

**Framework**: HomeExtensions  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether people can change the setting.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+

## Declaration

```swift
final var isEnabled: Bool
```

## Discussion

When this value is `false`, the Home app dims the setting.
