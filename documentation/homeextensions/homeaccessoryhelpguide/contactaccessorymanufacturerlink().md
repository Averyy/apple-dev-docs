# contactAccessoryManufacturerLink()

**Framework**: HomeExtensions  
**Kind**: method  
**Role**: Instance Method

Adds a button for contacting the accessory’s manufacturer.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+

## Declaration

```swift
@MainActor
func contactAccessoryManufacturerLink() -> HomeAccessoryHelpGuide
```

## Return Value

A help guide that displays the contact button.

## Discussion

The button appears at the bottom of the guide when contact options are available.
