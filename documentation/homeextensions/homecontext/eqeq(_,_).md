# ==(_:_:)

**Framework**: HomeExtensions  
**Kind**: op  
**Role**: Operator

Returns a Boolean value that indicates whether two contexts are equal.

**Availability**:
- iOS 27.2+
- iPadOS 27.2+
- Mac Catalyst 27.2+

## Declaration

```swift
@MainActor
static func == (lhs: HomeContext, rhs: HomeContext) -> Bool
```

## Parameters

- `lhs`: A context to compare.
- `rhs`: Another context to compare.
