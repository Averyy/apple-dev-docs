# accessoryErrorDetails

**Framework**: HomeExtensions  
**Kind**: property  
**Role**: Type Property

The key for additional details about the accessory’s top error.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+

## Declaration

```swift
static let accessoryErrorDetails: String
```

#### Discussion

This key is present only when details are available for the error in [`accessoryErrorCode`](./accessoryerrorcode.md).
