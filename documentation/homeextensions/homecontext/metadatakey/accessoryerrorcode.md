# accessoryErrorCode

**Framework**: HomeExtensions  
**Kind**: property  
**Role**: Type Property

The key for the code of the accessory’s top error.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+

## Declaration

```swift
static let accessoryErrorCode: String
```

## Discussion

This key is present only in troubleshooting content, and only when there’s an error to report.
