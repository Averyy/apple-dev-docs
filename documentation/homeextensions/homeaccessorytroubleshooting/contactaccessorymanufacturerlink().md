# contactAccessoryManufacturerLink()

**Framework**: HomeExtensions  
**Kind**: method  
**Role**: Instance Method

Adds a manufacturer contact button to the troubleshooting view.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+

## Declaration

```swift
@MainActor
func contactAccessoryManufacturerLink() -> HomeAccessoryTroubleshooting
```

#### Return Value

Troubleshooting content that displays the contact button.

#### Discussion

The button appears at the bottom of the view when contact options are available.
