# OS_UNFAIR_LOCK_FLAG_NONE

**Framework**: os  
**Kind**: case  
**Role**: Enumeration Case

An empty flag set that tells the lock function to apply no optional behaviors.

- iPadOS 18.0+

- macOS 15.0+
