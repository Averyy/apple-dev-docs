# os_activity_create

**Framework**: os  
**Kind**: macro  
**Role**: Macro

Creates a new activity object.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```c
#define os_activity_create(description, parent_activity, flags)
```

## Mentions

- [Collecting Log Messages in Activities](./collecting-log-messages-in-activities.md)

#### Return Value

An [`os_activity_t`](./os_activity_t.md) object for the new activity.

#### Discussion

To execute the new activity, call the [`os_activity_apply`](./os_activity_apply.md) function.

## Parameters

- `description`: A C string that describes the activity. The description must be a constant string within the calling executable or library.
- `parent_activity`: The [`os_activity_t`](./os_activity_t.md) object that represents the parent activity. Alternatively, pass in [`OS_ACTIVITY_NONE`](./os_activity_none.md) or [`OS_ACTIVITY_CURRENT`](./os_activity_current.md).
- `flags`: The flags to use when creating the new activity. Some flags override the parent_activity parameter; see [`os_activity_flag_t`](./os_activity_flag_t.md).
