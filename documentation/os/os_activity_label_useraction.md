# os_activity_label_useraction

**Framework**: os  
**Kind**: macro  
**Role**: Macro

Label an activity that is auto-generated by AppKit or UIKit.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```c
#define os_activity_label_useraction(label)
```

#### Discussion

When AppKit or UIKit executes a user-initiated action, each framework automatically creates an activity to capture the logs for that action, before calling through to the `IBAction` method. Call this method to associate a higher-level semantic action with the underlying AppKit or UIKit action. For example, when the user selects a menu item, you might associate the expected action for that menu item, as shown in the examples below:

```objc
os_activity_label_useraction("New mail message");
os_activity_label_useraction("Empty trash");
```

You must call this function within the scope of the `IBAction` method called by AppKit or UIKit. Call this function early within the scope of the action, and before creating any subactivities.

## Parameters

- `label`: A C string that describes the intent of the user’s action. The description must be a constant string within the calling executable or library.
