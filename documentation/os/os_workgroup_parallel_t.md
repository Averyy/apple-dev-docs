# os_workgroup_parallel_t

**Framework**: os  
**Kind**: typealias  
**Role**: Type Alias

A workgroup object that supports the scheduling of threads that work in parallel to complete a task.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS
