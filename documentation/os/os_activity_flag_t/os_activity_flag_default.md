# OS_ACTIVITY_FLAG_DEFAULT

**Framework**: os  
**Kind**: case  
**Role**: Enumeration Case

Creates a new activity and associates it as a child of any provided parent activity.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```c
OS_ACTIVITY_FLAG_DEFAULT
```
