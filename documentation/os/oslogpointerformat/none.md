# OSLogPointerFormat.none

**Framework**: os  
**Kind**: case  
**Role**: Case

An option to treat the pointer as raw bytes, and not format it.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS
- watchOS 7.0+

## Declaration

```swift
case none
```
