# os_activity_flag_t

**Framework**: os  
**Kind**: enum  
**Role**: Enumeration

Flags that adjust the behavior when you create an activity.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```c
typedef enum { ... } os_activity_flag_t;
```

## Topics

### Adjusting Activity Creation
- [OS_ACTIVITY_FLAG_DEFAULT](./os_activity_flag_t/os_activity_flag_default.md)
  Creates a new activity and associates it as a child of any provided parent activity.
- [OS_ACTIVITY_FLAG_DETACHED](./os_activity_flag_t/os_activity_flag_detached.md)
  Creates a new activity that is independent of any provided parent activity.
- [OS_ACTIVITY_FLAG_IF_NONE_PRESENT](./os_activity_flag_t/os_activity_flag_if_none_present.md)
  Creates a new activity only if one is not already present.
