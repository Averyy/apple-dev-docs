# !=(_:_:)

**Framework**: Playground Bluetooth  
**Kind**: opfunc  
**Role**: Operator

Compares two firmware statuses and returns [`true`](../../../../Swift/true.md) when they're different.

**Availability**:
- Xcode 10.2+
- Swift Playgrounds 2.0+

## Declaration

```swift
static func != (lhs: PlaygroundBluetoothConnectionView.Item.FirmwareStatus, rhs: PlaygroundBluetoothConnectionView.Item.FirmwareStatus) -> Bool
```
