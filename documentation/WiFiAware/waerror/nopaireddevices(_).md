# WAError.noPairedDevices(_:)

**Framework**: Wi-Fi Aware  
**Kind**: case  
**Role**: Case

An error that occurs if your app doesn’t have access to any paired devices.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+

case noPairedDevices(WAError.NoPairedDevicesDetails)
