# WAError.wifiAwareUnsupported(_:)

**Framework**: Wi-Fi Aware  
**Kind**: case  
**Role**: Case

An error that occurs if Wi-Fi Aware isn’t supported on the device.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+

## Declaration

```swift
case wifiAwareUnsupported(WAError.WiFiAwareUnsupportedDetails)
```
