# GetDeviceIsRunning

**Framework**: VideoDriverKit  
**Kind**: method  
**Role**: Instance Method

Gets bool value indicating if device is running.

**Availability**:
- DriverKit 27.0+

## Declaration

```c
bool GetDeviceIsRunning();
```

## Discussion

The object’s work queue synchronizes access to the value.
