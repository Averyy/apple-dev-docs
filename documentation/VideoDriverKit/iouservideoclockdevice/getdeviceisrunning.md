# GetDeviceIsRunning

**Framework**: VideoDriverKit  
**Kind**: method

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
bool GetDeviceIsRunning();
```

#### Return Value

Returns bool

#### Discussion

Get bool value indicating if device is running.

Getting the value will be synchronized using the work queue created by the object.
