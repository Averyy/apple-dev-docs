# GetSampleRate

**Framework**: VideoDriverKit  
**Kind**: method

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
double GetSampleRate();
```

#### Return Value

Returns double

#### Discussion

Get sample rate of the clock device.

Getting the value will be synchronized using the work queue created by the object.
