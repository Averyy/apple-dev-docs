# IOUserVideoCustomPropertyInfo

**Framework**: VideoDriverKit  
**Kind**: struct

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
struct IOUserVideoCustomPropertyInfo;
```

#### Overview

The IOUserVideoCustomPropertyInfo struct is used to describe enough about a custom property to allow the Host to marshal the data between the Host and its clients.

The IOUserVideoObjectPropertySelector of the custom property

A IOUserVideoCustomPropertyDataType whose value indicates the data type of the data of the custom property.

A IOUserVideoCustomPropertyDataType whose value indicates the data type of the qualifier data of the custom property.
