# AppleLosslessFormatFlag_20BitSourceData

**Framework**: VideoDriverKit  
**Kind**: case

This flag is set for Apple Lossless data that was sourced from 20 bit native endian signed integer data aligned high in 24 bits.

**Availability**:
- DriverKit 27.0+
