# Stopped

**Framework**: VideoDriverKit  
**Kind**: case

Device transport state is stopped.

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
Stopped
```

#### Discussion

In this state, disable the hardware necessary for I/O.
