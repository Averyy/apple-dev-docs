# IOUserVideoObjectPropertyAddress

**Framework**: VideoDriverKit  
**Kind**: struct

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
struct IOUserVideoObjectPropertyAddress;
```

#### Overview

An IOUserVideoObjectPropertyAddress collects the three parts that identify a specific property together in a struct for easy transmission.

The IOUserVideoObjectPropertySelector for the property.

The IOUserVideoObjectPropertyScope for the property.

The IOUserVideoObjectPropertyElement for the property.
