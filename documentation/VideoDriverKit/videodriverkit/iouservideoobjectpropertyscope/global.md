# Global

**Framework**: VideoDriverKit  
**Kind**: case

The scope for properties that apply to the object as a whole.

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
Global
```

#### Discussion

All objects have a global scope, and for most objects, it is their only scope.
