# IOUserVideoFormatID

**Framework**: VideoDriverKit  
**Kind**: enum

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
enum IOUserVideoFormatID : uint32_t;
```

#### Overview

The IOUserVideoFormatIDs used to identify individual formats of audio data.

Linear PCM, uses the standard flags.

AC-3, has no flags.

AC-3 packaged for transport over an IEC 60958 compliant digital audio interface. Uses the standard flags.

Apples implementation of IMA 4:1 ADPCM, has no flags.

MPEG-4 Low Complexity AAC audio object, has no flags.

MPEG-4 CELP audio object, has no flags

MPEG-4 HVXC audio object, has no flags.

MPEG-4 TwinVQ audio object type, has no flags.

MACE 3:1, has no flags.

MACE 6:1, has no flags.

µLaw 2:1, has no flags.

aLaw 2:1, has no flags.

QDesign music, has no flags

QDesign2 music, has no flags

QUALCOMM PureVoice, has no flags

MPEG-1/2, Layer 1 audio, has no flags

MPEG-1/2, Layer 2 audio, has no flags

MPEG-1/2, Layer 3 audio, has no flags

A stream of IOVideoTimeStamps, uses the IOVideoTimeStamp flags.

A stream of MIDIPacketLists where the time stamps in the MIDIPacketList are sample offsets in the stream. The mSampleRate field is used to describe how time is passed in this kind of stream and an VideoUnit that receives or generates this stream can use this sample rate, the number of frames it is rendering and the sample offsets within the MIDIPacketList to define the time for any MIDI event within this list. It has no flags.

A “side-chain” of Float32 data that can be fed or generated by an VideoUnit and is used to send a high density of parameter value control information. An AU will typically run a ParameterValueStream at either the sample rate of the VideoUnit’s audio data, or some integer divisor of this (say a half or a third of the sample rate of the audio). The Sample Rate of the ASBD describes this relationship. It has no flags.

Apple Lossless, the flags indicate the bit depth of the source material.

MPEG-4 High Efficiency AAC audio object, has no flags.

MPEG-4 AAC Low Delay audio object, has no flags.

MPEG-4 AAC Enhanced Low Delay audio object, has no flags. This is the formatID of the base layer without the SBR extension. See also FormatMPEG4AAC_ELD_SBR

MPEG-4 AAC Enhanced Low Delay audio object with SBR extension layer, has no flags.

MPEG-4 High Efficiency AAC Version 2 audio object, has no flags.

MPEG-4 Spatial Video audio object, has no flags.

MPEG-D Unified Speech and Video Coding, has no flags.

The AMR Narrow Band speech codec.

The AMR Wide Band speech codec.

The format used for Audible audio books. It has no flags.

The iLBC narrow band speech codec. It has no flags.

DVI/Intel IMA ADPCM - ACM code 17.

Microsoft GSM 6.10 - ACM code 49.

This format is defined by AES3-2003, and adopted into MXF and MPEG-2 containers and SDTI transport streams with SMPTE specs 302M-2002 and 331M-2000. It has no flags.

Enhanced AC-3, has no flags.

Free Lossless Video Codec, the flags indicate the bit depth of the source material.

Opus codec, has no flags.
