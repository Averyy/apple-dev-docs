# FormatFlagsAreAllClear

**Framework**: VideoDriverKit  
**Kind**: case  
**Role**: Enumeration Case

Set if all the flags would be clear.

**Availability**:
- DriverKit 27.0+

## Declaration

```c
FormatFlagsAreAllClear
```

#### Discussion

This flag preserves `0` as the wildcard value.
