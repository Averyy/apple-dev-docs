# FormatFlagIsSignedInteger

**Framework**: VideoDriverKit  
**Kind**: case  
**Role**: Enumeration Case

Set for signed integer, clear for unsigned integer.

**Availability**:
- DriverKit 27.0+

## Declaration

```c
FormatFlagIsSignedInteger
```

#### Discussion

This flag is only valid if `FormatFlagIsFloat` is clear.
