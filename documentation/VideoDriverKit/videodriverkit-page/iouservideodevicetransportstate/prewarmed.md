# Prewarmed

**Framework**: VideoDriverKit  
**Kind**: case  
**Role**: Enumeration Case

Device transport state is prewarmed.

**Availability**:
- DriverKit 27.0+

## Declaration

```c
Prewarmed
```

#### Discussion

In this state, enable the minimal hardware for I/O, to minimize transition to normal I/O operation.
