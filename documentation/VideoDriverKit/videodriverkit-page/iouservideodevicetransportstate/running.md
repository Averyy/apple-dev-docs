# Running

**Framework**: VideoDriverKit  
**Kind**: case  
**Role**: Enumeration Case

Device transport state is running.

**Availability**:
- DriverKit 27.0+

## Declaration

```c
Running
```

## Discussion

In this state, enable the hardware to fully run I/O.
