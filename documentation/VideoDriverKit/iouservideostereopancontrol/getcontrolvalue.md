# GetControlValue

**Framework**: VideoDriverKit  
**Kind**: method  
**Role**: Instance Method

Gets the current value of the control.

**Availability**:
- DriverKit 27.0+

## Declaration

```c
float GetControlValue();
```

## Discussion

The object’s work queue synchronizes access to the value.
