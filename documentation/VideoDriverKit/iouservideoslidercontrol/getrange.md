# GetRange

**Framework**: VideoDriverKit  
**Kind**: method  
**Role**: Instance Method

Gets the current range of the slider control.

**Availability**:
- DriverKit 27.0+

## Declaration

```c
IOUserVideoSliderRange GetRange();
```

## Discussion

The object’s work queue synchronizes access to the value.
