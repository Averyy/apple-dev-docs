# GetControlValue

**Framework**: VideoDriverKit  
**Kind**: method

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
bool GetControlValue();
```

#### Return Value

Returns bool

#### Discussion

Get the current value of the control.

Getting the value will be synchronized using the work queue created by the object.
