# GetControlValue

**Framework**: VideoDriverKit  
**Kind**: method

Gets the current value of the control.

**Availability**:
- DriverKit 27.0+

## Declaration

```swift
bool GetControlValue();
```

#### Return Value

A Boolean value that represents the control’s current value.

#### Discussion

The object’s work queue synchronizes access to this value.
