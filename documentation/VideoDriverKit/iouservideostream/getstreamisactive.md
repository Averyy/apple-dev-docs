# GetStreamIsActive

**Framework**: VideoDriverKit  
**Kind**: method

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
bool GetStreamIsActive();
```

#### Return Value

Returns bool.

#### Discussion

Get the stream activity state, where a true indicates that the stream is enabled and doing IO.
