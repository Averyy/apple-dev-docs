# GetIsSettable

**Framework**: VideoDriverKit  
**Kind**: method

Returns a Boolean value indicating if the control value can be set.

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
bool GetIsSettable();
```

#### Return Value

True if the control value can be set.
