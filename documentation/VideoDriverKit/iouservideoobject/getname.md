# GetName

**Framework**: VideoDriverKit  
**Kind**: method  
**Role**: Instance Method

Gets the name of the video object.

**Availability**:
- DriverKit 27.0+

## Declaration

```c
OSSharedPtr<OSString> GetName();
```

## Return Value

The video object’s name.

## Discussion

The object’s work queue synchronizes access to the value.
