**Kind**: method

## Declaration

```swift
IOUserVideoObjectID GetObjectID();
```

Returns IOUserVideoObjectID

#### Discussion

Get the IOUserVideoObjectID of the object, which can be used for object lookup with IOUserVideoDriver
