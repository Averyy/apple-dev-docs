# GetObjectID

**Framework**: VideoDriverKit  
**Kind**: method

Gets the video object identifier of the object.

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
IOUserVideoObjectID GetObjectID();
```

#### Discussion

This identifier can be used for object lookup with IOUserVideoDriver.
