# GetDecibelValue

**Framework**: VideoDriverKit  
**Kind**: method

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
float GetDecibelValue();
```

#### Return Value

Returns float.

#### Discussion

Get the decibel level value for the control.

Getting the control value will be synchronized using the work queue created by the object.
