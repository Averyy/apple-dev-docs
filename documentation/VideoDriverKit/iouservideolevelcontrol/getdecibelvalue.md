# GetDecibelValue

**Framework**: VideoDriverKit  
**Kind**: method  
**Role**: Instance Method

Gets the decibel level value for the control.

**Availability**:
- DriverKit 27.0+

## Declaration

```c
float GetDecibelValue();
```

## Discussion

The object’s work queue synchronizes access to the control value.
