# GetTransportType

**Framework**: VideoDriverKit  
**Kind**: method  
**Role**: Instance Method

Gets the transport type of the video box.

**Availability**:
- DriverKit 27.0+

## Declaration

```c
IOUserVideoTransportType GetTransportType();
```

#### Discussion

The object’s work queue synchronizes access to the value.
