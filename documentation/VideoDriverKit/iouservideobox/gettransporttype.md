# GetTransportType

**Framework**: VideoDriverKit  
**Kind**: method

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
IOUserVideoTransportType GetTransportType();
```

#### Return Value

Returns IOUserVideoTransportType

#### Discussion

Get the transport type of the IOUserVideoBox. Getting the value will be synchronized using the work queue created by the object.
