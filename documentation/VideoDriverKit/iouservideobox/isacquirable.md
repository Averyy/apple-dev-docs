# IsAcquirable

**Framework**: VideoDriverKit  
**Kind**: method

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
bool IsAcquirable();
```

#### Return Value

Returns bool

#### Discussion

Bool value indiciating if box can be acquired. Getting the value will be synchronized using the work queue created by the object.
