# HasVideo

**Framework**: VideoDriverKit  
**Kind**: method  
**Role**: Instance Method

A Boolean value indicating if box has video capabilities.

**Availability**:
- DriverKit 27.0+

## Declaration

```c
bool HasVideo();
```

#### Discussion

The object’s work queue synchronizes access to the value.
