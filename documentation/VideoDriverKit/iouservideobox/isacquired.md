# IsAcquired

**Framework**: VideoDriverKit  
**Kind**: method

**Availability**:
- DriverKit 27.0+ (Beta)

## Declaration

```swift
bool IsAcquired();
```

#### Return Value

Returns bool.

#### Discussion

Bool value indiciating if box is acquired. Getting the value will be synchronized using the work queue created by the object.
