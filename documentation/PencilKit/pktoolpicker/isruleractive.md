# isRulerActive

**Framework**: PencilKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the ruler is visible on the canvas.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- visionOS 1.0+
