# init(_:)

**Framework**: PencilKit  
**Kind**: init

Creates a `PKStrokeRenderStateReference` from its Swift counterpart `PKStroke.RenderState`.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- visionOS 27.0+

## Declaration

```swift
convenience init(_ swiftValue: PKStroke.RenderState)
```

## Parameters

- `swiftValue`: The Swift `PKStroke.RenderState` to convert from.
