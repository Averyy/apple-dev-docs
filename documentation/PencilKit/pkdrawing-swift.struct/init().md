# init()

**Framework**: PencilKit  
**Kind**: init  
**Role**: Initializer

Creates an empty drawing object.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- macOS 10.15+
- visionOS 1.0+

## Declaration

```swift
init()
```

## Discussion

This initializer creates a new canvas object that doesn’t contain any data.
