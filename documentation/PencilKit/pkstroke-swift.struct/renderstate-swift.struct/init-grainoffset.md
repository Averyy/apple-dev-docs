# init(grainOffset:)

**Framework**: PencilKit  
**Kind**: init

Creates a render state with the specified grain offset.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init(grainOffset: CGPoint? = nil)
```

## Parameters

- `grainOffset`: The grain texture offset. Defaults to nil.
