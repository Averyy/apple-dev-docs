# lateralJitter

**Framework**: PencilKit  
**Kind**: property

The amount of lateral particle jitter at the stroke edge for supported inks.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- visionOS 27.0+

## Declaration

```swift
var lateralJitter: CGFloat { get }
```

#### Discussion

Lateral jitter applies only to some inks, such as `PKInkIdentifierPencil`.
