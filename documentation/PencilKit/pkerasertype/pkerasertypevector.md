# PKEraserTypeVector

**Framework**: PencilKit  
**Kind**: case  
**Role**: Enumeration Case

An eraser that removes an entire drawn line.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- macOS 10.15+
- visionOS 1.0+

## Declaration

```c
PKEraserTypeVector
```

## Discussion

When a vector eraser touches any portion of a drawn line, it removes the entire line.
