# PKToolPickerVisibilityInherited

**Framework**: PencilKit  
**Kind**: case  
**Role**: Enumeration Case

Inherit the tool picker visibility from the next responder.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- visionOS 1.0+
