# allowsColorSelection

**Framework**: PencilKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that determines whether to show the color selection UI for the tool.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- visionOS 2.0+

## Declaration

```objc
@property (nonatomic, assign) BOOL allowsColorSelection;
```
