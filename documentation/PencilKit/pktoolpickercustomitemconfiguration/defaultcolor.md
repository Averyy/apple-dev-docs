# defaultColor

**Framework**: PencilKit  
**Kind**: property  
**Role**: Instance Property

The default color for the tool.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- visionOS 2.0+

## Declaration

```objc
@property (nonatomic, strong) UIColor * defaultColor;
```

## Discussion

The default color is black.
