# defaultWidth

**Framework**: PencilKit  
**Kind**: property  
**Role**: Instance Property

The default width for the tool.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- visionOS 2.0+

## Declaration

```objc
@property (nonatomic, assign) CGFloat defaultWidth;
```

#### Discussion

The default width is `0`.
