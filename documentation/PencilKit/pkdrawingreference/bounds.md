# bounds

**Framework**: PencilKit  
**Kind**: property  
**Role**: Instance Property

The smallest rectangle used to represent the content’s bounds, taking into account line widths of that content.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- macOS 10.15+
- visionOS 1.0+
