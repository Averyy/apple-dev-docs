# init()

**Framework**: PencilKit  
**Kind**: init  
**Role**: Initializer

Creates an empty drawing object.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- macOS 10.15+
- visionOS 1.0+

## Declaration

```swift
init()
```

```objc
- (instancetype) init;
```

## Return Value

A new canvas object that doesn’t contain any data.
