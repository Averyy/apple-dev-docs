# placeholder

**Framework**: Social  
**Kind**: property  
**Role**: Instance Property

A string that’s displayed in the compose view’s text view when the text view is empty.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.10+
