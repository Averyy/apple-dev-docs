# init(_:)

**Framework**: PhotosUI  
**Kind**: init  
**Role**: Initializer

Creates a custom aspect ratio.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- macOS 27.3+ (Beta)
- visionOS 27.3+ (Beta)

## Declaration

```swift
init(_ aspectRatio: CGFloat)
```

## Parameters

- `aspectRatio`: The ratio of an item’s width to its height. Must be greater than 0.
