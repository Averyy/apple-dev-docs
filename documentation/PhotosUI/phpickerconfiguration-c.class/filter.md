# filter

**Framework**: PhotosUI  
**Kind**: property  
**Role**: Instance Property

The filter you apply to restrict the asset types the picker displays.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 13.0+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic, copy, nullable) PHPickerFilter * filter;
```

## Discussion

By default, a configuration object displays all asset types: images, Live Photos, and videos.
