# minimumSelectionLimit

**Framework**: PhotosUI  
**Kind**: property  
**Role**: Instance Property

The minimum number of items that should be selected. Default is \c NSNotFound.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- macOS 27.3+ (Beta)
- visionOS 27.3+ (Beta)

## Declaration

```objc
@property (nonatomic) NSInteger minimumSelectionLimit;
```

## Discussion

Setting \c minimumSelectionLimit to \c NSNotFound means 1 without preselection and 0 with preselection.
