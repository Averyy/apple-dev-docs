# PHPickerConfiguration.Selection.continuous

**Framework**: PhotosUI  
**Kind**: case  
**Role**: Case

An option that provides the app a person’s selection immediately.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- visionOS

## Declaration

```swift
case continuous
```

## Discussion

This option notifies the app of photo selections dynamically, as someone taps the photo picker.
