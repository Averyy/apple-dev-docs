# init(photoLibrary:)

**Framework**: PhotosUI  
**Kind**: init  
**Role**: Initializer

Creates a new configuration object for a photo library.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 13.0+
- visionOS

## Declaration

```swift
init(photoLibrary: PHPhotoLibrary)
```

## Parameters

- `photoLibrary`: The library from which to pick photos and videos.
