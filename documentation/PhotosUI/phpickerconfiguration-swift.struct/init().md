# init()

**Framework**: PhotosUI  
**Kind**: init  
**Role**: Initializer

Creates a new configuration object.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 13.0+
- visionOS

## Declaration

```swift
init()
```

#### Discussion

This configuration doesn’t return asset identifiers. To create configuration object with the system photo library use [`init(photoLibrary:)`](./init%28photolibrary%29.md).
