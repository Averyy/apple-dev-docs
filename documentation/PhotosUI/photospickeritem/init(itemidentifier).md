# init(itemIdentifier:)

**Framework**: PhotosUI  
**Kind**: init  
**Role**: Initializer

Creates a picker item with the identifier you specify, and without any representation.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
- visionOS

## Declaration

```swift
init(itemIdentifier: String)
```

## Parameters

- `itemIdentifier`: The local identifier of the item.
