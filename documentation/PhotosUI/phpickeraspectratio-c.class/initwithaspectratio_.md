# initWithAspectRatio:

**Framework**: PhotosUI  
**Kind**: method  
**Role**: Instance Method

Creates a custom aspect ratio (width / height).

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- macOS 27.3+ (Beta)
- visionOS 27.3+ (Beta)

## Declaration

```objc
- (instancetype) initWithAspectRatio:(CGFloat) aspectRatio;
```

## Parameters

- `aspectRatio`: The ratio of an item’s width to its height. Must be greater than 0.
