# PHPickerSecondaryButtonType

**Framework**: PhotosUI  
**Kind**: enum  
**Role**: Enumeration

An enum that determines the secondary button type for the picker.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- macOS 27.3+ (Beta)
- visionOS 27.3+ (Beta)

## Topics

### Enumeration Cases
- [PHPickerSecondaryButtonType.automatic](./phpickersecondarybuttontype/automatic.md)
  The system chooses the secondary button based on context.
- [PHPickerSecondaryButtonType.back](./phpickersecondarybuttontype/back.md)
  A “Back” button.
- [PHPickerSecondaryButtonType.cancel](./phpickersecondarybuttontype/cancel.md)
  A “Cancel” button.
- [PHPickerSecondaryButtonType.clear](./phpickersecondarybuttontype/clear.md)
  A “Clear” button that clears the current selection.
- [PHPickerSecondaryButtonType.close](./phpickersecondarybuttontype/close.md)
  A “Close” button.
- [PHPickerSecondaryButtonType.hidden](./phpickersecondarybuttontype/hidden.md)
  No secondary button is shown.
