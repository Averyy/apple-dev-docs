# init(configuration:)

**Framework**: PhotosUI  
**Kind**: init  
**Role**: Initializer

Returns a view controller that allows the user to create a new shared album.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- visionOS 27.0+

## Declaration

```swift
@MainActor
@preconcurrency convenience init(configuration: PHSharedAlbumCreationConfiguration)
```

## Parameters

- `configuration`: The configuration for creating a new shared album.
