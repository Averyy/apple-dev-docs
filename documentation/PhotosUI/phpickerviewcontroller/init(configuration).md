# init(configuration:)

**Framework**: PhotosUI  
**Kind**: init  
**Role**: Initializer

Creates a new picker view controller with the configuration you specify.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 13.0+
- visionOS

## Declaration

```swift
@MainActor
@preconcurrency convenience init(configuration: PHPickerConfiguration)
```

## Parameters

- `configuration`: The configuration with which to initialize the view controller.
