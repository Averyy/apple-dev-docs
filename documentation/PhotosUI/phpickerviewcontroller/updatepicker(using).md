# updatePicker(using:)

**Framework**: PhotosUI  
**Kind**: method  
**Role**: Instance Method

Customizes your app’s photo picker according to the given configuration.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- visionOS

## Declaration

```swift
@MainActor
@preconcurrency func updatePicker(using configuration: PHPickerConfiguration.Update)
```

## Parameters

- `configuration`: An object that customizes your app’s photo picker.
