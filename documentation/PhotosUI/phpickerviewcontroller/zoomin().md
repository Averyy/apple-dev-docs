# zoomIn()

**Framework**: PhotosUI  
**Kind**: method  
**Role**: Instance Method

Changes the picker’s content scale by making the photo thumbnails larger in the view.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- visionOS 1.0+
