# scrollToInitialPosition()

**Framework**: PhotosUI  
**Kind**: method  
**Role**: Instance Method

Resets the visible photo thumbnails by scrolling the view to the picker’s initial position.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- visionOS 1.0+
