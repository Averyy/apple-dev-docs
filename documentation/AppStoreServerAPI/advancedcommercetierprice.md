# advancedCommerceTierPrice

**Framework**: App Store Server API  
**Kind**: typealias  
**Role**: Type

The price per seat, in milliunits of the currency, for a price tier of an Advanced Commerce subscription item.

**Availability**:
- App Store Server API 1.25+

## Declaration

```
int64 advancedCommerceTierPrice
```

## Mentions

- [App Store Server API changelog](./app-store-server-api-changelog.md)

## Discussion

> ❗ **Important**:  Multiseat purchases with the Advanced Commerce API are only available in the sandbox environment.

The `price` field of [`advancedCommerceSeatPriceTier`](./advancedcommerceseatpricetier.md) uses this type.
