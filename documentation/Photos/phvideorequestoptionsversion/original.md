# PHVideoRequestOptionsVersion.original

**Framework**: Photos  
**Kind**: case  
**Role**: Case

Request a version of the video asset without adjustments.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.15+
- tvOS 10.0+
- visionOS 1.0+

## Declaration

```swift
case original
```

```c
PHVideoRequestOptionsVersionOriginal
```

## Discussion

The resulting video is the originally captured or imported version of the asset, regardless of any edits that have been made.
