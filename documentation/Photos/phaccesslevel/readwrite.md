# PHAccessLevel.readWrite

**Framework**: Photos  
**Kind**: case  
**Role**: Case

A value that indicates the app can read from and write to the user’s photo library.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.13+
- tvOS 10.0+
- visionOS 1.0+
