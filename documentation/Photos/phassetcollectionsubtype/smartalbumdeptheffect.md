# PHAssetCollectionSubtype.smartAlbumDepthEffect

**Framework**: Photos  
**Kind**: case  
**Role**: Case

A Smart Album that groups all images captured using the Depth Effect camera mode on compatible devices.

**Availability**:
- iOS 10.2+
- iPadOS 10.2+
- Mac Catalyst 13.1+
- macOS 10.13+
- tvOS 10.1+
- visionOS 1.0+
