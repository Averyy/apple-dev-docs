# videoHighFrameRate

**Framework**: Photos  
**Kind**: property  
**Role**: Type Property

The asset is a high-frame-rate video.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.11+
- tvOS 10.0+
- visionOS 1.0+

## Declaration

```swift
static var videoHighFrameRate: PHAssetMediaSubtype { get }
```

```c
PHAssetMediaSubtypeVideoHighFrameRate
```

#### Discussion

High-frame-rate videos are created by the Slow-Mo feature in the Camera app on an iOS device.
