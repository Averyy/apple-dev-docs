# PHAssetMediaSubtypeNone

**Framework**: Photos  
**Kind**: case  
**Role**: Enumeration Case

The asset has no subtype.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.11+
- tvOS 10.0+
- visionOS 1.0+

## Declaration

```c
PHAssetMediaSubtypeNone
```

#### Discussion

This is the default subtype for most photo and video assets.
