# photoDepthEffect

**Framework**: Photos  
**Kind**: property  
**Role**: Type Property

The asset is a photo captured with the Camera app’s Portrait mode depth effect.

**Availability**:
- iOS 10.2+
- iPadOS 10.2+
- Mac Catalyst 13.1+
- macOS 10.12.2+
- tvOS 10.1+
