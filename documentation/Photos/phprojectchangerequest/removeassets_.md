# removeAssets:

**Framework**: Photos  
**Kind**: method  
**Role**: Instance Method

Removes the specified assets from the project.

**Availability**:
- macOS 10.14+

## Declaration

```objc
- (void) removeAssets:(id<NSFastEnumeration>) assets;
```

## Parameters

- `assets`: A collection of [`PHAsset`](../phasset.md)s to be removed from the project.
