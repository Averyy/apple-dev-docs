# PHCollectionListSubtype.regularFolder

**Framework**: Photos  
**Kind**: case  
**Role**: Case

The collection list is a folder containing albums or other folders.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.11+
- tvOS 10.0+
- visionOS 1.0+

## Declaration

```swift
case regularFolder
```

```c
PHCollectionListSubtypeRegularFolder
```

## Discussion

This subtype applies only to collection lists whose type is [`PHCollectionListType.folder`](../phcollectionlisttype/folder.md).
