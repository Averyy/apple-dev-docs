# PHCollectionListSubtype.momentListCluster

**Framework**: Photos  
**Kind**: case  
**Role**: Case

The collection list is a moment cluster, grouping several related moments.

**Availability**:
- iOS 8.0+ - Deprecated in 13.0
- iPadOS 8.0+ - Deprecated in 13.0
- Mac Catalyst 13.1+
- tvOS 10.0+ - Deprecated in 13.0
- visionOS 1.0+ - Deprecated in 1.0

> **Deprecated**: Will be removed in a future release

## Declaration

```swift
case momentListCluster
```

```c
PHCollectionListSubtypeMomentListCluster
```

#### Discussion

This subtype applies only to collection lists whose type is [`PHCollectionListType.momentList`](../phcollectionlisttype/momentlist.md).
