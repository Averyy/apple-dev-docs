# PHCollectionListSubtype.smartFolderEvents

**Framework**: Photos  
**Kind**: case  
**Role**: Case

The collection list is a smart folder containing one or more Events synced from a Mac.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.11+
- tvOS 10.0+
- visionOS 1.0+

## Declaration

```swift
case smartFolderEvents
```

```c
PHCollectionListSubtypeSmartFolderEvents
```

#### Discussion

This subtype applies only to collection lists whose type is [`PHCollectionListType.smartFolder`](../phcollectionlisttype/smartfolder.md).
