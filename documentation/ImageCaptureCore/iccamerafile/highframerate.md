# highFramerate

**Framework**: ImageCaptureCore  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the file is a slow motion or high-frame-rate video file.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- macOS 10.4+
- visionOS 1.0+
