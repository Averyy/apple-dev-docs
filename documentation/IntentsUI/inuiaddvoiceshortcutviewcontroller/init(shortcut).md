# init(shortcut:)

**Framework**: IntentsUI  
**Kind**: init  
**Role**: Initializer

Creates a view controller with a shortcut the user can add to Siri.

**Availability**:
- iOS 12.0+
- iPadOS 12.0+
- Mac Catalyst 13.1+
- macOS 12.0+
- visionOS 1.0+

## Declaration

```swift
init(shortcut: INShortcut)
```

```objc
- (instancetype) initWithShortcut:(INShortcut *) shortcut;
```

## Return Value

A newly initialized view controller.

## Parameters

- `shortcut`: The shortcut to add to Siri.
