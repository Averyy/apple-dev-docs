# init(voiceShortcut:)

**Framework**: IntentsUI  
**Kind**: init  
**Role**: Initializer

Creates a view controller with the shortcut to edit or remove.

**Availability**:
- iOS 12.0+
- iPadOS 12.0+
- Mac Catalyst 13.1+
- macOS 12.0+
- visionOS 1.0+

## Declaration

```swift
init(voiceShortcut: INVoiceShortcut)
```

```objc
- (instancetype) initWithVoiceShortcut:(INVoiceShortcut *) voiceShortcut;
```

#### Return Value

A newly initialized view controller.

## Parameters

- `voiceShortcut`: The shortcut to edit or remove.
