# init(style:)

**Framework**: IntentsUI  
**Kind**: init  
**Role**: Initializer

Creates an *Add to Siri* button with the specified style.

**Availability**:
- iOS 12.0+
- iPadOS 12.0+
- Mac Catalyst 13.1+
- macOS 12.0+
- visionOS 1.0+

## Declaration

```swift
init(style: INUIAddVoiceShortcutButtonStyle)
```

```objc
- (instancetype) initWithStyle:(INUIAddVoiceShortcutButtonStyle) style;
```

## Return Value

A button initialized with the specified style.

## Parameters

- `style`: The style of the button.
