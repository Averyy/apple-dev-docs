# GLKVector4Distance(_:_:)

**Framework**: GLKit  
**Kind**: func  
**Role**: Function

Returns the distance between two points.

**Availability**:
- iOS 5.0+
- iPadOS 5.0+
- macOS 10.8+
- tvOS 9.0+

## Declaration

```swift
func GLKVector4Distance(_ vectorStart: GLKVector4, _ vectorEnd: GLKVector4) -> Float
```

```c
static float GLKVector4Distance(GLKVector4 vectorStart, GLKVector4 vectorEnd);
```

#### Return Value

The distance between the two points.

## Parameters

- `vectorStart`: A vector providing the coordinates of the starting point.
- `vectorEnd`: A vector providing the coordinates of the ending point.
