# GLKQuaternionLength(_:)

**Framework**: GLKit  
**Kind**: func  
**Role**: Function

Returns the length of a quaternion.

**Availability**:
- iOS 5.0+
- iPadOS 5.0+
- macOS 10.8+
- tvOS 9.0+

## Declaration

```swift

```


#### Return Value
