# NSStringFromGLKMatrix3(_:)

**Framework**: GLKit  
**Kind**: func  
**Role**: Function

Returns a string that represents the contents of a matrix.

**Availability**:
- iOS 5.0+
- iPadOS 5.0+
- macOS 10.8+
- tvOS 9.0+

## Declaration

```swift
func NSStringFromGLKMatrix3(_ matrix: GLKMatrix3) -> String
```

```c
NSString *NSStringFromGLKMatrix3(GLKMatrix3 matrix);
```

## Parameters

- `matrix`: A `3x3` matrix.
