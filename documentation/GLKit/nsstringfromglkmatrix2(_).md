# NSStringFromGLKMatrix2(_:)

**Framework**: GLKit  
**Kind**: func  
**Role**: Function

Returns a string that represents the contents of a matrix.

**Availability**:
- iOS 5.0+
- iPadOS 5.0+
- macOS 10.8+
- tvOS 9.0+

## Declaration

```swift
func NSStringFromGLKMatrix2(_ matrix: GLKMatrix2) -> String
```

```c
NSString *NSStringFromGLKMatrix2(GLKMatrix2 matrix);
```

## Parameters

- `matrix`: A `2x2` matrix.
