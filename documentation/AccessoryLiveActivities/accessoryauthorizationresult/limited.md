# AccessoryAuthorizationResult.limited

**Framework**: Accessory Live Activities  
**Kind**: case

An option that indicates the person allows Live Activities from a selected subset of apps.

**Availability**:
- iOS 26.5+
- iPadOS 26.5+
- Mac Catalyst 26.5+

## Declaration

```swift
case limited
```
