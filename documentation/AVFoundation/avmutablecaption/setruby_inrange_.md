# setRuby:inRange:

**Framework**: AVFoundation  
**Kind**: method  
**Role**: Instance Method

Sets ruby text for a range.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS

## Declaration

```objc
- (void) setRuby:(AVCaptionRuby *) ruby inRange:(NSRange) range;
```

## Parameters

- `ruby`: The ruby text.
- `range`: The range to which the ruby text applies.
