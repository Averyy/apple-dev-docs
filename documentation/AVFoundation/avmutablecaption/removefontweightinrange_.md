# removeFontWeightInRange:

**Framework**: AVFoundation  
**Kind**: method  
**Role**: Instance Method

Removes a font weight from a range of text.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS

## Declaration

```objc
- (void) removeFontWeightInRange:(NSRange) range;
```

## Parameters

- `range`: The range from which to remove the style.
