# removeRubyInRange:

**Framework**: AVFoundation  
**Kind**: method  
**Role**: Instance Method

Removes ruby text from a range.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS

## Declaration

```objc
- (void) removeRubyInRange:(NSRange) range;
```

## Parameters

- `range`: The range from which the system removes the ruby text.
