# containsZoomFactor:

**Framework**: AVFoundation  
**Kind**: method  
**Role**: Instance Method

Returns a Boolean value that indicates whether the specified zoom factor exists in the range.

**Availability**:
- iOS 17.2+
- iPadOS 17.2+
- Mac Catalyst 17.2+
- macOS 14.2+
- tvOS 17.2+

## Declaration

```objc
- (BOOL) containsZoomFactor:(CGFloat) zoomFactor;
```
