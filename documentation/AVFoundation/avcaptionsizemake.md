# AVCaptionSizeMake

**Framework**: AVFoundation  
**Kind**: func  
**Role**: Function

Creates a caption size with the specified width and height.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 15.0+
- macOS 12.0+

## Declaration

extern AVCaptionSize AVCaptionSizeMake(AVCaptionDimension width, AVCaptionDimension height);
