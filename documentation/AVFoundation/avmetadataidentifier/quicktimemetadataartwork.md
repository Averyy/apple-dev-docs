# quickTimeMetadataArtwork

**Framework**: AVFoundation  
**Kind**: property  
**Role**: Type Property

An identifier that represents an image relating to the movie file content.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.10+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 1.0+
