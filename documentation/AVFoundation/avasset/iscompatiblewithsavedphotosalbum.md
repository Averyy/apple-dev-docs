# isCompatibleWithSavedPhotosAlbum

**Framework**: AVFoundation  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether you can write the asset to the Saved Photos album.

**Availability**:
- iOS 5.0+ - Deprecated in 16.0
- iPadOS 5.0+ - Deprecated in 16.0
- Mac Catalyst 13.1+ - Deprecated in 16.0
- tvOS 9.0+ - Deprecated in 16.0

> **Deprecated**: Load the value of [`isCompatibleWithSavedPhotosAlbum`](../avpartialasyncproperty/iscompatiblewithsavedphotosalbum.md) asynchronously instead.
