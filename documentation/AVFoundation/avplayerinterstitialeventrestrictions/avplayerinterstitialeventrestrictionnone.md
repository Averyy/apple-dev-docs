# AVPlayerInterstitialEventRestrictionNone

**Framework**: AVFoundation  
**Kind**: case  
**Role**: Enumeration Case

A value that indicates no restrictions on playback of primary or interstitial content.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+
