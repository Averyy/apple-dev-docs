# progress

**Framework**: AVFoundation  
**Kind**: property

**Availability**:
- iOS 4.0+
- iPadOS 4.0+
- Mac Catalyst 13.1+
- macOS 10.7+
- tvOS 9.0+
- visionOS 1.0+

## Declaration

```swift
var progress: Float { get }
```

#### Discussion

The value of this property ranges from `0.0` to `1.0.`
