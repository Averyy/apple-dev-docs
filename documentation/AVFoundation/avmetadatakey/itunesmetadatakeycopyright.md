# iTunesMetadataKeyCopyright

**Framework**: AVFoundation  
**Kind**: property  
**Role**: Type Property

**Availability**:
- iOS 4.0+
- iPadOS 4.0+
- Mac Catalyst 13.1+
- macOS 10.7+
- tvOS 9.0+
