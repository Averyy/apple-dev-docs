# commonKeyAccessibilityDescription

**Framework**: AVFoundation  
**Kind**: property  
**Role**: Type Property

A key that represents the accessibility description for the media.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
