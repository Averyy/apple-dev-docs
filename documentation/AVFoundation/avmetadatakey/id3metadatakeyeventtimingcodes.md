# id3MetadataKeyEventTimingCodes

**Framework**: AVFoundation  
**Kind**: property  
**Role**: Type Property

A key that represents the timing codes used for synchronization with key events in a song or sound.

**Availability**:
- iOS 4.0+
- iPadOS 4.0+
- Mac Catalyst 13.1+
- macOS 10.7+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 1.0+
