# isSupported

**Framework**: AVFoundation  
**Kind**: property

Whether Pro Video Storage is supported in its current configuration.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+

## Declaration

```swift
class var isSupported: Bool { get }
```

#### Return Value

`YES` if the device and OS support Pro Video Storage functionality; otherwise, `NO`.
