# Encoder bit rate strategy values

**Framework**: AVFoundation

The constants that represent the possible bit rate strategy values.

## Overview

You use these values with [`AVEncoderBitRateStrategyKey`](../AVFAudio/avencoderbitratestrategykey.md).

## Topics

### Strategies
- [let AVAudioBitRateStrategy_Constant: String](../AVFAudio/avaudiobitratestrategy_constant.md)
  A value that represents a constant bit rate strategy.
- [let AVAudioBitRateStrategy_LongTermAverage: String](../AVFAudio/avaudiobitratestrategy_longtermaverage.md)
  A value that represents an average bit rate strategy.
- [let AVAudioBitRateStrategy_VariableConstrained: String](../AVFAudio/avaudiobitratestrategy_variableconstrained.md)
  A value that represents a constrained variable bit rate strategy.
- [let AVAudioBitRateStrategy_Variable: String](../AVFAudio/avaudiobitratestrategy_variable.md)
  A value that represents a variable bit rate strategy.
