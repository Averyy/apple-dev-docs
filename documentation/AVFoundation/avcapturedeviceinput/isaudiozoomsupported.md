# isAudioZoomSupported

**Framework**: AVFoundation  
**Kind**: property

Whether or not audio zoom is supported.

**Availability**:
- iOS 26.4+
- iPadOS 26.4+
- Mac Catalyst 26.4+
- macOS 26.4+
- tvOS 26.4+

## Declaration

```swift
var isAudioZoomSupported: Bool { get }
```

#### Discussion

This property returns `true` if the device supports audio zoom.
