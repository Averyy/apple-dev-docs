# valueURI

**Framework**: AVFoundation  
**Kind**: property  
**Role**: Type Property

A key that identifies a resource to use as the item’s value.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.10+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 1.0+

This key supports string values.
