# enhancesSpeechIntelligibility

**Framework**: AVFoundation  
**Kind**: property  
**Role**: Type Property

A media characteristic that indicates a track or media selection option includes audio processed to enhance the intelligibility of speech.

- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
