# init(timeRange:)

**Framework**: AVFoundation  
**Kind**: init  
**Role**: Initializer

Creates a caption group with a time range.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 15.0+
- macOS 12.0+

## Declaration

```swift
init(timeRange: CMTimeRange)
```

```objc
- (instancetype) initWithTimeRange:(CMTimeRange) timeRange;
```

## Parameters

- `timeRange`: The time range of the caption group.
