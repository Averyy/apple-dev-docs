**Kind**: property

**Availability**:

- macOS 27.0+ (Beta)

## Declaration

```swift
static let unsupportedFileSystem: AVExternalStorageDevice.ReasonNotRecommendedForCaptureUse
```

#### Discussion

Indicates that the storage device is not recommended for capture as it is not a supported file system.
