# stopShowingCaptionPreview()

**Framework**: AVFoundation  
**Kind**: method

Stops showing the caption preview.

**Availability**:
- iOS 26.4+
- iPadOS 26.4+
- Mac Catalyst 26.4+
- macOS 26.4+
- tvOS 26.4+
- visionOS 26.4+

## Declaration

```swift
func stopShowingCaptionPreview()
```

#### Discussion

This method stops the caption preview and restores any currently active subtitles and/or closed captions.
