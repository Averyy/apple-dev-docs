# peakBitRate

**Framework**: AVFoundation  
**Kind**: property  
**Role**: Instance Property

The peak bit rate for the variant.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```objc
@property (nonatomic, readonly) double peakBitRate;
```

#### Discussion

If the variant doesn’t define a peak bit rate, the value is negative.
