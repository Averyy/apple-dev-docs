# AVVideoFieldMode.bottomOnly

**Framework**: AVFoundation  
**Kind**: case  
**Role**: Case

A value that indicates that a video connection only passes the bottom video field.

**Availability**:
- macOS 10.7+

## Declaration

```swift
case bottomOnly
```

```c
AVVideoFieldModeBottomOnly
```
