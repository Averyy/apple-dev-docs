# qta

**Framework**: AVFoundation  
**Kind**: property  
**Role**: Type Property

A UTI for the QuickTime audio file format

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- tvOS 26.0+
- visionOS 26.0+
- watchOS 26.0+

## Declaration

```swift
static let qta: AVFileType
```

```c
extern AVFileType const AVFileTypeQuickTimeAudio;
```

## Discussion

The value of this UTI is @“com.apple.quicktime-audio”. Files are identified with the .qta extension.
