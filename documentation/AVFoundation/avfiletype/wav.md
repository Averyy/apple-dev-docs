# wav

**Framework**: AVFoundation  
**Kind**: property  
**Role**: Type Property

The UTI for the WAVE audio file format.

**Availability**:
- iOS 4.0+
- iPadOS 4.0+
- Mac Catalyst 13.1+
- macOS 10.7+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 1.0+

## Declaration

```swift
static let wav: AVFileType
```

```c
extern AVFileType const AVFileTypeWAVE;
```

## Discussion

The value of this UTI is `com.microsoft.waveform-audio`. Files of this type have a `.wav`, `.wave`, or `.bwf` extension.
