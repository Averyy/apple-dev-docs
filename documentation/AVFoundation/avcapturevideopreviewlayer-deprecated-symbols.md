# Deprecated symbols

**Framework**: AVFoundation  
**Role**: API Collection

Review unsupported symbols and their replacements.

## Overview

Configure the properties below on the associated [`AVCaptureConnection`](./avcaptureconnection.md) instead.

## Topics

### Layer configuration
- [orientation](./avcapturevideopreviewlayer/orientation.md)
  The layer’s orientation.
- [orientationSupported](./avcapturevideopreviewlayer/orientationsupported.md)
  Indicates whether the layer display supports changing the orientation.
- [mirrored](./avcapturevideopreviewlayer/mirrored.md)
  Indicates whether the layer display is mirrored.
- [mirroringSupported](./avcapturevideopreviewlayer/mirroringsupported.md)
  Indicates whether the layer display supports mirroring.
- [automaticallyAdjustsMirroring](./avcapturevideopreviewlayer/automaticallyadjustsmirroring.md)
  Indicates whether the layer display automatically adjusts mirroring.
