# init(identifier:)

**Framework**: AVFoundation  
**Kind**: init  
**Role**: Initializer

Creates a caption region that has an identifier.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 15.0+
- macOS 12.0+

## Declaration

```swift
init(identifier: String)
```

```objc
- (instancetype) initWithIdentifier:(NSString *) identifier;
```

## Parameters

- `identifier`: The identifier of the caption region.
