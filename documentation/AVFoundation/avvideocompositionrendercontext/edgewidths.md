# edgeWidths

**Framework**: AVFoundation  
**Kind**: property  
**Role**: Instance Property

The width of the edge processing region on the left, top, right, and bottom edges, in pixels.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- macOS 10.9+
- tvOS 9.0+
