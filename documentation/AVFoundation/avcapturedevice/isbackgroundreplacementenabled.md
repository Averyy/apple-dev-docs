# isBackgroundReplacementEnabled

**Framework**: AVFoundation  
**Kind**: property  
**Role**: Type Property

A class property that indicates whether a person enables the Background Replacement feature for this app.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- macOS 15.0+
- tvOS 18.0+
