# batteryStress

**Framework**: AVFoundation  
**Kind**: property

Indicates that under the current battery conditions, the device will shut down within 30 seconds if system load is not reduced.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- tvOS 27.0+
- visionOS 27.0+
