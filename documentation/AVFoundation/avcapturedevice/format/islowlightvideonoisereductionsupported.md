# isLowLightVideoNoiseReductionSupported

**Framework**: AVFoundation  
**Kind**: property

Indicates whether the format supports low light video noise reduction.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
var isLowLightVideoNoiseReductionSupported: Bool { get }
```

#### Discussion

This property returns `true` if the format supports low light video noise reduction.
