# AVAudioSpatializationFormatNone

**Framework**: AVFoundation  
**Kind**: case  
**Role**: Enumeration Case

A value that indicates the player item doesn’t support audio spatialization.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS
