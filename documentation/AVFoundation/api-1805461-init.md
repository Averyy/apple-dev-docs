# init

**Framework**: AVFoundation  
**Role**: Article

Creates an initialized legible output object.

## Overview

This method will create a properly configured legible output instance.

> **Note**:  Using this method is preferred over using the [`init(mediaSubtypesForNativeRepresentation:)`](./avplayeritemlegibleoutput/init%28mediasubtypesfornativerepresentation%29.md) method.
