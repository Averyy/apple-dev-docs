# IOByteCount32

**Framework**: DriverKit  
**Kind**: typealias  
**Role**: Type Alias

A type that represents a number of bytes in a 32-bit address space.

**Availability**:
- DriverKit
- iOS
- iPadOS
- macOS

*macOS*
