# kIOServicePMAssertionCPUBit

**Framework**: DriverKit  
**Kind**: case  
**Role**: Enumeration Case

kIOServicePMAssertionCPUBit When set, PM kernel will prefer to leave the CPU and core hardware running in “Dark Wake” state, instead of sleeping.

- DriverKit
