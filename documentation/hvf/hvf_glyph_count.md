# HVF_glyph_count

**Framework**: hvf  
**Kind**: func  
**Role**: Function

Returns the number of glyphs (suitable for rendering) in the `hvgl` table.

**Availability**:
- iOS 18.4+
- iPadOS 18.4+
- Mac Catalyst 18.4+
- macOS 15.4+
- tvOS 18.4+
- visionOS 2.4+
- watchOS 11.4+

## Declaration

```c
uint32_t HVF_glyph_count(HVFPartRenderer *renderer);
```

#### Discussion

The glyphs are always a prefix of all parts.
