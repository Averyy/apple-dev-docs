# HVFPartRenderAction

**Framework**: hvf  
**Kind**: enum  
**Role**: Enumeration

Actions that a render context may return to the scaler.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```c
enum HVFPartRenderAction : unsigned int;
```

## Topics

### Enumeration Cases
- [HVFPartRenderActionContinue](./hvfpartrenderaction/hvfpartrenderactioncontinue.md)
  Instruct the scaler to continue rendering.
- [HVFPartRenderActionSkip](./hvfpartrenderaction/hvfpartrenderactionskip.md)
  Instruct the scaler to skip rendering this part.
- [HVFPartRenderActionStop](./hvfpartrenderaction/hvfpartrenderactionstop.md)
  Instruct the scaler to stop rendering.
