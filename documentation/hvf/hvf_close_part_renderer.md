# HVF_close_part_renderer

**Framework**: hvf  
**Kind**: func  
**Role**: Function

Reclaim any subsidiary storage used by the renderer and destroy it.

**Availability**:
- iOS 18.4+
- iPadOS 18.4+
- Mac Catalyst 18.4+
- macOS 15.4+
- tvOS 18.4+
- visionOS 2.4+
- watchOS 11.4+

## Declaration

```c
int HVF_close_part_renderer(HVFPartRenderer *renderer);
```

## Discussion

The return value is 0 for success, nonzero for failure.
