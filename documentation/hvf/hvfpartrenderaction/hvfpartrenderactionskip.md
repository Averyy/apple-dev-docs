# HVFPartRenderActionSkip

**Framework**: hvf  
**Kind**: case  
**Role**: Enumeration Case

Instruct the scaler to skip rendering this part.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```c
HVFPartRenderActionSkip
```

#### Discussion

This action is ignored except in response to the `HVFPartRenderInstructionBeginPart` instruction.
