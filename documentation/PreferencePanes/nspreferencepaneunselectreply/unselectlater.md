# NSPreferencePaneUnselectReply.unselectLater

**Framework**: Preference Panes  
**Kind**: case  
**Role**: Case

Delay the deselection until the preference pane invokes [`reply(toShouldUnselect:)`](../nspreferencepane/reply%28toshouldunselect%29.md).

**Availability**:
- Mac Catalyst 14.0+
- macOS 10.1+
