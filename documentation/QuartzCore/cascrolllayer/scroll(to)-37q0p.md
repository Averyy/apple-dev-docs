# scroll(to:)

**Framework**: Core Animation  
**Kind**: method  
**Role**: Instance Method

Changes the origin of the receiver to the specified point.

**Availability**:

- iPadOS 2.0+
- Mac Catalyst 13.1+
- macOS 10.5+
- tvOS 9.0+
- visionOS 1.0+
