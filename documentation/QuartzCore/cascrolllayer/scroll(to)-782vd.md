# scroll(to:)

**Framework**: Core Animation  
**Kind**: method  
**Role**: Instance Method

**Availability**:

- iPadOS 2.0+
- Mac Catalyst 13.1+
- macOS 10.5+
- tvOS 9.0+

## Parameters

- `r`: The rectangle that should be visible.
