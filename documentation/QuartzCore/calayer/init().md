# init()

**Framework**: Core Animation  
**Kind**: init  
**Role**: Initializer

Returns an initialized `CALayer` object.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- macOS 10.5+
- tvOS 9.0+
- visionOS 1.0+

## Declaration

```swift
init()
```

```objc
- (instancetype) init;
```

#### Return Value

An initialized `CALayer` object.

#### Discussion

This is the designated initializer for layer objects that are not in the presentation layer.
