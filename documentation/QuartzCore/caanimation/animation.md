# animation

**Framework**: Core Animation  
**Kind**: method  
**Role**: Type Method

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- macOS 10.5+
- tvOS 9.0+
- visionOS 1.0+

## Declaration


#### Return Value

An `CAAnimation` object whose input values are initialized.
