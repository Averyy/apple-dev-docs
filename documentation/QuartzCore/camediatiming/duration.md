# duration

**Framework**: Core Animation  
**Kind**: property  
**Role**: Instance Property  
**Required**: Yes

Specifies the basic duration of the animation, in seconds.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- macOS 10.5+
- tvOS 9.0+
- visionOS 1.0+

## Declaration

```swift
var duration: CFTimeInterval { get set }
```

```objc
@property CFTimeInterval duration;
```

## Discussion

Defaults to 0.
