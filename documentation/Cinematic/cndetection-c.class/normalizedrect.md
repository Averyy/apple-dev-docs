# normalizedRect

**Framework**: Cinematic  
**Kind**: property  
**Role**: Instance Property

The rectangle within the image where the object occurs, normalized such that (0.0, 0.0) is the top-left and (1.0, 1.0) is the bottom-right.

- iPadOS 17.0+
