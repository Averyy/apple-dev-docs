# init(_:)

**Framework**: Device Activity  
**Kind**: init  
**Role**: Initializer

Creates a new instance with the specified raw value.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+

## Declaration

```swift
init(_ rawValue: String)
```

## Parameters

- `rawValue`: The raw value to use for the new instance.
