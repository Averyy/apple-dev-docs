# supportsAudioTranslation

**Framework**: LiveCommunicationKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the app supports real-time audio translation.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 17.4+
- visionOS 1.1+
- watchOS 10.4+
