# Song.Album

**Framework**: Apple Music Feed  
**Kind**: dictionary  
**Role**: Object

Information about the related album that contains the song.

**Availability**:
- AppleMusicFeed 1.0+

## Declaration

```
object Song.Album
```

## Properties

- `id` (string): The identifier for the album in Apple Music.
- `nameDefault` (string): The default name for the album.
