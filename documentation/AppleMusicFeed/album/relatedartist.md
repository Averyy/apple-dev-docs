# Album.RelatedArtist

**Framework**: Apple Music Feed  
**Kind**: dictionary  
**Role**: Object

Information about a related artist.

**Availability**:
- AppleMusicFeed 1.0+

## Declaration

```
object Album.RelatedArtist
```

## Properties

- `id` (string): The identifier for the artist in Apple Music.
- `nameDefault` (string): The default name for the artist.
