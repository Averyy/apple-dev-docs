# title

**Framework**: Accessory Notifications  
**Kind**: property  
**Role**: Instance Property

A primary text for the notification.

**Availability**:
- iOS 26.5+

## Declaration

```swift
let title: String?
```

#### Discussion

This property contains the notification’s main display text. For supplementary text, see [`subtitle`](./subtitle.md).
