# url

**Framework**: Accessory Notifications  
**Kind**: property

A URL that locates the file’s data.

**Availability**:
- iOS 26.5+ (Beta)
- iPadOS 26.5+ (Beta)

## Declaration

```swift
var url: URL { get async throws }
```

#### Discussion

Use this URL to retrieve the file’s data and include its contents in your transmission to the accessory.
