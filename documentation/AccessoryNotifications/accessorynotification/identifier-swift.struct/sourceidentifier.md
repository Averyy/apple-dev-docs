# sourceIdentifier

**Framework**: Accessory Notifications  
**Kind**: property

The source app’s bundle identifier.

**Availability**:
- iOS 26.5+

## Declaration

```swift
let sourceIdentifier: String
```

#### Discussion

If Messages is the app that sends the notification, the value of this property is `com.apple.MobileSMS`.
