# removeNotification(identifier:)

**Framework**: Accessory Notifications  
**Kind**: method  
**Required**: Yes

Called to indicate that a notification that has been posted should be removed.

**Availability**:
- iOS 26.5+ (Beta)
- iPadOS 26.5+ (Beta)

## Declaration

```swift
func removeNotification(identifier: AccessoryNotification.Identifier)
```

#### Discussion

- identifier: The identifier of the notification that was removed.
