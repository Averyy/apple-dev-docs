# fail(_:)

**Framework**: Accessory Notifications  
**Kind**: method  
**Required**: Yes

Notifies the system that alerting for a notification failed.

**Availability**:
- iOS 26.4+ (Beta)
- iPadOS 26.4+ (Beta)

## Declaration

```swift
func fail(_ error: any Error)
```

## Parameters

- `error`: The error that caused coordination to fail.
