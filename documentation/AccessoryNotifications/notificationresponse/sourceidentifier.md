# sourceIdentifier

**Framework**: Accessory Notifications  
**Kind**: property

A bundle identifier for the app that sent the notification.

**Availability**:
- iOS 26.5+ (Beta)
- iPadOS 26.5+ (Beta)

## Declaration

```swift
var sourceIdentifier: String
```

#### Discussion

For example, if Messages sends the notification, this value is `com.apple.MobileSMS`.
