# kCTFontCollectionCopyDefaultOptions

**Framework**: Core Text  
**Kind**: case  
**Role**: Enumeration Case

Passing this option indicates that defaults are to be used.

**Availability**:
- iOS 12.0+
- iPadOS 12.0+
- Mac Catalyst 13.1+
- macOS 10.7+
- tvOS 12.0+
- visionOS 1.0+
- watchOS 5.0+
