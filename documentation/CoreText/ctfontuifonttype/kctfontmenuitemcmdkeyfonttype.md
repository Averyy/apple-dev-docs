# kCTFontMenuItemCmdKeyFontType

**Framework**: Core Text  
**Kind**: property  
**Role**: Type Property

- iPadOS 3.2+ - Deprecated in 9.0
- Mac Catalyst 13.1+ - Deprecated in 13.1
- macOS 10.5+ - Deprecated in 10.11
