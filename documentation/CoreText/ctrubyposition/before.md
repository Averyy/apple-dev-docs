# CTRubyPosition.before

**Framework**: Core Text  
**Kind**: case  
**Role**: Case

The ruby text is positioned before the base text, appearing above horizontal text and to the right of vertical text.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.10+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+
