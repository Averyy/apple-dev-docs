### Data Types

- [IOHardwareCursorInfo](./iographicstypes_h_user-space/iohardwarecursorinfo.md)
  A structure defining the converted data of a hardware cursor.
- [IOPixelInformation](./iographicstypes_h_user-space/iopixelinformation.md)
  A structure defining the format of a framebuffer.
