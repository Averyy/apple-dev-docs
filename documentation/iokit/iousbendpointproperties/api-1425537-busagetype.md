# bUsageType

**Framework**: IOKit  
**Kind**: structp  
**Role**: Instance Property

For interrupt and isoc endpoints, the usage type. For Bulk endpoints of the UAS Mass Storage Protocol, the pipe ID.

**Availability**:
- Mac Catalyst 18.4+
- macOS 10.8+

## Declaration

