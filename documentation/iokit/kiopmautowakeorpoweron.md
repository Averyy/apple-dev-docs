# kIOPMAutoWakeOrPowerOn

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

Value for scheduled wake from sleep, or power on. The system will either wake OR power on, whichever is necessary.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.3+

## Declaration

```c
#define kIOPMAutoWakeOrPowerOn
```
