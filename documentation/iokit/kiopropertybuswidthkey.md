# kIOPropertyBusWidthKey

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.7+

## Declaration

```c
#define kIOPropertyBusWidthKey
```

## Discussion

This key defines the current bus width for the device.

Requirement: Mandatory.

Example:

```occ
 
 
<dict>
   <key>Bus Width</key>
   <integer>4</integer>
</dict>
```
