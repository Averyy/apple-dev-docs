# kIOHIDManufacturerKey

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

A key that specifies the manufacturer of the device.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
#define kIOHIDManufacturerKey
```

## Discussion

The value of this key is a string that contains the manufacturer's name.
