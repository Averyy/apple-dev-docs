# kIOFWMustBeRoot

**Framework**: IOKit  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.5+

## Declaration

```c
kIOFWMustBeRoot = (1 << 5)
```

## Discussion

Attempt to make this device root, There is no guarentee Mac OS will succeed in making the device root.
