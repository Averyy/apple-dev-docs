# kIOPSInternalType

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

Value for key [`kIOPSTransportTypeKey`](./kiopstransporttypekey.md). Indicates the power source is an internal battery.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.2+

```c
#define kIOPSInternalType
```
