# kIOPMPowerEventTypeKey

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

Key for the type of power event. Value is a CFStringRef, with the c-string value of one of the "kIOPMAuto" strings.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.3+

## Declaration

```c
#define kIOPMPowerEventTypeKey
```
