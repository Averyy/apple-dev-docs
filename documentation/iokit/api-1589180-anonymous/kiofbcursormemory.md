# kIOFBCursorMemory

**Framework**: IOKit  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- Mac Catalyst 18.4+
- macOS 10.0+

## Declaration

```c
kIOFBCursorMemory = 100
```

#### Discussion

The memory type for IOConnectMapMemory() to get a slice of shared memory that contains the StdFBShmem_t structure.
