# kIOPSNotifyLowBattery

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

Notify(3) key. The system delivers notifications on this key when the battery time remaining drops into a warnable level.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.6+

## Declaration

```c
#define kIOPSNotifyLowBattery
```
