# kIOPSNetworkTransportType

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

Value for key [`kIOPSTransportTypeKey`](./kiopstransporttypekey.md).

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.2+

## Declaration

```c
#define kIOPSNetworkTransportType
```

## Discussion

Indicates the power source is a UPS attached over a network connection (and it may be managing several computers).
