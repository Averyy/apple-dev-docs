# kIOPropertyCardPresentKey

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.7+

## Declaration

```c
#define kIOPropertyCardPresentKey
```

## Discussion

This key defines wether a MMC or SD card is physically present.

Requirement: Mandatory

Example:

```occ
 
 
<dict>
   <key>Card Present</key>
   <true/>
</dict>
```
