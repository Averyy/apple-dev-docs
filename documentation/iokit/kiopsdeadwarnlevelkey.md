# kIOPSDeadWarnLevelKey

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

Key for the "Shutdown System" low power trigger-level. Default is 20%.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.2+

## Declaration

```c
#define kIOPSDeadWarnLevelKey
```
