# kUSBNotificationPreForcedSuspend

**Framework**: IOKit  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- Mac Catalyst 18.4+
- macOS 10.9+

## Declaration

```c
kUSBNotificationPreForcedSuspend = (1 << kUSBNotificationPreForcedSuspendBit)
```

## Discussion

A notification is sent prior to a forced suspend (e.g. system sleep).
