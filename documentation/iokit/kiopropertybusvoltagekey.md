# kIOPropertyBusVoltageKey

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.7+

## Declaration

```c
#define kIOPropertyBusVoltageKey
```

#### Discussion

This key defines the current bus voltage for the device in mV

Requirement: Mandatory.

Example:

```occ
 
 
<dict>
   <key>Bus Voltage</key>
   <integer>3300</integer>
</dict>
</dict>
```
