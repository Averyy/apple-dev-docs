# kIOCatalogModuleUnload

**Framework**: IOKit  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kIOCatalogModuleUnload = 1
```

#### Discussion

Terminates all services which depend on a particular module and unloads the module.
