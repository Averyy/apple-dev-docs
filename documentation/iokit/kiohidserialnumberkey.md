# kIOHIDSerialNumberKey

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

A key that specifies the device's serial number.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
#define kIOHIDSerialNumberKey
```

#### Discussion

The value of this key is a string that contains the serial number of the device.
