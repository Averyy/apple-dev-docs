# kIOHIDProductKey

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

A key that describes the product.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
#define kIOHIDProductKey
```

## Discussion

The value of this key is a string that describes the product.
