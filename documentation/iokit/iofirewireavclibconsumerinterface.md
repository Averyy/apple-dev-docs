# IOFireWireAVCLibConsumerInterface

**Framework**: IOKit  
**Kind**: struct  
**Role**: Structure

Interface for an asynchronous connection consumer.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.2+

## Declaration

```c
typedef struct IOFireWireAVCLibConsumerInterface {
    ...
} IOFireWireAVCLibConsumerInterface;
```

## Overview

Used to receive data from an asynchronous connection producer.
