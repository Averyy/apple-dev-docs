# kIOPropertyBaseFrequencyKey

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.7+

## Declaration

```c
#define kIOPropertyBaseFrequencyKey
```

## Discussion

This key defines the current base frequency for the device.

Requirement: Mandatory.

Example:

```occ
 
 
<dict>
   <key>Base Frequency</key>
   <integer>50</integer>
</dict>
```
