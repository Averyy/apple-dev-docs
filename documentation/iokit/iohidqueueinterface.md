# IOHIDQueueInterface

**Framework**: IOKit  
**Kind**: struct  
**Role**: Structure

CFPlugin object subclass which provides an interface for input queues from HID devices. Created by an IOHIDDeviceInterface object.

**Availability**:
- Mac Catalyst 18.4+
- macOS 10.0+

## Declaration

```c
typedef struct IOHIDQueueInterface {
    ...
} IOHIDQueueInterface;
```
