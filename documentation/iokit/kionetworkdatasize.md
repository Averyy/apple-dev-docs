# kIONetworkDataSize

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

A property of IONetworkData objects.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
#define kIONetworkDataSize
```

#### Discussion

The kIONetworkDataSize property is an OSNumber that describes the size of the data buffer of an IONetworkData object.
