# kIOPMDriverAssertionBluetoothHIDDevicePairedBit

**Framework**: IOKit  
**Kind**: data

## Overview

kIOPMDriverAssertionCPUBit When set, PM kernel will prefer to leave the CPU and core hardware running in "Dark Wake" state, instead of sleeping.
