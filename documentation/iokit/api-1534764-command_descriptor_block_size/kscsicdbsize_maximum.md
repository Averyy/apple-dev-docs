# kSCSICDBSize_Maximum

**Framework**: IOKit  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kSCSICDBSize_Maximum = 16
```

#### Discussion

This is the largest size a Command Descriptor Block can be as specified in SPC-2.
