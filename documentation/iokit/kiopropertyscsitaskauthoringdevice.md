# kIOPropertySCSITaskAuthoringDevice

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.1+

## Declaration

```c
#define kIOPropertySCSITaskAuthoringDevice
```

#### Discussion

IORegistry property for the SCSI Task User Client. This property identifies an SCSITask enabled device capable of authoring.
