# IOHIDDeviceInterface

**Framework**: IOKit  
**Kind**: struct  
**Role**: Structure

CFPlugin object subclass which provides the primary interface to HID devices.

**Availability**:
- Mac Catalyst 18.4+
- macOS 10.0+

## Declaration

```c
typedef struct IOHIDDeviceInterface {
    ...
} IOHIDDeviceInterface;
```
