# kUSBPowerDuringWake

**Framework**: IOKit  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- Mac Catalyst 18.4+
- macOS 10.6+

## Declaration

```c
kUSBPowerDuringWake = 1
```

#### Discussion

The power is to be used while the system is awake (i.e not sleeping)
