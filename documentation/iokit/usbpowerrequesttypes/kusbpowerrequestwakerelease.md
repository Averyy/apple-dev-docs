# kUSBPowerRequestWakeRelease

**Framework**: IOKit  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- Mac Catalyst 18.4+
- macOS 10.7+

## Declaration

```c
kUSBPowerRequestWakeRelease = 2
```

#### Discussion

When used with ReturnExtraPower(), it will send a message to all devices to return any extra wake power if possible.
