# kUSBPowerDuringWakeUSB3

**Framework**: IOKit  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- Mac Catalyst 18.4+
- macOS 10.8+

## Declaration

```c
kUSBPowerDuringWakeUSB3 = 7
```

## Discussion

This is used by the USB stack to allocate the 400mA extra for USB3, above the 500ma allocated by USB2
