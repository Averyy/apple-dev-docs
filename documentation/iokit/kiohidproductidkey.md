# kIOHIDProductIDKey

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

A key for specifying the product identifier of the device.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
#define kIOHIDProductIDKey
```

#### Discussion

The value of this key is the numerical ID that the manufacturer assigned to the device.
