# kIOProperty64BitKey

**Framework**: IOKit  
**Kind**: macro  
**Role**: Macro

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.7+

## Declaration

```c
#define kIOProperty64BitKey
```

#### Discussion

This key defines wether the device supports 64-bit.

Requirement: Mandatory

Example:

```occ
 
 
<dict>
   <key>64-bit</key>
   <true/>
</dict>
```
