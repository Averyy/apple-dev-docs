# IOFWAsyncStreamListenerInterface

**Framework**: IOKit  
**Kind**: struct  
**Role**: Structure

Represents and provides management functions for a asyn stream listener object.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.5+

## Declaration

```c
typedef struct IOFWAsyncStreamListenerInterface_t {
    ...
} IOFWAsyncStreamListenerInterface;
```
