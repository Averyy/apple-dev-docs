# kUSBInformationDeviceIsInternalBit

**Framework**: IOKit  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- Mac Catalyst 18.4+
- macOS 10.6+

## Declaration

```c
kUSBInformationDeviceIsInternalBit = 2
```

## Discussion

The USB device is internal to the enclosure (all the hubs it attaches to are captive)
