# HTMLVideoElement

**Framework**: WebKit JS  
**Kind**: cl  
**Role**: Class

A class representing the HTML `video` element that plays a video in a webpage. Use the [`HTMLAudioElement`](./htmlaudioelement.md) class for the HTML `audio` element.

**Availability**:
- Safari Desktop 10.0+
- Safari Mobile 3.0+

## Declaration

```
interface HTMLVideoElement
```
