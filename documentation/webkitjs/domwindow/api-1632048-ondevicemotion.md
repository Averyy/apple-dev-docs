# ondevicemotion

**Framework**: WebKit JS  
**Kind**: instp  
**Role**: Instance Property

The event listener that is called when the device motion changes. 

**Availability**:
- Safari Desktop 10.1+
- Safari Mobile 4.2+

## Declaration

```
attribute EventHandler ondevicemotion;
```
