# toString

**Framework**: WebKit JS  
**Kind**: instm  
**Role**: Instance Method

Returns a string representation of the matrix.

**Availability**:
- Safari Desktop 10.0+
- Safari Mobile 10.0+

## Declaration

```
DOMString toString();
```

## Return Value

A string representation of the matrix’s values.
