# src

**Framework**: WebKit JS  
**Kind**: instp  
**Role**: Instance Property

The URI address of the media resource to play.

**Availability**:
- Safari Desktop 10.0+
- Safari Mobile 10.0+

## Declaration

```
attribute USVString src;
```
