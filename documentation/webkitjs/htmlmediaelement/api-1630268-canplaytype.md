# canPlayType

**Framework**: WebKit JS  
**Kind**: instm  
**Role**: Instance Method

Returns whether the media element supports the specified MIME type.

**Availability**:
- Safari Desktop 4.0+
- Safari Mobile 3.0+

## Declaration

```
DOMString canPlayType(
    DOMString type
);
```

## Return Value

The possible string values are: “no”, “probably” and “maybe”.
