# play

**Framework**: WebKit JS  
**Kind**: instm  
**Role**: Instance Method

Begins playing the media resource.

**Availability**:
- Safari Desktop 3.1+
- Safari Mobile 3.0+

## Declaration

```
Promise <void> play();
```

## Discussion

If the media resource is not available for playback, this method loads it.
