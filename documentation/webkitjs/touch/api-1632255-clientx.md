# clientX

**Framework**: WebKit JS  
**Kind**: instp  
**Role**: Instance Property

The x-coordinate of the touch’s location relative to the window’s viewport.

**Availability**:
- Safari Desktop 10.1+
- Safari Mobile 2.0+
