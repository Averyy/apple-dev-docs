# onwebkitfullscreenchange

**Framework**: WebKit JS  
**Kind**: instp  
**Role**: Instance Property

An event listener that is called when entering or exiting full-screen mode.

**Availability**:
- Safari Desktop 5.1+
- Safari Mobile 9.0+

## Declaration

```
attribute EventHandler onwebkitfullscreenchange;
```
