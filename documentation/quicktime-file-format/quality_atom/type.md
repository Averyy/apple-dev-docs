# Type

**Framework**: QuickTime File Format  
**Kind**: property  
**Role**: Data field

The type of this atom.

## Overview

This field must be set to ‘`rmqu`’.

## See Also

### Data fields

  The number of bytes in this quality atom.
- [Quality](./quality.md)
