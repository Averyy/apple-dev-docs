# kMovieMediaBackgroundColor

**Framework**: QuickTime File Format  
**Kind**: property  
**Role**: Data field

A color that is used for filling the background when the movie is being instantiated or when it fails to instantiate.

## Overview

The color is an `RGBColor`.
