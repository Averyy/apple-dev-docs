# Datatype array

**Framework**: QuickTime File Format  
**Kind**: property  
**Role**: Data field

An array of unsigned 8-bit bytes holding the data type designation for values in timed metadata media samples having this key.

## Overview

The interpretation of this array is defined by the associated datatype namespace.

## See Also

### Data fields
- [Size](./size.md)
  A 32-bit unsigned integer that indicates the size in bytes of the atom structure.
- [Type](./type.md)
  A 32-bit unsigned integer value.
- [Datatype namespace](./datatype_namespace.md)
  A 32-bit identifier describing how to interpret the data type for the value.
