# CPU speed atom

**Framework**: QuickTime File Format  
**Kind**: property  
**Role**: Data field

A reference movie atom may contain an optional CPU speed atom.

#### Overview

Only one CPU speed atom can be present. See [`CPU speed atom`](../cpu_speed_atom.md) for more information.
