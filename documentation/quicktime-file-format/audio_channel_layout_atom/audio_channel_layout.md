# Audio channel layout

**Framework**: QuickTime File Format  
**Kind**: property  
**Role**: Data field

An audio channel layout structure.

#### Overview

A big-endian `AudioChannelLayout` structure as defined in CoreAudioTypes.h. See the OS X Developer Library for CoreAudio framework details.

## See Also

### Data fields
- [Size](./size.md)
  An unsigned 32-bit integer holding the size of the audio channel layout atom.
- [Type](./type.md)
  An unsigned 32-bit field.
- [Version](./version.md)
  A 1-byte specification of the version of the audio channel layout atom.
- [Flags](./flags.md)
  A 3-byte space for audio channel layout flags.
