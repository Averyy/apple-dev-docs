# init(bundleIdentifier:)

**Framework**: Managed Settings  
**Kind**: init  
**Role**: Initializer

Creates an object that represents the app with the specified bundle identifier.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+

## Declaration

```swift
init(bundleIdentifier: String)
```

## Parameters

- `bundleIdentifier`: The app’s bundle identifier.
