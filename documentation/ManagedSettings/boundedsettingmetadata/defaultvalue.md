# defaultValue

**Framework**: Managed Settings  
**Kind**: property  
**Role**: Instance Property

The implicit value for a setting if your app doesn’t set a value.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
