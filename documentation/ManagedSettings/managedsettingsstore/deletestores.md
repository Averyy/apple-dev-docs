# deleteStores(_:)

**Framework**: Managed Settings  
**Kind**: method

Deletes the given stores configured by your app if they exist

**Availability**:
- iOS 26.5+
- iPadOS 26.5+
- Mac Catalyst ?+

## Declaration

```swift
static func deleteStores(_ storeNames: Set<ManagedSettingsStore.Name>)
```

## Parameters

- `storeNames`: The names of the stores to delete
