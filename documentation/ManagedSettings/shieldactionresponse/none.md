# ShieldActionResponse.none

**Framework**: Managed Settings  
**Kind**: case  
**Role**: Case

An instruction that the system doesn’t need to take any additional action on behalf of the extension.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
