# lockCellularPlan

**Framework**: Managed Settings  
**Kind**: property  
**Role**: Type Property

The metadata associated with the constraint that locks the user’s cellular plan.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+

## Declaration

```swift
static let lockCellularPlan: SettingMetadata<Bool>
```

## Discussion

The default value is `false`.
