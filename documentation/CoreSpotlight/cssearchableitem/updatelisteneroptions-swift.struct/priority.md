# priority

**Framework**: Core Spotlight  
**Kind**: property  
**Role**: Type Property

An option to classify the priority of SMS message content. Specify this option only if your item contains messages.

**Availability**:
- iOS 18.4+
- iPadOS 18.4+
- Mac Catalyst 18.4+
- macOS 15.4+
- visionOS 2.4+
