# CSIndexError.Code.indexingUnsupported

**Framework**: Core Spotlight  
**Kind**: case  
**Role**: Case

Indexing isn’t supported on the device.

**Availability**:
- iOS 9.0+
- iPadOS 9.0+
- Mac Catalyst 13.1+
- macOS 10.11+
