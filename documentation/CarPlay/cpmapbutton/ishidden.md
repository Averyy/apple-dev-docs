# isHidden

**Framework**: CarPlay  
**Kind**: property  
**Role**: Instance Property

A Boolean value that hides and shows the map button.

**Availability**:
- iOS 12.0+
- iPadOS 12.0+
- Mac Catalyst 13.1+

## Declaration

```swift
var isHidden: Bool { get set }
```

```objc
@property (nonatomic, assign, getter=isHidden) BOOL hidden;
```

#### Discussion

The default value is [`false`](../../Swift/false.md).
