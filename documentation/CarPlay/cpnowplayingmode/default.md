# default

**Framework**: CarPlay  
**Kind**: property  
**Role**: Type Property

The default now playing mode. While this mode is active, your app will display now playing metadata as donated to the shared system now playing info center.

**Availability**:

- iPadOS 18.4+
- Mac Catalyst 18.4+
