# altitude

**Framework**: CarPlay  
**Kind**: property

altitude is the coordinate’s elevation above sea level in meters. If no altitude is available, use CLLocationDistanceMax.

**Availability**:
- iOS 26.4+ (Beta)
- iPadOS 26.4+ (Beta)
- Mac Catalyst 26.4+ (Beta)
