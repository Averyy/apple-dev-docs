# showsExplicitLabel

**Framework**: CarPlay  
**Kind**: property  
**Role**: Instance Property

If YES, a cell displaying this list item will render with an explicit label to the trailing edge of the text

**Availability**:
- iOS 14.0+ - Deprecated in 14.0
- iPadOS 14.0+ - Deprecated in 14.0
- Mac Catalyst 14.0+ - Deprecated in 14.0

## Declaration

```swift
var showsExplicitLabel: Bool { get set }
```


## Discussion

Defaults to NO.
