# conversationIdentifier

**Framework**: CarPlay  
**Kind**: property  
**Role**: Instance Property

The string you use to uniquely identify the conversation in your app.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+

## Declaration

```swift
var conversationIdentifier: String { get }
```

```objc
@property (nonatomic, readonly) NSString * conversationIdentifier;
```

## Discussion

Specify this value at initialization time from the value you use to identify the conversation in your app.
