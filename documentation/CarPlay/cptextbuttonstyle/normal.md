# CPTextButtonStyle.normal

**Framework**: CarPlay  
**Kind**: case  
**Role**: Case

A style that indicates the button performs an action other than to confirm or cancel.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
