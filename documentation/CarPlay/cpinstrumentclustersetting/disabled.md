# CPInstrumentClusterSetting.disabled

**Framework**: CarPlay  
**Kind**: case  
**Role**: Case

An option to disable the specified setting.

**Availability**:
- iOS 15.4+
- iPadOS 15.4+
- Mac Catalyst 15.4+

## Declaration

```swift
case disabled
```

```c
CPInstrumentClusterSettingDisabled
```

## Discussion

Don’t display information for the associated setting, even if your app supports doing so.
