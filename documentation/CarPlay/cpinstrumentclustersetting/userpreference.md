# CPInstrumentClusterSetting.userPreference

**Framework**: CarPlay  
**Kind**: case  
**Role**: Case

An option to enable the setting according to personal preferences your app manages.

**Availability**:
- iOS 15.4+
- iPadOS 15.4+
- Mac Catalyst 15.4+

## Declaration

```swift
case userPreference
```

```c
CPInstrumentClusterSettingUserPreference
```

## Discussion

Use your app’s preferences to determine whether to display the setting.
