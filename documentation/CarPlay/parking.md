# Parking

**Framework**: CarPlay

Build an app that provides helpful information about nearby parking facilities.

## Overview

A parking app helps people find nearby parking facilities and manage the parking process. Create this type of app to find parking lots or garages with available spaces, pay for parking, or manage parking access. Show the location of parking lots or garages on the map using the point-of-interest template. Display relevant infomation about the facilities using other available templates.

This type of app supports the following CarPlay templates:

- [`CPInformationTemplate`](./cpinformationtemplate.md)
- [`CPPointOfInterestTemplate`](./cppointofinteresttemplate.md)
- [`CPSearchTemplate`](./cpsearchtemplate.md)
- [`CPTabBarTemplate`](./cptabbartemplate.md)
- [`CPListTemplate`](./cplisttemplate.md)
- [`CPGridTemplate`](./cpgridtemplate.md)
- [`CPVoiceControlTemplate`](./cpvoicecontroltemplate.md)
- [`CPActionSheetTemplate`](./cpactionsheettemplate.md)
- [`CPAlertTemplate`](./cpalerttemplate.md)
