# allowsMiniPlayer

**Framework**: CarPlay  
**Kind**: property  
**Role**: Instance Property

A Boolean value indicating whether the mini player is allowed to appear.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+

## Declaration

```swift
var allowsMiniPlayer: Bool { get set }
```

```objc
@property (nonatomic, assign) BOOL allowsMiniPlayer;
```

#### Discussion

Set the value of this property to @c NO to hide the mini player.

Defaults to YES.
