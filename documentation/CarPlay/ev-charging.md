# EV charging

**Framework**: CarPlay

Build an app that provides helpful information about nearby charging facilities.

## Overview

An EV charging app provides people with information about charging facilities. Create this type of app to provide people with a facility’s charging capacity, connector types, availability, and location. Show the location of EV chargers on the map using the point-of-interest template. Display relevant infomation about the charging facilities using other available templates. You can combine this type of app with a fueling app, but don’t show charging and fueling stations together on the same map.

This type of app supports the following CarPlay templates:

- [`CPInformationTemplate`](./cpinformationtemplate.md)
- [`CPPointOfInterestTemplate`](./cppointofinteresttemplate.md)
- [`CPSearchTemplate`](./cpsearchtemplate.md)
- [`CPTabBarTemplate`](./cptabbartemplate.md)
- [`CPListTemplate`](./cplisttemplate.md)
- [`CPGridTemplate`](./cpgridtemplate.md)
- [`CPVoiceControlTemplate`](./cpvoicecontroltemplate.md)
- [`CPActionSheetTemplate`](./cpactionsheettemplate.md)
- [`CPAlertTemplate`](./cpalerttemplate.md)
