# CPManeuverDisplayStyleDefault

**Framework**: CarPlay  
**Kind**: case  
**Role**: Enumeration Case

The default display style for the maneuver.

**Availability**:
- iOS 12.0+
- iPadOS 12.0+
- Mac Catalyst 13.1+

## Declaration

```c
CPManeuverDisplayStyleDefault
```

## Discussion

The visual layout for this display style is the same as [`leadingSymbol`](./leadingsymbol.md).
