# Fueling

**Framework**: CarPlay

Build an app that provides helpful information about nearby fueling stations.

## Overview

A fueling app provides people with information about nearby fueling stations. Create this type of app to provide people with the types of services available at fueling stations as well as their locations. Show the location of fueling stations on the map using the point-of-interest template. Display relevant infomation about the fueling stations using other available templates. You can combine this type of app with an EV charging app, but don’t show charging and fueling stations together on the same map.

This type of app supports the following CarPlay templates:

- [`CPInformationTemplate`](./cpinformationtemplate.md)
- [`CPPointOfInterestTemplate`](./cppointofinteresttemplate.md)
- [`CPSearchTemplate`](./cpsearchtemplate.md)
- [`CPTabBarTemplate`](./cptabbartemplate.md)
- [`CPListTemplate`](./cplisttemplate.md)
- [`CPGridTemplate`](./cpgridtemplate.md)
- [`CPVoiceControlTemplate`](./cpvoicecontroltemplate.md)
- [`CPActionSheetTemplate`](./cpactionsheettemplate.md)
- [`CPAlertTemplate`](./cpalerttemplate.md)
