# init(image:)

**Framework**: CarPlay  
**Kind**: init

**Availability**:
- iOS 26.4+ (Beta)
- iPadOS 26.4+ (Beta)
- Mac Catalyst 26.4+ (Beta)

## Declaration

```swift

```

## Parameters

- `image`: The image to display in the thumbnail.
