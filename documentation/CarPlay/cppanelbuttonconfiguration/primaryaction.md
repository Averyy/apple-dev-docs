# primaryAction

**Framework**: CarPlay  
**Kind**: property

The primary action button for the panel.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+

## Declaration

```swift
@NSCopying
var primaryAction: CPTextButton { get }
```

#### Discussion

Specify the button at initialization time and use this property to retrieve it later.
