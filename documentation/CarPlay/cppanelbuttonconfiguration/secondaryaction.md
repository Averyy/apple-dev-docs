# secondaryAction

**Framework**: CarPlay  
**Kind**: property

An optional action button to display in the panel.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+

## Declaration

```swift
@NSCopying
var secondaryAction: CPTextButton? { get }
```

#### Discussion

Specify this button at initialization time and use this property to retrieve it later.
