# new

**Framework**: CarPlay  
**Kind**: method  
**Role**: Type Method

Creates a message compose button with a system-provided image.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+

## Declaration

```objc
+ (instancetype) new;
```

## Discussion

> **Note**:  This button type does not use a handler. Instead, tapping this button activates Siri and initiates the compose message flow.
