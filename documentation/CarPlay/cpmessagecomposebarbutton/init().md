# init()

**Framework**: CarPlay  
**Kind**: init  
**Role**: Initializer

Creates a button for composing messages that uses the system-provided image.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+

## Declaration

```swift
init()
```

```objc
- (instancetype) init;
```

## Return Value

An initialized message compose bar button.
