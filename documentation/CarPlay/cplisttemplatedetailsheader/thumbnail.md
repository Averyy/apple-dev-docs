# thumbnail

**Framework**: CarPlay  
**Kind**: property

The thumbnail image displayed in the header.

**Availability**:
- iOS 26.4+ (Beta)
- iPadOS 26.4+ (Beta)
- Mac Catalyst 26.4+ (Beta)

## Declaration

```swift
var thumbnail: CPThumbnailImage { get set }
```

#### Discussion

This property represents the primary visual content of the header. The thumbnail may include image overlays, playback progress indicators, or sports overlays depending on the content type.
