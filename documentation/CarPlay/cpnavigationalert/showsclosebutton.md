# showsCloseButton

**Framework**: CarPlay  
**Kind**: property

A Boolean value indicating whether the close button is allowed to appear.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)

## Declaration

```swift
var showsCloseButton: Bool { get set }
```

#### Discussion

Set the value of this property to @c NO to hide the close button.

Defaults to @c YES.
