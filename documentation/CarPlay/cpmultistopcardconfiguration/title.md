# title

**Framework**: CarPlay  
**Kind**: property  
**Role**: Instance Property

Title of panel presented to configure waypoints along a route. If no panel is provided, the panel title will default to “Add Stop”.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
