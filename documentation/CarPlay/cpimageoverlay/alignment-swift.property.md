# alignment

**Framework**: CarPlay  
**Kind**: property  
**Role**: Instance Property

The alignment of the overlay inside the top edge of the thumbnail.

**Availability**:
- iOS 26.4+
- iPadOS 26.4+
- Mac Catalyst 26.4+

## Declaration

```swift
var alignment: CPImageOverlay.Alignment { get }
```

```objc
@property (nonatomic, assign, readonly) CPImageOverlayAlignment alignment;
```

## Discussion

Overlays appear inside the top edge of the thumbnail image and with the alignment in this property.
