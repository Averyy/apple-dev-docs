# accessibilityLabel

**Framework**: CarPlay  
**Kind**: property  
**Role**: Instance Property

Accessibility text to apply to the element’s image.

**Availability**:
- iOS 26.4+
- iPadOS 26.4+
- Mac Catalyst 26.4+

## Declaration

```swift
var accessibilityLabel: String? { get set }
```

```objc
@property (nonatomic, copy, nullable) NSString * accessibilityLabel;
```

## Discussion

Use this string to describe the contents of the image. Voice control and other system features can use this string to help people navigate your content.
