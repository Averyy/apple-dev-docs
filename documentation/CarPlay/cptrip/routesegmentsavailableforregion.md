# routeSegmentsAvailableForRegion

**Framework**: CarPlay  
**Kind**: property

Set to @NO to disable route sharing for this trip when route sharing is not supported in the current region.

**Availability**:
- iOS 26.4+
- iPadOS 26.4+
- Mac Catalyst 26.4+
