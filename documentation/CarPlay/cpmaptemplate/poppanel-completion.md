# popPanel(completion:)

**Framework**: CarPlay  
**Kind**: method

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)

## Declaration

```swift
func popPanel() async throws -> Bool
```

## Parameters

- `completion`: An optional block called when the panel has been popped.
