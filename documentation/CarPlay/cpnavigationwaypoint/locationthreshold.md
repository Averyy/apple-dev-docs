# locationThreshold

**Framework**: CarPlay  
**Kind**: property  
**Role**: Instance Property

locationThreshold is the maximum distance in meters from the centerPoint used to determine if a destination is valid.

**Availability**:
- iOS 26.4+
- iPadOS 26.4+
- Mac Catalyst 26.4+
