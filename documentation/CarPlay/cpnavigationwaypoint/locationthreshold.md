# locationThreshold

**Framework**: CarPlay  
**Kind**: property

locationThreshold is the maximum distance in meters from the centerPoint used to determine if a destination is valid.

**Availability**:
- iOS 26.4+ (Beta)
- iPadOS 26.4+ (Beta)
- Mac Catalyst 26.4+ (Beta)
