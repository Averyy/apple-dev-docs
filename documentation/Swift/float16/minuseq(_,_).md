# -=(_:_:)

**Framework**: Swift  
**Kind**: op  
**Role**: Operator

Subtracts the second value from the first and stores the difference in the left-hand-side variable, rounding to a representable value.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 7.0+

## Declaration

```swift
static func -= (lhs: inout Float16, rhs: Float16)
```

## Parameters

- `lhs`: A numeric value.
- `rhs`: The value to subtract from `lhs`.
