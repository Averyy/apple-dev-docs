# -(_:)

**Framework**: Swift  
**Kind**: op  
**Role**: Operator

Calculates the additive inverse of a value.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 7.0+

## Declaration

```swift
static func - (x: Float16) -> Float16
```

## Discussion

The unary minus operator (prefix `-`) calculates the negation of its operand. The result is always exact.

```swift
let x = 21.5
let y = -x
// y == -21.5
```
