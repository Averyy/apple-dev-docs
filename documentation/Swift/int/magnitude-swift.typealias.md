# Int.Magnitude

**Framework**: Swift  
**Kind**: typealias  
**Role**: Type Alias

A type that can represent the absolute value of any possible value of this type.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.0+
- macOS 10.10+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+
