# init(viewing:)

**Framework**: Swift  
**Kind**: init

View initialized raw memory as a span of bytes.

**Availability**:
- iOS 12.2+
- iPadOS 12.2+
- Mac Catalyst 12.2+
- macOS 10.14.4+
- tvOS 12.2+
- visionOS 1.0+
- watchOS 5.2+

## Declaration

```swift
init(viewing bytes: RawSpan)
```

## Parameters

- `bytes`: An existing `RawSpan`, which will define both this `Span`’s lifetime and the memory it represents.
