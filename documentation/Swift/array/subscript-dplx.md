# subscript(_:)

**Framework**: Swift  
**Kind**: subscript

Returns the first metric whose `Metric/name` equals the given metric’s name, or `nil` if not found.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
