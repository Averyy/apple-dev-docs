# init(_:)

**Framework**: Swift  
**Kind**: init  
**Role**: Initializer

Constructs an Array with the elements of a DataColumn.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 10.14+
- tvOS 16.0+
- visionOS 1.0+

## Declaration

```swift
init(_ column: MLDataColumn<Element>)
```

Available when `Element` conforms to `MLDataValueConvertible`.
