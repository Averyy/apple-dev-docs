# subscript(_:)

**Framework**: Swift  
**Kind**: subscript  
**Role**: Instance Subscript

Returns the first metric with a metric name that equals the given metric’s name.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- macOS 27.0+
- visionOS 27.0+
- watchOS 27.0+

## Declaration

```swift
subscript(metric: Metric) -> Metric? { get }
```

Available when `Element` is `Metric`.
