# removeLast()

**Framework**: Swift  
**Kind**: method  
**Role**: Instance Method

Removes and returns the last element of the array.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+
- watchOS 27.0+

## Declaration

```swift
@discardableResult
mutating func removeLast() -> Element
```

#### Return Value

The last element of the original array.

#### Discussion

The array must not be empty.

> **Complexity**: O(1)
