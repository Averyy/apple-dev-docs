# removeAll()

**Framework**: Swift  
**Kind**: method

Removes all elements from the array, preserving its allocated capacity.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+

```swift
mutating func removeAll()
```

#### Discussion

> **Note**: O(*n*), where *n* is the original count of the array.
