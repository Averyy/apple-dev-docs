# popLast()

**Framework**: Swift  
**Kind**: method

Removes and returns the last element of the array, if there is one.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- watchOS 27.0+ (Beta)

## Declaration

```swift
mutating func popLast() -> Element?
```

#### Return Value

The last element of the array if the array is not empty; otherwise, `nil`.

#### Discussion

> **Note**: O(1)
