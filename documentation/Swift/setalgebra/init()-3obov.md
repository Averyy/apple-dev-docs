# init()

**Framework**: Swift  
**Kind**: init  
**Role**: Initializer

Creates an empty option set.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.0+
- macOS 10.10+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
init()
```

Available when `RawValue` conforms to `FixedWidthInteger`.

#### Discussion

This initializer creates an option set with a raw value of zero.
