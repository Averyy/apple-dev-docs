# removeLast()

**Framework**: Swift  
**Kind**: method  
**Role**: Instance Method

Remove the last initialized element from this span.

**Availability**:
- iOS 12.2+
- iPadOS 12.2+
- Mac Catalyst 12.2+
- macOS 10.14.4+
- tvOS 12.2+
- visionOS 1.0+
- watchOS 5.2+

## Declaration

```swift
mutating func removeLast() -> Element
```

#### Return Value

The removed element.

#### Discussion

Returns the last element. The `OutputSpan` must not be empty.
