# zero

**Kind**: property  
**Role**: Type Property

The zero value.

- tvOS 9.0+

## Declaration

```swift
static var zero: Self { get }
```

Available when `Self` conforms to `ExpressibleByIntegerLiteral`.

#### Discussion

Zero is the identity element for addition. For any value, `x + .zero == x` and `.zero + x == x`.
