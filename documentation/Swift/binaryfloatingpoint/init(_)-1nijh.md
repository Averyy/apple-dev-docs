# init(_:)

**Framework**: Swift  
**Kind**: init  
**Role**: Initializer  
**Required**: Yes

Creates a new instance from the given value, rounded to the closest possible representation.

**Availability**:
- macOS 10.10+

## Declaration

```swift
init(_ value: Float80)
```

## Parameters
