# OrgDevice

**Framework**: AppleSchoolManagerAPI  
**Kind**: dictionary  
**Role**: Object

The data structure that represents an organization device resource.

**Availability**:
- Apple School Manager API 1.8+

## Declaration

```
object OrgDevice
```

## Topics

### Dictionaries
- [object OrgDevice.Attributes](./orgdevice/attributes-data.dictionary.md)
  Attributes that describe an organization device resource.
- [object OrgDevice.Relationships](./orgdevice/relationships-data.dictionary.md)
  The relationships you include in the request, and those that you can operate on.

## Properties

- `attributes` (OrgDevice.Attributes): The resource’s attributes.
- `id` (string) *(required)*: The opaque resource ID that uniquely identifies the resource.
- `links` (ResourceLinks): Navigational links that include the self-link.
- `relationships` (OrgDevice.Relationships): Navigational links to related data and included resource types and IDs.
- `type` (string) *(required)*: The resource type.

  **Allowed Values**: `orgDevices`
