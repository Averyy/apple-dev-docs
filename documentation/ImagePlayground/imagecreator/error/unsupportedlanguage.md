# ImageCreator.Error.unsupportedLanguage

**Framework**: Image Playground  
**Kind**: case  
**Role**: Case

**Availability**:

- iPadOS 18.4+ - Deprecated in 27.0
- Mac Catalyst 18.4+ - Deprecated in 27.0
