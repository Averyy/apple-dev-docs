# viewDidLoad()

**Framework**: Image Playground  
**Kind**: method

Called after the controller’s view is loaded into memory.

**Availability**:
- iOS 18.1+
- iPadOS 18.1+
- Mac Catalyst 18.1+
- macOS 15.1+
- visionOS 2.4+

## Declaration

```swift
@MainActor
@preconcurrency override dynamic func viewDidLoad()
```

#### Discussion

The view controller uses this method to configure its interface.
