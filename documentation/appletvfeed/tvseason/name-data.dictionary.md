# TvSeason.Name

**Framework**: Apple TV Feed  
**Kind**: dictionary  
**Role**: Object

A mapping of locale to localized names for the TV season.

**Availability**:
- AppleTVFeed 1.0+

## Declaration

```
object TvSeason.Name
```

## Properties

- `locale` (string): The locale in IETF language tag format, or `default` to indicate the default value.
- `name` (string): The localized name of the content.
