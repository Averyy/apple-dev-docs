# SportingEvent.LeagueAbbreviation

**Framework**: Apple TV Feed  
**Kind**: dictionary  
**Role**: Object

A mapping of locale to localized abbreviations for the league of the sporting event.

**Availability**:
- AppleTVFeed 1.0+

## Declaration

```
object SportingEvent.LeagueAbbreviation
```

## Properties

- `leagueAbbreviation` (string): The localized abbreviation of the league.
- `locale` (string): The locale in IETF language tag format, or `default` to indicate the default value.
