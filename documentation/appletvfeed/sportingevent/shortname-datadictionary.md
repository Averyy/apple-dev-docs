# SportingEvent.ShortName

**Framework**: Apple TV Feed  
**Kind**: dictionary

A mapping of locale to localized short versions of the sporting event name.

**Availability**:
- AppleTVFeed 1.0+

## Declaration

```swift
object SportingEvent.ShortName
```

## Properties

- `locale` (string): The locale in IETF language tag format, or `default` to indicate the default value.
- `shortName` (string): The localized short name of the event.
