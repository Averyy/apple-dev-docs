# TvShow.Artworks.Artwork

**Framework**: Apple TV Feed  
**Kind**: dictionary  
**Role**: Object

The artwork related to this content.

## Declaration

```
object TvShow.Artworks.Artwork
```

## Properties

- `artworkType` (string): The type of artwork, for example, `cover_artwork_horizontal`, `cover_artwork_vertical`, or `centered_background`.
- `height` (integer): The height of the artwork.
- `url` (string): The URL to view the artwork.
- `width` (integer): The width of the artwork.
