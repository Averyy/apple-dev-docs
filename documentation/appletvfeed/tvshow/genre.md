# TvShow.Genre

**Framework**: Apple TV Feed  
**Kind**: dictionary

A genre name and its structure.

**Availability**:
- AppleTVFeed 1.0+

## Declaration

```swift
object TvShow.Genre
```

## Properties

- `name` (string): The name of the genre.
- `path` ([string]): A list of genres in hierarchical order. Each item in the list is a subgenre of the previous item.
