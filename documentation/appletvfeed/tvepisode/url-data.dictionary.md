# TvEpisode.Url

**Framework**: Apple TV Feed  
**Kind**: dictionary  
**Role**: Object

A mapping of locale to localized URLs for the content.

**Availability**:
- AppleTVFeed 1.0+

## Declaration

```
object TvEpisode.Url
```

## Properties

- `locale` (string): The locale in IETF language tag format, or `default` to indicate the default value.
- `url` (string): A localized URL for the content.
