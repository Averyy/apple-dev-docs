# capture()

**Framework**: Game Controller  
**Kind**: method  
**Role**: Instance Method

Returns a snapshot of the racing wheel with its current element values.

**Availability**:
- Mac Catalyst 16.0+
- macOS 13.0+

## Declaration

```swift
func capture() -> GCRacingWheel
```

```objc
- (GCRacingWheel *) capture;
```

#### Return Value

A snapshot of the racing wheel.
