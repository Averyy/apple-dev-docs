# isHidden

**Framework**: Game Controller  
**Kind**: property  
**Role**: Instance Property

A Boolean value that determines whether the virtual controller hides the element.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
