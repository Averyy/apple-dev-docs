# mouseInput

**Framework**: Game Controller  
**Kind**: property  
**Role**: Instance Property

The controller profile for the mouse device.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+

## Declaration

```swift
var mouseInput: GCMouseInput? { get }
```

```objc
@property (nonatomic, strong, readonly, nullable) GCMouseInput * mouseInput;
```

#### Discussion

Get the mouse’s current state, and input values for its buttons and scroll wheel, from this object.
