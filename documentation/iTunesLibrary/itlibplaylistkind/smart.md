# ITLibPlaylistKind.smart

**Framework**: iTunes Library  
**Kind**: case

A playlist with contents that iTunes generates by evaluating a set of rules, such as *90s Music* or *Songs from 1999*.

**Availability**:
- Mac Catalyst 14.0+
- macOS 10.13+

## Declaration

```swift
case smart
```
