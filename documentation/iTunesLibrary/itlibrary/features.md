# features

**Framework**: iTunes Library  
**Kind**: property  
**Role**: Instance Property

A bitwise OR combination of the features of this library.

**Availability**:
- Mac Catalyst 14.0+
- macOS 10.13+

> **Deprecated**: Apple has deprecated this property and will remove it in future versions of the framework.
