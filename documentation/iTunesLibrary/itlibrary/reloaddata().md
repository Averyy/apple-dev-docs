# reloadData()

**Framework**: iTunes Library  
**Kind**: method  
**Role**: Instance Method

Refreshes the data that the framework uses.

**Availability**:
- Mac Catalyst 14.0+
- macOS 10.13+

## Declaration

```swift
func reloadData() -> Bool
```

```objc
- (BOOL) reloadData;
```

#### Return Value

Returns [`true`](../../Swift/true.md) if the data reloads, or [`false`](../../Swift/false.md) if an error occurs.
