# ITLibDistinguishedPlaylistKind.kindLibraryMusicVideos

**Framework**: iTunes Library  
**Kind**: case  
**Role**: Case

The playlist contains all the music videos in the iTunes library.

**Availability**:
- Mac Catalyst 14.0+
- macOS 10.13+

## Declaration

```swift
case kindLibraryMusicVideos
```

```c
ITLibDistinguishedPlaylistKindLibraryMusicVideos
```

## Discussion

This isn’t the same as the default Music Videos Smart Playlist.
