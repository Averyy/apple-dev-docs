# ODRecordAddMember(_:_:_:)

**Framework**: Open Directory  
**Kind**: func  
**Role**: Function

Adds a record as a member of a group record.

**Availability**:
- Mac Catalyst
- macOS 10.6+

## Declaration

```swift
func ODRecordAddMember(_ group: ODRecordRef!, _ member: ODRecordRef!, _ error: UnsafeMutablePointer<Unmanaged<CFError>?>!) -> Bool
```

```c
extern bool ODRecordAddMember(ODRecordRef group, ODRecordRef member, CFErrorRef*error);
```

#### Return Value

`true` if the record is successfully added; `false` otherwise.

#### Discussion

Returns an error if `inGroup` is not a group record or if `inMember` is not of a type allowed in a group record.

## Parameters

- `group`: The group record.
- `member`: The record to add.
- `error`: An error reference for error details. Can be `NULL`.
