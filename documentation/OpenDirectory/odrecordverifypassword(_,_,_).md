# ODRecordVerifyPassword(_:_:_:)

**Framework**: Open Directory  
**Kind**: func  
**Role**: Function

Verifies a given password for a record.

**Availability**:
- Mac Catalyst
- macOS 10.6+

## Declaration

```swift
func ODRecordVerifyPassword(_ record: ODRecordRef!, _ password: CFString!, _ error: UnsafeMutablePointer<Unmanaged<CFError>?>!) -> Bool
```

```c
extern bool ODRecordVerifyPassword(ODRecordRef record, CFStringRef password, CFErrorRef*error);
```

#### Return Value

`true` if the password is valid; otherwise, `false`.

## Parameters

- `record`: The record.
- `password`: The password.
- `error`: An error reference for error details. Can be `NULL`.
