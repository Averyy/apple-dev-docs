# propertyStateWithValue:

**Framework**: Core Media I/O  
**Kind**: method  
**Role**: Type Method

Returns a new property state with a value.

**Availability**:
- Mac Catalyst 15.4+
- macOS 12.3+

## Declaration

```objc
+ (instancetype) propertyStateWithValue:(ObjectType) value;
```

#### Return Value

A new property state.

## Parameters

- `value`: The value to associate with the property state.
