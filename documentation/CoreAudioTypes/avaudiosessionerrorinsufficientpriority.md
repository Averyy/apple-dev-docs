# AVAudioSessionErrorInsufficientPriority

**Framework**: Core Audio Types  
**Kind**: var  
**Role**: Global Variable

An error code that indicates the app isn’t allowed to set the audio category because it’s in use by another app.

**Availability**:
- iOS 7.0+ - Deprecated in 12.0 (renamed: AVAudioSession.ErrorCode.insufficientPriority)
- iPadOS 7.0+ - Deprecated in 12.0 (renamed: AVAudioSession.ErrorCode.insufficientPriority)
- Mac Catalyst 13.1+ - Deprecated in 13.1 (renamed: AVAudioSession.ErrorCode.insufficientPriority)

- visionOS 1.0+ - Deprecated in 1.0 (renamed: AVAudioSession.ErrorCode.insufficientPriority)
