# COREAUDIOTYPES_VERSION

**Framework**: Core Audio Types  
**Kind**: var  
**Role**: Global Variable

- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.5+
- tvOS 9.0+
