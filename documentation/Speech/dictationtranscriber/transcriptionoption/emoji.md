# DictationTranscriber.TranscriptionOption.emoji

**Framework**: Speech  
**Kind**: case  
**Role**: Case

Transcribes named emoji as emoji.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- visionOS 26.0+

## Declaration

```swift
case emoji
```

## Discussion

If included, the spoken phrase “smiling emoji” would be transcribed as “🙂”.
