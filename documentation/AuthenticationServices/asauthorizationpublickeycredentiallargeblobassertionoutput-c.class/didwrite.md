# didWrite

**Framework**: Authentication Services  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether a write operation for a large binary object succeeds.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- visionOS 1.0+
