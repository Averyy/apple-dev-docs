# ASImportableCredential.GeneratedPassword

**Framework**: Authentication Services  
**Kind**: struct  
**Role**: Structure

A representation of GeneratedPassword as defined in the [Credential Exchange Format (CXF) specs](https://fidoalliance.org/specs/cx/cxf-v1.0-rd-20250313.html) This represents a machine-generated password.
