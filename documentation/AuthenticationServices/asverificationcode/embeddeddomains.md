# embeddedDomains

**Framework**: Authentication Services  
**Kind**: property

Embedded page or frame domains. For domain-bound codes, this array contains all the domains specified after the code field.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
