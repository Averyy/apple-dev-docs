# id

**Framework**: Authentication Services  
**Kind**: property  
**Role**: Instance Property

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- visionOS 26.0+

## Declaration


## Discussion

The editable field doesn’t display this value to someone using the app.
