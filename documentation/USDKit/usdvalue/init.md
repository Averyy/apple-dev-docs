# init(_:)

**Framework**: USDKit  
**Kind**: init

Creates a value wrapping `value`.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init<T>(_ value: T) where T : USDValueProtocol
```

## Parameters

- `value`: A value of any type that conforms to [`USDValueProtocol`](usdvalueprotocol.md).
