# init(displayName:loadingPayloads:)

**Framework**: USDKit  
**Kind**: init

Creates a new memory-backed stage.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init(displayName: String? = nil, loadingPayloads: USDStage.InitialLoadRule = .all)
```

#### Discussion

This is analogous to creating an anonymous `SdfLayer`.
