# init(namespaceComponents:)

**Framework**: USDKit  
**Kind**: init

Creates a namespaced token by joining `components` with `:`.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init(namespaceComponents: [USDToken])
```

## Parameters

- `namespaceComponents`: The namespace components to join.
