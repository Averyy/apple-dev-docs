# reload()

**Framework**: USDKit  
**Kind**: method

Reloads the stage’s layers from their sources, discarding any unsaved changes.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+
