# hasAuthoredMetadata(_:keyPath:)

**Framework**: USDKit  
**Kind**: method

Returns a Boolean value that indicates whether the dictionary-valued metadata for the given key has an authored value at `keyPath`.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
