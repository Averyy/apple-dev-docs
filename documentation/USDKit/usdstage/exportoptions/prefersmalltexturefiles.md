# preferSmallTextureFiles

**Framework**: USDKit  
**Kind**: property

Reduce textures’ file size at the standard quality level.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
static var preferSmallTextureFiles: USDStage.ExportOptions { get }
```

#### Discussion

This is the same as `preferSmallTextureFiles(quality: .standard)`.
