# init(_:)

**Framework**: USDKit  
**Kind**: init

Narrows an untyped [`USDLayer.Spec`](usdlayer/spec.md) to a variant set spec.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init?(_ spec: USDLayer.Spec)
```

#### Return Value

A variant set spec, or `nil` if `spec` is not a variant set spec.

## Parameters

- `spec`: The spec to narrow.
