# init(owner:name:)

**Framework**: USDKit  
**Kind**: init

Creates a new variant set spec under the given prim spec.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init?(owner: USDPrim.Spec, name: USDToken)
```

## Parameters

- `owner`: The prim spec that owns the new variant set.
- `name`: The variant set’s name.
