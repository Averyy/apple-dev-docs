# init(owner:name:)

**Framework**: USDKit  
**Kind**: init

Creates a new variant set spec nested inside a variant spec.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init?(owner: USDPrim.VariantSpec, name: USDToken)
```

## Parameters

- `owner`: The variant spec that owns the new (nested) variant set.
- `name`: The variant set’s name.
