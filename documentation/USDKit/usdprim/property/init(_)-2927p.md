# init(_:)

**Framework**: USDKit  
**Kind**: init

Casts an object handle to a property handle.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+

- tvOS 27.0+

## Declaration

```swift
init?(_ object: USDStage.Object)
```

#### Discussion

Returns `nil` if the object is not an attribute or a relationship.
