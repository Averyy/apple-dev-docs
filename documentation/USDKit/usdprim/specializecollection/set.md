# set(_:)

**Framework**: USDKit  
**Kind**: method

Replaces all specializes arcs with the specified list.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
func set(_ primPaths: [USDLayer.Path]) throws
```

#### Discussion

> **Note**: An error if the specializes cannot be set.

## Parameters

- `primPaths`: The new list of specializes paths.
