# remove(_:)

**Framework**: USDKit  
**Kind**: method

Removes a specific specializes arc from the prim.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
func remove(_ primPath: USDLayer.Path) throws
```

#### Discussion

> **Note**: An error if the specializes cannot be removed.

## Parameters

- `primPath`: The path of the specializes to remove.
