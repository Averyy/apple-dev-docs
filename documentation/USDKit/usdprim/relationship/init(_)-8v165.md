# init(_:)

**Framework**: USDKit  
**Kind**: init

Casts a property handle to a relationship handle.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init?(_ object: USDPrim.Property)
```

#### Discussion

Returns `nil` if the property is not a relationship.
