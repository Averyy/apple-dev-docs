# rename(to:)

**Framework**: USDKit  
**Kind**: method

Sets the relationship’s name.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
func rename(to name: USDToken) throws
```

#### Discussion

> **Note**: An error if the new name is invalid or already used by a sibling.

## Parameters

- `name`: The new name to assign.
