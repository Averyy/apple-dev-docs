# noLoadHint

**Framework**: USDKit  
**Kind**: property

Hint to the runtime to skip loading payloads on targeted prims. Default: `false`.

**Availability**:

- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
