# set(_:)

**Framework**: USDKit  
**Kind**: method

Replaces all payload arcs with the specified list.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
func set(_ payloads: [USDPrim.Payload]) throws
```

#### Discussion

> **Note**: An error if the payloads cannot be set.

## Parameters

- `payloads`: The new list of payloads.
