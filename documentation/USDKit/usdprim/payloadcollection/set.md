# set(_:)

**Framework**: USDKit  
**Kind**: method

Replaces all payload arcs with the specified list.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
func set(_ payloads: [USDPrim.Payload]) throws
```

#### Discussion

> **Note**: An error if the payloads cannot be set.

## Parameters

- `payloads`: The new list of payloads.
