# setCustomData(_:to:)

**Framework**: USDKit  
**Kind**: method

Sets `key` in `customData` to `value`.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
mutating func setCustomData(_ key: String, to value: USDValue)
```

## Parameters

- `key`: The dictionary key.
- `value`: The new value.
