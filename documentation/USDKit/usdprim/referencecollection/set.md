# set(_:)

**Framework**: USDKit  
**Kind**: method

Replaces all reference arcs with the specified list.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
func set(_ references: [USDPrim.Reference]) throws
```

#### Discussion

> **Note**: An error if the references cannot be set.

## Parameters

- `references`: The new list of references.
