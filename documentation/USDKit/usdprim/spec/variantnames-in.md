# variantNames(in:)

**Framework**: USDKit  
**Kind**: method

Returns the variant names available in the given variant set.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
func variantNames(in setName: USDToken) -> [USDToken]
```

#### Return Value

The variant names defined in `setName`.

## Parameters

- `setName`: The variant set name.
