# init(_:)

**Framework**: USDKit  
**Kind**: init

Narrows an untyped [`USDLayer.Spec`](usdlayer/spec.md) to a `USDPrim.Spec`.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init?(_ spec: USDLayer.Spec)
```

#### Discussion

Returns `nil` if `spec` is not a prim spec.
