# init(layer:primPath:)

**Framework**: USDKit  
**Kind**: init

Creates a prim spec at the given path in the layer, authoring intermediate ancestor prim specs as `over`s where needed.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
