# childrenOrder

**Framework**: USDKit  
**Kind**: property

The authored override for child ordering, or `nil` if no order is authored. When non-nil, this list controls the order in which child prim specs appear during composition.

**Availability**:

- iPadOS 27.0+
- Mac Catalyst 27.0+
