# isValidName(_:)

**Framework**: USDKit  
**Kind**: method

Returns a Boolean value that indicates whether `name` is a valid prim name.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
static func isValidName(_ name: USDToken) -> Bool
```

#### Return Value

`true` if `name` is a valid prim name; otherwise, `false`.

## Parameters

- `name`: The candidate name.
