# setSymmetryArgument(_:to:)

**Framework**: USDKit  
**Kind**: method

**Availability**:

- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)

## Declaration

```swift
func setSymmetryArgument(_ name: String, to value: USDValue)
```

## Parameters

- `name`: The argument name.
- `value`: The new value.
