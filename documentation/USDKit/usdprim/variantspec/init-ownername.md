# init(owner:name:)

**Framework**: USDKit  
**Kind**: init

Creates a new variant spec under the given variant set spec.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init?(owner: USDPrim.VariantSetSpec, name: USDToken)
```

## Parameters

- `owner`: The variant set that owns the new variant.
- `name`: The variant’s name.
