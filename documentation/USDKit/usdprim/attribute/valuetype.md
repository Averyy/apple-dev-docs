# USDPrim.Attribute.ValueType

**Framework**: USDKit  
**Kind**: struct

A type that describes the kind of value an attribute can store, such as `float3` or `token[]`.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
