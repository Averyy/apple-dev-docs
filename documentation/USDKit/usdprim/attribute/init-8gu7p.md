# init(_:)

**Framework**: USDKit  
**Kind**: init

Casts an object handle to an attribute handle.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init?(_ object: USDStage.Object)
```

#### Discussion

Returns `nil` if the object is not an attribute.
