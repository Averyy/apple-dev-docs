# colorSpace

**Framework**: USDKit  
**Kind**: property

The authored color space, or `nil` if not authored. Assigning `nil` clears the color space.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+
