# rename(to:)

**Framework**: USDKit  
**Kind**: method

Sets the attribute’s name.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
func rename(to name: USDToken) throws
```

#### Discussion

> **Note**: An error if the new name is invalid or already used by a sibling.

## Parameters

- `name`: The new name to assign.
