# isGroup

**Framework**: USDKit  
**Kind**: property

Returns true if this prim’s kind metadata identifies it as a model group.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
static var isGroup: USDPrim.Predicate { get }
```

#### Discussion

If this prim is a model group, it is always a model.
