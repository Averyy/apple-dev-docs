# add(_:)

**Framework**: USDKit  
**Kind**: method

Adds a new variant to this variant set.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
func add(_ variantName: String) throws
```

#### Discussion

> **Note**: An error if the variant cannot be added.

## Parameters

- `variantName`: The name of the variant to add.
