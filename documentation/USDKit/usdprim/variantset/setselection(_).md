# setSelection(_:)

**Framework**: USDKit  
**Kind**: method

Sets the variant selection.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
func setSelection(_ variantName: String) throws
```

#### Discussion

> **Note**: An error if the selection cannot be set.

## Parameters

- `variantName`: The name of the variant to select.
