# blockSelection()

**Framework**: USDKit  
**Kind**: method  
**Role**: Instance Method

Blocks the variant selection by authoring an explicit empty value on the current edit target.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
func blockSelection() throws
```

#### Discussion

> **Throws**: An error if the selection cannot be blocked.
