# blockSelection()

**Framework**: USDKit  
**Kind**: method

Blocks the variant selection by authoring an explicit empty value on the current edit target.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
func blockSelection() throws
```

#### Discussion

> **Note**: An error if the selection cannot be blocked.
