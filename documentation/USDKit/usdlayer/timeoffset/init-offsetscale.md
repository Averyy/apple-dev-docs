# init(offset:scale:)

**Framework**: USDKit  
**Kind**: init

Creates a time offset with the given shift and scale.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init(offset: Double = 0.0, scale: Double = 1.0)
```

## Parameters

- `offset`: The time shift applied during composition.
- `scale`: The scale factor applied during composition.
