# items(for:)

**Framework**: USDKit  
**Kind**: method

Returns the items in the given operation’s slot.

**Availability**:

- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)

## Declaration

```swift
func items(for operation: USDLayer.ListOperationType) -> [T]
```

#### Return Value

The items authored in `operation`’s slot.

## Parameters

- `operation`: The slot to read.
