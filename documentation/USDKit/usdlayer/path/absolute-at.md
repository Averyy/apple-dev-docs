# absolute(at:)

**Framework**: USDKit  
**Kind**: method

Returns this path made absolute, anchored at the given path.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
func absolute(at anchor: USDLayer.Path) -> USDLayer.Path
```

#### Return Value

An absolute version of this path.

## Parameters

- `anchor`: The absolute path to use as the anchor.
