# commonPrefix(with:)

**Framework**: USDKit  
**Kind**: method

Returns the longest common ancestor path of this path and `other`.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
func commonPrefix(with other: USDLayer.Path) -> USDLayer.Path
```

#### Return Value

The longest path that is a prefix of both.

## Parameters

- `other`: The path to compare against.
