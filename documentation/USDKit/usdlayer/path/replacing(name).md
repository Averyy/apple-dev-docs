# replacing(name:)

**Framework**: USDKit  
**Kind**: method

Returns a new path with the leaf name replaced.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
func replacing(name newName: USDToken) -> USDLayer.Path
```

#### Return Value

A new path with `newName` as its leaf.

## Parameters

- `newName`: The new leaf name.
