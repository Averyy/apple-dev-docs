# replacing(name:)

**Framework**: USDKit  
**Kind**: method

Returns a new path with the leaf name replaced.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
func replacing(name newName: USDToken) -> USDLayer.Path
```

#### Return Value

A new path with `newName` as its leaf.

## Parameters

- `newName`: The new leaf name.
