# init(_:resolvedPath:)

**Framework**: USDKit  
**Kind**: init

Creates an asset path with both authored and resolved values.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init(_ path: String, resolvedPath: String)
```

## Parameters

- `path`: The authored path string.
- `resolvedPath`: The resolved location after asset resolution.
