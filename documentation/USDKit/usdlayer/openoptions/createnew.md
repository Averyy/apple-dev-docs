# createNew

**Framework**: USDKit  
**Kind**: property

Creates a new layer instead of opening an existing file. Any existing file at the identifier will be overwritten.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
