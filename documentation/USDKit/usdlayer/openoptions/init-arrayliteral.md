# init(arrayLiteral:)

**Framework**: USDKit  
**Kind**: init

Creates an option set from a sequence of options.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init(arrayLiteral elements: USDLayer.OpenOptions...)
```

## Parameters

- `elements`: The options to include in the set.
