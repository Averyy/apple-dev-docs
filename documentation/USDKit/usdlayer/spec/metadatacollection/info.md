# info(_:)

**Framework**: USDKit  
**Kind**: method

Returns the value of `key`, or `nil` if the key is unauthored.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
func info(_ key: USDToken) -> USDValue?
```

#### Return Value

The authored value, or `nil` if unauthored.

## Parameters

- `key`: The info key to look up.
