# info(_:)

**Framework**: USDKit  
**Kind**: method

Returns the value of `key`, or `nil` if the key is unauthored.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
func info(_ key: USDToken) -> USDValue?
```

#### Return Value

The authored value, or `nil` if unauthored.

## Parameters

- `key`: The info key to look up.
