# init(_:)

**Framework**: USDKit  
**Kind**: init

Widens a `USDPrim.PseudoRootSpec` into an untyped [`USDLayer.Spec`](usdlayer/spec.md).

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init(_ pseudoRootSpec: USDPrim.PseudoRootSpec)
```

## Parameters

- `pseudoRootSpec`: The pseudo-root spec to widen.
