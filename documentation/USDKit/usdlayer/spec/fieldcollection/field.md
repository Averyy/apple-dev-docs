# field(_:)

**Framework**: USDKit  
**Kind**: method

Returns the value of `name`, or `nil` if the field is unauthored.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
func field(_ name: USDToken) -> USDValue?
```

#### Return Value

The field’s value, or `nil` if unauthored.

## Parameters

- `name`: The field name to look up.
