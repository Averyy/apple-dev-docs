# field(_:)

**Framework**: USDKit  
**Kind**: method

Returns the value of `name`, or `nil` if the field is unauthored.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
func field(_ name: USDToken) -> USDValue?
```

#### Return Value

The field’s value, or `nil` if unauthored.

## Parameters

- `name`: The field name to look up.
