# setField(_:to:)

**Framework**: USDKit  
**Kind**: method

Sets the field `name` to `value`.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
@discardableResult
func setField(_ name: USDToken, to value: USDValue) -> Bool
```

#### Return Value

`true` on success.

## Parameters

- `name`: The field name.
- `value`: The new value.
