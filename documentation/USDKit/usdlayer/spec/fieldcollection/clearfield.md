# clearField(_:)

**Framework**: USDKit  
**Kind**: method

Clears the authored value for `name`.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
@discardableResult
func clearField(_ name: USDToken) -> Bool
```

#### Return Value

`true` if the field had been authored.

## Parameters

- `name`: The field name to clear.
