# init(vasMerchants:)

**Framework**: ProximityReader  
**Kind**: init  
**Role**: Initializer

Creates a new options structure with the specified list of merchants.

**Availability**:
- iOS 15.4+ - Deprecated in 18.0
- iPadOS 15.4+ - Deprecated in 18.0
- Mac Catalyst 17.0+ - Deprecated in 18.0

> **Deprecated**: Use the init without vasMerchants

## Declaration

```swift
init(vasMerchants: [VASRequest.Merchant] = [])
```

## Parameters

- `vasMerchants`: An array of merchants with supported loyalty cards.
