# summaryLines

**Framework**: ProximityReader  
**Kind**: property

An array of label-value pairs listing taxes, discounts, or other cart-level entries in the summary. These entries apply to the entire cart rather than individual line items.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
