# MobileDocumentReader

**Framework**: ProximityReader  
**Kind**: class  
**Role**: Class

An object for configuring mobile document reading on the current device.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+

## Declaration

```swift
final class MobileDocumentReader
```

## Mentions

- [Adopting the Verifier API in your iPhone app](./adopting-the-verifier-api-in-your-iphone-app.md)

## Overview

After creating the `MobileDocumentReader` object, call [`prepare(using:)`](./mobiledocumentreader/prepare%28using%29.md) to prepare the device for mobile document reading. Use the returned [`MobileDocumentReaderSession`](./mobiledocumentreadersession.md) object to read mobile documents.

You can optionally display your brand’s name and logo during a mobile document read. To do this, your server needs to generate a reader token, then pass the token as an argument to the [`prepare(using:)`](./mobiledocumentreader/prepare%28using%29.md) method.
