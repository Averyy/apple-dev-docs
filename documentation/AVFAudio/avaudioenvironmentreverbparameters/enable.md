# enable

**Framework**: AVFAudio  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether reverberation is in an enabled state.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.10+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
var enable: Bool { get set }
```

```objc
@property (nonatomic) BOOL enable;
```

## Discussion

The default value is [`false`](../../Swift/false.md).
