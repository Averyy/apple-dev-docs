# up

**Framework**: AVFAudio  
**Kind**: property  
**Role**: Instance Property

The up vector is orthogonal to the forward vector and points upward from the listener’s head.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
