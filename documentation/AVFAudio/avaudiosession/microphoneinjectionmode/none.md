# AVAudioSession.MicrophoneInjectionMode.none

**Framework**: AVFAudio  
**Kind**: case  
**Role**: Case

A mode that indicates not to use spoken audio injection.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS
- watchOS

## Declaration

```swift
case none
```

```c
AVAudioSessionMicrophoneInjectionModeNone
```

#### Discussion

This is the default mode.
