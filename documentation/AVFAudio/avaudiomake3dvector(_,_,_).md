# AVAudioMake3DVector(_:_:_:)

**Framework**: AVFAudio  
**Kind**: func  
**Role**: Function

Creates a vector in 3D space, in degrees.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
func AVAudioMake3DVector(_ x: Float, _ y: Float, _ z: Float) -> AVAudio3DVector
```

```c
static AVAudio3DVector AVAudioMake3DVector(float x, float y, float z);
```

#### Return Value

A new [`AVAudio3DVector`](./avaudio3dvector.md) instance.

## Parameters

- `x`: The x position of the vector.
- `y`: The y position of the vector.
- `z`: The z position of the vector.
