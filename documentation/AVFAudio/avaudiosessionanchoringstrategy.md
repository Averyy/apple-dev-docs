# AVAudioSessionAnchoringStrategy

**Framework**: AVFAudio  
**Kind**: enum  
**Role**: Enumeration

Constants that specify how to set the origin of audio in a head-tracked spatial experience.

**Availability**:
- visionOS

## Declaration

```c
enum AVAudioSessionAnchoringStrategy : NSInteger;
```
