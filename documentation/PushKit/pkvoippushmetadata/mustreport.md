# mustReport

**Framework**: PushKit  
**Kind**: property

A boolean indicating whether a VoIP app must report a call or live conversation in response to receiving this VoIP notification.

**Availability**:
- iOS 26.4+ (Beta)
- iPadOS 26.4+ (Beta)
- Mac Catalyst 26.4+ (Beta)
- macOS 26.4+ (Beta)
- visionOS 26.4+ (Beta)
- watchOS 26.4+ (Beta)
