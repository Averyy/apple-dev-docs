# AVKitError.Code.contentDisallowedByPasscode

**Framework**: AVKit  
**Kind**: case  
**Role**: Case

A restriction disallows access to this content, but the user can override the restriction by entering the device passcode.

**Availability**:
- tvOS 13.0+
