# AVInterfaceMetadata.MediaMode.video(presentationSize:)

**Framework**: AVKit  
**Kind**: case

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)

## Declaration

```swift

```

## Parameters

- `presentationSize`: The natural pixel dimensions of the video content, used for aspect ratio calculations and layout.
