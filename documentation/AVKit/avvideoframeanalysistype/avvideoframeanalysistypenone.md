# AVVideoFrameAnalysisTypeNone

**Framework**: AVKit  
**Kind**: case  
**Role**: Enumeration Case

A type that performs no analysis.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- visionOS 1.0+
