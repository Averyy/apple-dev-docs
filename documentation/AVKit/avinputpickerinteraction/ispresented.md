# isPresented

**Framework**: AVKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the picker is currently visible.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+

## Declaration

```swift
var isPresented: Bool { get }
```

```objc
@property (nonatomic, readonly, getter=isPresented) BOOL presented;
```
