# MTLDataType.bfloat4

**Framework**: Metal  
**Kind**: case  
**Role**: Case

A four-component vector with 16-bit, brain floating-point values.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```swift
case bfloat4
```

```c
MTLDataTypeBFloat4
```

#### Discussion

Each 16-bit value stores one sign bit, eight exponent bits, and seven mantissa bits.
