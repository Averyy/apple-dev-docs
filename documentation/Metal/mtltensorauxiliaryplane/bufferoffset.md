# bufferOffset

**Framework**: Metal  
**Kind**: property  
**Required**: Yes

The byte offset into [`buffer`](mtltensorauxiliaryplane/buffer.md) where this plane’s data begins, or `0` if no buffer was provided at initialization.

**Availability**:
