# vertexDescriptor

**Framework**: Metal  
**Kind**: method  
**Role**: Type Method

Creates and returns a new vertex descriptor.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.11+
- tvOS
- visionOS 1.0+

## Declaration

```objc
+ (MTLVertexDescriptor *) vertexDescriptor;
```

## Return Value

A default object with allocated arrays in the [`attributes`](./attributes.md) and [`layouts`](./layouts.md) properties.
