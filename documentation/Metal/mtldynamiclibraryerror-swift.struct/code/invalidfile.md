# MTLDynamicLibraryError.Code.invalidFile

**Framework**: Metal  
**Kind**: case  
**Role**: Case

An error code that indicates an app is using an invalid reference to a library file, typically related to a URL.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+

## Declaration

```swift
case invalidFile
```
