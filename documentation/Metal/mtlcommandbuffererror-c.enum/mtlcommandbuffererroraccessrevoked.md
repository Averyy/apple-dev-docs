# MTLCommandBufferErrorAccessRevoked

**Framework**: Metal  
**Kind**: case  
**Role**: Enumeration Case

An error code that indicates the system has revoked the Metal device’s access because it’s responsible for too many timeouts or hangs.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.11+
- tvOS
- visionOS 1.0+
