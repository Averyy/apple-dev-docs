# MTLGPUFamily.apple3

**Framework**: Metal  
**Kind**: case  
**Role**: Case

Represents the Apple family 3 GPU features that correspond to the Apple A9 and A10 GPUs.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- macOS 10.15+
- tvOS 13.0+
- visionOS 1.0+

## Declaration

```swift
case apple3
```

```c
MTLGPUFamilyApple3
```
