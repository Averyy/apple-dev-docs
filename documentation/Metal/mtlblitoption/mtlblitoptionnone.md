# MTLBlitOptionNone

**Framework**: Metal  
**Kind**: case  
**Role**: Enumeration Case

A blit option that clears other blit options, which removes any optional behavior for a blit operation.

**Availability**:
- iOS 9.0+
- iPadOS 9.0+
- Mac Catalyst 13.1+
