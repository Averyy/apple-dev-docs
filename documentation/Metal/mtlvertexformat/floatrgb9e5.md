# MTLVertexFormat.floatRGB9E5

**Framework**: Metal  
**Kind**: case

A three-component vector with 9-bit floating-point values for red, green, and blue, and a 5-bit shared exponent.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```swift
case floatRGB9E5
```

#### Discussion

The red, green, and blue components each have 9 bits, and the shared exponent has 5 bits.
