# MTLBinaryArchiveError.Code.internalError

**Framework**: Metal  
**Kind**: case  
**Role**: Case

An error code that indicates the Metal framework has an internal problem.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
- tvOS 16.0+
- visionOS 1.0+
