# MTLLogicalToPhysicalColorAttachmentMap

**Framework**: Metal  
**Kind**: class  
**Role**: Class

Allows you to easily specify color attachment remapping from logical to physical indices.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- tvOS 26.0+
