# MTLCompareFunction.equal

**Framework**: Metal  
**Kind**: case  
**Role**: Case

A new value passes the comparison test if it is equal to the existing value.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.11+
- tvOS
- visionOS 1.0+
