# MTLAttributeFormat.floatRGB9E5

**Framework**: Metal  
**Kind**: case

One packed 32-bit value representing pixel data containing 9-bit float red, green, and blue channels, and a 5-bit float shared exponent channel.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```swift
case floatRGB9E5
```

#### Discussion

This data format is identical to [`MTLPixelFormat.rgb9e5Float`](mtlpixelformat/rgb9e5float.md), and used in compute functions for manipulating pixels.
