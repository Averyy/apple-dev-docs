# Delete a BundleId

**Framework**: Enterprise Program API  
**Kind**: httpRequest

Delete a bundle ID that is used for app development.

## Endpoint

`DELETE https://api.enterprise.developer.apple.com/v1/bundleIds/{id}`

## Parameters

- `id` (string) *(required)*
