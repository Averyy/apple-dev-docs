# Modify a Registered Device

**Framework**: Enterprise Program API  
**Kind**: httpRequest

Update the name or status of a specific device.

#### Overview

- HTTPBody

## Endpoint

`PATCH https://api.enterprise.developer.apple.com/v1/devices/{id}`

## Parameters

- `id` (string) *(required)*
