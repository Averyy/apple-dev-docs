# List Devices

**Framework**: Enterprise Program API  
**Kind**: httpRequest

Find and list devices registered to your team.

## Endpoint

`GET https://api.enterprise.developer.apple.com/v1/devices`

## Parameters

- `fields[devices]` ([string])
- `filter[id]` ([string])
- `filter[name]` ([string])
- `filter[platform]` ([string])
- `filter[status]` ([string])
- `filter[udid]` ([string])
- `limit` (integer)
- `sort` ([string])
