# supportedScaleFactorsForFrameWidth:frameHeight:

**Framework**: Video Toolbox  
**Kind**: method  
**Role**: Type Method

Returns an array of supported scale factors values, or an empty list if the processor doesn’t support the dimensions.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- tvOS 26.0+
- visionOS 26.0+
