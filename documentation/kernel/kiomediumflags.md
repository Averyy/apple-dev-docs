# kIOMediumFlags

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

A property of IONetworkMedium objects.

**Availability**:
- macOS 10.0+

## Declaration

```c
#define kIOMediumFlags
```

## Discussion

The kIOMediumFlags property is an OSNumber object that describes a set of attributes assigned to the medium.
