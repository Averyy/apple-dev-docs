# MBUF_CSUM_REQ_TCPIPV6

**Framework**: Kernel  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- macOS 10.12+

## Declaration

```c
MBUF_CSUM_REQ_TCPIPV6 = 0x0020
```

## Discussion

Indicates the TCP checksum for IPv6 has not been calculated yet.
