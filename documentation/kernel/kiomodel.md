# kIOModel

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

A property of IONetworkController objects.

**Availability**:
- macOS 10.0+

## Declaration

```c
#define kIOModel
```

## Discussion

The kIOModel property is a property of IONetworkController objects. It has an OSString value that describes the model of the network controller.
