# MBUF_BCAST

**Framework**: Kernel  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- macOS 10.12+

## Declaration

```c
MBUF_BCAST = 0x0100
```

## Discussion

Indicates this packet will be sent or was received as a brodcast.
