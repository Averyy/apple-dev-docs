# kIOAudioEngineRunning

**Framework**: Kernel  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- macOS 10.1+

## Declaration

```c
kIOAudioEngineRunning = 1
```

## Discussion

The IOAudioEngine is currently running - it is transferring data to or from the device.
