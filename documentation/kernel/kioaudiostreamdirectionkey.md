# kIOAudioStreamDirectionKey

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

The key in the IORegistry for the IOAudioStream direction attribute.

**Availability**:
- macOS 10.1+

## Declaration

```c
#define kIOAudioStreamDirectionKey
```

## Discussion

The value for this key may be either "Output" or "Input".
