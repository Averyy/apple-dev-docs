# kIOPropertySCSIVendorIdentification

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

**Availability**:
- macOS 10.0+

## Declaration

```c
#define kIOPropertySCSIVendorIdentification
```

#### Discussion

Vendor ID as reported in the INQUIRY data. Additional space characters (0x20) are truncated.
