# kIOMediaWritableKey

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

A property of IOMedia objects.

**Availability**:
- macOS 10.0+

## Declaration

```c
#define kIOMediaWritableKey
```

## Discussion

The kIOMediaWritableKey property has an OSBoolean value and describes whether the media is writable.
