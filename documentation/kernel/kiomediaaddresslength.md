# kIOMediaAddressLength

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

A property of IONetworkInterface objects.

**Availability**:
- macOS 10.0+

## Declaration

```c
#define kIOMediaAddressLength
```

## Discussion

The kIOMediaAddressLength property has an OSNumber value that specifies the size of the media address in bytes.
