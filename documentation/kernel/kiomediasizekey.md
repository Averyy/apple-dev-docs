# kIOMediaSizeKey

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

A property of IOMedia objects.

**Availability**:
- macOS 10.0+

## Declaration

```c
#define kIOMediaSizeKey
```

## Discussion

The kIOMediaSizeKey property has an OSNumber value and describes the total length of the media in bytes.
