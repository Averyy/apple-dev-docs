# Log

**Framework**: Kernel  
**Kind**: clm  
**Role**: Type Method

Log the current execution context with respect to any queues the current thread holds.

**Availability**:
- DriverKit 19.0+
- macOS 10.15.2+

## Declaration

```c
static void Log(const char *message, IODispatchLogFunction output);
```

## Parameters

- `message`: A C string that contains the message to add to the log file. 
- `output`: The function address to use for logging the content. The address of [`IOLog`](../api-1575337-iolog.md) is suitable for use.
