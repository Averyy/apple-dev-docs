# kIORevision

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

A property of IONetworkController objects.

**Availability**:
- macOS 10.0+

## Declaration

```c
#define kIORevision
```

## Discussion

The kIORevision property is a property of IONetworkController objects. It has an OSString value that describes the revision level of the network controller.
