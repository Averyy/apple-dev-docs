# kIOCatalogModuleTerminate

**Framework**: Kernel  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- macOS 10.12+

## Declaration

```c
kIOCatalogModuleTerminate
```

## Discussion

Terminates all services which depend on a particular module but does not unload the module.
