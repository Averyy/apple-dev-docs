# kIOMaxTransferUnit

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

A property of IONetworkInterface objects.

**Availability**:
- macOS 10.0+

## Declaration

```c
#define kIOMaxTransferUnit
```

## Discussion

The kIOMaxTransferUnit property has an OSNumber value that specifies the maximum transfer unit for the interface in bytes.
