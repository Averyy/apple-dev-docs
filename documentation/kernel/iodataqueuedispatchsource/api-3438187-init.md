# init

**Framework**: Kernel  
**Kind**: instm  
**Role**: Instance Method

Handles the basic initialization of the dispatch source.

**Availability**:
- DriverKit 19.0+
- macOS 10.15.2+

## Declaration

```cpp
virtual bool init(void);
```

#### Return Value

`true` if initialization was successful, or `false` if an error occurred.

#### Discussion

Don't call this method directly. Call [`Create`](./api-3438177-create.md) when you want to create a new data-queue dispatch source.

## See Also

### Configuring the Dispatch Source
- [+ Create](./api-3438177-create.md)
  Creates a dispatch source that you use as a shared-memory data queue.
