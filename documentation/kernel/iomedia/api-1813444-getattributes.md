# getAttributes

**Framework**: Kernel  
**Kind**: instm

## Declaration

```cpp
virtual IOMediaAttributeMask getAttributes() const;
```

#### Return Value

Media attributes, such as ejectability and removability. See IOMediaAttributeMask.

#### Overview

Ask the media object for its attributes.
