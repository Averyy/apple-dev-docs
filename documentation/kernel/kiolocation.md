# kIOLocation

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

kIOLocation is a property of IONetworkInterface objects. It has an OSString value.

**Availability**:
- macOS 10.3+

## Declaration

```c
#define kIOLocation
```

#### Discussion

The kIOLocation property describes the physical location of built-in interfaces.
