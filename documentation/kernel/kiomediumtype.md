# kIOMediumType

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

A property of IONetworkMedium objects.

**Availability**:
- macOS 10.0+

## Declaration

```c
#define kIOMediumType
```

#### Discussion

The kIOMediumType property is an OSNumber object that describes the type of medium that this object represents.
