# kIOInterfaceUnit

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

A property of IONetworkInterface objects.

**Availability**:
- macOS 10.0+

## Declaration

```c
#define kIOInterfaceUnit
```

## Discussion

The kIOInterfaceUnit property has an OSNumber value that describes the unit number assigned to the interface object.
