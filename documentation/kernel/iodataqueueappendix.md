# IODataQueueAppendix

**Framework**: Kernel  
**Kind**: tdef  
**Role**: Type Alias

**Availability**:
- macOS 10.5+

## Declaration

```c
typedef struct _IODataQueueAppendix IODataQueueAppendix;
```

## Discussion

This struct is variable sized dependent on the version. The struct represents the data queue appendix information.
