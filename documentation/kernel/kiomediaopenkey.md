# kIOMediaOpenKey

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

A property of IOMedia objects.

**Availability**:
- macOS 10.5+

## Declaration

```c
#define kIOMediaOpenKey
```

## Discussion

The kIOMediaOpenKey property has an OSBoolean value and describes whether a client presently has an open on this media.
