# retain

**Framework**: Kernel  
**Kind**: instm

Retains the OSObject instance

**Availability**:
- DriverKit 19.0+
- macOS 10.15+

## Declaration

```swift
virtual void retain(void);
```

#### Discussion

Increases the retain count of the instance by one.
