# kIOAudioControlChannelNameRightRear

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

The value for the kIOAudioControlChannelNameKey in the IORegistry representing the channel name for the right rear channel.

**Availability**:
- macOS 10.1+
