# getLength

**Framework**: Kernel  
**Kind**: instm  
**Role**: Instance Method

Returns length of string not including null terminator.

**Availability**:
- DriverKit 19.0+
- macOS 10.15+

## Declaration

*DriverKit*

```cpp
size_t getLength(void);
```

*macOS*

```cpp
virtual unsigned int getLength(void);
```

#### Return Value

length of data present.
