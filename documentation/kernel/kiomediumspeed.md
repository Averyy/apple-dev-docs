# kIOMediumSpeed

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

A property of IONetworkMedium objects.

**Availability**:
- macOS 10.0+

## Declaration

```c
#define kIOMediumSpeed
```

## Discussion

The kIOMediumSpeed property is an OSNumber object that describes the maximum link speed supported by the medium in bits per second.
