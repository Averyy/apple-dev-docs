# kIOPropertySCSIProductIdentification

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

**Availability**:
- macOS 10.0+

## Declaration

```c
#define kIOPropertySCSIProductIdentification
```

#### Discussion

Product ID as reported in the INQUIRY data. Additional space characters (0x20) are truncated.
