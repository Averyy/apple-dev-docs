# init

**Framework**: Kernel  
**Kind**: instm

Initializes the IONetworkController object.

## Declaration

```cpp
virtual bool init(
 OSDictionary *properties);
```

## Return Value

Returns true on success, false otherwise.

## Overview

Instance variables are initialized, then super::init() is called.

## Parameters

- `properties`: A dictionary object containing a property table associated with this instance.
