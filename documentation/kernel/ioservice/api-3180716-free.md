# free

**Framework**: Kernel  
**Kind**: instm  
**Role**: Instance Method

Performs any final cleanup for the service.

**Availability**:
- DriverKit 19.0+
- macOS 10.15+

## Declaration

```cpp
virtual void free(void);
```

#### Discussion

Use this method to perform any final cleanup of your service, such as deallocating any memory you allocated. The system calls this method at some point after it calls your service's [`Stop`](./api-3180713-stop.md) method.

Always call `super` at the end of your custom implementation.
