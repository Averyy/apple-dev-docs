# init

**Framework**: Kernel  
**Kind**: instm

Handles the basic initialization of the service.

**Availability**:
- DriverKit 19.0+
- macOS 10.15+

## Declaration

```swift
virtual bool init(IORegistryEntry *from, const IORegistryPlane *inPlane);
```

#### Return_value

`true` if initialization was successful, or `false` if an error occurred.

#### Discussion

The system calls this method shortly after it instantiates your custom [`IOService`](https://developer.apple.com/documentation/driverkit/ioservice) subclass, and before it calls the [`Start`](ioservice/3180710-start.md) method of your service. Limit the work you do in this method to simple tasks that must occur before your service starts. For example, use this method to allocate memory for your `ivars` structure.

Always call `super` early in your implementation of this method.
