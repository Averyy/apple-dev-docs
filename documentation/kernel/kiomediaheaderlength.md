# kIOMediaHeaderLength

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

A property of IONetworkInterface objects.

**Availability**:
- macOS 10.0+

## Declaration

```c
#define kIOMediaHeaderLength
```

## Discussion

The kIOMediaHeaderLength property has an OSNumber value that specifies the size of the media header in bytes.
