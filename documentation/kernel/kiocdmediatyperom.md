# kIOCDMediaTypeROM

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

**Availability**:
- macOS 10.0+

## Declaration

```c
#define kIOCDMediaTypeROM
```

#### Discussion

The kIOCDMediaTypeKey constant for CD-ROM media (inclusive of the CD-I, CD-ROM XA, and CD Audio standards, and mixed mode combinations thereof).
