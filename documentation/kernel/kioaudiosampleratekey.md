# kIOAudioSampleRateKey

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

The key in the IORegistry for the IOAudioEngine sample rate attribute

**Availability**:
- macOS 10.1+

## Declaration

```c
#define kIOAudioSampleRateKey
```

## Discussion

This value is represented as an integer in samples per second.
