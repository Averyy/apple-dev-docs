# kIOBuiltin

**Framework**: Kernel  
**Kind**: macro  
**Role**: Macro

kIOBuiltin is a property of IONetworkInterface objects. It has an OSBoolean value.

**Availability**:
- macOS 10.3+

## Declaration

```c
#define kIOBuiltin
```

## Discussion

The kIOBuiltin property describes whether the interface is built-in.
