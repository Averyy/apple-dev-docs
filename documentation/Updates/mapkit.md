# MapKit updates

**Framework**: Updates  
**Role**: Article

Learn about important changes to MapKit.

#### Overview

Browse notable changes in [MapKit](../MapKit/MapKit.md).

#### June 2025

- Find information about a place using [`MKGeocodingRequest`](../MapKit/mkgeocodingrequest.md) and [`MKReverseGeocodingRequest`](../MapKit/mkreversegeocodingrequest.md).
- Get address information to use in displays, such as place cards and annotations you create using an MKMapItem, by using [`MKAddress`](../MapKit/mkaddress.md) with Search and reverse geocoding.
- Obtain formatted address strings for a place’s full address, city, or region using [`MKAddressRepresentations`](../MapKit/mkaddressrepresentations.md).
- Request cycling directions and ETAs using the [`cycling`](../MapKit/mkdirectionstransporttype/cycling.md) transport type.

#### June 2024

- Obtain a place identifier to track a specific location, such as a business, park, physical feature, or landmark, over its lifetime.
- Show detailed information about a point of interest across [MapKit](http://developer.apple.com/documentation/mapkit/mapkit_for_appkit_and_uikit), [MapKit for SwiftUI](../MapKit/mapkit_for_swiftui.md), and [MapKit JS](../MapKitJS/MapKitJS.md).
- Filter location results using criteria such as neighborhoods, postal codes, and municipalities.
- Use pagination to obtain significantly more results over a successive set of calls when using the [Apple Maps Server API](../AppleMapsServerAPI/AppleMapsServerAPI.md).
