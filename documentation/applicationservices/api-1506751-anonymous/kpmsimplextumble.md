# kPMSimplexTumble

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- macOS 10.0+

## Declaration

```c
kPMSimplexTumble = 0x0004
```

## Discussion

Print on only one side of the paper, but tumble the images while printing. This mode is not supported at this time.
