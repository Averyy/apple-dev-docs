# soSoundOutput

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

Get or set the speech channel’s current outputchannel.

**Availability**:
- macOS 10.0+

> **Deprecated**: Use [`soOutputToFileWithCFURL`](./sooutputtofilewithcfurl.md) instead.

## Declaration

```c
soSoundOutput = 'sndo'
```

#### Discussion

This selector works with both the `GetSpeechInfo` and `SetSpeechInfo` functions.
