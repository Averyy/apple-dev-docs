# cmEmbeddedUse

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

0 is to use anywhere, 1 is to use as embedded profile only

**Availability**:
- macOS 10.0+

## Declaration

```c
cmEmbeddedUse = 1
```
