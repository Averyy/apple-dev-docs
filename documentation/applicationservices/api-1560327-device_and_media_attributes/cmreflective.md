# cmReflective

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

If the bit 0 of the associated mask is `0` then reflective media; if `1` then transparency media.

**Availability**:
- macOS 10.0+

## Declaration

```c
cmReflective = 0
```
