# cmGlossy

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

If the bit 1 of the associated mask is `0` then glossy; if `1` then matte.

**Availability**:
- macOS 10.0+

## Declaration

```c
cmGlossy = 1
```
