# cmReadSpool

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

Directs the function to read the number of bytes specified by the `CMFlattenProcPtr` function’s `size` parameter. 

**Availability**:
- macOS 10.0+

## Declaration

```c
cmReadSpool = 3
```
