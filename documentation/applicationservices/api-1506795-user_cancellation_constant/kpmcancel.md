# kPMCancel

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

Specifies that the user clicked the Cancel button in a Print or Page Setup dialog.

**Availability**:
- macOS 10.0+

## Declaration

```c
kPMCancel = 0x0080
```
