# kSpeechErrorNewestCharacterOffset

**Framework**: Application Services  
**Kind**: data  
**Role**: Global Variable

The position in the text string of the most recent error that occurred since the last call to the [`CopySpeechProperty(_:_:_:)`](./api-1459075-copyspeechproperty.md) function with the `kSpeechErrorsProperty` property.
