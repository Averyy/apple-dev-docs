# kSpeechStatusOutputPaused

**Framework**: Application Services  
**Kind**: data  
**Role**: Global Variable

Indicates whether speech output in the speech channel has been paused by a call to the [`PauseSpeechAt(_:_:)`](./api-1461174-pausespeechat.md) function.

**Availability**:
- macOS 10.5+
