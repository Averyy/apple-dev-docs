# kPMInvalidValue

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

The value in a ticket, job template, or dictionary is missing.

**Availability**:
- macOS 10.0+

## Declaration

```c
kPMInvalidValue = -30889
```
