# cmLinesPer

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

Lines per unit; can have an associated value of `0` for lines per centimeter or `1` for lines per inch.

**Availability**:
- macOS 10.0+

## Declaration

```c
cmLinesPer = 1
```
