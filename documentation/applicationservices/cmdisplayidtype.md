# CMDisplayIDType

**Framework**: Application Services  
**Kind**: tdef  
**Role**: Type Alias

Defines a data type for a display ID type.

**Availability**:
- macOS 10.0+ - Deprecated in 10.6

## Declaration

```c
typedef UInt32 CMDisplayIDType;
```

#### Discussion

This data type is passed as a parameter to the functions [CMGetProfileByAVID](./colorsync_manager/api-1804955-cmgetprofilebyavid.md) and [CMSetProfileByAVID](./colorsync_manager/api-1804959-cmsetprofilebyavid.md).
