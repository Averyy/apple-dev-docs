# kCMMCheckColors

**Framework**: Application Services  
**Kind**: econst

## Overview

In response to this request code, your CMM should test the given list of colors in the `myColors` parameter against the gamut specified by the destination profile and report if the colors fall within a destination device’s color gamut. For more information, see the function [CWCheckColors](../api-1805111-cwcheckcolors.md). Required.
