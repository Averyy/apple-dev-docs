# kCMMGetNamedColorValue

**Framework**: Application Services  
**Kind**: econst

#### Overview

In response to this request code, your CMM extracts device and profile connection space (PCS) color values for a specific color name from the profile whose reference is passed in the `prof` parameter. For more information, see the function [CMGetNamedColorValue](../api-1805053-cmgetnamedcolorvalue.md).
