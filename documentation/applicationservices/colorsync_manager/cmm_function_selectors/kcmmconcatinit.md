# kCMMConcatInit

**Framework**: Application Services  
**Kind**: econst

#### Overview

In response to this request code, your CMM should initialize any private data your CMM will need for a color session involving the set of profiles specified by the profile array pointed to by the `profileSet` parameter. Your function should also initialize any additional private data needed in handling subsequent calls pertaining to this component instance. For more information, see the function [CWConcatColorWorld](../api-1805087-cwconcatcolorworld.md).
