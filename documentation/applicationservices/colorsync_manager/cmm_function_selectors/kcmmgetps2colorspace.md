# kCMMGetPS2ColorSpace

**Framework**: Application Services  
**Kind**: econst

#### Overview

In response to this request code, your CMM must obtain or derive the color space element data from the source profile whose reference is passed to your function in the `srcProf` parameter and pass the data to a low-level data-transfer function supplied by the calling application or device driver. For more information, see the function [CMGetPS2ColorSpace](../api-1805191-cmgetps2colorspace.md).
