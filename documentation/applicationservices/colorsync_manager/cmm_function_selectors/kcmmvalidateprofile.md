# kCMMValidateProfile

**Framework**: Application Services  
**Kind**: econst

## Overview

In response to this request code, your CMM should test the profile whose reference is passed in the `prof` parameter to determine if the profile contains the minimum set of elements required for a profile of its type. For more information, see the function [CMValidateProfile](../api-1804856-cmvalidateprofile.md).
