# kCMMGetPS2ColorRendering

**Framework**: Application Services  
**Kind**: econst

## Overview

In response to this request code, your CMM must obtain the rendering intent from the source profile’s header and generate the color rendering dictionary (CRD) data from the destination profile, and then pass the data to a low-level data-transfer function supplied by the calling application or device driver. For more information, see the function [CMGetPS2ColorRendering](../api-1805202-cmgetps2colorrendering.md).
