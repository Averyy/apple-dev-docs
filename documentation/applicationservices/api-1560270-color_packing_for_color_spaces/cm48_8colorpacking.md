# cm48_8ColorPacking

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

The color values for six 8-bit color channels are stored in consecutive bytes, for a total of 48 bits.

**Availability**:
- macOS 10.0+

## Declaration

```c
cm48_8ColorPacking = 0x2300
```
