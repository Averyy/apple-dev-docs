# cm56_8ColorPacking

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

The color values for seven 8-bit color channels are stored in consecutive bytes, for a total of 56 bits.

**Availability**:
- macOS 10.0+

## Declaration

```c
cm56_8ColorPacking = 0x2400
```
