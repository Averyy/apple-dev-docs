# cm64_8ColorPacking

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

The color values for eight 8-bit color channels are stored in consecutive bytes, for a total of 64 bits.

**Availability**:
- macOS 10.0+

## Declaration

```c
cm64_8ColorPacking = 0x2500
```
