# cm64_16ColorPacking

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

The color values for four 16-bit color channels are stored in 64 consecutive bits.

**Availability**:
- macOS 10.0+

## Declaration

```c
cm64_16ColorPacking = 0x2A00
```
