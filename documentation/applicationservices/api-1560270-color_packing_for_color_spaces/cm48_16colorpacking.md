# cm48_16ColorPacking

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

The color values for three 16-bit color channels are stored in 48 consecutive bits.

**Availability**:
- macOS 10.0+

## Declaration

```c
cm48_16ColorPacking = 0x2900
```
