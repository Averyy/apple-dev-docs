# cm24_8ColorPacking

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

The color values for three 8-bit color channels are stored in consecutive bytes, for a total of 24 bits.

**Availability**:
- macOS 10.0+

## Declaration

```c
cm24_8ColorPacking = 0x2100
```
