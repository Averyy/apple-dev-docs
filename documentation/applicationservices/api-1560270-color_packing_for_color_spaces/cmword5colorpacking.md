# cmWord5ColorPacking

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

The color values for three 5-bit color channels are stored consecutively in 16-bits, with the highest order bit unused.

**Availability**:
- macOS 10.0+

## Declaration

```c
cmWord5ColorPacking = 0x0500
```
