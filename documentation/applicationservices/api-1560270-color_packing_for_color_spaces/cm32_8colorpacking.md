# cm32_8ColorPacking

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

The color values for four 8-bit color channels are stored in consecutive bytes, for a total of 32 bits.

**Availability**:
- macOS 10.0+
