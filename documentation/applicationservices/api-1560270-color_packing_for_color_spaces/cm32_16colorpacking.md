# cm32_16ColorPacking

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

The color values for two 16-bit color channels are stored in a 32-bit word.

**Availability**:
- macOS 10.0+

## Declaration

```c
cm32_16ColorPacking = 0x2600
```
