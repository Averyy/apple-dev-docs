# cm32_32ColorPacking

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

The color value for a 32-bit color channel is stored in a 32-bit word.

**Availability**:
- macOS 10.0+

## Declaration

```c
cm32_32ColorPacking = 0x2700
```
