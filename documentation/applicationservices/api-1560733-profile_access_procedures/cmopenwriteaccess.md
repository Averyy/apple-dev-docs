# cmOpenWriteAccess

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

Open the profile for writing. The total size of the profile is specified in the `size` parameter. 

**Availability**:
- macOS 10.0+

## Declaration

```c
cmOpenWriteAccess = 2
```
