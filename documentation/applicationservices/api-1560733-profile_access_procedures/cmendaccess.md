# cmEndAccess

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

End the process of procedural access. This is always the last operation constant passed to the access procedure (unless the `cmBeginAccess` call failed).

**Availability**:
- macOS 10.0+

## Declaration

```c
cmEndAccess = 9
```
