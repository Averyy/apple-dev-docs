# kPMPortrait

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

Specifies portrait (vertical) page orientation. Portrait orientation performs no alteration of the logical page.

**Availability**:
- macOS 10.0+

## Declaration

```c
kPMPortrait = 1
```
