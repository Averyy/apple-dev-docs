# cmPerceptual

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

All the colors of a given gamut can be scaled to fit within another gamut. This intent is best suited to realistic images, such as photographic images.

**Availability**:
- macOS 10.0+
