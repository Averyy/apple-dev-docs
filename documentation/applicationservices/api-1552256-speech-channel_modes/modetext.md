# modeText

**Framework**: Application Services  
**Kind**: econst  
**Role**: Enumeration Case

Used with [`soInputMode`](../api-1552228-speech-channel_information_constants/soinputmode.md) to indicate that the speech channel is in text-processing mode.

**Availability**:
- macOS 10.0+

## Declaration

```c
modeText = 'TEXT'
```
