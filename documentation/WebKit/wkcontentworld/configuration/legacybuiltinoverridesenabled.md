# legacyBuiltinOverridesEnabled

**Framework**: WebKit  
**Kind**: property

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- visionOS 27.0+

## Declaration

```swift
var legacyBuiltinOverridesEnabled: Bool { get set }
```

#### Discussion

A boolean value indicating whether the behavior that elements with a name attribute overrides builtin methods on document object should be enabled or not.
