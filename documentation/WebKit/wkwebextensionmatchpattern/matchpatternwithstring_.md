# matchPatternWithString:

**Framework**: WebKit  
**Kind**: method  
**Role**: Type Method

Returns a pattern object for the specified pattern string.

**Availability**:
- iOS 18.4+
- iPadOS 18.4+
- Mac Catalyst 18.4+
- macOS 15.4+
- visionOS 2.4+

## Declaration

```objc
+ (instancetype) matchPatternWithString:(NSString *) string;
```

#### Return Value

Returns `nil` if the pattern string is invalid.
