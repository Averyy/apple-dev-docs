# init(data:)

**Framework**: WebKit  
**Kind**: init  
**Role**: Initializer

Initializes and returns the receiver, specifying the initial content data.

**Availability**:
- macOS 10.3+ - Deprecated in 10.14

## Declaration

```swift
init!(data: Data!)
```

```objc
- (instancetype) initWithData:(NSData *) data;
```

#### Discussion

Use the [`data`](./data.md) method to get the receiver’s data.
