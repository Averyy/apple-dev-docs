# chooseFilenames(_:)

**Framework**: WebKit  
**Kind**: method  
**Role**: Instance Method  
**Required**: Yes

Displays a file open panel and returns the multiple selected filenames.

**Availability**:
- macOS 10.6+ - Deprecated in 10.14

## Declaration

```swift
func chooseFilenames(_ fileNames: [Any]!)
```

```objc
- (void) chooseFilenames:(NSArray *) fileNames;
```

## Parameters

- `fileNames`: An array of selected file names.
