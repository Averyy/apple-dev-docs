# userStyleSheetEnabled

**Framework**: WebKit  
**Kind**: property  
**Role**: Instance Property

A Boolean that indicates whether or not user style sheets are enabled in the web view.

**Availability**:
- macOS 10.3+ - Deprecated in 10.14

## Declaration

```swift
var userStyleSheetEnabled: Bool { get set }
```

```objc
@property (nonatomic) BOOL userStyleSheetEnabled;
```

#### Discussion

Set to [`true`](../../Swift/true.md) if the user style sheets should be enabled in the web view, otherwise [`false`](../../Swift/false.md).
