# isJavaEnabled

**Framework**: WebKit  
**Kind**: property  
**Role**: Instance Property

A Boolean that indicates whether or not the web view allows Java.

**Availability**:
- macOS 10.3+ - Deprecated in 10.14

## Declaration

```swift
var isJavaEnabled: Bool { get set }
```

```objc
@property (nonatomic, getter=isJavaEnabled) BOOL javaEnabled;
```

#### Discussion

Set to [`true`](../../Swift/true.md) to indicate that the web view allows Java, otherwise [`false`](../../Swift/false.md).
