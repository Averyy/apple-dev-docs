# loadsImagesAutomatically

**Framework**: WebKit  
**Kind**: property  
**Role**: Instance Property

A Boolean that indicates whether or not the web view allows images to be loaded automatically.

**Availability**:
- macOS 10.3+ - Deprecated in 10.14

## Declaration

```swift
var loadsImagesAutomatically: Bool { get set }
```

```objc
@property (nonatomic) BOOL loadsImagesAutomatically;
```

## Discussion

[`true`](../../Swift/true.md) if the web view should allow images to be loaded automatically, otherwise [`false`](../../Swift/false.md).
