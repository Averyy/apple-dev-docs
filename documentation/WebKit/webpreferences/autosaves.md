# autosaves

**Framework**: WebKit  
**Kind**: property  
**Role**: Instance Property

A Boolean that indicates whether or not the receiver’s attributes are automatically stored in the user defaults database.

**Availability**:
- macOS 10.3+ - Deprecated in 10.14

## Declaration

```swift
var autosaves: Bool { get set }
```

```objc
@property (nonatomic) BOOL autosaves;
```

## Discussion

[`true`](../../Swift/true.md) if the receiver’s attributes are automatically stored, [`false`](../../Swift/false.md) otherwise.

The default value is [`false`](../../Swift/false.md).
