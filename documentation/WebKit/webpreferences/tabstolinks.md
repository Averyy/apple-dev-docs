# tabsToLinks

**Framework**: WebKit  
**Kind**: property  
**Role**: Instance Property

A Boolean that indicates whether or not the tab key will focus links.

**Availability**:
- macOS 10.3+ - Deprecated in 10.14

## Declaration

```swift
var tabsToLinks: Bool { get set }
```

```objc
@property (nonatomic) BOOL tabsToLinks;
```

## Discussion

[`true`](../../Swift/true.md) if the user should be able to navigate to links by pressing the tab key, [`false`](../../Swift/false.md) otherwise.
