# allowsDirectories

**Framework**: WebKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the file upload control supports the selection of directories.

**Availability**:
- iOS 18.4+
- iPadOS 18.4+
- Mac Catalyst 18.4+
- macOS 10.13.4+
- visionOS 2.4+


```objc
@property (nonatomic, readonly) BOOL allowsDirectories;
```
