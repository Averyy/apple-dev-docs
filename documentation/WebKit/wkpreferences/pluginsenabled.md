# plugInsEnabled

**Framework**: WebKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether plug-ins are enabled.

**Availability**:
- macOS 10.10+ - Deprecated in 10.15

> **Deprecated**: Plug-ins are no longer supported

## Declaration

```swift
var plugInsEnabled: Bool { get set }
```

```objc
@property (nonatomic) BOOL plugInsEnabled;
```

## Discussion

The default value is [`false`](../../Swift/false.md).
