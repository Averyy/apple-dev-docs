# matchesAllHosts

**Framework**: WebKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates if the pattern is `<all_urls>` or has `*` as the host.

**Availability**:
- iOS 18.4+
- iPadOS 18.4+
- Mac Catalyst 18.4+
- macOS 15.4+
- visionOS 2.4+
