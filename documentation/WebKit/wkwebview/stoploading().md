# stopLoading()

**Framework**: WebKit  
**Kind**: method  
**Role**: Instance Method

Stops loading all resources on the current page.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.10+
- visionOS 1.0+
