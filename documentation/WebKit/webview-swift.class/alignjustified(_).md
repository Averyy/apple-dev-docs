# alignJustified(_:)

**Framework**: WebKit  
**Kind**: method  
**Role**: Instance Method

An action method that applies full justification to selected content or all content if there’s no selection.

**Availability**:
- macOS

## Declaration

```swift
func alignJustified(_ sender: Any?)
```

```objc
- (void) alignJustified:(id) sender;
```

#### Discussion

This method behaves similar to the [`alignJustified(_:)`](../../AppKit/nstextview/alignjustified%28_%29.md) method in [`NSTextView`](../../AppKit/nstextview.md).

## Parameters

- `sender`: The object that sent this message.
