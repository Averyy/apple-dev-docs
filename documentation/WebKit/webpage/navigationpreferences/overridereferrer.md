# overrideReferrer

**Framework**: WebKit  
**Kind**: property

Used to apply a custom `referer` header to all resource loads in the frame of this navigation.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
