# overrideReferrer

**Framework**: WebKit  
**Kind**: property

Used to apply a custom `referer` header to all resource loads in the frame of this navigation.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- visionOS 27.0+
