# init(data:)

**Framework**: WebKit  
**Kind**: init

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init?(data: Data)
```

#### Discussion

Initializes the newly created `WKJSScriptingBuffer` object with the passed in `NSData` data

## Parameters

- `data`: The data to provide to the `window.webkit.buffers` JavaScript object.
