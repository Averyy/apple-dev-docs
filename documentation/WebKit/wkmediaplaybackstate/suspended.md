# WKMediaPlaybackState.suspended

**Framework**: WebKit  
**Kind**: case  
**Role**: Case

The media is not playing, and cannot be resumed until the user revokes the suspension.

**Availability**:
- iOS 14.5+
- iPadOS 14.5+
- Mac Catalyst 14.5+
- macOS 11.3+
- visionOS 1.0+
