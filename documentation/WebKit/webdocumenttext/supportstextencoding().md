# supportsTextEncoding()

**Framework**: WebKit  
**Kind**: method  
**Role**: Instance Method  
**Required**: Yes

Returns a Boolean value that indicates whether the web document supports text encoding.

**Availability**:
- macOS 10.3+ - Deprecated in 10.14

## Declaration

```swift
func supportsTextEncoding() -> Bool
```

```objc
- (BOOL) supportsTextEncoding;
```

## Return Value

[`true`](../../Swift/true.md) if the web document supports text encoding; otherwise, [`false`](../../Swift/false.md).
