# string()

**Framework**: WebKit  
**Kind**: method  
**Role**: Instance Method  
**Required**: Yes

Returns the entire content of the web document as a string.

**Availability**:
- macOS 10.3+ - Deprecated in 10.14

## Declaration

```swift
func string() -> String!
```


#### Return Value
