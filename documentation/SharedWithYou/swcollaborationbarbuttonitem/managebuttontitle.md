# manageButtonTitle

**Framework**: Shared with You  
**Kind**: property  
**Role**: Instance Property

The title of the built-in button that manages a share.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- visionOS 27.3+ (Beta)

## Declaration

```swift
var manageButtonTitle: String { get set }
```

```objc
@property (nonatomic, copy) NSString * manageButtonTitle;
```

## Discussion

The default value is “Manage Share”.
