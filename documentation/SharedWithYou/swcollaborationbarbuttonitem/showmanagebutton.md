# showManageButton

**Framework**: Shared with You  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the item shows the built-in button that manages a share.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- visionOS 27.3+ (Beta)

## Declaration

```swift
var showManageButton: Bool { get set }
```

```objc
@property (nonatomic, assign) BOOL showManageButton;
```

## Discussion

The default value is `true`.
