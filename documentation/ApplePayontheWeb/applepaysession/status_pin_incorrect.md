# STATUS_PIN_INCORRECT

**Framework**: Apple Pay on the Web  
**Kind**: var

The PIN information is not valid.

**Availability**:
- Safari Desktop 10.0+
- Safari Mobile 10.0+

## Declaration

```
const unsigned short STATUS_PIN_INCORRECT;
```

#### Discussion

Cards on the China Union Pay network may require a PIN.
