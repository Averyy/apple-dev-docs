# paymentPass

**Framework**: Apple Pay on the Web  
**Kind**: property  
**Role**: Instance Property

The payment pass object currently selected to complete the payment.

**Availability**:
- Safari Desktop 10.0+
- Safari Mobile 10.0+

## Declaration

```
ApplePayPaymentPass paymentPass;
```
