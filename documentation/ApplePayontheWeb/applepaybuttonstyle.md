# ApplePayButtonStyle

**Framework**: Apple Pay on the Web  
**Kind**: enum  
**Role**: Enumeration

A type that indicates the available appearances for an Apple Pay Button.

**Availability**:
- Safari Desktop 10.0+
- Safari Mobile 10.0+

## Declaration

```
enum ApplePayButtonStyle
```

## Overview

The values for the button style:

- **`"black"`**: A black button with white lettering.

For more information, see [`PKPaymentButtonStyle.black`](../PassKit/pkpaymentbuttonstyle/black.md).

- **`"white"`**: A white button with black lettering.

For more information, see [`PKPaymentButtonStyle.white`](../PassKit/pkpaymentbuttonstyle/white.md).

- **`"white-outline"`**: A white button with black lettering and a black outline.

For more information, see [`PKPaymentButtonStyle.whiteOutline`](../PassKit/pkpaymentbuttonstyle/whiteoutline.md).
