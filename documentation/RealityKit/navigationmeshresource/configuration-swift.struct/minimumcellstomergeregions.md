# minimumCellsToMergeRegions

**Framework**: RealityKit  
**Kind**: property

The number of walkable cells in a region below which the region will be merged with nearby regions to simplify the Navigation Mesh.

**Availability**:

- iPadOS 27.0+ (Beta)
