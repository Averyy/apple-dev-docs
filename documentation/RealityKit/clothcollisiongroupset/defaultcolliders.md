# defaultColliders

**Framework**: RealityKit  
**Kind**: property

Default option reserved for colliders.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
static let defaultColliders: ClothCollisionGroupSet
```

#### Discussion

All colliders have their [`groups`](clothcollisionfilter/groups.md) set to this value by default.
