# MeshDescriptor.Primitives

**Framework**: RealityKit  
**Kind**: enum  
**Role**: Enumeration

Indicates which primitive shape type a mesh applies to its vertex indices.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 26.0+
- visionOS

## Declaration

```swift
enum Primitives
```

## Topics

### Enumeration Cases
- [MeshDescriptor.Primitives.polygons(_:_:)](./primitives-swift.enum/polygons%28_,_%29.md)
  Defines one or more triangles and quadrilaterals with two separate arrays of indices.
- [MeshDescriptor.Primitives.triangles(_:)](./primitives-swift.enum/triangles%28_%29.md)
  Defines one or more triangles with an integer array of indices.
- [MeshDescriptor.Primitives.trianglesAndQuads(triangles:quads:)](./primitives-swift.enum/trianglesandquads%28triangles,quads%29.md)
