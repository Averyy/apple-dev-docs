# inputPort

**Framework**: RealityKit  
**Kind**: property

The name of the input port on the destination node.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
var inputPort: String
```

#### Discussion

Input ports represent values consumed by a node, which can be connected to outputs of other nodes.
