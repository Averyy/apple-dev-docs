# CustomMaterial.Texture

**Framework**: RealityKit  
**Kind**: typealias  
**Role**: Type Alias

The object type that custom materials use to hold texture properties.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 26.0+

## Declaration

```swift
typealias Texture = CustomMaterial.CustomMaterialTexture
```
