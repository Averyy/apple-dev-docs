# MeshResource.Font

**Framework**: RealityKit  
**Kind**: typealias  
**Role**: Type Alias

A platform-specific type that represents a font for use in generating a text mesh.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- macOS 10.15+
- tvOS 26.0+
- visionOS 1.0+

## Declaration

*iOS, iPadOS, Mac Catalyst, tvOS, visionOS*

```swift
typealias Font = UIFont
```

*macOS*

```swift
typealias Font = NSFont
```
