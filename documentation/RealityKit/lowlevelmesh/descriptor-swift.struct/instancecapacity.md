# instanceCapacity

**Framework**: RealityKit  
**Kind**: property

The maximum number of instances the mesh supports.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
var instanceCapacity: Int
```

#### Discussion

Use this when using vertex attributes with a per-instance step rate.
