# isColorDitheringEnabled

**Framework**: RealityKit  
**Kind**: property

Whether to dither color values before writing to the frame buffer.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
var isColorDitheringEnabled: Bool
```

#### Discussion

Enable this to reduce color banding artifacts on gradients.
