# parameter(_:)

**Framework**: RealityKit  
**Kind**: method  
**Role**: Instance Method

Provides a bind target for a particular animated property.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 26.0+
- visionOS

## Declaration

```swift
func parameter(_ name: String) -> BindTarget
```

## Parameters

- `name`: The animated property’s name.
