# BindTarget.transform

**Framework**: RealityKit  
**Kind**: case  
**Role**: Case

A option that specifies that the target entity’s transform animates.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
