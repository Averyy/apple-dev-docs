# init(layers:)

**Framework**: RealityKit  
**Kind**: init  
**Role**: Initializer

Creates a layer component with the specified layers.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init(layers: RenderLayer.Set)
```

## Parameters

- `layers`: The layers this entity participates in
