# portalEntity

**Framework**: RealityKit  
**Kind**: property

The portal entity with `ModelComponent` and `PortalComponent` configured.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst ?+
- macOS 27.0+ (Beta)

## Declaration

```swift
let portalEntity: Entity
```

#### Discussion

This entity displays the portal surface and is a child of `rootEntity`.
