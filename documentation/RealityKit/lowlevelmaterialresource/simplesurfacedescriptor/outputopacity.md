# outputOpacity

**Framework**: RealityKit  
**Kind**: property

A Boolean value that indicates whether the shader also writes the computed alpha to the surface opacity output.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
