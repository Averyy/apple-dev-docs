# init(descriptor:)

**Framework**: RealityKit  
**Kind**: init

Creates a program by compiling the shader node graph in the given descriptor.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init(descriptor: PortalMaterial.Program.Descriptor) async throws
```

#### Discussion

> **Note**: If the graph is invalid or shader compilation fails.
