# init(device:)

**Framework**: RealityKit  
**Kind**: init

Creates a configuration using the given device.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init(device: any MTLDevice)
```

## Parameters

- `device`: The Metal device to use for all rendering operations.
