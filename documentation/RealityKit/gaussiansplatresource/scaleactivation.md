# scaleActivation

**Framework**: RealityKit  
**Kind**: property

The transformation the framework applies to the scale values before rendering.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
final var scaleActivation: GaussianSplatResource.ActivationFunction
```

#### Discussion

The default value applies no transformation.
