# sortingMode

**Framework**: RealityKit  
**Kind**: property

The order in which the framework draws splats to blend their opacity.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
final var sortingMode: GaussianSplatResource.SortingMode
```

#### Discussion

The default value sorts by depth relative to the camera.
