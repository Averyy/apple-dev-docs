# projectionMode

**Framework**: RealityKit  
**Kind**: property

The projection technique the framework uses for splat footprints.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- visionOS 27.0+

## Declaration

```swift
final var projectionMode: GaussianSplatResource.ProjectionMode
```

#### Discussion

The default value uses a tangential approximation.
