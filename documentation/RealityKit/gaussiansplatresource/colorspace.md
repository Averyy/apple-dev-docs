# colorSpace

**Framework**: RealityKit  
**Kind**: property

The color space the framework uses to interpret splat colors.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
final var colorSpace: CGColorSpace
```

#### Discussion

The default value is the sRGB color space.
