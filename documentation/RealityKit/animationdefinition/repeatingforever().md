# repeatingForever()

**Framework**: RealityKit  
**Kind**: method  
**Role**: Instance Method

Repeats the animation infinitely.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 26.0+
- visionOS

## Declaration

```swift
func repeatingForever() -> Self
```

## Return Value

A version of the calling animation that will repeat infinitely.
