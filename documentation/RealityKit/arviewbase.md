# ARViewBase

**Framework**: RealityKit  
**Kind**: typealias  
**Role**: Type Alias

The platform-specific base class for the view into which RealityKit renders content.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- macOS 10.15+
- tvOS 26.0+

## Declaration

*iOS, iPadOS, Mac Catalyst, tvOS*

```swift
typealias ARViewBase = UIView
```

*macOS*

```swift
typealias ARViewBase = NSView
```
