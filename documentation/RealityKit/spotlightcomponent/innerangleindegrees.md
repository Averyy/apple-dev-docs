# innerAngleInDegrees

**Framework**: RealityKit  
**Kind**: property  
**Role**: Instance Property

The inner angle of the spotlight in degrees.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- macOS 10.15+
- tvOS 26.0+
- visionOS 2.0+

## Declaration

```swift
var innerAngleInDegrees: Float
```

## Discussion

The default value is `45.0` degrees.
