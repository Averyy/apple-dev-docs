# init(_:)

**Framework**: RealityKit  
**Kind**: init  
**Role**: Initializer

Create buffer from an array of elements.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 26.0+
- visionOS

## Declaration

```swift
init(_ array: [Element])
```

Available when `Element` is `SIMD3<Float>`.
