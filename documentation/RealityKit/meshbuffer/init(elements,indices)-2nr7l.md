# init(elements:indices:)

**Framework**: RealityKit  
**Kind**: init  
**Role**: Initializer

Create buffer from an array of element values and an array of indices into that value array.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 26.0+
- visionOS

## Declaration

```swift
init(elements: [Element], indices: [UInt32])
```

Available when `Element` is `Float`.
