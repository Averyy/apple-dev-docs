# init(_:)

**Framework**: RealityKit  
**Kind**: init  
**Role**: Initializer

Create buffer from an array of elements.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- macOS 15.0+
- tvOS 26.0+
- visionOS 1.0+

## Declaration

```swift
init(_ array: [Element])
```

Available when `Element` is `MeshJointInfluence`.
