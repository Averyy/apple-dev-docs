# init(_:)

**Framework**: RealityKit  
**Kind**: init  
**Role**: Initializer

Creates a color of emitted light from a custom material’s emissive color property.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 26.0+

## Declaration

```swift
init(_ value: CustomMaterial.EmissiveColor)
```

## Parameters

- `value`: The custom material emissive color object.
