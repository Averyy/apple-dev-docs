# init(texture:)

**Framework**: RealityKit  
**Kind**: init  
**Role**: Initializer

Creates an object from an image texture.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 26.0+
- visionOS

## Declaration

```swift
init(texture: PhysicallyBasedMaterial.Texture? = nil)
```

## Parameters

- `texture`: The ambient occlusion texture map.
