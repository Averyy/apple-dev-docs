# init(floatLiteral:)

**Framework**: RealityKit  
**Kind**: init  
**Role**: Initializer

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 26.0+
- visionOS

## Declaration

```swift

```

## Parameters

- `value`: The opacity value.
