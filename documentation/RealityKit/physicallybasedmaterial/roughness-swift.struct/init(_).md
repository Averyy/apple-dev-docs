# init(_:)

**Framework**: RealityKit  
**Kind**: init  
**Role**: Initializer

Creates a roughness object from a custom material’s roughness property.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 26.0+

## Declaration

```swift
init(_ value: CustomMaterial.Roughness)
```

## Parameters

- `value`: The custom material’s roughness property.
