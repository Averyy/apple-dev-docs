# init(size:)

**Framework**: RealityKit  
**Kind**: init

Creates a box shape with the given size.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init(size: SIMD3<Float>)
```

## Parameters

- `size`: The size of the box along each axis.
