# init(type:)

**Framework**: RealityKit  
**Kind**: init

Creates a texture slot descriptor with the given texture type.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init(type: MTLTextureType)
```

## Parameters

- `type`: The texture type expected at this slot.
