# init(size:)

**Framework**: RealityKit  
**Kind**: init

Creates a buffer slot descriptor with the given size.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init(size: Int)
```

## Parameters

- `size`: The size of the buffer slot, in bytes.
