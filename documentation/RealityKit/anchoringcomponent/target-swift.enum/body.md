# AnchoringComponent.Target.body

**Framework**: RealityKit  
**Kind**: case  
**Role**: Case

An anchor point attached to a human body in motion within the scene.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 14.0+
- macOS 10.15+
- tvOS 26.0+
