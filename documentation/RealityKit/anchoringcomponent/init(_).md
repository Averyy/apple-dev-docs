# init(_:)

**Framework**: RealityKit  
**Kind**: init  
**Role**: Initializer

Creates an anchoring component with the given AR anchor.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 14.0+

## Declaration

```swift
init(_ anchor: ARAnchor)
```

**Other overloads**:

```swift
init(_ target: AnchoringComponent.Target)
```

## Parameters

- `anchor`: An existing AR anchor to use.
