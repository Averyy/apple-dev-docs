# preferFastExport

**Framework**: RealityKit  
**Kind**: property

Expedite the reality file export when possible. This may disable reality file compression, resulting in larger file size.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
