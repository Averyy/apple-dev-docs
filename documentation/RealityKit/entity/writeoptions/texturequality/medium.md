# medium

**Framework**: RealityKit  
**Kind**: property

Reduces more the texture file size. RealityKit might not preserve fine details to reach a small file size.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
