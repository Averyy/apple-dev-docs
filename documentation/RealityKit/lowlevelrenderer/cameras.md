# cameras

**Framework**: RealityKit  
**Kind**: property

The array of active cameras.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
final var cameras: LowLevelRenderer.CameraArray { get set }
```

#### Discussion

Set `cameras.count` to the number of active cameras.
