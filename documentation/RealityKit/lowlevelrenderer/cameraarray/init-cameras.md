# init(cameras:)

**Framework**: RealityKit  
**Kind**: init

Creates a camera array populated with the given cameras.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init(cameras: [LowLevelRenderer.Camera])
```

## Parameters

- `cameras`: The initial set of cameras to populate the array with.
