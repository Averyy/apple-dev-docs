# subscript(_:)

**Framework**: RealityKit  
**Kind**: subscript

Returns or sets the camera at the given index.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
subscript(index: Int) -> LowLevelRenderer.Camera { get set }
```

#### Return Value

The [`LowLevelRenderer.Camera`](lowlevelrenderer/camera.md) at `index`.

## Parameters

- `index`: The zero-based index of the camera to access.
