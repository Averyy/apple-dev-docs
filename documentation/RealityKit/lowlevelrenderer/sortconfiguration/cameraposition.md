# cameraPosition

**Framework**: RealityKit  
**Kind**: property  
**Role**: Instance Property

The camera position used to compute per-instance back-to-front sort distances for transparent draw calls.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- tvOS 27.0+
- visionOS 27.0+
