# init(cameraPosition:)

**Framework**: RealityKit  
**Kind**: init

Creates a sort configuration with the given camera position.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init(cameraPosition: SIMD3<Float>)
```

## Parameters

- `cameraPosition`: The camera position to use for depth sorting.
