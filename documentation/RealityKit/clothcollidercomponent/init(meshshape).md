# init(meshShape:)

**Framework**: RealityKit  
**Kind**: init  
**Role**: Initializer

Creates a cloth collider component with the given mesh shape.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init(meshShape: ClothMeshShape)
```

## Parameters

- `meshShape`: Defines the mesh shape of the collider.
