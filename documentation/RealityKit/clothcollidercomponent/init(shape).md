# init(shape:)

**Framework**: RealityKit  
**Kind**: init  
**Role**: Initializer

Creates a cloth collider component with the given shape.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init(shape: ClothColliderShape)
```

## Parameters

- `shape`: Defines the shape of the collider.
