# computesBitangent

**Framework**: RealityKit  
**Kind**: property

Indicates if bitangents should be recomputed from blended normals and tangents. Only valid if blendsOutputs = [normal, tangent].

**Availability**:

- iPadOS 27.0+ (Beta)
