# Mixing spatial music

**Framework**: RealityKit  
**Role**: Sample Code  
**Download**: [MixingSpatialMusic.zip](https://docs-assets.developer.apple.com/published/3d1002862fe2/MixingSpatialMusic.zip)

Preview ray-traced reverb by adjusting a spatialized multitrack audio mix in an immersive scene.

**Availability**:
- visionOS 27.0+
- Xcode 27.0+

#### Overview

> **Note**: This sample code project is associated with WWDC26 session 279: [Explore advances in RealityKit](https://developer.apple.com/videos/play/wwdc2026/279/).
