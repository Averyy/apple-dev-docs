# falloff

**Framework**: RealityKit  
**Kind**: property

Controls whether the grabbing strength falls off based on distance from the volume surface.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
var falloff: ClothGrabComponent.Falloff
```

#### Discussion

This property only applies to the `.volume` mode.
