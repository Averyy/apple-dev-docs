# init(_:)

**Framework**: RealityKit  
**Kind**: init

Creates a context targeting the specified Metal device.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init(_ device: any MTLDevice) throws
```

#### Discussion

> **Note**: If the context cannot be initialized for the given device.

## Parameters

- `device`: The Metal device to target.
