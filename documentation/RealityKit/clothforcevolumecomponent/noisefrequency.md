# noiseFrequency

**Framework**: RealityKit  
**Kind**: property

The frequency of the noise applied to particles inside the volume.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
var noiseFrequency: Float { get set }
```

#### Discussion

Must be non-negative; negative values are clamped to zero.
