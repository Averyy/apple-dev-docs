# maxVertexBufferCount

**Framework**: RealityKit  
**Kind**: property

The maximum number of separate vertex buffers the renderer supports.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
static let maxVertexBufferCount: Int
```

#### Discussion

For optimal performance, most apps use one buffer.
