# vertexBufferCount

**Framework**: RealityKit  
**Kind**: property

The number of buffers this descriptor uses.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
var vertexBufferCount: Int { get }
```

#### Discussion

The value derives from the maximum `bufferIndex` specified across `vertexLayouts`.
