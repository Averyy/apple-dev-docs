# init(scope:)

**Framework**: RealityKit  
**Kind**: init

Creates a BloomComponent with the specified scope.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init(scope: BloomComponent.BloomScope = .unbounded)
```

## Parameters

- `scope`: The bloom scope. Defaults to [`unbounded`](bloomcomponent/bloomscope/unbounded.md).
