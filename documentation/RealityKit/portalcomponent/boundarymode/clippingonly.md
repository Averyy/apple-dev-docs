# PortalComponent.BoundaryMode.clippingOnly

**Framework**: RealityKit  
**Kind**: case

The portal clips its content to the boundary.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
case clippingOnly
```

#### Discussion

Entities with [`PortalCrossingComponent`](portalcrossingcomponent.md) don’t cross the portal.
