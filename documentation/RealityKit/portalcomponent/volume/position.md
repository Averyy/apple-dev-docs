# position

**Framework**: RealityKit  
**Kind**: property

The center of the volume in portal-local space, in meters.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
var position: SIMD3<Float>
```

#### Discussion

Defaults to `.zero`, which places the box center at the portal entity’s origin.
