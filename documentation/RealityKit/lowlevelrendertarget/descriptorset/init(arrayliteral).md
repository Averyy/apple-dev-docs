# init(arrayLiteral:)

**Framework**: RealityKit  
**Kind**: init

Creates a descriptor set from an array literal of render target descriptors.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
init(arrayLiteral elements: LowLevelRenderTarget.Descriptor...)
```

## Parameters

- `elements`: The render target descriptors to include in the set.
