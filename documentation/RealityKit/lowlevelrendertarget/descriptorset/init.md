# init(_:)

**Framework**: RealityKit  
**Kind**: init

Creates a descriptor set from an array of render target descriptors.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init(_ descriptors: [LowLevelRenderTarget.Descriptor])
```

## Parameters

- `descriptors`: The render target descriptors to include in the set.
