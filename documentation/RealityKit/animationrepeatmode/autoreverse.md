# AnimationRepeatMode.autoReverse

**Framework**: RealityKit  
**Kind**: case  
**Role**: Case

A mode that reverses the animation after reaching the end or the beginning.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 26.0+
- visionOS
