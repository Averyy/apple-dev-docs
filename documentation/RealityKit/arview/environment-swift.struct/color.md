# ARView.Environment.Color

**Framework**: RealityKit  
**Kind**: typealias  
**Role**: Type Alias

An alias for the color type that’s appropriate for the current platform.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- macOS 10.15+
- tvOS 26.0+

## Declaration

*iOS, iPadOS, Mac Catalyst, tvOS*

```swift
typealias Color = UIColor
```

*macOS*

```swift
typealias Color = NSColor
```
