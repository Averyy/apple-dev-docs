# weight

**Framework**: RealityKit  
**Kind**: property

The weight by which the body will be pulled towards this target shape.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
var weight: Float
```

#### Discussion

Clamped between 0 and 1. A weight of 0 will effectively inactivate the target shape.
