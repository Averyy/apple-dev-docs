# init(for:)

**Framework**: RealityKit  
**Kind**: init

Creates a target shape that is compatible with the given [`ClothBodyComponent`](clothbodycomponent.md).

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
init(for bodyComponent: ClothBodyComponent)
```

## Parameters

- `bodyComponent`: The body component that this target shape will be applied to.
