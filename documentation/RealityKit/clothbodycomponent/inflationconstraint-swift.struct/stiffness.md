# stiffness

**Framework**: RealityKit  
**Kind**: property

The resistance of the body’s volume to diverge from `targetVolume`.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
var stiffness: Float { get set }
```

#### Discussion

The valid range is [0.0, 1.0], both included.
