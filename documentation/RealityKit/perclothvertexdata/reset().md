# reset()

**Framework**: RealityKit  
**Kind**: method  
**Role**: Instance Method

Resets the per-vertex data of each vertex to the default position constraint.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- visionOS 27.0+

Available when `ElementType` is `ClothBodyComponent.TargetShape.PositionConstraint`.
