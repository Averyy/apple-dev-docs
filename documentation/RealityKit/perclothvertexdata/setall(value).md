# setAll(value:)

**Framework**: RealityKit  
**Kind**: method  
**Role**: Instance Method

Sets the data for all vertices to a common value.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- visionOS 27.0+

## Declaration

```swift
mutating func setAll(value: ElementType)
```

## Parameters

- `value`: The value to assign to every vertex.
