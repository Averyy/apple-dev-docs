# subscript(_:)

**Framework**: RealityKit  
**Kind**: subscript

Accesses the friction override for the given material pair, returning `nil` if no override exists.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
