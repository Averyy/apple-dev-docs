# randomSeed

**Framework**: RealityKit  
**Kind**: property

An optional fixed random seed for the simulation.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)

## Declaration

```swift
var randomSeed: UInt32? { get set }
```

#### Discussion

When `nil`, a random seed is chosen each time the simulation is (re)initialized.
