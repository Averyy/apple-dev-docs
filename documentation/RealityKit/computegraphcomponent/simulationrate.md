# simulationRate

**Framework**: RealityKit  
**Kind**: property

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
var simulationRate: ComputeGraphSimulation.SimulationRate { get set }
```

#### Discussion

Defaults to `SimulationRate/default` if no custom rate has been set.
