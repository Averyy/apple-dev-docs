# init()

**Framework**: RealityKit  
**Kind**: init  
**Role**: Initializer

Creates a new physics joints component.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- macOS 15.0+
- tvOS 26.0+
- visionOS 2.0+

## Declaration

```swift
init()
```

## Discussion

The initializer sets the component’s [`joints`](./joints.md) property to an empty set.
