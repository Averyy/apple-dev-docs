# FamilyTransactionNotSupportedError

**Framework**: Advanced Commerce API  
**Kind**: dictionary  
**Role**: Object

An error that indicates the transaction is for a product the customer obtains through Family Sharing, which the endpoint doesn’t support.

**Availability**:
- Advanced Commerce API 1.3+

## Declaration

```
object FamilyTransactionNotSupportedError
```

## Discussion

The [`Migrate a Subscription to Advanced Commerce API`](./migrate-subscription-to-advanced-commerce-api.md) endpoint returns this error if you provide the identifier of a transaction that the customer has access to through Family Sharing. Provide the transaction identifier of the purchaser’s subscription instead.

## Properties

- `errorCode` (int64): **Allowed Values**: `4000185`
- `errorMessage` (string): **Allowed Values**: `Invalid request. Family Sharing transactions aren't supported by this endpoint.`
