# InvalidRevokeSeatQuantityError

**Framework**: Advanced Commerce API  
**Kind**: dictionary  
**Role**: Object

An error that indicates the number of seats to revoke is invalid.

**Availability**:
- Advanced Commerce API 1.3+

## Declaration

```
object InvalidRevokeSeatQuantityError
```

## Mentions

- [Advanced Commerce API changelog](./changelog.md)

## Discussion

The [`Revoke Subscription`](./revoke-subscription.md) endpoint returns this error if the [`revokeSeatQuantity`](./revokeseatquantity.md) isn’t a positive number, or exceeds the subscription’s number of unclaimed seats.

## Properties

- `errorCode` (number): **Allowed Values**: `4000289`
- `errorMessage` (string): **Allowed Values**: `Invalid request. revokeSeatQuantity must be positive and must not exceed the subscription's unclaimed seats.`
