# TransactionCannotBeRefundedContactSupportError

**Framework**: Advanced Commerce API  
**Kind**: dictionary  
**Role**: Object

An error that indicates the App Store can’t refund the transaction.

**Availability**:
- Advanced Commerce API 1.1+

## Declaration

```
object TransactionCannotBeRefundedContactSupportError
```

## Mentions

- [Advanced Commerce API changelog](./changelog.md)

## Discussion

A request returns this error if the App Store can’t refund the transaction you specify. The customer can contact Apple Support for help with a refund.

## Properties

- `errorCode` (number): **Allowed Values**: `4030025`
- `errorMessage` (string): **Allowed Values**: `The transaction can't be refunded; customer can contact Apple Support for assistance.`
