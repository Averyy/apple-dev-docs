# InvalidMaximumSeatQuantityError

**Framework**: Advanced Commerce API  
**Kind**: dictionary  
**Role**: Object

An error that indicates a volume price tier has an invalid maximum seat quantity.

**Availability**:
- Advanced Commerce API 1.3+

## Declaration

```
object InvalidMaximumSeatQuantityError
```

## Mentions

- [Advanced Commerce API changelog](./changelog.md)

## Discussion

A request returns this error unless every [`SeatPriceTier`](./seatpricetier.md) in its `seatPriceTiers` array, except the last, has a positive `maximumSeatQuantity`, and the last tier omits it.

## Properties

- `errorCode` (number): **Allowed Values**: `4000267`
- `errorMessage` (string): **Allowed Values**: `Invalid request. Every seatPriceTiers entry except the last must specify a positive maximumSeatQuantity, and the last must omit it.`
