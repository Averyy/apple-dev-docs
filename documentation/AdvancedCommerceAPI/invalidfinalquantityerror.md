# InvalidFinalQuantityError

**Framework**: Advanced Commerce API  
**Kind**: dictionary  
**Role**: Object

An error that indicates the final number of seats is invalid.

**Availability**:
- Advanced Commerce API 1.3+

## Declaration

```
object InvalidFinalQuantityError
```

## Mentions

- [Advanced Commerce API changelog](./changelog.md)

## Discussion

A request returns this error if the [`finalQuantity`](./finalquantity.md) isn’t a positive number, or exceeds the maximum number of seats that the App Store allows.

## Properties

- `errorCode` (number): **Allowed Values**: `4000280`
- `errorMessage` (string): **Allowed Values**: `Invalid request. finalQuantity must be positive and must not exceed the maximum allowed seat quantity.`
