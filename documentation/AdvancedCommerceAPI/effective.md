# effective

**Framework**: Advanced Commerce API  
**Kind**: typealias  
**Role**: Type

A string value that indicates when a requested change to an auto-renewable subscription goes into effect.

**Availability**:
- Advanced Commerce API 1.0+

## Declaration

```
string effective
```

## Possible Values

- `IMMEDIATELY`: The requested change goes into effect immediately.
- `NEXT_BILL_CYCLE`: The requested change goes into effect at the start of the next billing cycle.
