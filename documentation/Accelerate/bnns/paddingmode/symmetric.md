# BNNS.PaddingMode.symmetric

**Framework**: Accelerate  
**Kind**: case  
**Role**: Case

A constant that indicates that a padding operation fills the padded area to form an even-symmetric pattern.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS
