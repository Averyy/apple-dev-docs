# init(cvPixelBuffer:)

**Framework**: Accelerate  
**Kind**: init  
**Role**: Initializer

Creates a size with dimensions specified by a Core Video pixel buffer.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
- tvOS 16.0+
- visionOS
- watchOS 9.0+

## Declaration

```swift
init(cvPixelBuffer: CVPixelBuffer)
```

## Parameters

- `cvPixelBuffer`: The source Core Video pixel buffer.
