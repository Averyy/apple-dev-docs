# vImagePixelCount

**Framework**: Accelerate  
**Kind**: typealias  
**Role**: Type Alias

A type for the number of pixels.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
typealias vImagePixelCount = UInt
```

```c
typedef unsigned long vImagePixelCount;
```

#### Discussion

This is typically used to describe the height or width of an image.
