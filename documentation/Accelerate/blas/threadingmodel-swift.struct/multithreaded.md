# multiThreaded

**Framework**: Accelerate  
**Kind**: property  
**Role**: Type Property

A constant that specifies that the Accelerate framework decides whether BLAS and LAPACK execute on single or multiple threads.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS 15.0+
- tvOS
- visionOS
- watchOS

## Declaration

```swift
static let multiThreaded: BLAS.ThreadingModel
```
