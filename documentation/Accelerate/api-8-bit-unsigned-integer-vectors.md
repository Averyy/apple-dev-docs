# 8-Bit Unsigned Integer Vectors

**Framework**: Accelerate  
**Role**: API Collection

Perform operations on vectors that contain unsigned 8-bit integer elements.

## Topics

- [typealias simd_uchar1](https://developer.apple.com/documentation/simd/simd_uchar1)
  A vector of one 8-bit unsigned integer element.
- [typealias simd_uchar2](https://developer.apple.com/documentation/simd/simd_uchar2)
  A vector of two 8-bit unsigned integer elements.
- [typealias simd_uchar3](https://developer.apple.com/documentation/simd/simd_uchar3)
  A vector of three 8-bit unsigned integer elements.
- [typealias simd_uchar4](https://developer.apple.com/documentation/simd/simd_uchar4)
  A vector of four 8-bit unsigned integer elements.
- [typealias simd_uchar8](https://developer.apple.com/documentation/simd/simd_uchar8)
  A vector of eight 8-bit unsigned integer elements.
- [typealias simd_uchar16](https://developer.apple.com/documentation/simd/simd_uchar16)
  A vector of sixteen 8-bit unsigned integer elements.
- [typealias simd_uchar32](https://developer.apple.com/documentation/simd/simd_uchar32)
  A vector of thirty-two 8-bit unsigned integer elements.
- [typealias simd_uchar64](https://developer.apple.com/documentation/simd/simd_uchar64)
  A vector of sixty-four 8-bit unsigned integer elements.
