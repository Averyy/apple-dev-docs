# scrollView

**Framework**: StoreKit  
**Kind**: property  
**Role**: Type Property

A placement that locates the subscription controls within the main scroll view of a subscription store view.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- macOS 15.0+
- visionOS 2.0+
- watchOS 11.0+

## Declaration

```swift
static var scrollView: SubscriptionStoreControlPlacementKey { get }
```
