# SKError.Code.overlayInvalidConfiguration

**Framework**: StoreKit  
**Kind**: case  
**Role**: Case

An error code that indicates the overlay’s configuration is invalid.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
