# automatic

**Framework**: StoreKit  
**Kind**: property  
**Role**: Type Property

A behavior in which the system presents the invitation sheet inline, right after the customer buys a multiseat subscription.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- macOS 27.3+ (Beta)

## Declaration

```swift
static let automatic: MultiSeatInvitationBehavior
```

## Discussion

This is the default behavior.
