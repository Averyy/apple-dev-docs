# ProductIconPhase.unavailable

**Framework**: StoreKit  
**Kind**: case  
**Role**: Case

**Availability**:

- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
