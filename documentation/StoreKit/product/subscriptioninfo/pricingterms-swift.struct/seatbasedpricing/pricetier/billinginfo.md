# billingInfo

**Framework**: StoreKit  
**Kind**: property  
**Role**: Instance Property

The price of one seat in this tier, and the period between renewals.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- macOS 27.3+ (Beta)
- tvOS 27.3+ (Beta)
- visionOS 27.3+ (Beta)
- watchOS 27.3+ (Beta)

## Declaration

```swift
let billingInfo: Product.SubscriptionInfo.BillingInfo
```

## Discussion

The [`price`](../../../billinginfo/price.md) and [`displayPrice`](../../../billinginfo/displayprice.md) values are per-seat prices for seat counts in this tier’s range.
