# Product.SubscriptionInfo.MultiSeatDataSharingConsentEligibility.eligible

**Framework**: StoreKit  
**Kind**: case  
**Role**: Case

A value that indicates that the person signed in to the App Store can choose whether to share group information with you.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- macOS 27.3+ (Beta)

## Declaration

```swift
case eligible
```

When the eligibility has this value, you can present the data sharing consent sheet.
