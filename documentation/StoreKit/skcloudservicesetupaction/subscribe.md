# subscribe

**Framework**: StoreKit  
**Kind**: property  
**Role**: Type Property

A subscribe action in a cloud service setup view, such as an offer to subscribe to Apple Music.

- iPadOS 10.1+ - Deprecated in 18.0
- Mac Catalyst 13.1+ - Deprecated in 18.0
- tvOS 10.0+ - Deprecated in 18.0
