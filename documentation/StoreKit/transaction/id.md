# id

**Framework**: StoreKit  
**Kind**: property  
**Role**: Instance Property

The unique identifier for the transaction.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
let id: UInt64
```

## Discussion

Every transaction such as an Apple In-App Purchase, restore, or subscription renewal has a unique transaction identifier.
