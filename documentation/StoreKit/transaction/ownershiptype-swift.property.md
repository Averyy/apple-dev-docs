# ownershipType

**Framework**: StoreKit  
**Kind**: property  
**Role**: Instance Property

A value that indicates whether the transaction was purchased by the user, or is made available to them through Family Sharing.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+
