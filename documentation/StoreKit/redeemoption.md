# RedeemOption

**Framework**: StoreKit  
**Kind**: struct  
**Role**: Structure

An option that customizes the behavior of an offer code redemption.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- visionOS 27.0+

## Declaration

```swift
struct RedeemOption
```

#### Overview

Pass a set of these values to `AppStore/presentOfferCodeRedeemSheet(from:options:)` to configure the offer code redemption.
