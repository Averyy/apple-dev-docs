# policies

**Framework**: StoreKit  
**Kind**: property  
**Role**: Type Property

A type of button that people use to display store policies.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```swift
static var policies: StoreButtonKind { get }
```

## Discussion

This button type is available for [`SubscriptionStoreView`](../subscriptionstoreview.md) only.
