# init()

**Framework**: MapKit  
**Kind**: init  
**Role**: Initializer

Creates the rectangle with an empty region.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
init()
```

## Discussion

This method sets the origin point to `(0, 0)` and the size to `(0, 0)`.
