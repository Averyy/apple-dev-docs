# MKStringFromMapRect(_:)

**Framework**: MapKit  
**Kind**: func  
**Role**: Function

Returns a formatted string for the specified map rectangle.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
func MKStringFromMapRect(_ rect: MKMapRect) -> String
```

```c
static NSString *MKStringFromMapRect(MKMapRect rect);
```

#### Return Value

A formatted string containing the origin and size values of the map rectangle.

## Parameters

- `rect`: The map rectangle to format.
