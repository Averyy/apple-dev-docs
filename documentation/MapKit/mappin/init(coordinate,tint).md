# init(coordinate:tint:)

**Framework**: MapKit  
**Kind**: init  
**Role**: Initializer

Creates a map pin at the map location that you specify.

**Availability**:
- iOS 14.0+ - Deprecated in 16.0
- iPadOS 14.0+ - Deprecated in 16.0
- Mac Catalyst 14.0+ - Deprecated in 16.0
- macOS 11.0+ - Deprecated in 13.0
- tvOS 14.0+ - Deprecated in 16.0
- visionOS
- watchOS 7.0+ - Deprecated in 9.0

> **Deprecated**: Use Marker

## Declaration

```swift
init(coordinate: CLLocationCoordinate2D, tint: Color? = nil)
```

## Parameters

- `coordinate`: The location of the specified pin.
- `tint`: The color of the pin.
