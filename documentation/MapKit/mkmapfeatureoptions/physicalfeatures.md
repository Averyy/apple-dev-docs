# physicalFeatures

**Framework**: MapKit  
**Kind**: property  
**Role**: Type Property

The option that represents physical map features such as mountain ranges, rivers, and ocean basins.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- visionOS 1.0+
