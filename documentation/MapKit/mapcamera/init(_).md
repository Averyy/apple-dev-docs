# init(_:)

**Framework**: MapKit  
**Kind**: init  
**Role**: Initializer

Creates a map camera from the given MapKit camera object.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS
- watchOS 10.0+

## Declaration

```swift
init(_ camera: MKMapCamera)
```

## Parameters

- `camera`: An [`MKMapCamera`](../mkmapcamera.md) object.
