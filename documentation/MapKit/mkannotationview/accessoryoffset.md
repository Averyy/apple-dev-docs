# accessoryOffset

**Framework**: MapKit  
**Kind**: property  
**Role**: Instance Property

An offset that changes the accessory’s default anchor point.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- macOS 15.0+
- visionOS 2.0+

## Declaration

```swift
var accessoryOffset: CGPoint { get set }
```

```objc
@property (nonatomic, assign) CGPoint accessoryOffset;
```
