# MKAnnotationView.DragState.dragging

**Framework**: MapKit  
**Kind**: case  
**Role**: Case

An annotation view is actively dragging.

**Availability**:
- iOS 4.0+
- iPadOS 4.0+
- Mac Catalyst 13.1+
- macOS 10.9+
- visionOS 1.0+

## Declaration

```swift
case dragging
```

```c
MKAnnotationViewDragStateDragging
```

## Discussion

The view is in the middle of a drag operation and is tracking progress.
