# init(_:)

**Framework**: MapKit  
**Kind**: init  
**Role**: Initializer

Creates a circle overlay from an existing map circle object.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS
- watchOS 10.0+

## Declaration

```swift
init(_ circle: MKCircle)
```

## Parameters

- `circle`: The circle to convert.
