# init(coordinates:)

**Framework**: MapKit  
**Kind**: init  
**Role**: Initializer

Creates a polygon from a list of coordinates you provide.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS
- watchOS 10.0+

## Declaration

```swift
init(coordinates: [CLLocationCoordinate2D])
```

## Parameters

- `coordinates`: An array of [`CLLocationCoordinate2D`](../../CoreLocation/cllocationcoordinate2d.md) coordinates.
