# init(points:)

**Framework**: MapKit  
**Kind**: init  
**Role**: Initializer

Creates a polygon from a list of map points.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS
- watchOS 10.0+

## Declaration

```swift
init(points: [MKMapPoint])
```

## Parameters

- `points`: An array of [`MKMapPoint`](../mkmappoint.md) points that make up the vertices of the polygon.
