# purplePinColor()

**Framework**: MapKit  
**Kind**: method  
**Role**: Type Method

Returns the standard color for purple pins.

**Availability**:
- iOS 9.0+ - Deprecated in 16.0
- iPadOS 9.0+ - Deprecated in 16.0
- Mac Catalyst 13.1+ - Deprecated in 16.0
- macOS 10.11+ - Deprecated in 13.0
- tvOS 9.0+ - Deprecated in 16.0
- visionOS 1.0+ - Deprecated in 1.0

## Declaration

*iOS, iPadOS, Mac Catalyst, tvOS, visionOS*


*macOS*

```swift

```

*iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS*

```objc
+ (UIColor *) purplePinColor;
```

*macOS*


## Return Value

The purple pin color.

## Discussion

The system uses purple pins to indicate user-specified points on the map.
