# init(rawValue:)

**Framework**: MapKit  
**Kind**: init  
**Role**: Initializer

Creates a feature display priority using the specified raw floating point value.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- Mac Catalyst 13.1+
- macOS 10.13+
- tvOS 11.0+
- visionOS 1.0+

## Declaration

```swift
init(rawValue: Float)
```

## Parameters

- `rawValue`: The floating point value of the feature display priority.
