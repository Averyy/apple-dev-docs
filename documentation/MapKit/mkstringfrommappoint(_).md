# MKStringFromMapPoint(_:)

**Framework**: MapKit  
**Kind**: func  
**Role**: Function

Returns a formatted string for the specified map point.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
func MKStringFromMapPoint(_ point: MKMapPoint) -> String
```

```c
static NSString *MKStringFromMapPoint(MKMapPoint point);
```

## Return Value

A formatted string containing the x and y coordinates of the map point.

## Parameters

- `point`: The map point to format.
