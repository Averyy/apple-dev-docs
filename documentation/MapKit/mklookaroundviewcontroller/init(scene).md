# init(scene:)

**Framework**: MapKit  
**Kind**: init  
**Role**: Initializer

Creates a new LookAround view controller with the specified scene.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
- visionOS 1.0+

- `scene`: A [`MKLookAroundScene`](../mklookaroundscene.md).
