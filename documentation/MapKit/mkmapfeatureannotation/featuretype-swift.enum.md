# MKMapFeatureAnnotation.FeatureType

**Framework**: MapKit  
**Kind**: enum  
**Role**: Enumeration

Values that describe the kinds of features visible on the map.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- visionOS 1.0+

