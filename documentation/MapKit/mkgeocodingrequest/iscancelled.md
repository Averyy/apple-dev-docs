# isCancelled

**Framework**: MapKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the current geocoding request is in a cancelled state.

**Availability**:

- iPadOS 26.0+
- Mac Catalyst 26.0+
