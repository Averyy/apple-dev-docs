# init()

**Framework**: MapKit  
**Kind**: init  
**Role**: Initializer

Creates a map annotation that shows a title string at a point on a map.

**Availability**:
- iOS 4.0+
- iPadOS 4.0+
- Mac Catalyst 13.1+
- macOS 10.9+
- tvOS 9.2+
- visionOS 1.0+
- watchOS 1.0+
