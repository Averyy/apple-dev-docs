# automatic

**Framework**: MapKit  
**Kind**: property  
**Role**: Type Property

A value that allows the framework to choose an appropriate callout style automatically.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- macOS 15.0+
- visionOS 2.0+

## Declaration

