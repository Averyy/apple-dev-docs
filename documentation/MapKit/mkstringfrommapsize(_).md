# MKStringFromMapSize(_:)

**Framework**: MapKit  
**Kind**: func  
**Role**: Function

Returns a formatted string for the specified map size.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
func MKStringFromMapSize(_ size: MKMapSize) -> String
```

```c
static NSString *MKStringFromMapSize(MKMapSize size);
```

## Return Value

A formatted string containing the width and height values of the map size.

## Parameters

- `size`: The map size to format.
