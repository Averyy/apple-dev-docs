# AAAttributionError.Code.platformNotSupported

**Framework**: AdServices  
**Kind**: case  
**Role**: Case

The server is unable to provide a token because of an unsupported operating system.

**Availability**:
- iOS 14.3+
- iPadOS 14.3+
- Mac Catalyst 14.3+
- macOS 11.1+
- visionOS 1.0+
