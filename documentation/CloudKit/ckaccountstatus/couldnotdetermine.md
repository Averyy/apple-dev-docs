# CKAccountStatus.couldNotDetermine

**Framework**: CloudKit  
**Kind**: case  
**Role**: Case

CloudKit can’t determine the status of the user’s iCloud account.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.10+
- tvOS
- visionOS 1.0+
- watchOS 3.0+
