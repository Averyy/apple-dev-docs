# initWithScope:

**Framework**: CloudKit  
**Kind**: method  
**Role**: Instance Method

Initializes a set of options with the specific scope.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```objc
- (instancetype) initWithScope:(CKSyncEngineSendChangesScope *) scope;
```

## Discussion

If no scope is provided, the default scope will include everything.
