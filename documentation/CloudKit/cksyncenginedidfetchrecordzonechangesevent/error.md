# error

**Framework**: CloudKit  
**Kind**: property  
**Role**: Instance Property

An error that describes the cause of a failed fetch operation.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```objc
@property (nonatomic, copy, readonly, nullable) NSError * error;
```

## Discussion

A `nil` value indicates a successful fetch.
