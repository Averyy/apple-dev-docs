# accountChangeEvent

**Framework**: CloudKit  
**Kind**: property  
**Role**: Instance Property

The event downcast to the subclass that represents a change to the device’s iCloud account.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+
