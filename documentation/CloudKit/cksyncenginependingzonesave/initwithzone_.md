# initWithZone:

**Framework**: CloudKit  
**Kind**: method  
**Role**: Instance Method

Creates a pending zone save for the specified record zone.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```objc
- (instancetype) initWithZone:(CKRecordZone *) zone;
```

## Return Value

An initialized pending zone save.

## Parameters

- `zone`: The record zone to save.
