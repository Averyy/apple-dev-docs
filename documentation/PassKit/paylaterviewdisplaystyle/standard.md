# standard

**Framework**: PassKit (Apple Pay and Wallet)  
**Kind**: property  
**Role**: Type Property

The standard Apple Pay Later visual merchandising widget style.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+

> **Deprecated**: Apple Pay Later is deprecated.
