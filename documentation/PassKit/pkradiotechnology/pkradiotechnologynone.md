# PKRadioTechnologyNone

**Framework**: PassKit (Apple Pay and Wallet)  
**Kind**: case  
**Role**: Enumeration Case

An identifier that indicates the pass doesn’t use radio frequency communication.

**Availability**:
- iOS 14.5+
- iPadOS 14.5+
- Mac Catalyst 14.5+
- macOS
- visionOS 1.0+
- watchOS 7.3+
