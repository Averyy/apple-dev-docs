# version

**Framework**: System Configuration  
**Kind**: property  
**Role**: Instance Property

The version number of the structure type being passed in as a parameter to the `SCDynamicStore` creation function (such as [`SCDynamicStoreCreate(_:_:_:_:)`](../scdynamicstorecreate%28_,_,_,_%29.md)). This structure is version `0`.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
