# MLFinalCutEventLibraryGroupTypeIdentifier

**Framework**: Media Library  
**Kind**: var  
**Role**: Global Variable

The media group that represents the event library in Final Cut Pro. The event library contains all event calendar groups.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.9+ - Deprecated in 10.15

> **Deprecated**: MediaLibrary.framework will be removed in a future OS version. Use Photos.framework or iTunesLibrary.framework instead.
