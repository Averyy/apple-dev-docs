# CFAttributedStringEndEditing(_:)

**Framework**: Core Foundation  
**Kind**: func  
**Role**: Function

Re-enables internal consistency-checking and coalescing for a mutable attributed string.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
func CFAttributedStringEndEditing(_ aStr: CFMutableAttributedString!)
```

```c
extern void CFAttributedStringEndEditing(CFMutableAttributedStringRef aStr);
```

## Parameters

- `aStr`: A mutable attributed string, following a call to [`CFAttributedStringBeginEditing(_:)`](./cfattributedstringbeginediting%28_%29.md).
