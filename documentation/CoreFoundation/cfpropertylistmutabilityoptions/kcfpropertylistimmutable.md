# kCFPropertyListImmutable

**Framework**: Core Foundation  
**Kind**: case  
**Role**: Enumeration Case

Specifies that the property list should be immutable.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS
