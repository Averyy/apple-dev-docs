# naNSymbol

**Framework**: Core Foundation  
**Kind**: property  
**Role**: Type Property

Specifies the string that is used to represent NaN (“not a number”) when values are converted to strings, a `CFString` object.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS
