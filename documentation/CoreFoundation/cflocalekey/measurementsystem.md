# measurementSystem

**Framework**: Core Foundation  
**Kind**: property  
**Role**: Type Property

Specifies the measurement system used.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
static let measurementSystem: CFLocaleKey!
```

```c
extern CFLocaleKey const kCFLocaleMeasurementSystem;
```

## Discussion

The corresponding value is a CFString object, for example “Metric” or “U.S.”.
