# SEL

**Framework**: Objective-C Runtime  
**Kind**: typealias  
**Role**: Type Alias

Defines an opaque type that represents a method selector.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```c
typedef struct objc_selector * SEL;
```

#### Discussion

Method selectors are used to represent the name of a method at runtime. A method selector is a C string that has been registered (or “mapped”) with the Objective-C runtime. Selectors generated by the compiler are automatically mapped by the runtime when the class is loaded.

You can add new selectors at runtime and retrieve existing selectors using the function [`sel_registerName(_:)`](./sel_registername%28_%29.md).

When using selectors, you must use the value returned from [`sel_registerName(_:)`](./sel_registername%28_%29.md) or the Objective-C compiler directive `@selector()`. You cannot simply cast a C string to `SEL`.
