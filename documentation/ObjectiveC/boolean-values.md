# Boolean Values

**Framework**: Objective-C Runtime  
**Role**: API Collection

These macros define convenient constants to represent Boolean values.

## Topics

### Constants
- [YES](./yes.md)
  Defines `YES` as `1`.
- [NO](./no.md)
  Defines `NO` as `0`.
