# NO

**Framework**: Objective-C Runtime  
**Kind**: macro  
**Role**: Macro

Defines `NO` as `0`.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```c
#define NO
```

#### Discussion

The `NO` macro from Objective-C is bridged to Swift as an [`ObjCBool`](./objcbool.md) value of `false`.
