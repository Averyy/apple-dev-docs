# YES

**Framework**: Objective-C Runtime  
**Kind**: macro  
**Role**: Macro

Defines `YES` as `1`.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```c
#define YES
```

## Discussion

The `YES` macro from Objective-C is bridged to Swift as an [`ObjCBool`](./objcbool.md) value of `true`.
