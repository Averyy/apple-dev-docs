# titleText

**Framework**: TVUIKit  
**Kind**: property  
**Role**: Instance Property

**Availability**:
- tvOS 12.0+

## Declaration

```swift
var titleText: String? { get set }
```


#### Discussion

The title is displayed along the top of the view.
