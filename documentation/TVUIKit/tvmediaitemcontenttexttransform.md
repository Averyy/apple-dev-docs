# TVMediaItemContentTextTransform

**Framework**: TVUIKit  
**Kind**: enum  
**Role**: Enumeration

Constants that specify the transform to apply to the text.

**Availability**:
- tvOS 15.0+

## Declaration

```c
enum TVMediaItemContentTextTransform : NSInteger;
```

- [TVMediaItemContentTextTransformLowercase](./tvmediaitemcontenttexttransform/tvmediaitemcontenttexttransformlowercase.md)
  A transform for displaying the text in all lowercase characters.
- [TVMediaItemContentTextTransformUppercase](./tvmediaitemcontenttexttransform/tvmediaitemcontenttexttransformuppercase.md)
  A transform for displaying the text in all uppercase characters.
