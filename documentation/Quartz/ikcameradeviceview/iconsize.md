# iconSize

**Framework**: Quartz  
**Kind**: property  
**Role**: Instance Property

Specifies the icon size.

**Availability**:
- macOS 10.6+

## Declaration

```swift
var iconSize: Int { get set }
```

```objc
@property NSUInteger iconSize;
```

## Discussion

The icon is square, so only a single dimension is required.
