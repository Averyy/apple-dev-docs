# Deprecated Annotations

**Framework**: Quartz

These symbols are deprecated and should no longer be used.

## Topics

### Deprecated Annotation Types
- [class PDFAnnotationButtonWidget](../pdfkit/pdfannotationbuttonwidget.md)
  A `PDFAnnotationButtonWidget` object provides user interactivity on a page of a PDF document. There are three types of buttons available: push button, radio button, and checkbox.
- [class PDFAnnotationChoiceWidget](../pdfkit/pdfannotationchoicewidget.md)
  A `PDFAnnotationChoiceWidget` object provides user interactivity on a page of a PDF document, in the form of pop-up menus and lists.
- [class PDFAnnotationCircle](../pdfkit/pdfannotationcircle.md)
- [class PDFAnnotationFreeText](../pdfkit/pdfannotationfreetext.md)
  A `PDFAnnotationFreeText` object displays text on a page.
- [class PDFAnnotationInk](../pdfkit/pdfannotationink.md)
- [class PDFAnnotationLine](../pdfkit/pdfannotationline.md)
  A `PDFAnnotationLine` object displays a single line on a page.
- [class PDFAnnotationLink](../pdfkit/pdfannotationlink.md)
- [class PDFAnnotationMarkup](../pdfkit/pdfannotationmarkup.md)
  A `PDFAnnotationMarkup` object appears as highlighting, underlining, or a strikethrough style applied to the text of a document.
- [class PDFAnnotationPopup](../pdfkit/pdfannotationpopup.md)
  A `PDFAnnotationPopup` object provides user interactivity on a PDF page in the form of a pop-up menu.
- [class PDFAnnotationSquare](../pdfkit/pdfannotationsquare.md)
  A rectangle annotation on a page.
- [class PDFAnnotationStamp](../pdfkit/pdfannotationstamp.md)
  A `PDFAnnotationStamp` object allows you to display a word or phrase, such as “Confidential,” in a PDF page.
- [class PDFAnnotationText](../pdfkit/pdfannotationtext.md)
  A `PDFAnnotationText` object displays as an icon (such as a “sticky note”) attached to a specified point in the PDF document.
- [class PDFAnnotationTextWidget](../pdfkit/pdfannotationtextwidget.md)
  A `PDFAnnotationTextWidget` object allows you to manage the appearance and content of text fields.
