# setMirroring(_:)

**Framework**: Quartz  
**Kind**: method  
**Role**: Instance Method

Controls whether the receiver enables video mirroring during snapshots.

**Availability**:
- macOS 10.4+

## Declaration

```swift
func setMirroring(_ b: Bool)
```

```objc
- (void) setMirroring:(BOOL) b;
```

## Parameters

- `b`: The default setting is [`true`](../../Swift/true.md).
