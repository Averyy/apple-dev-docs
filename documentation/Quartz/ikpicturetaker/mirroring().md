# mirroring()

**Framework**: Quartz  
**Kind**: method  
**Role**: Instance Method

Returns whether video mirroring is enabled during snapshots.

**Availability**:
- macOS 10.4+

## Declaration

```swift
func mirroring() -> Bool
```

```objc
- (BOOL) mirroring;
```

#### Return Value

Returns YES if video mirroring is enabled, NO otherwise.
