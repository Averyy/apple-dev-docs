# inputImage()

**Framework**: Quartz  
**Kind**: method  
**Role**: Instance Method

Returns the  input  image associated with the picture taker.

**Availability**:
- macOS 10.4+

## Declaration

```swift
func inputImage() -> NSImage!
```

```objc
- (NSImage *) inputImage;
```

## Return Value

The input image.

## Discussion

The input image is never modified by the picture taker.
