# initWithFrame:

**Framework**: Quartz  
**Kind**: method  
**Role**: Instance Method

Initializes a newly allocated image browser view with the provided frame rectangle.

**Availability**:
- macOS 10.4+

## Declaration

```objc
- (id) initWithFrame:(NSRect) frame;
```

## Return Value

The initialized object.

## Parameters

- `frame`: The rectangle for the image browser.
