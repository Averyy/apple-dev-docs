# hasAdjustMode

**Framework**: Quartz  
**Kind**: property  
**Role**: Instance Property

**Availability**:
- macOS 10.4+



#### Return Value

[`true`](../../Swift/true.md) if the tab should be displayed, otherwise NO.
