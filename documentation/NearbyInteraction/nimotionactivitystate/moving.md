# NIMotionActivityState.moving

**Framework**: Nearby Interaction  
**Kind**: case  
**Role**: Case

A value that indicates the accessory is moving.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+

## Declaration

```swift
case moving
```

```c
NIMotionActivityStateMoving
```

## Discussion

Update the session with this state when the accessory begins moving.
