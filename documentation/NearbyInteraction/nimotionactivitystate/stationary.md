# NIMotionActivityState.stationary

**Framework**: Nearby Interaction  
**Kind**: case

A value that indicates the accessory isn’t moving.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+

## Declaration

```swift
case stationary
```

#### Discussion

Update the session with this state when the accessory stops moving.
