# format

**Framework**: TVML  
**Role**: Article

Specifies how a date is displayed.

#### Overview

Here’s an example that sets the date to January 19, 2031.

```xml
<date format="MMMM dd, yyyy">2031-01-19</date>
```

##### Values for format

- **String**: The format for the date string.

##### Elements that Use format

- [date](./date.md)
