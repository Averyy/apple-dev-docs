# rowCount

**Framework**: TVML  
**Role**: Article

Specifies the number of rows in a shelf.

## Overview

Items inside of the shelf fill up a column before moving to the next column.

### Values for rowCount

- **Integer**: The number of rows contained inside of a shelf.

### Values that Use rowCount

- [shelf](./shelf.md)
