# HostSDKPolicy.matchingPreferred

**Framework**: xcselect  
**Kind**: case  
**Role**: Case

Return an SDK that matches the host’s major OS version if it is available, otherwise return the latest macOS SDK available.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.15+
