# init()

**Framework**: Core WLAN  
**Kind**: init  
**Role**: Initializer

Initializes a Wi-Fi client object.

**Availability**:
- macOS 10.10+

## Declaration

```swift
init()
```

```objc
- (instancetype) init;
```

## Discussion

Instead of initializing a Wi-Fi client directly, consider using the shared instance available from the [`shared()`](./shared%28%29.md) class method.
