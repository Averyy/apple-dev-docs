# init()

**Framework**: Core WLAN  
**Kind**: init  
**Role**: Initializer

Creates and returns a CWNetworkProfile object.

**Availability**:
- macOS 10.7+

## Declaration

```swift
init()
```

```objc
- (instancetype) init;
```

## Return Value

An CWNetworkProfile object.

## Discussion

This method is the designated initializer for the CWNetworkProfile class.
