# init(_:)

**Framework**: ExtensionFoundation  
**Kind**: init

Initializes the type with the specified Boolean value.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+

## Declaration

```swift
init(_ value: Bool = true)
```

## Parameters

- `value`: `true` if the extension point requires extra security, or `false` if it doesn’t.
