# MarketplaceKitError.missingInstallVerificationToken

**Framework**: MarketplaceKit  
**Kind**: case  
**Role**: Case

An error that indicates the required install verification token is missing.

**Availability**:
- iOS 17.4+
- iPadOS 17.4+
