# MarketplaceKitError.installationOfMarketplaceDenied

**Framework**: MarketplaceKit  
**Kind**: case  
**Role**: Case

An error that indicates that the device disallows the installation of marketplaces.

**Availability**:
- iOS 17.4+
- iPadOS 17.4+
