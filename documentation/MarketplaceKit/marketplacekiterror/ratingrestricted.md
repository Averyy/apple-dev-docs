# MarketplaceKitError.ratingRestricted

**Framework**: MarketplaceKit  
**Kind**: case  
**Role**: Case

An error that indicates the requested app’s age rating is beyond that allowed for the device.

**Availability**:
- iOS 17.4+
- iPadOS 17.4+
