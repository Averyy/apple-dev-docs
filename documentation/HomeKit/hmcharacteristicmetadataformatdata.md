# HMCharacteristicMetadataFormatData

**Framework**: HomeKit  
**Kind**: var  
**Role**: Global Variable

Indicates that the characteristic has data blob values.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 8.0+
- tvOS 10.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
let HMCharacteristicMetadataFormatData: String
```

```c
extern NSString * const HMCharacteristicMetadataFormatData;
```

#### Discussion

The value is an [`NSData`](../Foundation/nsdata.md) object containing bytes of data.
