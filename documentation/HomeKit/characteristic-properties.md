# Characteristic Properties

**Framework**: HomeKit  
**Role**: API Collection

The properties that characteristics can have.

#### Overview

Check to see if a characteristic’s [`properties`](./hmcharacteristic/properties.md) array contains any of these constants to learn something about the corresponding characteristic ([`HMCharacteristic`](./hmcharacteristic.md)).

## Topics

### Properties of Characteristics
- [let HMCharacteristicPropertyReadable: String](./hmcharacteristicpropertyreadable.md)
  The characteristic is readable.
- [let HMCharacteristicPropertyWritable: String](./hmcharacteristicpropertywritable.md)
  The characteristic is writable.
- [let HMCharacteristicPropertyHidden: String](./hmcharacteristicpropertyhidden.md)
  The characteristic should be hidden from the user.
- [HMCharacteristicPropertySupportsEventNotification](./hmcharacteristicpropertysupportseventnotification-19wy1.md)
  The characteristic supports event notifications.
