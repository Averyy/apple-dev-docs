# HMError.Code.accessDenied

**Framework**: HomeKit  
**Kind**: case  
**Role**: Case

An error indicating the current user doesn’t have privileges to perform the operation.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 8.0+
- tvOS 10.0+
- visionOS 1.0+
- watchOS 2.0+
