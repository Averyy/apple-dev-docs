# HMCharacteristicMetadataFormatFloat

**Framework**: HomeKit  
**Kind**: var  
**Role**: Global Variable

Indicates that the characteristic has `float` values.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 8.0+
- tvOS 10.0+
- visionOS 1.0+
- watchOS 2.0+
