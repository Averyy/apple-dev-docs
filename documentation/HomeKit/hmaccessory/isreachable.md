# isReachable

**Framework**: HomeKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value indicating whether the accessory can be communicated with in the current network environment.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 8.0+
- tvOS 10.0+
- visionOS 1.0+
- watchOS 2.0+
