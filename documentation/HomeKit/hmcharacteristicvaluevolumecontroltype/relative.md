# HMCharacteristicValueVolumeControlType.relative

**Framework**: HomeKit  
**Kind**: case  
**Role**: Case

The volume adjusts incrementally, without taking the current level into consideration.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- tvOS 18.0+
