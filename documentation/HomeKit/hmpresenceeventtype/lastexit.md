# HMPresenceEventType.lastExit

**Framework**: HomeKit  
**Kind**: case  
**Role**: Case

Triggers an event when the last user leaves the home.

**Availability**:

- iPadOS 11.0+
- Mac Catalyst 11.0+
- tvOS 11.0+
