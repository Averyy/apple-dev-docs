# init(transferToken:)

**Framework**: HomeKit  
**Kind**: init

Creates a structure that contains the token you need to transfer a temporary home to a person’s home hub.

**Availability**:
- iOS 26.4+
- iPadOS 26.4+

## Declaration

```swift
init(transferToken: Data)
```

#### Return Value

The structure that contains the token you need to transfer a temporary home to a person’s home hub.

## Parameters

- `transferToken`: An opaque token you need to transfer a temporary home to a person’s home hub.
