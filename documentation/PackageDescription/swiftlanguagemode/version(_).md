# SwiftLanguageMode.version(_:)

**Framework**: PackageDescription  
**Kind**: case  
**Role**: Case

A user-defined value for the Swift version.

## Declaration

```swift
case version(String)
```

#### Discussion

The value is passed as-is to the Swift compiler’s `-swift-version` flag.
