# init(tool:)

**Framework**: Foundation Models  
**Kind**: init

Creates a tool definition that describes the tool you provide.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- visionOS 26.0+
- watchOS 27.0+

## Declaration

```swift
init(tool: some Tool)
```

## Parameters

- `tool`: The tool whose name, description, and parameters describe the definition.
