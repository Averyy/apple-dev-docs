# usage

**Framework**: Foundation Models  
**Kind**: property

The total accumulated usage across all responses generated by this session.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- visionOS 27.0+
- watchOS 27.0+

## Declaration

```swift
final var usage: LanguageModelSession.Usage { get }
```

#### Discussion

This value increases monotonically over the lifetime of the session.
