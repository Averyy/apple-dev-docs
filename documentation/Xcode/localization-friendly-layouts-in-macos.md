# Localization-friendly layouts in macOS

**Framework**: Xcode  
**Role**: Sample Code  
**Download**: [LocalizationFriendlyLayoutsInMacOS.zip](https://docs-assets.developer.apple.com/published/3db0b11a1ce3/LocalizationFriendlyLayoutsInMacOS.zip)

This project demonstrates localization-friendly auto layout constraints.

**Availability**:
- macOS 10.14+
- Xcode 12.0+

## Overview

The sample uses `NSGridView` as a container view to achieve localized layouts.

## Overview

> **Note**: This sample code project is associated with WWDC 2020 session [10219: Build localization-friendly layouts using Xcode](https://developer.apple.com/videos/play/wwdc2020/10219/).
