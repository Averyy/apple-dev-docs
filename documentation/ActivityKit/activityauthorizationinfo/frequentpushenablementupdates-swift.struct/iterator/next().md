# next()

**Framework**: ActivityKit  
**Kind**: method  
**Role**: Instance Method

Asynchronously advances to the next element and returns it, or ends the sequence if there is no next element.

**Availability**:
- iOS 16.2+
- iPadOS 16.2+
- Mac Catalyst 27.3+ (Beta)
- macOS 27.3+ (Beta)
