# activityUpdates

**Framework**: ActivityKit  
**Kind**: property  
**Role**: Type Property

An asynchronous sequence you use to observe changes to ongoing Live Activities and to asynchronously access a Live Activity when you start it.

**Availability**:
- iOS 16.1+
- iPadOS 16.1+
