# kColorSyncCameraDeviceClass

**Framework**: ColorSync  
**Kind**: var

The device class for a camera device.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.13+

## Declaration

```swift
var kColorSyncCameraDeviceClass: Unmanaged<CFString>!
```

#### Discussion

The string that represents a camera device is `cmra`.
