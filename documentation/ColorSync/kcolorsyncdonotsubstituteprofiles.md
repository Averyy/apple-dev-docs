# kColorSyncDoNotSubstituteProfiles

**Framework**: ColorSync  
**Kind**: var

An option that, when set to `kCFBooleanTrue`, skips substituting a matching system-provided profile.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 13.0+
- macOS 10.13+
- tvOS 16.0+
- visionOS 1.0+
- watchOS 9.0+
