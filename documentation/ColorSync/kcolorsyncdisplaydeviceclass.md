# kColorSyncDisplayDeviceClass

**Framework**: ColorSync  
**Kind**: var

The device class for a display device.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.13+

## Declaration

```swift
var kColorSyncDisplayDeviceClass: Unmanaged<CFString>!
```

#### Discussion

The string that represents a display device is `mntr`.
