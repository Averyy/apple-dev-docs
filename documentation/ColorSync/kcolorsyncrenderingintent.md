# kColorSyncRenderingIntent

**Framework**: ColorSync  
**Kind**: var

A key for the rendering intent to use for the profile in a profile-sequence dictionary.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 13.0+
- macOS 10.13+
- tvOS 16.0+
- visionOS 1.0+
- watchOS 9.0+
