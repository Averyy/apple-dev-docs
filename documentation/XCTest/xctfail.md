# XCTFail

**Framework**: XCTest  
**Kind**: macro  
**Role**: Macro

This function generates a failure immediately and unconditionally.

## Declaration

```c
#define XCTFail(...)
```

## Parameters

- `…`: An optional description of the failure. A literal [`NSString`](../Foundation/nsstring.md), optionally with string format specifiers.
