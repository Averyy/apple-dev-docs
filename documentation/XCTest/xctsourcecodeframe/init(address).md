# init(address:)

**Framework**: XCTest  
**Kind**: init  
**Role**: Initializer

Initializes an instance with a frame address.

## Declaration

```swift
convenience init(address: UInt64)
```

```objc
- (instancetype) initWithAddress:(uint64_t) address;
```

## Parameters

- `address`: An address that represents a specific frame in a call stack.
