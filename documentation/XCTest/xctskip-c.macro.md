# XCTSkip

**Framework**: XCTest  
**Kind**: macro  
**Role**: Macro

Throws an exception that causes the test runner to cease executing the current test and mark the test skipped.

## Declaration

```c
#define XCTSkip(...)
```

### Methods for Skipping Tests
