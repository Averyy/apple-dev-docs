# init(application:)

**Framework**: XCTest  
**Kind**: init  
**Role**: Initializer

Initializes a metric that measures memory use in the target app.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- tvOS 13.0+
- visionOS 1.0+
- watchOS 7.0+
