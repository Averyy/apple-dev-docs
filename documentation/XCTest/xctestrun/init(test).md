# init(test:)

**Framework**: XCTest  
**Kind**: init  
**Role**: Initializer

Creates a new test run for the provided test.

## Declaration

```swift
init(test: XCTest)
```

```objc
- (instancetype) initWithTest:(XCTest *) test;
```

#### Return Value

A test run for the provided test.

## Parameters
