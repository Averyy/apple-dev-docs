# videoNodeWithVideoURL:

**Framework**: SpriteKit  
**Kind**: method  
**Role**: Type Method

Creates and initializes a video node using a URL that points to a video file.

**Availability**:
- iOS 7.0+ - Deprecated in 9.0
- iPadOS 7.0+ - Deprecated in 9.0
- Mac Catalyst 13.1+ - Deprecated in 13.1
- macOS 10.8+ - Deprecated in 10.11
- tvOS - Deprecated in 9.0
- visionOS 1.0+ - Deprecated in 1.0
- watchOS 2.0+ - Deprecated in 2.0

> **Deprecated**: Use [`videoNodeWithURL:`](./videonodewithurl_.md) instead.

## Declaration

```objc
+ (SKVideoNode *) videoNodeWithVideoURL:(NSURL *) videoURL;
```

#### Return Value

An initialized video node.

## Parameters

- `videoURL`: The URL for the video to play.
