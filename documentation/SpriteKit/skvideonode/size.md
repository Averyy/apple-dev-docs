# size

**Framework**: SpriteKit  
**Kind**: property  
**Role**: Instance Property

The dimensions of the video node, in points.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift

```

```objc

```

## Mentions

The default value is the size of the video used to instantiate the node.
