# videoNodeWithVideoFileNamed:

**Framework**: SpriteKit  
**Kind**: method  
**Role**: Type Method

Creates and initializes a new video node using a video file stored in the app bundle.

**Availability**:
- iOS 7.0+ - Deprecated in 9.0
- iPadOS 7.0+ - Deprecated in 9.0
- Mac Catalyst 13.1+ - Deprecated in 13.1
- macOS 10.8+ - Deprecated in 10.11
- tvOS - Deprecated in 9.0
- visionOS 1.0+ - Deprecated in 1.0
- watchOS 2.0+ - Deprecated in 2.0

> **Deprecated**: Use [`videoNodeWithFileNamed:`](./videonodewithfilenamed_.md) instead.

## Declaration

```objc
+ (SKVideoNode *) videoNodeWithVideoFileNamed:(NSString *) videoFile;
```

#### Return Value

A new video node.

## Parameters

- `videoFile`: The name of the video file.
