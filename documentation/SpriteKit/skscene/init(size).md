# init(size:)

**Framework**: SpriteKit  
**Kind**: init  
**Role**: Initializer

Initializes a new scene object.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
init(size: CGSize)
```

```objc
- (instancetype) initWithSize:(CGSize) size;
```

#### Return Value

A newly initialized scene object.

#### Discussion

This is the class’s designated initializer method.

## Parameters

- `size`: The size of the scene in points.
