# init(capacity:)

**Framework**: SpriteKit  
**Kind**: init  
**Role**: Initializer

Initializes a new keyframe sequence.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
convenience init(capacity numItems: Int)
```

```objc
- (instancetype) initWithCapacity:(NSUInteger) numItems;
```

#### Return Value

A newly initialized empty sequence.

#### Discussion

## Parameters

- `numItems`: The initial capacity of the new sequence.
