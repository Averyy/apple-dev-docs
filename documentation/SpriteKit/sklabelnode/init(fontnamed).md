# init(fontNamed:)

**Framework**: SpriteKit  
**Kind**: init  
**Role**: Initializer

Initializes a new label object with a specified font.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
init(fontNamed fontName: String?)
```

```objc
- (instancetype) initWithFontNamed:(NSString *) fontName;
```

#### Return Value

An initialized label object.

## Parameters

- `fontName`: The name of the font used by the label.
