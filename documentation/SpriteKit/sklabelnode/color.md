# color

**Framework**: SpriteKit  
**Kind**: property  
**Role**: Instance Property

An alternative to the font color that can be used for animations.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS
