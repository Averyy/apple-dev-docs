# setScale(_:)

**Framework**: SpriteKit  
**Kind**: method  
**Role**: Instance Method

Sets the [`xScale`](./xscale.md) and [`yScale`](./yscale.md) properties of the node.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
func setScale(_ scale: CGFloat)
```

```objc
- (void) setScale:(CGFloat) scale;
```

## Parameters

- `scale`: The new value to use for the node’s [`xScale`](./xscale.md) and [`yScale`](./yscale.md) properties.
