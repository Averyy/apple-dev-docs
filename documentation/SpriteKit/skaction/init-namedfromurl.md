# init(named:fromURL:)

**Framework**: SpriteKit  
**Kind**: init

Creates an action of the given name from an action file.

**Availability**:
- iOS 9.0+
- iPadOS 9.0+
- Mac Catalyst 13.1+
- macOS 10.11+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
init?(named name: String, fromURL url: URL)
```

#### Return Value

A new action object.

## Parameters

- `name`: The name of the action.
- `url`: The URL of the file containing the action.
