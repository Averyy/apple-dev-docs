# particleLifetime

**Framework**: SpriteKit  
**Kind**: property  
**Role**: Instance Property

The average lifetime of a particle, in seconds.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
var particleLifetime: CGFloat { get set }
```

```objc
@property (nonatomic) CGFloat particleLifetime;
```

## Discussion

The default value is `0.0`.
