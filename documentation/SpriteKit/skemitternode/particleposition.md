# particlePosition

**Framework**: SpriteKit  
**Kind**: property  
**Role**: Instance Property

The average starting position for a particle.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
var particlePosition: CGPoint { get set }
```

```objc
@property (nonatomic) CGPoint particlePosition;
```

## Discussion

The default value is `(0.0,0.0)`.
