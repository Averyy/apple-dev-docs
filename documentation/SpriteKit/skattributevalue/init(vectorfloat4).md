# init(vectorFloat4:)

**Framework**: SpriteKit  
**Kind**: init  
**Role**: Initializer

Creates and initializes a new attribute value object that holds a vector of four floating point numbers.

**Availability**:
- iOS 9.0+
- iPadOS 9.0+
- Mac Catalyst 13.1+
- macOS 10.11+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
convenience init(vectorFloat4 value: vector_float4)
```

```objc
+ (instancetype) valueWithVectorFloat4:(vector_float4) value;
```

#### Return Value

A new attribute value object.

## Parameters

- `value`: The vector of four point values for the new attribute value.
