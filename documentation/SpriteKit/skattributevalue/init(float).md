# init(float:)

**Framework**: SpriteKit  
**Kind**: init  
**Role**: Initializer

Creates and initializes a new attribute value object that holds a floating point number.

**Availability**:
- iOS 9.0+
- iPadOS 9.0+
- Mac Catalyst 13.1+
- macOS 10.11+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
convenience init(float value: Float)
```

```objc
+ (instancetype) valueWithFloat:(float) value;
```

#### Return Value

A new attribute value object.

## Parameters

- `value`: The floating point value for the new attribute value.
