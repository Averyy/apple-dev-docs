# blendMode

**Framework**: SpriteKit  
**Kind**: property  
**Role**: Instance Property

The blend mode used to blend the shape into the parent’s framebuffer.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```swift
var blendMode: SKBlendMode { get set }
```

```objc
@property (nonatomic) SKBlendMode blendMode;
```

## Discussion

The default value is [`SKBlendMode.alpha`](../skblendmode/alpha.md).
