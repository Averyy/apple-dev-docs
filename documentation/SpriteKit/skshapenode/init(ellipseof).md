# init(ellipseOf:)

**Framework**: SpriteKit  
**Kind**: init  
**Role**: Initializer

Creates a shape node with an elliptical path centered on the node’s origin.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.10+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 1.0+

## Declaration

```swift
convenience init(ellipseOf size: CGSize)
```

```objc
+ (instancetype) shapeNodeWithEllipseOfSize:(CGSize) size;
```

## Return Value

A new shape node.

## Parameters

- `size`: The height and width of the ellipse.
