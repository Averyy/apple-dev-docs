# GenerateCompletionInfo

**Framework**: mlx-swift-lm/MLXLMCommon  
**Kind**: struct  
**Role**: Structure

Represents metadata and statistics related to token generation.

## Declaration

```swift
struct GenerateCompletionInfo
```

## Mentions

- [Observing token log probabilities](./generation-observability.md)

## Overview

Provides information about the number of tokens processed during both the prompt and generation phases, as well as the time taken for each phase.

### Instance Properties
- [let acceptedDraftTokens: Int?](./generatecompletioninfo/accepteddrafttokens.md)
  Total tokens accepted by the target across all speculation rounds in this stream, or nil for non-MTP iterators. The acceptance rate is `Double(acceptedDraftTokens) / Double(proposedDraftTokens)` when both are non-nil and proposed > 0.
- [let answerTokenCount: Int?](./generatecompletioninfo/answertokencount.md)
  Generated tokens outside the reasoning span when a thinking budget was configured.
- [var cacheEfficiency: Double](./generatecompletioninfo/cacheefficiency.md)
  Fraction of the prompt served from cache, in `0...1`.
- [var cachedPromptTokenCount: Int](./generatecompletioninfo/cachedprompttokencount.md)
  The number of prompt tokens served by a reused KV-cache prefix instead of being prefilled, or `0` when the whole prompt was prefilled.
- [let evictedTokenCount: Int](./generatecompletioninfo/evictedtokencount.md)
  Context tokens no longer retained by at least one rotating attention cache.
- [let generateTime: TimeInterval](./generatecompletioninfo/generatetime.md)
  The time interval (in seconds) taken to generate the output tokens.
- [let generationTokenCount: Int](./generatecompletioninfo/generationtokencount.md)
  The number of tokens generated by the language model.
- [let passthroughReason: String?](./generatecompletioninfo/passthroughreason.md)
  Non-nil when the MTP iterator transitioned into sticky-passthrough mode for the remainder of the stream; carries the reason string captured at the moment of engagement. Nil if the iterator stayed speculative for the full stream or for non-MTP streams.
- [let promptTime: TimeInterval](./generatecompletioninfo/prompttime.md)
  The time interval (in seconds) taken to process the input prompt.
- [let promptTokenCount: Int](./generatecompletioninfo/prompttokencount.md)
  The number of prompt tokens actually prefilled during this generation.
- [var promptTokensPerSecond: Double](./generatecompletioninfo/prompttokenspersecond.md)
  The number of tokens processed per second during the prompt phase.
- [let proposedDraftTokens: Int?](./generatecompletioninfo/proposeddrafttokens.md)
  Total tokens proposed by the MTP drafter across all speculation rounds in this stream, or nil for non-MTP iterators. Sourced from the iterator’s [`MTPStatsCollecting`](./mtpstatscollecting.md) conformance when present.
- [let reasoningTokenCount: Int?](./generatecompletioninfo/reasoningtokencount.md)
  Tokens emitted inside the reasoning span when a thinking budget was configured.
- [let recoveredToolCallCount: Int](./generatecompletioninfo/recoveredtoolcallcount.md)
  Number of accepted calls produced by bounded cross-dialect recovery. Native-format calls are intentionally excluded.
- [let rejectedToolCallCount: Int](./generatecompletioninfo/rejectedtoolcallcount.md)
  Number of tool-call-shaped outputs rejected during this generation.
- [let speculativeDecodingTelemetry: SpeculativeDecodingTelemetry?](./generatecompletioninfo/speculativedecodingtelemetry.md)
  Speculative decoding telemetry, when generation used speculative decoding.
- [let stopReason: GenerateStopReason](./generatecompletioninfo/stopreason.md)
  Reason generation stopped.
- [var tokensPerSecond: Double](./generatecompletioninfo/tokenspersecond.md)
  The number of tokens generated per second during the generation phase.
- [var totalPromptTokenCount: Int](./generatecompletioninfo/totalprompttokencount.md)
  The rendered prompt length: the reused cache prefix plus the prefilled tokens.
