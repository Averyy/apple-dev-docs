# init(_:context:)

**Framework**: swift-configuration/Configuration  
**Kind**: init  
**Role**: Initializer

Creates a new configuration key.

**Availability**:
- iOS 18.0+
- macOS 15.0+
- tvOS 18.0+
- visionOS 2.0+
- watchOS 11.0+

## Declaration

```swift
init(_ string: String, context: [String : ConfigContextValue] = [:])
```

## Parameters

- `string`: The string representation of the key path, for example `"http.timeout"`.
- `context`: Additional context information for the key.
