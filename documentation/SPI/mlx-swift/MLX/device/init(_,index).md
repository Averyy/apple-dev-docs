# init(_:index:)

**Framework**: mlx-swift/MLX  
**Kind**: init  
**Role**: Initializer

Initialize a new `Device` with a type and optional index.

## Declaration

```swift
init(_ deviceType: DeviceType, index: Int32 = 0)
```

#### Discussion

If `deviceType` is [`DeviceType.cpu`](../devicetype/cpu.md) then index *must* be 0.
