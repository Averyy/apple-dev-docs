# start(_:)

**Framework**: mlx-swift/MLX  
**Kind**: method  
**Role**: Instance Method

Start index using numpy conventions.

## Declaration

```swift
func start(_ size: Int32) -> Int32
```

#### Discussion

If `start` is not given it will be `size - 1` if [`stride`](./stride.md) is negative or `0` if positive.
