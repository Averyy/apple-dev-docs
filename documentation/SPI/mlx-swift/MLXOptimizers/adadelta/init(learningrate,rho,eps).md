# init(learningRate:rho:eps:)

**Framework**: mlx-swift/MLXOptimizers  
**Kind**: init  
**Role**: Initializer

Initialize the optimizer.

## Declaration

```swift
init(learningRate: Float, rho: Float = 0.9, eps: Float = 1e-6)
```

## Parameters

- `learningRate`: The learning rate
- `rho`: The coefficient used for computing a running average of squared gradients
- `eps`: The epsilon added to the denominator to improve numerical stability
