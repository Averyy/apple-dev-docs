# Upsample.Mode.linear(alignCorners:)

**Framework**: mlx-swift/MLXNN  
**Kind**: case  
**Role**: Case

Linear interpolation subsampling.  If `alignCorners` is `true` then the top and left edge of the input and output will match as will the bottom right edge.

## Declaration

```swift
case linear(alignCorners: Bool = false)
```
