# init(title:visibility:)

**Framework**: swift-argument-parser/ArgumentParser  
**Kind**: init  
**Role**: Initializer

Creates a property that represents another parsable type, using the specified title and visibility.

## Declaration

```swift
init(title: String = "", visibility: ArgumentVisibility = .default)
```

## Parameters

- `title`: A title for grouping this option group’s members in your command’s help screen. If `title` is empty, the members will be displayed alongside the other arguments, flags, and options declared by your command.
- `visibility`: The visibility to use for the entire option group.
