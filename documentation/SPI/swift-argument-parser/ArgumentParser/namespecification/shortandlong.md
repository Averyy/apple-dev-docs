# shortAndLong

**Framework**: swift-argument-parser/ArgumentParser  
**Kind**: property  
**Role**: Type Property

Combine the `.short` and `.long` specifications to allow both long and short labels.

## Declaration

```swift
static var shortAndLong: NameSpecification { get }
```

## Discussion

For example, a property named `verbose` would be converted to both the long `--verbose` and short `-v` labels.
