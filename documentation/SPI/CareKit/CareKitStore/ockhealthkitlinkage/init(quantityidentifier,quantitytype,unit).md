# init(quantityIdentifier:quantityType:unit:)

**Framework**: CareKit/CareKitStore  
**Kind**: init  
**Role**: Initializer

Initialize by specifying HealthKit types.

## Declaration

```swift
init(quantityIdentifier: HKQuantityTypeIdentifier, quantityType: QuantityType, unit: HKUnit)
```

## Parameters

- `quantityIdentifier`: A HealthKitQuantityIdentifier that describes the outcome’s data type.
- `quantityType`: Determines what kind of query will be used to fetch data from HealthKit.
- `unit`: A HealthKit unit that will be associated with outcomes saved to and fetched from HealthKit.
