# updateTasks(_:)

**Framework**: CareKit/CareKitStore  
**Kind**: method  
**Role**: Instance Method

`updateTasks` asynchronously updates an array of tasks in the store.

## Declaration

```swift

```

## Parameters

- `tasks`: An array of tasks to be updated. The tasks must already exist in the store.
