# attach(contactStore:)

**Framework**: CareKit/CareKitStore  
**Kind**: method  
**Role**: Instance Method

Attaches a new store. The new store must be capable of reading and writing contacts.

## Declaration

```swift
func attach(contactStore: OCKAnyContactStore)
```

#### Discussion

> **Note**: The order is which stores are attached is important.

> **See Also**: `OCKStoreCoordinator`

## Parameters

- `contactStore`: Any store that conforms to `OCKAnyContactStore`.
