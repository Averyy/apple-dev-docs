# attachReadOnly(contactStore:)

**Framework**: CareKit/CareKitStore  
**Kind**: method  
**Role**: Instance Method

Attaches a new store. The new store must be capable of reading contacts.

## Declaration

```swift
func attachReadOnly(contactStore: OCKAnyReadOnlyContactStore)
```

#### Discussion

> **Note**: The order is which stores are attached is important.

> **See Also**: `OCKStoreCoordinator`

## Parameters

- `contactStore`: Any store that conforms to `OCKAnyReadOnlyContactStore`.
