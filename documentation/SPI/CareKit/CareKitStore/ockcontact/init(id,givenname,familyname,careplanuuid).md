# init(id:givenName:familyName:carePlanUUID:)

**Framework**: CareKit/CareKitStore  
**Kind**: init  
**Role**: Initializer

Initialize a new `OCKContact` with a user-defined id, a name, and an optional care plan version ID.

## Declaration

```swift
init(id: String, givenName: String, familyName: String, carePlanUUID: UUID?)
```

## Parameters

- `id`: A user-defined id
- `givenName`: The contact’s given name
- `familyName`: The contact’s family name
- `carePlanUUID`: The local database id of the care plan with which this contact is associated.
