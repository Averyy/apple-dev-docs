# init(html:imageOverlayStyle:showsCloseButton:)

**Framework**: CareKit/CareKit  
**Kind**: init  
**Role**: Initializer

Create an instance.

## Declaration

```swift
@MainActor
init(html: OCKDetailView.StyledHTML? = nil, imageOverlayStyle: UIUserInterfaceStyle = .unspecified, showsCloseButton: Bool = false)
```

## Parameters

- `html`: HTML to render as the `bodyLabel` text.
- `imageOverlayStyle`: The interface style of the overlay over the image. Use `.unspecified` for no overlay.
- `showsCloseButton`: True if the view should show a close button.
