# init(title:detail:status:)

**Framework**: CareKit/CareKitUI  
**Kind**: init  
**Role**: Initializer

Create an instance with the default header.

## Declaration

```swift
@MainActor
init(title: Text, detail: Text? = nil, status: LabeledValueTaskViewStatus)
```

Available when `Header` is `_LabeledValueTaskViewHeader`.

## Parameters

- `title`: Title text to display in the header.
- `detail`: Detail text to display in the header.
- `status`: The status denoted by the view.
