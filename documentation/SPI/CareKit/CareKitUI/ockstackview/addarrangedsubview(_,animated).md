# addArrangedSubview(_:animated:)

**Framework**: CareKit/CareKitUI  
**Kind**: method  
**Role**: Instance Method

Add a subview to the end of the stack view. If the style is separated, separators will automatically be added. Provides the option to animate showing the new view.

## Declaration

```swift
@MainActor
func addArrangedSubview(_ view: UIView, animated: Bool)
```

## Parameters

- `view`: The view to add.
- `animated`: Flag that determines if the view should animated on screen.
