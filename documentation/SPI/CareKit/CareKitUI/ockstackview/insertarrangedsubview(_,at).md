# insertArrangedSubview(_:at:)

**Framework**: CareKit/CareKitUI  
**Kind**: method  
**Role**: Instance Method

Insert an arranged subview at a particular index in the stack view. If the style is separated, separators will automatically be added.

## Declaration

```swift
@MainActor
override func insertArrangedSubview(_ view: UIView, at stackIndex: Int)
```

## Parameters

- `view`: The view to add.
- `stackIndex`: Index in the stack view to add the view.
