# removeArrangedSubview(_:animated:)

**Framework**: CareKit/CareKitUI  
**Kind**: method  
**Role**: Instance Method

Remove an arranged subview from the stack view. If the style is separated, the separators will be automatically removed. Option to animated the removal of the view.

## Declaration

```swift
@MainActor
func removeArrangedSubview(_ view: UIView, animated: Bool)
```

## Parameters

- `view`: The view to remove.
- `animated`: Flag that determines if the view removal should be animated.
