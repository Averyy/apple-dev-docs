# insertArrangedSubview(_:at:animated:)

**Framework**: CareKit/CareKitUI  
**Kind**: method  
**Role**: Instance Method

Insert an arranged subview at a particular index in the stack view. If the style is separated, separators will be automatically added.  Provides the option to animate showing the new view.

## Declaration

```swift
@MainActor
func insertArrangedSubview(_ view: UIView, at stackIndex: Int, animated: Bool)
```

## Parameters

- `view`: The view to add.
- `stackIndex`: Index in the stack view to add the view.
- `animated`: Flag that determines if the view should animated on screen.
