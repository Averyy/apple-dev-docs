# level

**Framework**: CareKit/CareKitUI  
**Kind**: property  
**Role**: Type Property

Controls the log level for all of CareKitUI. You may set this value from within your CareKit app. To see messages that are helpful for app developers, use `.fault` or `.error`. To see messages that are helpful for framework developers, use `.debug` or `.info`.
