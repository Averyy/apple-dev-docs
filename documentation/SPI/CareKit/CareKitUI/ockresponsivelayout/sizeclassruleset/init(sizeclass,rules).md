# init(sizeClass:rules:)

**Framework**: CareKit/CareKitUI  
**Kind**: init  
**Role**: Initializer

Initialize a `SizeClassRuleSet` with a `UIUserInterfaceSizeClass` combination and `UIContentSizeCategory` specific rules.

## Declaration

```swift
init(sizeClass: SizeClass = (horizontal: .unspecified, vertical: .unspecified), rules: [OCKResponsiveLayout<LayoutOption>.Rule<LayoutOption>])
```

## Parameters

- `sizeClass`: The `SizeClass` horizontal and vertical definition for the rules
- `rules`: The `UIContentSizeCategory` rules for this size class
