# init(sizeClasses:rules:)

**Framework**: CareKit/CareKitUI  
**Kind**: init  
**Role**: Initializer

Initialize a `SizeClassRuleSet` with a set of `UIUserInterfaceSizeClass` combinations and `UIContentSizeCategory` specific rules.

## Declaration

```swift
init(sizeClasses: [SizeClass], rules: [OCKResponsiveLayout<LayoutOption>.Rule<LayoutOption>])
```

## Parameters

- `sizeClasses`: The `SizeClass` horizontal and vertical definitions for the rules
- `rules`: The `UIContentSizeCategory` rules for these size classes
