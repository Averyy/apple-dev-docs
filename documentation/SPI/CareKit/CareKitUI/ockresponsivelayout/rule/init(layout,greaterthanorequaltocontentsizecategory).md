# init(layout:greaterThanOrEqualToContentSizeCategory:)

**Framework**: CareKit/CareKitUI  
**Kind**: init  
**Role**: Initializer

Initialize a rule with a `Layout` defined by the user and a `UIContentSizeCategory` to display the layout at.

## Declaration

```swift
init(layout: Layout, greaterThanOrEqualToContentSizeCategory contentSizeCategory: UIContentSizeCategory = .extraSmall)
```

## Parameters

- `layout`: The `Layout` to display at or above the given `UIContentSizeCategory`
- `contentSizeCategory`: The `UIContentSizeCategory` that this layout will display at or above
