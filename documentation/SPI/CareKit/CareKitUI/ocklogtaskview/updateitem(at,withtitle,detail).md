# updateItem(at:withTitle:detail:)

**Framework**: CareKit/CareKitUI  
**Kind**: method  
**Role**: Instance Method

Updates the text for an item at a particular index.

## Declaration

```swift
@discardableResult
@MainActor func updateItem(at index: Int, withTitle title: String?, detail: String?) -> OCKLogItemButton?
```

#### Return Value

The item that was updated.

## Parameters

- `index`: The index of the item to update.
- `title`: The title text to display in the item.
- `detail`: The detail text to display in the item. The text is tinted by default.
