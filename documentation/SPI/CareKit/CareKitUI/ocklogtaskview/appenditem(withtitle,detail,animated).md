# appendItem(withTitle:detail:animated:)

**Framework**: CareKit/CareKitUI  
**Kind**: method  
**Role**: Instance Method

Appends an item to the list of logged items.

## Declaration

```swift
@discardableResult
@MainActor func appendItem(withTitle title: String?, detail: String?, animated: Bool) -> OCKLogItemButton
```

#### Return Value

The item that was appended.

## Parameters

- `title`: The detail text to display in the item. The text is tinted by default.
- `detail`: The detail text to display in the item. The text is tinted by default.
- `animated`: Animate appending the item.
