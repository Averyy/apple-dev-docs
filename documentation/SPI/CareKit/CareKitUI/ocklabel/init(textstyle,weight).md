# init(textStyle:weight:)

**Framework**: CareKit/CareKitUI  
**Kind**: init  
**Role**: Initializer

Create an instance of and `OCKLabel`. By default, the label will not animate text changes and will scale with accessibility content size changes.

## Declaration

```swift
@MainActor
init(textStyle: UIFont.TextStyle, weight: UIFont.Weight)
```

## Parameters

- `textStyle`: The style of the font.
- `weight`: The weight of the font.
