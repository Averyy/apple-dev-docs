# ==(_:_:)

**Framework**: swift-log/Logging

Returns a Boolean value that indicates whether two metadata values are equal.

## Declaration

```swift
static func == (lhs: Logger.Metadata.Value, rhs: Logger.Metadata.Value) -> Bool
```

## Return Value

Returns `true` if the metadata values are equivalent; otherwise `false`.

## Parameters

- `lhs`: The first metadata value.
- `rhs`: The second metadata value.
