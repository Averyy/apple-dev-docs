# all

**Framework**: Intents  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether to snooze all of the tasks.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- watchOS 6.0+

```swift
@nonobjc
final var all: Bool? { get }
```
