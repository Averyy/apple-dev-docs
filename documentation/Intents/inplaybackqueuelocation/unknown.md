# INPlaybackQueueLocation.unknown

**Framework**: Intents  
**Kind**: case  
**Role**: Case

A response that indicates the system doesn’t know where to place the media item.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 6.0+
