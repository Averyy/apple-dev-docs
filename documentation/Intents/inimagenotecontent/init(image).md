# init(image:)

**Framework**: Intents  
**Kind**: init  
**Role**: Initializer

Initializes the object with the specified image.

**Availability**:
- iOS 11.0+ - Deprecated in 27.0
- iPadOS 11.0+ - Deprecated in 27.0
- Mac Catalyst 13.1+ - Deprecated in 27.0
- visionOS 1.0+ - Deprecated in 27.0
- watchOS 4.0+ - Deprecated in 27.0

> **Deprecated**: INImageNoteContent is deprecated. Please adopt the Notes or Reminders AppSchema domain instead.

## Declaration

```swift
init(image: INImage)
```

```objc
- (instancetype) initWithImage:(INImage *) image;
```

#### Return Value

An initialized object or `nil` if the object could not be created.

## Parameters

- `image`: The image object to use.
