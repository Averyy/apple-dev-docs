# tesla

**Framework**: Intents  
**Kind**: property  
**Role**: Type Property

- iOS 14.0+ - Deprecated in 17.4
- iPadOS 14.0+ - Deprecated in 17.4
- Mac Catalyst 14.0+ - Deprecated in 17.4
