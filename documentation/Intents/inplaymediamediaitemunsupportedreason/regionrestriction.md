# INPlayMediaMediaItemUnsupportedReason.regionRestriction

**Framework**: Intents  
**Kind**: case  
**Role**: Case

The media isn’t available in the user’s geographic location.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 7.0+
