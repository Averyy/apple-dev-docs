# INAddMediaMediaItemUnsupportedReason.regionRestriction

**Framework**: Intents  
**Kind**: case  
**Role**: Case

The media is unavailable to add in the user’s geographic location.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
