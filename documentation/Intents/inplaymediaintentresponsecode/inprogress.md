# INPlayMediaIntentResponseCode.inProgress

**Framework**: Intents  
**Kind**: case  
**Role**: Case

The app is preparing to play the media content.

**Availability**:
- iOS 12.0+
- iPadOS 12.0+
- Mac Catalyst 13.1+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 5.0+

## Declaration

```swift
case inProgress
```

```c
INPlayMediaIntentResponseCodeInProgress
```

#### Discussion

Respond with this code when your app needs more time to load the media before playing it.
