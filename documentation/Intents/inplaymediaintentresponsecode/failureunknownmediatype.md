# INPlayMediaIntentResponseCode.failureUnknownMediaType

**Framework**: Intents  
**Kind**: case  
**Role**: Case

The app cannot play the media because the type is unknown or not supported.

**Availability**:
- iOS 12.0+
- iPadOS 12.0+
- Mac Catalyst 13.1+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 5.0+
