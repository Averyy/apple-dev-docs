# init(rawValue:)

**Framework**: Intents  
**Kind**: init  
**Role**: Initializer

Initializes a set that contains the specified days of the week.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- visionOS 1.0+
- watchOS 7.0+

## Declaration

```swift
init(rawValue: UInt)
```

## Parameters

- `rawValue`: The numeric value that represents the day or days for the set to contain.
