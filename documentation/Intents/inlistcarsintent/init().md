# init()

**Framework**: Intents  
**Kind**: init  
**Role**: Initializer

Creates an intent that represents a request for a list of the user’s electric vehicles.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- visionOS 1.0+
- watchOS 7.0+

## Declaration

```swift
init()
```

```objc
- (instancetype) init;
```

#### Discussion

> ❗ **Important**:  You don’t create instances of this intent yourself. Instead, Maps creates the intent when it requires a list of the user’s electric vehicles, usually before or during route planning.
