# init(rawValue:)

**Framework**: Intents  
**Kind**: init  
**Role**: Initializer

Initializes a new car signal option based on the provided raw value.

**Availability**:
- iOS 10.3+
- iPadOS 10.3+
- Mac Catalyst 13.1+
- visionOS 1.0+
- watchOS 3.2+

## Declaration

```swift
init(rawValue: UInt)
```

## Return Value

A newly initialized car signal option.

## Parameters

- `rawValue`: The raw value of the new enum.
