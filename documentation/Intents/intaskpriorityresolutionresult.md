# INTaskPriorityResolutionResult

**Framework**: Intents  
**Kind**: class  
**Role**: Class

A resolution result for the priority associated with a task.

**Availability**:
- iOS 13.0+ - Deprecated in 27.0
- iPadOS 13.0+ - Deprecated in 27.0
- Mac Catalyst 13.1+ - Deprecated in 27.0
- visionOS 1.0+ - Deprecated in 27.0
- watchOS 6.0+ - Deprecated in 27.0

> **Deprecated**: INTaskPriorityResolutionResult is deprecated. Please adopt the Notes or Reminders AppSchema domain instead.

## Declaration

```swift
class INTaskPriorityResolutionResult
```

```objc
@interface INTaskPriorityResolutionResult : INIntentResolutionResult
```

#### Overview

You return an [`INTaskPriorityResolutionResult`](./intaskpriorityresolutionresult.md) object when resolving parameters containing an [`INTaskPriority`](./intaskpriority.md) object. Use the creation method that best reflects your ability to successfully resolve the parameter.

For additional resolution operators, see [`INIntentResolutionResult`](./inintentresolutionresult.md).
