# init(title:)

**Framework**: Intents  
**Kind**: init  
**Role**: Initializer

Creates a default card template with the specified title.

**Availability**:
- iOS 12.0+
- iPadOS 12.0+
- Mac Catalyst 13.1+
- visionOS 1.0+
- watchOS 5.0+

## Declaration

```swift
init(title: String)
```

```objc
- (instancetype) initWithTitle:(NSString *) title;
```

## Return Value

A newly initialized default card template object.

## Parameters

- `title`: The title to display in the Siri watch face card.
