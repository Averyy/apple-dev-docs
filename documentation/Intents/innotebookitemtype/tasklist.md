# INNotebookItemType.taskList

**Framework**: Intents  
**Kind**: case  
**Role**: Case

A task list item type.

**Availability**:
- iOS 11.0+ - Deprecated in 27.0
- iPadOS 11.0+ - Deprecated in 27.0
- Mac Catalyst 13.1+ - Deprecated in 27.0
- visionOS 1.0+ - Deprecated in 27.0
- watchOS 4.0+ - Deprecated in 27.0

> **Deprecated**: INNotebookItemType is deprecated. Please adopt the Notes or Reminders AppSchema domain instead.

## Declaration

```swift
case taskList
```

```c
INNotebookItemTypeTaskList
```

#### Discussion

Search your app’s task lists and return each one using an [`INTaskList`](../intasklist.md) object. Task lists are a way of grouping related tasks together.
