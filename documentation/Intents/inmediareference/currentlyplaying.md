# INMediaReference.currentlyPlaying

**Framework**: Intents  
**Kind**: case  
**Role**: Case

Indicates that the user is referring to the media item which is currently playing.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 6.0+
