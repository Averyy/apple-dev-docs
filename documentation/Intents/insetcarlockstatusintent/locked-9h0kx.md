# locked

**Framework**: Intents  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether to lock the car.

**Availability**:
- iOS 10.3+
- iPadOS 10.3+
- Mac Catalyst 10.3+
- watchOS 3.2+

## Declaration

```swift
@nonobjc
final var locked: Bool? { get }
```

## Discussion

When this property is [`true`](../../Foundation/nsexpression/true.md), lock the car; otherwise unlock the car.
