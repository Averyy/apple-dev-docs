# genreNames

**Framework**: Intents  
**Kind**: property  
**Role**: Instance Property

The media genres to search.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 6.0+
