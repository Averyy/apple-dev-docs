# keyImage()

**Framework**: Intents  
**Kind**: method  
**Role**: Instance Method

The most relevant image to display to the user.

**Availability**:
- iOS 10.0+
- iPadOS 10.0+
- Mac Catalyst 13.1+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 3.2+

## Declaration

```swift
func keyImage() -> INImage?
```

```objc
- (INImage *) keyImage;
```

#### Return Value

An image associated with a named parameter or another image defined in the intent.
