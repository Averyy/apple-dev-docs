# INMediaSortOrder.worst

**Framework**: Intents  
**Kind**: case  
**Role**: Case

The app sorts the media items from worst to best.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 6.0+

## Declaration

```swift
case worst
```

```c
INMediaSortOrderWorst
```

#### Discussion

The app displays the sorted media items with those items matching the lowest number of search fields first.
