# init(focusStatus:)

**Framework**: Intents  
**Kind**: init  
**Role**: Initializer

Creates an intent with the specified focus status.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
init(focusStatus: INFocusStatus?)
```

```objc
- (instancetype) initWithFocusStatus:(INFocusStatus *) focusStatus;
```

## Parameters

- `focusStatus`: The focus status to share.
