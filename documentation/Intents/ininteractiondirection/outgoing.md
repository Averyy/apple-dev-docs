# INInteractionDirection.outgoing

**Framework**: Intents  
**Kind**: case  
**Role**: Case

An interaction in which information is sent from the device.

**Availability**:
- iOS 10.0+
- iPadOS 10.0+
- Mac Catalyst 13.1+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 3.2+

## Declaration

```swift
case outgoing
```

```c
INInteractionDirectionOutgoing
```

## Discussion

Choose this value when the interaction involves the user starting a video call from the current device.
