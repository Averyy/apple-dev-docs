# INConditionalOperator.any

**Framework**: Intents  
**Kind**: case  
**Role**: Case

One or more of the relevant attributes must be present for the search to yield a match. This is equivalent to an OR operator.

**Availability**:
- iOS 10.0+
- iPadOS 10.0+
- Mac Catalyst 13.1+
- visionOS 1.0+
- watchOS 3.2+
