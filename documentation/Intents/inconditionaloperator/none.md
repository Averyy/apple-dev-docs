# INConditionalOperator.none

**Framework**: Intents  
**Kind**: case  
**Role**: Case

None of the specified attributes must be present for the search to yield a match.

**Availability**:
- iOS 10.0+
- iPadOS 10.0+
- Mac Catalyst 13.1+
- visionOS 1.0+
- watchOS 3.2+
