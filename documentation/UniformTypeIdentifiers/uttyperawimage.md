# UTTypeRAWImage

**Framework**: Uniform Type Identifiers  
**Kind**: var  
**Role**: Global Variable

A base type that represents a raw image format that you use in digital photography.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 7.0+

## Declaration

```c
extern UTType * const UTTypeRAWImage;
```

## Discussion

The identifier for this type is `public.camera-raw-image`.

This type conforms to [`UTTypeImage`](./uttypeimage.md).
