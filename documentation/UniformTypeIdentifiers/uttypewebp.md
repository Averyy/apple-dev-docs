# UTTypeWebP

**Framework**: Uniform Type Identifiers  
**Kind**: var  
**Role**: Global Variable

A type that represents a WebP image.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 7.0+

## Declaration

```c
extern UTType * const UTTypeWebP;
```

#### Discussion

The identifier for this type is `org.webmproject.webp`.

This type conforms to [`UTTypeImage`](./uttypeimage.md).
