# log

**Framework**: Uniform Type Identifiers  
**Kind**: property  
**Role**: Type Property

A base type that represents console log data.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 7.0+

## Declaration

```swift
static var log: UTType { get }
```

## Discussion

The identifier for this type is `public.log`.
