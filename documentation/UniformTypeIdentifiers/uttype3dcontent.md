# UTType3DContent

**Framework**: Uniform Type Identifiers  
**Kind**: var  
**Role**: Global Variable

- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
