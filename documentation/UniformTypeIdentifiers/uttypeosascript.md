# UTTypeOSAScript

**Framework**: Uniform Type Identifiers  
**Kind**: var  
**Role**: Global Variable

A type that represents an Open Scripting Architecture binary script.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 7.0+

## Declaration

```c
extern UTType * const UTTypeOSAScript;
```

#### Discussion

The identifier for this type is `com.apple.applescript.script`.

This type conforms to [`UTTypeScript`](./uttypescript.md) and [`UTTypeData`](./uttypedata.md).
