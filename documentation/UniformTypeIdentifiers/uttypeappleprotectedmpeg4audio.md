# UTTypeAppleProtectedMPEG4Audio

**Framework**: Uniform Type Identifiers  
**Kind**: var  
**Role**: Global Variable

A type that represents data in Apple-protected MPEG-4 format.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 7.0+

## Declaration

```c
extern UTType * const UTTypeAppleProtectedMPEG4Audio;
```

#### Discussion

The identifier for this type is `com.apple.protected-mpeg-4-audio`.

This type conforms to [`UTTypeAudio`](./uttypeaudio.md).
