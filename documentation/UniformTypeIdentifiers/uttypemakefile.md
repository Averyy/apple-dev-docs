# UTTypeMakefile

**Framework**: Uniform Type Identifiers  
**Kind**: var  
**Role**: Global Variable

A type that represents a Makefile.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```c
extern UTType * const UTTypeMakefile;
```

## Discussion

The identifier for this type is `public.make-source`.

This type conforms to [`script`](./uttype-swift.struct/script.md).
