# IntentValueContainer.ConversionContext

**Framework**: App Intents  
**Kind**: struct

A context that provides additional information for value conversion.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+
- watchOS 27.0+

## Declaration

```swift
struct ConversionContext
```

#### Overview

The `ConversionContext` encapsulates contextual information that might be needed during the conversion process. Use it to customize how the system converts values to and from containers.
