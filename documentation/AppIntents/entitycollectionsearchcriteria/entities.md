# entities

**Framework**: App Intents  
**Kind**: property  
**Role**: Instance Property

The entity collection with the search results to display.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+
- watchOS 27.0+

## Declaration

```swift
var entities: EntityCollection<Entity>
```

## Discussion

Use this property to retrieve the entity identifiers for the [`AppEntity`](../appentity.md) types to display in your app’s interface.
