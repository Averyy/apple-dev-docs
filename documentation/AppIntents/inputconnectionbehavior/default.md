# InputConnectionBehavior.default

**Framework**: App Intents  
**Kind**: case  
**Role**: Case

A behavior that allows the system to determine if the parameter accepts the output.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
