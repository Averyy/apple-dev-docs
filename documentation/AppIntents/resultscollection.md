# ResultsCollection

**Framework**: App Intents  
**Kind**: protocol

A protocol representing a collection of returned items with support for sectioning.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst ?+
- macOS 13.0+
- tvOS 16.0+
- visionOS ?+
- watchOS 9.0+
