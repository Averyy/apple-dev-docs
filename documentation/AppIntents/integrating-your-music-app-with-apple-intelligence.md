# Integrating your music app with Apple Intelligence

**Framework**: App Intents  
**Role**: Sample Code  
**Download**: [IntegratingYourMusicAppWithAppleIntelligence.zip](https://docs-assets.developer.apple.com/published/fb0bdd7eec61/IntegratingYourMusicAppWithAppleIntelligence.zip)

Adopt the audio and clock schemas so people can play music and set alarms with Siri.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- Xcode 27.0+

#### Overview

> **Note**: This sample code project is associated with WWDC26 session [343: Explore advanced App Intents features for Siri and Apple Intelligence](https://developer.apple.com/wwdc26/343/).
