# family

**Framework**: App Intents  
**Kind**: property  
**Role**: Instance Property

**Availability**:

- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- macOS 27.3+ (Beta)

## Declaration

```swift
var family: CardSnippetFamily { get }
```

## Discussion

The value in this property reflects the amount of space available for your views and how the system intends to display them.
