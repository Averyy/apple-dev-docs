# id

**Framework**: App Intents  
**Kind**: property  
**Role**: Instance Property

The stable identity of the entity associated with this instance.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
- tvOS 16.0+
- visionOS
- watchOS 9.0+

## Declaration

```swift
var id: Self.ID { get }
```

Available when `Self` conforms to `RawRepresentable` and `ID` is `Self.RawValue`.
