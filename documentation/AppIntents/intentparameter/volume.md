# IntentParameter.Volume

**Framework**: App Intents  
**Kind**: enum  
**Role**: Enumeration

**Availability**:

- iPadOS 16.0+

## Declaration

```swift
enum Volume
```

Available when `Value` conforms to `_IntentValue`, `Value` conforms to `Sendable`, and `Value.ValueType` is `Measurement<UnitVolume>`.
