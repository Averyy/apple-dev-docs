# foreground

**Framework**: App Intents  
**Kind**: property  
**Role**: Type Property

A value that indicates the action needs to run in the foreground.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- tvOS 26.0+
- visionOS 26.0+
- watchOS 26.0+

## Declaration

```swift
static var foreground: IntentModes { get }
```

#### Discussion

This value is equivalent to the [`immediate`](./foregroundmode/immediate.md) mode.
