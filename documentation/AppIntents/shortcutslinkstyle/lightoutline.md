# lightOutline

**Framework**: App Intents  
**Kind**: property  
**Role**: Type Property

A button style that applies a light background with dark text along with a dark outline.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- visionOS
