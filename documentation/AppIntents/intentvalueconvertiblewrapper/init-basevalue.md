# init(baseValue:)

**Framework**: App Intents  
**Kind**: init  
**Required**: Yes

Creates a new instance that wraps the specified base value.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- watchOS 27.0+ (Beta)

## Declaration

```swift
init(baseValue: Self.BaseValue) throws
```

#### Discussion

> **Note**: An error if the wrapper cannot be initialized with the given base value.

## Parameters

- `baseValue`: The underlying value to wrap.
