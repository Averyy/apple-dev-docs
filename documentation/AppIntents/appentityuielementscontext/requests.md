# requests

**Framework**: App Intents  
**Kind**: property

The set of requests for elements from the system.

**Availability**:
- iOS 18.4+
- iPadOS 18.4+
- Mac Catalyst 18.4+
- macOS 15.4+
- tvOS 18.4+
- visionOS 2.4+
- watchOS 11.4+

## Declaration

```swift
let requests: Set<AppEntityUIElementsContext.ElementsRequest>
```

#### Discussion

UI elements that satisfy any of these requests should be returned.
