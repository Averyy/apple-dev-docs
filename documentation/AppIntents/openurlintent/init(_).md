# init(_:)

**Framework**: App Intents  
**Kind**: init

Configures the app intent with the provided URL.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- macOS 15.0+
- tvOS 18.0+
- visionOS 2.0+
- watchOS 11.0+

## Declaration

```swift
init(_ url: URL)
```

## Parameters

- `url`: A universal link to your app’s content.
