# AppSchema.WordProcessorIntent

**Framework**: App Intents  
**Kind**: protocol

Identifies intent schemas in the word processor domain.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- macOS 15.0+
- visionOS 2.0+
