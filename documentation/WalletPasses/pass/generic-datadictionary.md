# Pass.Generic

**Framework**: Wallet Passes  
**Kind**: dictionary

An object that represents the groups of fields that display the information for a generic pass.

**Availability**:
- iOS 6.0+
- iPadOS 6.0+
- watchOS 1.0+

Use the generic pass type for passes that don’t fit into other pass categories, such as a club membership pass or a valet claim ticket.
