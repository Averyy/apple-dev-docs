# Pascal String Utilities

**Framework**: Core Services  
**Role**: API Collection

Performing common string manipulations on Pascal strings.

> **Deprecated**: In macOS 10.4 and later, use Foundation and Core Foundation APIs instead. You can use the [`CFStringCreateWithPascalString(_:_:_:)`](../../CoreFoundation/cfstringcreatewithpascalstring%28_,_,_%29.md) function to convert from Pascal strings to [`CFString`](../../CoreFoundation/cfstring.md) objects, which are toll-free bridged to [`NSString`](../../Foundation/nsstring.md).  For more information, see [String Programming Guide](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/Strings/introStrings.html#//apple_ref/doc/uid/10000035i).
