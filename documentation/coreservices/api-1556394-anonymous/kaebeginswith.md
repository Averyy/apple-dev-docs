# kAEBeginsWith

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

The value of `operand1` begins with the value of `operand2` (for example, the string `"operand"` begins with the string `"opera"`).

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kAEBeginsWith = 'bgwt'
```
