# kAEContains

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

The value of `operand1` contains the value of `operand2 `(for example, the string `"operand"` contains the string `"era"`).

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kAEContains = 'cont'
```
