# kMacIcelandicTTEuroSignVariant

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

In Mac OS versions earlier than 8.5, 0xDB is the Euro sign; 0xBB/0xBC are fi/fl ligatures.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
kMacIcelandicTTEuroSignVariant = 5
```
