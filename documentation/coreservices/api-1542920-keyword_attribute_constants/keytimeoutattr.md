# keyTimeoutAttr

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Length of time, in ticks, that the client will wait for a reply or a result from the server.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+
