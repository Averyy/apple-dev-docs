# kUCCollateTypeMask

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

You can use this mask to directly test bits 24-31 of a `UCCollateOptions` value.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kUCCollateTypeMask = (UInt32)kUCCollateTypeSourceMask << kUCCollateTypeShiftBits
```
