# gestaltPowerPC

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If the `Gestalt` function returns `gestaltPowerPC`, the system is a PowerPC Macintosh.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltPowerPC = 2
```
