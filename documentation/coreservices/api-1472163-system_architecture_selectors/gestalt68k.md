# gestalt68k

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If the `Gestalt` function returns `gestalt68k`, the system is a MC680x0 Macintosh.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestalt68k = 1
```
