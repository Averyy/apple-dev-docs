# gestaltIntel

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If the `Gestalt` function returns `gestaltIntel`, the system is is an Intel-based Macintosh.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltIntel = 10
```
