# kLSRolesNone

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Requests the role `None` (theapplication cannot open the item, but provides an icon and a kindstring for it).

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kLSRolesNone = 0x00000001
```
