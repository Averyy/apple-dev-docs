# kLSRolesEditor

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Requests the role `Editor` (theapplication can read, present, manipulate, and save the item).

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration
