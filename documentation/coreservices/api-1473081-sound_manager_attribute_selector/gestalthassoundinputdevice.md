# gestaltHasSoundInputDevice

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Set if a sound input device is available. This device can be either built-in or external.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltHasSoundInputDevice = 5
```
