# TextEdit Version Selectors

**Framework**: Core Services  
**Kind**: enum  
**Role**: Enumeration

Specify version information for TextEdit.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
enum : unsigned int {
    ...
};
```

## Topics

### Constants
- [gestaltTextEditVersion](./api-1472747-textedit_version_selectors/gestalttexteditversion.md)
  The `Gestalt` selector you pass to determine what version of TextEdit is present.
- [gestaltTE1](./api-1472747-textedit_version_selectors/gestaltte1.md)
  The version of TextEdit found in Mac IIci ROM.
- [gestaltTE2](./api-1472747-textedit_version_selectors/gestaltte2.md)
  The version of TextEdit shipped with 6.0.4 Script Systems on Mac IIci (Script bug fixes for Mac IIci).
- [gestaltTE3](./api-1472747-textedit_version_selectors/gestaltte3.md)
  The version of TextEdit shipped with 6.0.4 Script Systems (all but Mac IIci).
- [gestaltTE4](./api-1472747-textedit_version_selectors/gestaltte4.md)
  The version of TextEdit shipped in System 7.0.
- [gestaltTE5](./api-1472747-textedit_version_selectors/gestaltte5.md)
  `TextWidthHook` is available in TextEdit.
