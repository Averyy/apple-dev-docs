# kAERemoteProcessUserIDKey

**Framework**: Core Services  
**Kind**: data  
**Role**: Global Variable

Use this key to obtain the user ID of the remote process, if available; if so, returned as a `CFNumberRef`.

**Availability**:
- macOS 10.3+
