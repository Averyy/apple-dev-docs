# gestaltColorSync20

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

A `Gestalt` response value of `gestaltColorSync20` indicates version 2.0 of the ColorSync Manager is present.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltColorSync20 = 0x0200
```
