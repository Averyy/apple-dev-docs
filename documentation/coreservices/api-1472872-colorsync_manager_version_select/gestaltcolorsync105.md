# gestaltColorSync105

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

A `Gestalt` response value of `gestaltColorSync105` indicates version 1.5 of the ColorSync Manager is present.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltColorSync105 = 0x0105
```
