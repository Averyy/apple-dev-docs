# gestaltColorSync21

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

A `Gestalt` response value of `gestaltColorSync21` indicates version 2.1 of the ColorSync Manager is present.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltColorSync21 = 0x0210
```
