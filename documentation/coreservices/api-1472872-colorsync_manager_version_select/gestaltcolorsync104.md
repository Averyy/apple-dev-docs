# gestaltColorSync104

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

A `Gestalt` response value of `gestaltColorSync104` indicates version 1.4 of the ColorSync Manager is present.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltColorSync104 = 0x0104
```
