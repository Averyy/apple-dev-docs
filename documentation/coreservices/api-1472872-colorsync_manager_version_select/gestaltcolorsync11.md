# gestaltColorSync11

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

A `Gestalt` response value of `gestaltColorSync11` indicates version 1.0.3 of the ColorSync Manager is present.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltColorSync11 = 0x0110
```
