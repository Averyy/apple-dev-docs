# kUCCollateComposeInsensitiveMask

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kUCCollateComposeInsensitiveMask = 1L << 1
```

#### Discussion

If the corresponding bit is set, then precomposed and decomposed representations of the same text element are treated as equivalent. This option is among those set by the `kUCCollateStandardOptions` constant, as described in [Standard Options Mask](../api-1390444-standard_options_mask.md).
