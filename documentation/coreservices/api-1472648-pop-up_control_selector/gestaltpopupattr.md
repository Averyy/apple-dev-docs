# gestaltPopupAttr

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

The selector you pass to the `Gestalt` function to determine the  attribute of the pop-up control definition.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltPopupAttr = 'pop!'
```
