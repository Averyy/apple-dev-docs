# kMDItemPixelCount

**Framework**: Core Services  
**Kind**: data  
**Role**: Global Variable

The total number of pixels in the contents. Same as [`kMDItemPixelWidth`](./kmditempixelwidth.md) x [`kMDItemPixelHeight`](./kmditempixelheight.md). A CFNumber.

**Availability**:
- macOS 10.6+
