# gestaltHasSCSI962

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

This bit is set if the machine has a SCSI implementation based on the 53C96 chip installed on an  external bus.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltHasSCSI962 = 22
```
