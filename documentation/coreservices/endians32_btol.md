# EndianS32_BtoL

**Framework**: Core Services  
**Kind**: macro  
**Role**: Macro

Converts a signed 32-bit big-endian value to the equivalentlittle-endian value.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
#define EndianS32_BtoL(value)
```

## Return Value

The equivalent little-endianvalue.

## Parameters

- `value`: A signed 32-bit big-endian value.
