# gestaltDragMgrHasImageSupport

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If the bit specified by this mask is set, the Drag Manager image support functions are available.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltDragMgrHasImageSupport = 3
```
