# keyAEContainer

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Specifies the container for the requested object or objects. The data is an object specifier (or in some cases a null descriptor).

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
keyAEContainer = 'from'
```
