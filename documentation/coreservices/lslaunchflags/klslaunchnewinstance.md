# kLSLaunchNewInstance

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Requests that a new instance of the application be started, even if one is already running.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kLSLaunchNewInstance = 0x00080000
```
