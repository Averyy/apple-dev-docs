# kLSLaunchAndHide

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Requests that the application be hidden as soon as it completes its launch sequence.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kLSLaunchAndHide = 0x00100000
```
