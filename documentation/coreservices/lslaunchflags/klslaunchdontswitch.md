# kLSLaunchDontSwitch

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Requests that the application be launched without being brought to the foreground.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kLSLaunchDontSwitch = 0x00000200
```
