# kLSLaunchDontAddToRecents

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Requests that the application or documents not be added to the Finder’s Recent Items menu.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kLSLaunchDontAddToRecents = 0x00000100
```
