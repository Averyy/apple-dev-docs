# kWSNetworkStreamFaultString

**Framework**: Core Services  
**Kind**: data  
**Role**: Global Variable

If `kWSFaultExtra` is a dictionary, this key returns a CFString from that dictionary for debug purposes.

**Availability**:
- macOS 10.2+ - Deprecated in 10.8
