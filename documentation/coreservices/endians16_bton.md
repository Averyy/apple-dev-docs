# EndianS16_BtoN

**Framework**: Core Services  
**Kind**: macro  
**Role**: Macro

Converts a signed 16-bit big-endian value to the equivalentvalue in the computer’s native format.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
#define EndianS16_BtoN(value)
```

#### Return Value

The equivalent valuein the computer’s native format.

## Parameters

- `value`: A signed 16-bit big-endian value.
