# MPOpaqueID

**Framework**: Core Services  
**Kind**: tdef  
**Role**: Type Alias

Represents a generic notification ID (that is, an ID that could be a queue ID, event ID, kernel notification ID, or semaphore ID). 

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

typedef struct OpaqueMPOpaqueID *MPOpaqueID;
