# gestaltStdNBPAttr

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

The selector you pass to the `Gestalt` function to determine information about the StandardNBP (Name-Binding Protocol) function.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltStdNBPAttr = 'nlup'
```
