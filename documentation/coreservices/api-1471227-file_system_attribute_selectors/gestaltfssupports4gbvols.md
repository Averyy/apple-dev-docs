# gestaltFSSupports4GBVols

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If this bit is set in the `response` parameter, the file system supports 4 gigabyte volumes.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltFSSupports4GBVols = 4
```
