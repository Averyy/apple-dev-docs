# gestaltFSNoMFSVols

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If this bit is set in the `response` parameter, the file system does not support MFS volumes. 

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltFSNoMFSVols = 8
```
