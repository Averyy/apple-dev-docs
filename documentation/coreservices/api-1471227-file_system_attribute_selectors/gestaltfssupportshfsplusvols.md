# gestaltFSSupportsHFSPlusVols

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If this bit is set in the `response` parameter, the file system supports HFS Plus volumes. 

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltFSSupportsHFSPlusVols = 9
```
