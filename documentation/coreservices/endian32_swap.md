# Endian32_Swap

**Framework**: Core Services  
**Kind**: macro  
**Role**: Macro

Changes the endian format of an unsigned 32-bit integer.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
#define Endian32_Swap(value)
```

#### Return Value

The unsigned 32-bitinteger result.

## Parameters

- `value`: An unsigned 32-bit integer input.
