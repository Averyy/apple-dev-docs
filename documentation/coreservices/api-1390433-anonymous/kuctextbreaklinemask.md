# kUCTextBreakLineMask

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If the bit specified by this mask is set, potential line breaks may be located.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kUCTextBreakLineMask = 1L << 6
```
