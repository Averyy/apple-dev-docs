**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- Mac Catalyst 13.1+ - Deprecated in 13.1

## Declaration

```c
kMPMaxAllocSize = 1024L * 1024 * 1024
```

## Discussion
