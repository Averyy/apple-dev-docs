# gestaltPhysicalRAMSize

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

The selector you pass to the `Gestalt` function to determine the  number of bytes of physical RAM currently installed.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+
