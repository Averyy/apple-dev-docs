# gestaltExtendedTimeMgr

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If this bit is set, the extended Time Manager is present.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltExtendedTimeMgr = 3
```
