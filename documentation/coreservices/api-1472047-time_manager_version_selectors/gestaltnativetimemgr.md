# gestaltNativeTimeMgr

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If this bit is set, the native Time Manager is present.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltNativeTimeMgr = 4
```
