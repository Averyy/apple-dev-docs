# gestaltUndefSelectorErr

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Specifies an undefined selector was passed to the Gestalt Manager.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
gestaltUndefSelectorErr = -5551
```
