# kAEDefaultTimeout

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

The timeout value is determined by the Apple Event Manager. The default timeout value is about one minute.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kAEDefaultTimeout = -1
```
