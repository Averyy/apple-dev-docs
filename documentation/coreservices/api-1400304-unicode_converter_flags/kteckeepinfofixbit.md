# kTECKeepInfoFixBit

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

This is set if the Unicode Converter has a bug fix to stop ignoring certain control flags 

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
kTECKeepInfoFixBit = 0
```
