# kMacCroatianCurrencySignVariant

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

In versions of Mac OS earlier than 8.5, 0xDB is the currency sign.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
kMacCroatianCurrencySignVariant = 1
```
