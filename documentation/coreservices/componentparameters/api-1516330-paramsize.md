# paramSize

**Framework**: Core Services  
**Kind**: structp  
**Role**: Instance Property

Specifies the number of bytes of parameter data for this request. The actual parameters are stored in the `params` field.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
UInt8 paramSize;
```
