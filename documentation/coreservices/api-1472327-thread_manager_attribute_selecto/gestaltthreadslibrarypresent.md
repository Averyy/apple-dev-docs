# gestaltThreadsLibraryPresent

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

This bit is set if the native version of the threads library has been loaded.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltThreadsLibraryPresent = 2
```
