# Unknown Type or Creator

**Framework**: Core Services  
**Kind**: enum  
**Role**: Enumeration

Represents an unknown file type or creator.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
enum : OSType {
    ...
};
```

## Topics

### Constants
- [kLSUnknownType](./api-1469201-unknown_type_or_creator/klsunknowntype.md)
  The value to supply as the file type (for example,to the `LSGetApplicationForInfo` function)if no file type information is available.
- [kLSUnknownCreator](./api-1469201-unknown_type_or_creator/klsunknowncreator.md)
  The value to supply as the creator signatureif no file creator information is available.
