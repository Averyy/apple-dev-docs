# nextState

**Framework**: Core Services  
**Kind**: structp  
**Role**: Instance Property

An unsigned 16-bit integer. This base dead-key state value is used to determine the following dead-key state, if any.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+
