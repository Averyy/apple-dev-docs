# gestaltMPFileManager

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If this bit is set, you can call preemptively safe File Manager functions.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+
