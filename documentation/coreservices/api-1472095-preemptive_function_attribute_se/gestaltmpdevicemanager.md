# gestaltMPDeviceManager

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If this bit is set, you can call preemptively safe Device Manager function.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltMPDeviceManager = 1
```
