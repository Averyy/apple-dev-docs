# kMacRomanStandardVariant

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

The standard variant of Mac OS Roman for Mac OS 8.5 and later; 0xDB is the Euro sign.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
kMacRomanStandardVariant = 0
```
