# Endian16_Swap

**Framework**: Core Services  
**Kind**: macro  
**Role**: Macro

Changes the endian format of an unsigned 16-bit integer.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
#define Endian16_Swap(value)
```

## Return Value

The unsigned 16-bitinteger result.

## Parameters

- `value`: An unsigned 16-bit integer input.
