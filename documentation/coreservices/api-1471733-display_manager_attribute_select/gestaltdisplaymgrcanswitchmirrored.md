# gestaltDisplayMgrCanSwitchMirrored

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If `true`, the Display Manager can switch modes on mirrored displays.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltDisplayMgrCanSwitchMirrored = 2
```
