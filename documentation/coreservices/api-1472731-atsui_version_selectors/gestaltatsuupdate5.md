# gestaltATSUUpdate5

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Indicates that version 2.3 of ATSUI is installed on the user’s system. Available beginning with ATSUI 2.3, in OS X version 10.1.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.1+

## Declaration

```c
gestaltATSUUpdate5 = (6 << 16)
```
