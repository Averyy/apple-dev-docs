# gestaltATSUUpdate6

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Indicates that version 2.4 of ATSUI is installed on the user’s system. Available beginning with ATSUI 2.4, in OS X version 10.2.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.2+

## Declaration

```c
gestaltATSUUpdate6 = (7 << 16)
```
