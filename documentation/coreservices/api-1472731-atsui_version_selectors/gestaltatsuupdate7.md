# gestaltATSUUpdate7

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Indicates that version 2.5 of ATSUI is installed on the user’s system. Available beginning with ATSUI 2.5, in OS X version 10.3.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.3+

## Declaration

```c
gestaltATSUUpdate7 = (8 << 16)
```
