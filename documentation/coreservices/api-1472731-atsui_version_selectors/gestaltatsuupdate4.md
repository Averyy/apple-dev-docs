# gestaltATSUUpdate4

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Indicates that ATSUI for a version of macOS from 10.0.1 through 10.0.4 is installed on the user’s system.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.1+

## Declaration

```c
gestaltATSUUpdate4 = (5 << 16)
```
