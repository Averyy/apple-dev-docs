# gestaltATSUUpdate2

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Indicates that version 1.2 of ATSUI is installed on the user’s system.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

gestaltATSUUpdate2 = (3 << 16)
