# gestaltDesktopSpeechRecognition

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If this bit is set, the Speech Recognition Manager supports the desktop microphone.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltDesktopSpeechRecognition = 1
```
