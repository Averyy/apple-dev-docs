# kUnicodeFallbackInterruptSafeMask

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Indicate that the caller’s fallback routine doesn’t move memory.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
kUnicodeFallbackInterruptSafeMask = 1L << 2
```
