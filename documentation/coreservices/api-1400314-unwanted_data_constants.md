# Unwanted Data Constants

**Framework**: Core Services  
**Kind**: enum  
**Role**: Enumeration

Specify data you don’t care about receiving.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

```c
enum : int {
    ...
```

  The region code is not provided for the derivation.
