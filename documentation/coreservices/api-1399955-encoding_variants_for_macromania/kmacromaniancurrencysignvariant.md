# kMacRomanianCurrencySignVariant

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

In Mac OS versions earlier than 8.5, 0xDB is the currency sign.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
kMacRomanianCurrencySignVariant = 1
```
