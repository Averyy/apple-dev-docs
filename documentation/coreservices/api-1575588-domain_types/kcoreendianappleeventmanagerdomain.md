# kCoreEndianAppleEventManagerDomain

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Specifies that the domain is limited to Appleevents.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.4+
