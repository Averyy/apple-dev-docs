# kCoreEndianResourceManagerDomain

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Specifies that the domain is limited to theresources for a specific application.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.4+

## Declaration

```c
kCoreEndianResourceManagerDomain = 'rsrc'
```
