# EndianS16_LtoB

**Framework**: Core Services  
**Kind**: macro  
**Role**: Macro

Converts a signed 16-bit little-endian value to the equivalentbig-endian value.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
#define EndianS16_LtoB(value)
```

#### Return Value

The equivalent big-endianvalue.

## Parameters

- `value`: A signed 16-bit little-endian value.
