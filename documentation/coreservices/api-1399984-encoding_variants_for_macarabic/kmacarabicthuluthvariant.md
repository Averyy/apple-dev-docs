# kMacArabicThuluthVariant

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

A Mac OS Arabic variant used for the Arabic PostScript-only fonts: Thuluth and Thuluth bold.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
kMacArabicThuluthVariant = 2
```
