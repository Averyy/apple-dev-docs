# kMacArabicTrueTypeVariant

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

A Mac OS Arabic variant used for most of the Arabic TrueType fonts: Baghdad, Geeza, Kufi, Nadeem. 

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
kMacArabicTrueTypeVariant = 1
```
