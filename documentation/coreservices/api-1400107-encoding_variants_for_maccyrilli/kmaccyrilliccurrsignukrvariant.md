# kMacCyrillicCurrSignUkrVariant

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

In Mac OS version 9.0 and later (UA, LangKit), 0xFF = currency sign, 0xA2/0xB6 = GHE with upturn.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
kMacCyrillicCurrSignUkrVariant = 2
```
