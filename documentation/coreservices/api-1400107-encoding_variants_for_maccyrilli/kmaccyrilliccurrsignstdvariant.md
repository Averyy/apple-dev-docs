# kMacCyrillicCurrSignStdVariant

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

In Mac OS versions prior to 9.0 (RU, BG), 0xFF = currency sign, 0xA2/0xB6 = CENT / PARTIAL DIFF.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
kMacCyrillicCurrSignStdVariant = 1
```
