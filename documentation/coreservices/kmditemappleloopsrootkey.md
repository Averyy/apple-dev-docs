# kMDItemAppleLoopsRootKey

**Framework**: Core Services  
**Kind**: data  
**Role**: Global Variable

Specifies the loop's original key. The key is the root note or tonic for the loop, and does not include the scale type. A CFString.

**Availability**:
- macOS 10.4+
