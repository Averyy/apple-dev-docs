# kUCCollateTypeShiftBits

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kUCCollateTypeShiftBits = 24
```

#### Discussion

You can use this value, along with one of the constants described in [Fixed Ordering Scheme](../api-1390361-fixed_ordering_scheme.md), to specify a fixed ordering scheme. You can also use this value, in conjunction with the `kUCCollateTypeSourceMask` constant, to obtain a value identifying a fixed ordering scheme.
