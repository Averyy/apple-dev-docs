# kTextEncodingMacFarsi

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Uses script code 4, `smArabic`. It is similar to Mac Arabic but uses Farsi digits.]

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+
