# MPProcessID

**Framework**: Core Services  
**Kind**: tdef  
**Role**: Type Alias

Represents a process ID. 

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
typedef struct OpaqueMPProcessID *MPProcessID;
```

#### Discussion

Note that this process ID is identical to the process ID (or context ID) handled by the Code Fragment Manager.
