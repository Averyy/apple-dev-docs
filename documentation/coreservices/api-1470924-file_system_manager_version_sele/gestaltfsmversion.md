# gestaltFSMVersion

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Pass this selector to the `Gestalt` function to determine the version of the HFS External File Systems Manager (FSM).

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltFSMVersion = 'fsm '
```
