# kLSAcceptDefault

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Requests the default behavior that does not require the user interface to log in be presented.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kLSAcceptDefault = 0x00000001
```
