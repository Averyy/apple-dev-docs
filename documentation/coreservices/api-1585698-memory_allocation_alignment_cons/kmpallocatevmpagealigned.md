# kMPAllocateVMPageAligned

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Use virtual memory page alignment. This alignment is set at runtime. 

**Availability**:
- Mac Catalyst 13.1+ - Deprecated in 13.1
- macOS 10.0+ - Deprecated in 10.7
