# gestaltFXfrMgrAttr

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

The selector you pass to the `Gestalt` function to determine the File Transfer Manager attributes.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration
