# Encoding Variants for MacCroatian

**Framework**: Core Services  
**Kind**: enum  
**Role**: Enumeration

Specify variants of MacCroation.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
enum : unsigned int {
    ...
};
```

## Topics

### Constants
- [kMacCroatianDefaultVariant](./api-1400365-encoding_variants_for_maccroatia/kmaccroatiandefaultvariant.md)
  This is a meta value that maps to one of the following constants, depending on version of the Mac OS.
- [kMacCroatianCurrencySignVariant](./api-1400365-encoding_variants_for_maccroatia/kmaccroatiancurrencysignvariant.md)
  In versions of Mac OS earlier than 8.5, 0xDB is the currency sign.
- [kMacCroatianEuroSignVariant](./api-1400365-encoding_variants_for_maccroatia/kmaccroatianeurosignvariant.md)
  In Mac OS version 8.5 and later, 0xDB is the Euro sign.
