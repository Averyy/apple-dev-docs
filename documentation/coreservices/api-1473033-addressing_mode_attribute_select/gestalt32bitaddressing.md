# gestalt32BitAddressing

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If `true`, the operating system is using 32-bit addressing mode.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+
