# gestaltTEHasWhiteBackground

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If `true`, TextEdit supports overriding the `TERec`' data structure background field to white.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltTEHasWhiteBackground = 3
```
