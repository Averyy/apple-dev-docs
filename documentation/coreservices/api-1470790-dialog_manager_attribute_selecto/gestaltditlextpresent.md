# gestaltDITLExtPresent

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If this flag bit is `TRUE`, then the Dialog Manager extensions included in System 7 are available. 

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltDITLExtPresent = 0
```
