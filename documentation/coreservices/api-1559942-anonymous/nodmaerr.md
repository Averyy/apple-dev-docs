# noDMAErr

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Can't do DMA digitizing; that is, can't go to the requested destination. 

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
noDMAErr = -2208
```
