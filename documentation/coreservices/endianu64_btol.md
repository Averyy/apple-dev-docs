# EndianU64_BtoL

**Framework**: Core Services  
**Kind**: macro  
**Role**: Macro

Converts an unsigned 64-bit big-endian value to the equivalentlittle-endian value.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
#define EndianU64_BtoL(value)
```

#### Return Value

The equivalent little-endianvalue.

## Parameters

- `value`: An unsigned 64-bit big-endian value.
