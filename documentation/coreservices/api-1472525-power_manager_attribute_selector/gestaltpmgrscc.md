# gestaltPMgrSCC

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

If true, it is possible to stop the SCC clock, thus effectively turning off the serial ports. 

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
gestaltPMgrSCC = 2
```
