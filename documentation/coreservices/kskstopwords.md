# kSKStopWords

**Framework**: Core Services  
**Kind**: data  
**Role**: Global Variable

A set of stopwords—words not to index. Specified as a CFSet object. There is no default stopword list. You must supply your own.

**Availability**:
- macOS 10.3+

## Declaration

```swift
let kSKStopWords: CFString!
```
