# kAEEndsWith

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

The value of `operand1` ends with the value of `operand2` (for example, the string `"operand"` ends with the string `"and"`).

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
kAEEndsWith = 'ends'
```
