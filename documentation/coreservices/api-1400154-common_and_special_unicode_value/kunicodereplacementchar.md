# kUnicodeReplacementChar

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Unicode replacement for an input character that cannot be converted.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
kUnicodeReplacementChar = 0xFFFD
```
