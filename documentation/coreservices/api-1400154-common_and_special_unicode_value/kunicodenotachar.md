# kUnicodeNotAChar

**Framework**: Core Services  
**Kind**: econst  
**Role**: Enumeration Case

Not a Unicode character; may be used as a terminator.

**Availability**:
- Mac Catalyst 17.0+
- macOS 10.0+

## Declaration

```c
kUnicodeNotAChar = 0xFFFF
```
