# init(_:)

**Framework**: VisionKit  
**Kind**: init  
**Role**: Initializer

Creates an interaction for Live Text actions with the specified delegate.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 17.0+
- visionOS 1.0+

## Declaration

```swift
@MainActor
convenience init(_ delegate: any ImageAnalysisInteractionDelegate)
```

## Parameters

- `delegate`: The object that provides details about the interface for the interaction.
