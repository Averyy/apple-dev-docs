# init(coder:)

**Framework**: VisionKit  
**Kind**: init  
**Role**: Initializer

Creates an overlay view from data in a coder object.

**Availability**:
- macOS 13.0+

## Declaration

```swift
@MainActor
required dynamic init?(coder: NSCoder)
```

## Parameters

- `coder`: The object that contains the data.
