# init(frame:)

**Framework**: VisionKit  
**Kind**: init  
**Role**: Initializer

Creates an overlay view with the specified frame rectangle.

**Availability**:
- macOS 13.0+

## Declaration

```swift
@MainActor
override dynamic init(frame frameRect: NSRect)
```

## Parameters

- `frameRect`: The frame rectangle for view.
