# overlayView(_:liveTextButtonDidChangeToVisible:)

**Framework**: VisionKit  
**Kind**: method

**Availability**:
- macOS 13.0+

## Declaration

```swift
@MainActor
func overlayView(_ overlayView: ImageAnalysisOverlayView, liveTextButtonDidChangeToVisible visible: Bool)
```

## Parameters
