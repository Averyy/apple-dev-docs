# SPPoint3DMakeWithVector

**Framework**: Spatial  
**Kind**: func  
**Role**: Function

Creates a point from the specified double-precision vector.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
- tvOS 16.0+
- visionOS 1.0+
- watchOS 9.0+

## Declaration

```c
static SPPoint3D SPPoint3DMakeWithVector(SPVector3D xyz);
```

## Parameters

- `xyz`: The vector to create a point from.
