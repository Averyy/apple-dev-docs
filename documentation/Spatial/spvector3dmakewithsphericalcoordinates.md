# SPVector3DMakeWithSphericalCoordinates

**Framework**: Spatial  
**Kind**: func  
**Role**: Function

Returns a Spatial vector that represents the Cartesian coordinates of the specified spherical coordinates structure.

**Availability**:

- iPadOS 18.0+
- Mac Catalyst 18.0+

- tvOS 18.0+
- visionOS 2.0+
