## Declaration

```c
static simd_float3 SPPoint3DFloatGetVector(SPPoint3DFloat point);
```

#### Return Value

A vector that represents the point.

#### Discussion

Returns the @p x, @p y, and @p z components of the point expressed as a simd vector.

## Parameters

- `point`: The source point.
