# *=(_:_:)

**Framework**: Spatial  
**Kind**: op  
**Role**: Operator

Calculates the vector that’s the element-wise product of a vector and a scalar value and stores the result in the left-hand-side variable.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- tvOS 26.0+
- visionOS 26.0+
- watchOS 26.0+

## Declaration

```swift
static func *= (lhs: inout Vector3DFloat, rhs: Float)
```

## Parameters

- `lhs`: The first value.
- `rhs`: The second value.
