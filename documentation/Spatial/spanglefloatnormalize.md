## Declaration

```c
static SPAngleFloat SPAngleFloatNormalize(SPAngleFloat angle);
```

## Return Value

The normalized angle.

## Discussion

Returns the specified angle normalized to `(-π, π]` radians (`(-180°, 180.0°]`).

## Parameters

- `angle`: The source angle.
