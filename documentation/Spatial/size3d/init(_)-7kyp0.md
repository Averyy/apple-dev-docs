# init(_:)

**Framework**: Spatial  
**Kind**: init  
**Role**: Initializer

Creates a size structure from the specified Spatial point.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
- tvOS 16.0+
- visionOS
- watchOS 9.0+

## Declaration

```swift
init(_ point: Point3D)
```

## Parameters

- `point`: A point structure that specifies the dimensions.
