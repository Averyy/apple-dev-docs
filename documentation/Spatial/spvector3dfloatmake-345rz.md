## Declaration

```c
static SPVector3DFloat SPVector3DFloatMake(float x, float y, float z);
```

## Return Value

A new vector.

## Discussion

Creates a single-precision  vector with the specified coordinates.

## Parameters

- `x`: The first element of the vector.
- `y`: The second element of the vector.
- `z`: The third element of the vector.
