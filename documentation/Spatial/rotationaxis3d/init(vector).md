# init(vector:)

**Framework**: Spatial  
**Kind**: init  
**Role**: Initializer

Creates a rotation axis from a three-element double-precision vector.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
- tvOS 16.0+
- visionOS 1.0+
- watchOS 9.0+

## Declaration

```swift
init(vector: simd_double3)
```

## Parameters

- `vector`: A double-precision vector that specifies the coordinates.
