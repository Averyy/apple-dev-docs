# init(_:)

**Framework**: Spatial  
**Kind**: init  
**Role**: Initializer

Returns a Spatial point that represents the Cartesian coordinates of the specified spherical coordinates structure.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- macOS 15.0+
- tvOS 18.0+
- visionOS
- watchOS 11.0+

## Declaration

