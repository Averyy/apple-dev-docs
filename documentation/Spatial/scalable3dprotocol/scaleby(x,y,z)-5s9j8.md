# scaleBy(x:y:z:)

**Framework**: Spatial  
**Kind**: method  
**Role**: Instance Method

Scales the entity by the specified values.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- tvOS 26.0+
- visionOS 26.0+
- watchOS 26.0+

## Declaration

```swift
mutating func scaleBy(x: Self.Scalar = 1, y: Self.Scalar = 1, z: Self.Scalar = 1)
```

Available when `Scalar` is `Float`.

## Parameters

- `x`: The scale factor on the `x` dimension.
- `y`: The scale factor on the `y` dimension.
- `z`: The scale factor on the `z` dimension.
