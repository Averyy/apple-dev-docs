# uniformlyScale(by:)

**Framework**: Spatial  
**Kind**: method  
**Role**: Instance Method

Uniformly scales the entity by the specified scalar value.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- tvOS 26.0+
- visionOS 26.0+
- watchOS 26.0+

## Declaration

```swift
mutating func uniformlyScale(by scale: Self.Scalar)
```

Available when `Scalar` is `Float`.

## Parameters

- `scale`: The value that defines that scale.
