# MusicSummaries.Attributes

**Framework**: Apple Music API  
**Kind**: dictionary

The attributes for the music summaries resource type.

**Availability**:
- Apple Music 1.0+

## Declaration

```swift
object MusicSummaries.Attributes
```

## Properties

- `period` (string) *(required)*: The period for the music summary. These values can be `year` or `month`.
- `year` (integer) *(required)*: The year of the music summary.
