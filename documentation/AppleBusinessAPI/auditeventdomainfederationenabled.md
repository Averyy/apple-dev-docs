# AuditEventDomainFederationEnabled

**Framework**: AppleBusinessAPI  
**Kind**: dictionary  
**Role**: Object

The data structure that represents the event data for a domain federation enabled audit event.

**Availability**:
- Apple Business API 2.6+

## Declaration

```
object AuditEventDomainFederationEnabled
```

## Properties

- `activityId` (string): The unique identifier for the domain federation activity.
- `scimActivityId` (string): The unique identifier for the associated SCIM provisioning activity.
