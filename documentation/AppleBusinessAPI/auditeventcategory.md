# AuditEventCategory

**Framework**: AppleBusinessAPI  
**Kind**: typealias  
**Role**: Type

Strings that represent audit event categories.

**Availability**:
- Apple Business API 2.6+

## Declaration

```
string AuditEventCategory
```

## Possible Values

- `ORGANIZATION`
- `ACCOUNT_ACTIVITY`
- `DEVICE_INVENTORY`
- `PURCHASING`
- `DEVICE_MANAGEMENT`

## Discussion

- Possible Values

  - ORGANIZATION: Organization-level events.
  - ACCOUNT_ACTIVITY: User and API account activity.
  - DEVICE_INVENTORY: Device inventory changes.
  - PURCHASING: Purchase-related events.
  - DEVICE_MANAGEMENT: Device management configuration events.
  - ACCESS_MANAGEMENT: Access and role management events.
