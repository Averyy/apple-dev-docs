# UserPhoneNumberType

**Framework**: AppleBusinessAPI  
**Kind**: typealias  
**Role**: Type

Strings that represent phone number types.

**Availability**:
- Apple Business API 2.6+

## Declaration

```
string UserPhoneNumberType
```

## Possible Values

- `WORK`
- `HOME`
- `MOBILE`

## Discussion

- Possible Values

  - WORK: A work phone number.
  - HOME: A home phone number.
  - MOBILE: A mobile phone number.
