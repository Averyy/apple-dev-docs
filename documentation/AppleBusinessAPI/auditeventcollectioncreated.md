# AuditEventCollectionCreated

**Framework**: AppleBusinessAPI  
**Kind**: dictionary  
**Role**: Object

The data structure that represents the event data for a collection created audit event.

**Availability**:
- Apple Business API 2.7+

## Declaration

```
object AuditEventCollectionCreated
```

## Properties

- `name` (string): Name of the collection given by admin who created the collection.
- `description` (string): Description of the collection given by admin who created the collection.
