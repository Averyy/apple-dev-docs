# BlueprintStatus

**Framework**: AppleBusinessAPI  
**Kind**: typealias  
**Role**: Type

The status of a Blueprint.

**Availability**:
- Apple Business API 2.7+

## Declaration

```
string BlueprintStatus
```

## Possible Values

- `ACTIVE`
- `TO_BE_DELETED`

## Possible Values

- `ACTIVE` - The Blueprint is active and operational.
- `TO_BE_DELETED` - The Blueprint is pending deletion.
