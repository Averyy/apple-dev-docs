# startSpecifier

**Framework**: Foundation  
**Kind**: property  
**Role**: Instance Property

Returns the object specifier representing the first object of the range.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+



#### Return Value
