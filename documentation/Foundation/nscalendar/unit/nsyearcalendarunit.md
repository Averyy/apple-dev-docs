# NSYearCalendarUnit

**Framework**: Foundation  
**Kind**: property  
**Role**: Type Property

Specifies the year unit.

**Availability**:
- iOS 2.0+ - Deprecated in 8.0 (renamed: NSCalendar.Unit.year)
- iPadOS 2.0+ - Deprecated in 8.0 (renamed: NSCalendar.Unit.year)
- Mac Catalyst 13.1+ - Deprecated in 13.1 (renamed: NSCalendar.Unit.year)
- macOS 10.4+ - Deprecated in 10.10 (renamed: NSCalendar.Unit.year)
- tvOS 9.0+ - Deprecated in 9.0 (renamed: NSCalendar.Unit.year)
- visionOS 1.0+ - Deprecated in 1.0 (renamed: NSCalendar.Unit.year)
- watchOS 2.0+ - Deprecated in 2.0 (renamed: NSCalendar.Unit.year)

> **Deprecated**: Use [`year`](./year.md) instead.

## Declaration

```swift
static var NSYearCalendarUnit: NSCalendar.Unit { get }
```


The corresponding value is an `NSInteger`. Equal to `kCFCalendarUnitYear`.
