# isRemote

**Framework**: Foundation  
**Kind**: property  
**Role**: Instance Property

Specifies whether the remote was generated by a push notification.

**Availability**:
- macOS 10.8+ - Deprecated in 11.0

> **Deprecated**: All NSUserNotifications API should be replaced with UserNotifications.frameworks API

## Declaration

```swift
var isRemote: Bool { get }
```

```objc
@property (readonly, getter=isRemote) BOOL remote;
```

#### Discussion

If this property is [`true`](../../Swift/true.md) then the user notification was generated by a push notification (that is, remotely); if [`false`](../../Swift/false.md) it was generated locally.
