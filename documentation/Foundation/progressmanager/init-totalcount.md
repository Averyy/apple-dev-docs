# init(totalCount:)

**Framework**: Foundation  
**Kind**: init

Initializes `self` with `totalCount`.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- watchOS 27.0+ (Beta)

## Declaration

```swift
convenience init(totalCount: Int?)
```

#### Discussion

If `totalCount` is set to `nil`, `self` is indeterminate.

## Parameters

- `totalCount`: Total units of work.
