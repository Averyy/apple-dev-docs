# NSBundleOnDemandResourceInvalidTagError

**Framework**: Foundation  
**Kind**: case  
**Role**: Enumeration Case

The application specified a tag that the system couldn’t find in the application tag manifest.

**Availability**:
- iOS 9.0+
- iPadOS 9.0+
- Mac Catalyst 13.1+
- macOS 10.11+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+
