# NSGrammaticalPartOfSpeech.notSet

**Framework**: Foundation  
**Kind**: case  
**Role**: Case

A value that indicates the part of speech is unset.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
