# init(orderedSet:)

**Framework**: Foundation  
**Kind**: init  
**Role**: Initializer

Initializes a new ordered set with the contents of a set.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
convenience init(orderedSet set: NSOrderedSet)
```

```objc
- (instancetype) initWithOrderedSet:(NSOrderedSet<id> *) set;
```

#### Return Value

An initialized ordered set containing references to the objects in the set.

## Parameters

- `set`: A set.
