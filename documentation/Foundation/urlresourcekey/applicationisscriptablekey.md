# applicationIsScriptableKey

**Framework**: Foundation  
**Kind**: property  
**Role**: Type Property

`true` if the resource is scriptable. Only applies to applications (Read-only, value type boolean `NSNumber`).

**Availability**:
- macOS 10.11+
