# init(data:)

**Framework**: Foundation  
**Kind**: init  
**Role**: Initializer

Initializes a data object with the contents of another data object.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
init(data: Data)
```

```objc
- (instancetype) initWithData:(NSData *) data;
```

#### Return Value

A data object initialized with the contents `data`.

## Parameters

- `data`: A data object.
