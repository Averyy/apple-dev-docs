# NSExecutableErrorMaximum

**Framework**: Foundation  
**Kind**: case  
**Role**: Enumeration Case

The end of the range of error codes reserved for errors related to executable files.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- macOS 10.5+
