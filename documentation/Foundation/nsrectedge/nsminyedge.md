# NSMinYEdge

**Framework**: Foundation  
**Kind**: case  
**Role**: Enumeration Case

The minimum Y edge.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
NSMinYEdge
```

## Discussion

This is equivalent to [`CGRectEdge.minYEdge`](../../CoreFoundation/cgrectedge/minyedge.md), and also to [`NSRectEdge.minY`](./miny.md).
