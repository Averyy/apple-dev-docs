# NSMinXEdge

**Framework**: Foundation  
**Kind**: case  
**Role**: Enumeration Case

The minimum X edge.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
NSMinXEdge
```

## Discussion

This is equivalent to [`CGRectEdge.minXEdge`](../../CoreFoundation/cgrectedge/minxedge.md), and also to [`NSRectEdge.minX`](./minx.md).
