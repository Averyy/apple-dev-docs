# NSMaxYEdge

**Framework**: Foundation  
**Kind**: case  
**Role**: Enumeration Case

The maximum Y edge.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```c
NSMaxYEdge
```

#### Discussion

This is equivalent to [`CGRectEdge.maxXEdge`](../../CoreFoundation/cgrectedge/maxxedge.md), and also to [`NSRectEdge.maxY`](./maxy.md).
