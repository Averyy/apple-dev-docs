# NSDecimalDigits

**Framework**: Foundation  
**Kind**: var  
**Role**: Global Variable

Strings that identify the decimal digits in addition to or instead of the ASCII digits.

**Availability**:
- macOS 10.0+ - Deprecated in 10.5
