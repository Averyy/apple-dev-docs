# Date.FormatStyle.Symbol.YearForWeekOfYear

**Framework**: Foundation  
**Kind**: struct  
**Role**: Structure

A type that specifies the format for a year in week-of-year calendars when you parse a string with a date format string.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
