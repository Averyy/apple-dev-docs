# wide

**Framework**: Foundation  
**Kind**: property  
**Role**: Type Property

The full representation of a month.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
static var wide: Date.FormatStyle.Symbol.Month { get }
```

## Discussion

This custom format style conveys the full representation of a month, like  `September`.
