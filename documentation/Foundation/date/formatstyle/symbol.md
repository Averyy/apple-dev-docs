# Date.FormatStyle.Symbol

**Framework**: Foundation  
**Kind**: struct  
**Role**: Structure

Types that customize formatting templates either by using the date format style’s modifier functions or by constructing fixed-pattern date format strings.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+
