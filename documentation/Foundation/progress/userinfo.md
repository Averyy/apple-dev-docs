# userInfo

**Framework**: Foundation  
**Kind**: property  
**Role**: Instance Property

A dictionary of arbitrary values for the receiver.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- macOS 10.9+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
var userInfo: [ProgressUserInfoKey : Any] { get }
```

```objc
@property (copy, readonly) NSDictionary<NSString *,id> * userInfo;
```

## Discussion

A KVO-compliant dictionary that changes in response to [`setUserInfoObject(_:forKey:)`](./setuserinfoobject%28_,forkey%29.md). The dictionary sends all of its KVO notifications on the thread that updates the property.

Some entries have meanings that the `NSProgress` class recognizes. For more information, see Recognizing Kinds of Progress, Using General Keys, Using File Operation Keys, and  Recognizing Kinds of File Operations.
