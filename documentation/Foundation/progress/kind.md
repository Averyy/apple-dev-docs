# kind

**Framework**: Foundation  
**Kind**: property  
**Role**: Instance Property

An object that represents the kind of progress for the progress object.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- macOS 10.9+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
var kind: ProgressKind? { get set }
```

```objc
@property (copy, nullable) NSProgressKind kind;
```

#### Discussion

This property identifies the kind of progress for the progress object, such as [`file`](../progresskind/file.md). It can be `nil`.

If you set a non-`nil` value to [`kind`](./kind.md), the default [`localizedDescription`](./localizeddescription.md) getter uses the kind of progress. The [`localizedDescription`](./localizeddescription.md) getter determines how to use the values of other properties, along with values in the user info dictionary, to create a string representation.
