# init(_:)

**Framework**: Foundation  
**Kind**: init  
**Role**: Initializer

Creates a new kind of file operation using the specified string.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
init(_ rawValue: String)
```

## Parameters

- `rawValue`: A string that represents the kind of file operation.
