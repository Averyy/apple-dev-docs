# NSURLErrorNetworkUnavailableReasonCellular

**Framework**: Foundation  
**Kind**: case  
**Role**: Enumeration Case

A reason that indicates network is unavailable because the interface is cellular and cellular network is disabled.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- macOS 10.15+
- tvOS 13.0+
- visionOS 1.0+
- watchOS 6.0+
