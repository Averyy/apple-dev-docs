# familyName

**Framework**: Foundation  
**Kind**: property  
**Role**: Instance Property

Name bestowed upon an individual to denote membership in a group or family.

**Availability**:
- iOS 9.0+
- iPadOS 9.0+
- Mac Catalyst 9.0+
- macOS 10.11+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

An example of a family name would be Ruiz.
