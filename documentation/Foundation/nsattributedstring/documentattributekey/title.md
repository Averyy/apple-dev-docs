# title

**Framework**: Foundation  
**Kind**: property  
**Role**: Type Property

The document title.

**Availability**:
- macOS 10.0+

## Declaration

```swift
static let title: NSAttributedString.DocumentAttributeKey
```

## Discussion

The value of this attribute is an [`NSString`](../../nsstring.md) object containing document title.
