# paperSize

**Framework**: Foundation  
**Kind**: property  
**Role**: Type Property

The paper size for the document.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
static let paperSize: NSAttributedString.DocumentAttributeKey
```

#### Discussion

The value of this attribute is an [`NSValue`](../../nsvalue.md) object containing an [`NSSize`](../../nssize.md).

The string constant in macOS 10.3 and earlier is `@"PaperSize"`.
