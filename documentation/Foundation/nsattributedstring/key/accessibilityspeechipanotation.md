# accessibilitySpeechIPANotation

**Framework**: Foundation  
**Kind**: property

A key that indicates the pronunciation of a specific word or phrase, such as a proper name.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- Mac Catalyst 13.1+
- tvOS 11.0+
- visionOS 1.0+
- watchOS 4.0+

## Declaration

```swift
nonisolated
static let accessibilitySpeechIPANotation: NSAttributedString.Key
```

#### Discussion

The value of this key is an [`NSString`](nsstring.md) object that contains International Phonetic Alphabet (IPA) symbols.
