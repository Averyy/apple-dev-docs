# next()

**Framework**: Foundation  
**Kind**: method

Returns the next key-value pair of a dictionary object as a tuple.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 8.0+
- macOS 10.10+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
final func next() -> (key: Any, value: Any)?
```

#### Discussion

If all key-value pairs have been iterated over, this method returns `nil`.
