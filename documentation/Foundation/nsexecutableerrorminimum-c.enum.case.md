# NSExecutableErrorMinimum

**Framework**: Foundation  
**Kind**: case  
**Role**: Enumeration Case

The beginning of the range of error codes reserved for errors related to executable files.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- macOS 10.5+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+
