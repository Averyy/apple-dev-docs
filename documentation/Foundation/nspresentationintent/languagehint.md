# languageHint

**Framework**: Foundation  
**Kind**: property  
**Role**: Instance Property

The language associated with the code listing.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```objc
@property (copy, readonly, nullable) NSString * languageHint;
```

## Discussion

If the intent is not a code block, the value of this property is `nil`.
