# ordinal

**Framework**: Foundation  
**Kind**: property  
**Role**: Instance Property

The number for an item in an ordered list.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```objc
@property (readonly) NSInteger ordinal;
```

#### Discussion

If the intent is not a list, the value of this property is `0`.
