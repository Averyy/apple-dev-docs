# appendLocalizedFormat:

**Framework**: Foundation  
**Kind**: method  
**Role**: Instance Method

Formats the specified string and arguments with the current locale, then appends the result to the receiver.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+
