# cgRectValue

**Framework**: Foundation  
**Kind**: property  
**Role**: Instance Property

Returns the CoreGraphics rectangle structure representation of the value.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
var cgRectValue: CGRect { get }
```

```objc
@property (nonatomic, readonly) CGRect CGRectValue;
```

The CoreGraphics rectangle structure representation of the value.
