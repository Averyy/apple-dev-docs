# arrayWithArray:

**Framework**: Foundation  
**Kind**: method  
**Role**: Type Method

Creates and returns an array containing the objects in another given array.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```objc
+ (instancetype) arrayWithArray:(NSArray<id> *) array;
```

## Return Value

An array containing the objects in `anArray`.

## Parameters

- `array`: An array.
