# locale(_:)

**Framework**: Foundation  
**Kind**: method

Modifies the format style to use the specified locale.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
func locale(_ locale: Locale) -> FloatingPointFormatStyle<Value>.Attributed
```

#### Return Value

A format style that uses the specified locale.

## Parameters

- `locale`: The locale to apply to the format style.
