# minusSign

**Framework**: Foundation  
**Kind**: property  
**Role**: Instance Property

The string used to represent a minus sign.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
var minusSign: String! { get set }
```

```objc
@property (copy, null_resettable) NSString * minusSign;
```

## Discussion

By default, this property is set to the minus sign (-).
