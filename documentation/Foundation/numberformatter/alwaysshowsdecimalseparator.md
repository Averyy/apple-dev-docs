# alwaysShowsDecimalSeparator

**Framework**: Foundation  
**Kind**: property  
**Role**: Instance Property

Determines whether the receiver always shows the decimal separator, even for integer numbers.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+
