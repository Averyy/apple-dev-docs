# NumberFormatter.Style.decimal

**Framework**: Foundation  
**Kind**: case  
**Role**: Case

A decimal style format.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
case decimal
```


#### Discussion

For example, in the en_US locale, the number 1234.5678 is represented as 1,234.568.
