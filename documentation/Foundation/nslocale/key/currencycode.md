# currencyCode

**Framework**: Foundation  
**Kind**: property  
**Role**: Type Property

The currency code associated with the locale.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
static let currencyCode: NSLocale.Key
```

```c
extern NSLocaleKey const NSLocaleCurrencyCode;
```

#### Discussion

The corresponding value is an `NSString` object; for example, `"USD"`.
