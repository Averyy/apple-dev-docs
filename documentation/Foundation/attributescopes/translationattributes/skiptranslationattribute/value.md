# AttributeScopes.TranslationAttributes.SkipTranslationAttribute.Value

**Framework**: Foundation  
**Kind**: typealias

**Availability**:

- tvOS 9.0+
- visionOS 1.0+

## Declaration

```swift
typealias Value = Bool
```

#### Discussion

A Boolean value indicating whether the associated text range should be excluded from translation. When `true`, the text will not be translated.
