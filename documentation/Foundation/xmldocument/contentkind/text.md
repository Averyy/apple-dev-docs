# XMLDocument.ContentKind.text

**Framework**: Foundation  
**Kind**: case  
**Role**: Case

Outputs the string value of the document by extracting the string values from all text nodes.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+
