# XMLDocument.ContentKind.html

**Framework**: Foundation  
**Kind**: case  
**Role**: Case

Outputs empty tags in HTML without a close tag, such as `<br>`.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+
