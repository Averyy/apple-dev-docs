# NSSaveOptions.ask

**Framework**: Foundation  
**Kind**: case  
**Role**: Case

Indicates the user should be asked before saving any modified documents on closing. When no option is specified, this is the default.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+

## Declaration

```swift
case ask
```

```c
NSSaveOptionsAsk
```
