# externalMediaContentIdentifier

**Framework**: Foundation  
**Kind**: property  
**Role**: Instance Property

A unique identifier from the app’s media content catalog for the currently displayed media item.

**Availability**:
- iOS 10.1+
- iPadOS 10.1+
- Mac Catalyst 13.1+
- tvOS 10.0.1+
- visionOS 1.0+
