# isClassKitDeepLink

**Framework**: Foundation  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether a user activity represents a ClassKit context.

**Availability**:
- iOS 11.3+
- iPadOS 11.3+
- Mac Catalyst 14.0+
- macOS 11.0+
- visionOS 1.0+

## Declaration

```swift
var isClassKitDeepLink: Bool { get }
```

```objc
@property (nonatomic, assign, readonly) BOOL isClassKitDeepLink;
```

#### Discussion

When a student taps on an assignment associated with an app that adopts ClassKit, the framework redirects the student to the corresponding app using either a universal link or a user activity, depending on the app’s configuration. Use the [`isClassKitDeepLink`](./isclasskitdeeplink.md) property of a [`NSUserActivity`](../nsuseractivity.md) instance that you receive to test if that activity is from ClassKit. See [Linking directly to assignments](../../ClassKit/linking-directly-to-assignments.md) for more information.
