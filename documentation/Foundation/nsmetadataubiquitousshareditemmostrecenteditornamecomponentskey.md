# NSMetadataUbiquitousSharedItemMostRecentEditorNameComponentsKey

**Framework**: Foundation  
**Kind**: var

The name components of the most recent editor of the shared document, or `nil` if it is the current user.

**Availability**:
- iOS 10.0+
- iPadOS 10.0+
- Mac Catalyst 13.1+
- macOS 10.12+
- visionOS 1.0+
