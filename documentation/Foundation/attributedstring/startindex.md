# startIndex

**Framework**: Foundation  
**Kind**: property

The position of the first character in a nonempty attributed string.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
var startIndex: AttributedString.Index { get }
```

#### Discussion

In an empty string, `startIndex` is equal to `endIndex`.
