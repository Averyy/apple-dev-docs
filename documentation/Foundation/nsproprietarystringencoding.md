# NSProprietaryStringEncoding

**Framework**: Foundation  
**Kind**: var  
**Role**: Global Variable

Installation-specific encoding.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

> **Deprecated**: This encoding has been deprecated—there is no replacement.

## Declaration

```swift
var NSProprietaryStringEncoding: UInt { get }
```

```c
NSProprietaryStringEncoding
```

#### Discussion

Proprietary encodings have not been used since OS X v10.0. You should specify a standard encoding instead.
