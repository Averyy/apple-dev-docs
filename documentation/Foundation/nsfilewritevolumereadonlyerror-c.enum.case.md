# NSFileWriteVolumeReadOnlyError

**Framework**: Foundation  
**Kind**: case  
**Role**: Enumeration Case

**Availability**:
- iOS 4.0+
- iPadOS 4.0+
- Mac Catalyst 13.1+
- macOS 10.6+
