# preferredLocales

**Framework**: Foundation  
**Kind**: property  
**Role**: Type Property

Returns a list of the user’s preferred locales, as specified in Language & Region settings, taking into account any per-app language overrides.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- tvOS 26.0+
