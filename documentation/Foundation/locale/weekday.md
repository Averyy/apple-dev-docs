# Locale.Weekday

**Framework**: Foundation  
**Kind**: enum  
**Role**: Enumeration

A type that represents weekdays, used for indicating a locale’s first day of the week.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+

- visionOS 1.0+
