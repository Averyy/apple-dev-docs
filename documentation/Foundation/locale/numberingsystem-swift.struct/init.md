# init(_:)

**Framework**: Foundation  
**Kind**: init

Creates a numbering system instance from a BCP 47 identifier.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
- tvOS 16.0+
- visionOS 1.0+
- watchOS 9.0+

## Declaration

```swift
init(_ identifier: String)
```

## Parameters

- `identifier`: The numbering system’s BCP 47 identifier, such as `latn` for Latin digits.
