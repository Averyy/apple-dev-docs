# NSPresentationIntentKind

**Framework**: Foundation  
**Kind**: enum  
**Role**: Enumeration

An enumeration of intended display styles for blocks of text like paragraphs, lists, and code blocks.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```c
enum NSPresentationIntentKind : NSInteger;
```
