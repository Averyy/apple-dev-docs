# NSCloudSharingQuotaExceededError

**Framework**: Foundation  
**Kind**: case  
**Role**: Enumeration Case

The user doesn’t have enough storage space available to share the requested items.

**Availability**:
- iOS 10.0+
- iPadOS 10.0+
- Mac Catalyst 13.1+
- macOS 10.12+
- visionOS 1.0+
