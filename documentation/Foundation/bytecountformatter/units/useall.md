# useAll

**Framework**: Foundation  
**Kind**: property  
**Role**: Type Property

Can use any unit in the formatter content.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+
