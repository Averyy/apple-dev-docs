# NSIntMapValueCallBacks

**Framework**: Foundation  
**Kind**: var  
**Role**: Global Variable

For values that are pointer-sized quantities, (for example, `int`, `long`, or `unichar`).

**Availability**:
- iOS 2.0+ - Deprecated in 2.0
- iPadOS 2.0+ - Deprecated in 2.0
- Mac Catalyst 2.0+ - Deprecated in 2.0
- tvOS 9.0+ - Deprecated in 9.0
- visionOS 1.0+ - Deprecated in 1.0
- watchOS 2.0+ - Deprecated in 2.0

> **Deprecated**: Use `NSIntegerMapValueCallBacks` instead.
