# markdownName

**Framework**: Foundation  
**Kind**: property  
**Role**: Type Property

The Markdown name associated with an attributed string key, as provided by a default implementation.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
static var markdownName: String { get }
```

## Discussion

The default value of this property is the value of the [`AttributedStringKey`](../attributedstringkey.md)’s [`name`](../attributedstringkey/name.md).
