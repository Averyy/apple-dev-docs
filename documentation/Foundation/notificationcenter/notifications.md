# NotificationCenter.Notifications

**Framework**: Foundation  
**Kind**: class  
**Role**: Class

An asynchronous sequence of notifications generated by a notification center.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
final class Notifications
```

## Overview

Use the [`notifications(named:object:)`](./notifications%28named,object%29.md) method to create an instance of this type, then iterate over its elements with the `for`-`await`-`in` syntax.

> 💡 **Tip**:  The [`Notification`](../notification.md) type doesn’t conform to [`Sendable`](../../Swift/sendable.md), so iterating over this asynchronous sequence produces a compiler warning. You can use a [`map(_:)`](../../Swift/asyncsequence/map%28_%29-1q1k3.md) or [`compactMap(_:)`](../../Swift/asyncsequence/compactmap%28_%29-gfdq.md) operator on the sequence to extract sendable properties of the notification and iterate over those instead. See [`notifications(named:object:)`](./notifications%28named,object%29.md) for an example of this approach.
