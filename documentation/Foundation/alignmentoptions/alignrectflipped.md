# alignRectFlipped

**Framework**: Foundation  
**Kind**: property  
**Role**: Type Property

This option should be included  if the rectangle is in a flipped coordinate system. This allows 0.5 to be treated in a visually consistent way.

**Availability**:
- Mac Catalyst 13.0+
- macOS 10.0+
