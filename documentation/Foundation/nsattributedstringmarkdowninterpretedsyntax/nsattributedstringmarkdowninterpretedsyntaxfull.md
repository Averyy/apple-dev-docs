# NSAttributedStringMarkdownInterpretedSyntaxFull

**Framework**: Foundation  
**Kind**: case  
**Role**: Enumeration Case

A syntax value that interprets the full Markdown syntax and produces all relevant attributes.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

NSAttributedStringMarkdownInterpretedSyntaxFull
