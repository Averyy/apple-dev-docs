# init()

**Framework**: Foundation  
**Kind**: init  
**Role**: Initializer

Creates a URL components instance without defining any of the components.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 8.0+
- macOS 10.10+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+
