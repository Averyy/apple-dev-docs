# localizedCaseInsensitiveContains(_:)

**Framework**: Foundation  
**Kind**: method  
**Role**: Instance Method

Returns a Boolean value indicating whether the string contains a given string by performing a case-insensitive, locale-aware search.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- macOS 10.10+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
func localizedCaseInsensitiveContains(_ str: String) -> Bool
```

```objc
- (BOOL) localizedCaseInsensitiveContainsString:(NSString *) str;
```

#### Return Value

[`true`](../../Swift/true.md) if the receiver contains `str`, otherwise [`false`](../../Swift/false.md).

## Parameters

- `str`: The string to search for. This value must not be `nil`.
