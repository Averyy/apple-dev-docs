# URLError.BackgroundTaskCancelledReason.backgroundUpdatesDisabled

**Framework**: Foundation  
**Kind**: case  
**Role**: Case

A reason that indicates the system canceled the background task because background tasks are disabled.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- macOS 10.15+
- tvOS 13.0+
