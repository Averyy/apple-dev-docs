# readOnly

**Framework**: Foundation  
**Kind**: property  
**Role**: Type Property

The values returned for the `NSURLUbiquitousSharedItemCurrentUserPermissionsKey`. The current user is only allowed to read this item.

**Availability**:

- iPadOS 10.0+
- Mac Catalyst 13.1+

- visionOS 1.0+
