# pointee

**Framework**: Swift-Org/Cxx  
**Kind**: property  
**Role**: Instance Property  
**Required**: Yes

Returns the unwrapped result of C++ `operator*()`.

## Declaration

```swift
var pointee: Pointee { get }
```

#### Discussion

Generally, Swift creates this property automatically for C++ types that define `operator*()`.
