# CxxConvertibleToBool

**Framework**: Swift-Org/Cxx  
**Kind**: protocol  
**Role**: Protocol

A C++ type that can be converted to a Boolean value.

## Declaration

```swift
protocol CxxConvertibleToBool
```

## Overview

Any C++ type that defines `operator bool()` conforms to this protocol.
