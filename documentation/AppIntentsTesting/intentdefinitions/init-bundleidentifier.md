# init(bundleIdentifier:)

**Framework**: App Intents Testing  
**Kind**: init

Creates a new collection of definitions for intents that the specified app bundle contains.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- watchOS 27.0+ (Beta)

## Declaration

```swift
init(bundleIdentifier: String)
```

## Parameters

- `bundleIdentifier`: The bundle identifier of the app target under test.
