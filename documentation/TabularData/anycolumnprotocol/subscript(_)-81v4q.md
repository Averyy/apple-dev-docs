# subscript(_:)

**Framework**: TabularData  
**Kind**: subscript  
**Role**: Instance Subscript  
**Required**: Yes

Retrieves a contiguous subrange of the column type’s elements.

## Declaration

```swift

```

## Parameters

- `range`: An integer range of valid indices in the column.
