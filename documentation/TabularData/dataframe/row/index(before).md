# index(before:)

**Framework**: TabularData  
**Kind**: method  
**Role**: Instance Method

Returns the column index immediately after a column index in the row.

**Availability**:

- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+

- visionOS 1.0+

```swift

```

## Parameters

- `i`: A valid column index to a value in the row.
