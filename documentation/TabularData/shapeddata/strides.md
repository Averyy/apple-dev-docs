# strides

**Framework**: TabularData  
**Kind**: property  
**Role**: Instance Property

An integer array that stores the number of memory locations that span the length of each dimension in the corresponding element.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+
