# JoinKind.right

**Framework**: TabularData  
**Kind**: case  
**Role**: Case

A join kind that contains all rows from the right data frame type, and only the rows with matching values from the left data frame type.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+
