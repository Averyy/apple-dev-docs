# nameComponents

**Framework**: CloudKit JS  
**Kind**: property  
**Role**: Instance Property

An object that contains the user’s name. Use the `familyName` key to get the last name, and the `givenName` key to get the first name.

**Availability**:
- CloudKit JS 1.0+

