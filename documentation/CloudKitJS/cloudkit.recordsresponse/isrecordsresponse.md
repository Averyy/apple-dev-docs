# isRecordsResponse

**Framework**: CloudKit JS  
**Kind**: property  
**Role**: Instance Property

A Boolean value indicating whether this object is an instance of the [`CloudKit.RecordsResponse`](../cloudkit.recordsresponse.md) class.

**Availability**:
- CloudKit JS 1.0+

## Declaration

```
readonly attribute Boolean isRecordsResponse;
```

#### Discussion

This property is always `true`.
