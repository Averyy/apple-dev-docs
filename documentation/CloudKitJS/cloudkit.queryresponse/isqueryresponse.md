# isQueryResponse

**Framework**: CloudKit JS  
**Kind**: property  
**Role**: Instance Property

A Boolean value indicating whether this object is an instance of the [`CloudKit.QueryResponse`](../cloudkit.queryresponse.md) class.

**Availability**:
- CloudKit JS 1.0+

## Declaration

```
readonly attribute Boolean isQueryResponse;
```

## Discussion

This property is always `true`.
