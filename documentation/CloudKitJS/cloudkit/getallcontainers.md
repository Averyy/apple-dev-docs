# getAllContainers

**Framework**: CloudKit JS  
**Kind**: method  
**Role**: Instance Method

Returns all the containers that were configured.

**Availability**:
- CloudKit JS 1.0+

## Declaration

```
CloudKit.Container[] getAllContainers();
```

## Return Value

All the configured containers.
