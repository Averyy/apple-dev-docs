# UserI

**Framework**: SigninwithAppleJS  
**Kind**: class  
**Role**: Class

An object that contains the user’s name and email address.

**Availability**:
- Sign in with Apple JS 1.4.1+

## Declaration

```
interface UserI
```

#### Overview

Apple only returns the `UserI` object the first time the user authorizes the app. For more information, visit [Authenticating users with Sign in with Apple](../SigninwithApple/authenticating-users-with-sign-in-with-apple.md).

## Topics

### Identifying the user by email address
- [email](./useri/email.md)
  The user’s email address.
- [name](./useri/name.md)
  The user’s full name from their Apple Account or a user-submitted value provided from the Sign in with Apple UI.
