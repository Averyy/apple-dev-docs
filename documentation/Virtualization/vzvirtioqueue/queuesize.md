# queueSize

**Framework**: Virtualization  
**Kind**: property

Size of this queue.

**Availability**:
- macOS 27.0+ (Beta)

## Declaration

```swift
var queueSize: UInt16 { get }
```

#### Discussion

The size of the queue indicates the maximum number of `VZVirtioQueueElement` that can be made available in the queue.
