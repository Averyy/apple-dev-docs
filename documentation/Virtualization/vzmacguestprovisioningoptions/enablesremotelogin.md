# enablesRemoteLogin

**Framework**: Virtualization  
**Kind**: property

A Boolean value that indicates whether to enable Remote Login (using SSH) for the macOS virtual machine.

**Availability**:
- macOS 27.0+ (Beta)

## Declaration

```swift
var enablesRemoteLogin: Bool { get set }
```

#### Discussion

Defaults to `NO`.
