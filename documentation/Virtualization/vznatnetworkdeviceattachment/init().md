# init()

**Framework**: Virtualization  
**Kind**: init  
**Role**: Initializer

Creates an attachment that performs network address translation on the guest system’s network packets.

**Availability**:
- macOS 11.0+

## Declaration

```swift
init()
```

```objc
- (instancetype) init;
```

#### Return Value

An attachment object that communicates with external networks via the host computer.
