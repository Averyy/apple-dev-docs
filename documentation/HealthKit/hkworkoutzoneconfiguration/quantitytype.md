# quantityType

**Framework**: HealthKit  
**Kind**: property

A property that specifies the quantity type to which the zones apply.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- watchOS 27.0+ (Beta)

## Declaration

```swift
var quantityType: HKQuantityType { get }
```

#### Discussion

Workout zones support the heart rate and cycling power quantity types.
