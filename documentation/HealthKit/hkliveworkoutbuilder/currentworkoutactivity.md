# currentWorkoutActivity

**Framework**: HealthKit  
**Kind**: property  
**Role**: Instance Property

The current workout activity.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS
- watchOS 9.0+

## Declaration

```swift
@NSCopying
var currentWorkoutActivity: HKWorkoutActivity? { get }
```

```objc
@property (copy, readonly, nullable) HKWorkoutActivity * currentWorkoutActivity;
```

#### Discussion

This property contains a workout activity that’s currently in progress, an activity with an [`endDate`](../hkworkoutactivity/enddate.md) property set to `nil`. If you end the activity — for example, by calling [`endCurrentActivity(on:)`](../hkworkoutsession/endcurrentactivity%28on%29.md) or [`updateActivity(uuid:end:completion:)`](../hkworkoutbuilder/updateactivity%28uuid,end,completion%29.md) — the system sets this property to `nil` until you begin a new activity.
