# shouldCollectWorkoutEvents

**Framework**: HealthKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that determines whether the workout builder automatically adds events generated by the workout session.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS
- watchOS 5.0+

## Declaration

```swift
var shouldCollectWorkoutEvents: Bool { get set }
```

```objc
@property (assign) BOOL shouldCollectWorkoutEvents;
```

## Mentions

- [Running workout sessions](../running-workout-sessions.md)

#### Discussion

By default, this property is [`true`](../../Swift/true.md). Set it to [`false`](../../Swift/false.md) if your app adds its own events to the workout builder, and you want to ignore events from the workout session.

You must set this property before calling the workout builder’s [`beginCollection(withStart:completion:)`](../hkworkoutbuilder/begincollection%28withstart,completion%29.md) method.
