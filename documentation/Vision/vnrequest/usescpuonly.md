# usesCPUOnly

**Framework**: Vision  
**Kind**: property  
**Role**: Instance Property

A Boolean signifying that the Vision request should execute exclusively on the CPU.

**Availability**:
- iOS 11.0+ - Deprecated in 17.0
- iPadOS 11.0+ - Deprecated in 17.0
- Mac Catalyst 13.1+ - Deprecated in 17.0
- macOS 10.13+ - Deprecated in 14.0
- tvOS 11.0+ - Deprecated in 17.0
- visionOS 1.0+ - Deprecated in 1.0

## Declaration

```swift
var usesCPUOnly: Bool { get set }
```

```objc
@property (nonatomic, readwrite) BOOL usesCPUOnly;
```

## Discussion

This value defaults to [`false`](../../Swift/false.md) to signify that the Vision request is free to leverage the GPU to accelerate its processing.
