# init(_:)

**Framework**: Vision  
**Kind**: init  
**Role**: Initializer

Creates a new frame-based cadence with a frame rate.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+

## Declaration

```swift
init(_ frameRate: Int)
```

```objc
- (instancetype) initWithFrameRate:(NSInteger) frameRate;
```

## Parameters

- `frameRate`: The frame rate at which to process video.
