# OpenConfiguration.Mode.readWrite

**Framework**: DiskImageKit  
**Kind**: case

Open the disk-image with read-write permissions.

**Availability**:
- macOS 27.0+ (Beta)

## Declaration

```swift
case readWrite
```

#### Discussion

Fails if there’s no permission to open the image in this mode.
