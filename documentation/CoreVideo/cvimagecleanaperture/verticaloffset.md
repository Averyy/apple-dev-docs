# verticalOffset

**Framework**: Core Video  
**Kind**: property

Vertical offset from the center of the image buffer.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- watchOS 27.0+ (Beta)

## Declaration

```swift
var verticalOffset: Float
```

#### Discussion

A positive value of this property will move the center of clean aperture downwards.
