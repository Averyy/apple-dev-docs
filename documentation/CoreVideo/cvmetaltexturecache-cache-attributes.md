# Cache Attributes

**Framework**: Core Video  
**Role**: API Collection

Attributes specifying texture cache behavior, used with the [`CVMetalTextureCacheCreate(_:_:_:_:_:)`](./cvmetaltexturecachecreate%28_,_,_,_,_%29.md) function.

## Topics

### Constants
- [let kCVMetalTextureCacheMaximumTextureAgeKey: CFString](./kcvmetaltexturecachemaximumtextureagekey.md)
  The length of time, in seconds, before the cache is automatically evicted.
- [let kCVMetalTextureUsage: CFString](./kcvmetaltextureusage.md)
  The set of options that define how you can use a texture on the GPU.
