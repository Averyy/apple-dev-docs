# Data Types

**Framework**: Core Video

Common data types used by the Core Video framework.

## Topics

### Data Types
- [typealias CVReturn](cvreturn.md)
  A Core Video error type return value.

## See Also

- [Result Codes](result-codes.md)
  Describes the result codes generated by Core Video operations.
- [struct CVError](cverror.md)
  `CVError` wraps `CVReturn` values to present them as Swift Error values. This type is used for all errors thrown in the CoreVideo framework. All `CVReturn` values are provided as static constants.
