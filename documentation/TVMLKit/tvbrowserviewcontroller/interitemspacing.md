# interitemSpacing

**Framework**: TVMLKit  
**Kind**: property  
**Role**: Instance Property

The spacing between full-screen browser items.

**Availability**:
- tvOS 13.0+

## Declaration

```swift
var interitemSpacing: CGFloat { get set }
```

```objc
@property (nonatomic, assign) CGFloat interitemSpacing;
```

#### Discussion

The default value is 20.0.
