# value(propertyName:)

**Framework**: TVMLKit  
**Kind**: method  
**Role**: Instance Method

Returns the value associated with a given style name.

**Availability**:
- tvOS 9.0+ - Deprecated in 18.0

> **Deprecated**: Please use SwiftUI or UIKit

## Declaration

```swift
func value(propertyName name: String) -> Any?
```

```objc
- (id) valueForStyleProperty:(NSString *) name;
```

## Return Value

An object containing the value associated with the style name.

## Parameters

- `name`: A user defined string representing the name of the style.
