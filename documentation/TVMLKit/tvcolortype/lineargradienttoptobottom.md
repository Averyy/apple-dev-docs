# TVColorType.linearGradientTopToBottom

**Framework**: TVMLKit  
**Kind**: case  
**Role**: Case

Indicates that a color gradient goes from the top to the bottom of an element.

**Availability**:
- tvOS 9.0+ - Deprecated in 18.0

> **Deprecated**: Please use SwiftUI or UIKit
