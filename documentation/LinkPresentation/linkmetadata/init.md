# init(_:)

**Framework**: Link Presentation  
**Kind**: init

Creates a [`LinkMetadata`](linkmetadata.md) value from a [`LPLinkMetadata`](lplinkmetadata.md) instance.

**Availability**:
- iOS 26.4+ (Beta)
- iPadOS 26.4+ (Beta)
- Mac Catalyst 26.4+ (Beta)
- macOS 26.4+ (Beta)
- tvOS 26.4+ (Beta)
- visionOS 26.4+ (Beta)
- watchOS 26.4+ (Beta)

## Declaration

```swift
nonisolated
init?(_ metadata: sending LPLinkMetadata)
```

## Parameters

- `metadata`: The `LPLinkMetadata` instance to convert from.
