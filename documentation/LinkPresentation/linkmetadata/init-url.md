# init(url:)

**Framework**: Link Presentation  
**Kind**: init

Creates a new [`LinkMetadata`](linkmetadata.md) value for the specified URL.

**Availability**:
- iOS 26.4+ (Beta)
- iPadOS 26.4+ (Beta)
- Mac Catalyst 26.4+ (Beta)
- macOS 26.4+ (Beta)
- tvOS 26.4+ (Beta)
- visionOS 26.4+ (Beta)
- watchOS 26.4+ (Beta)

## Declaration

```swift
nonisolated
init(url: URL)
```

## Parameters

- `url`: The URL that the metadata is for.
