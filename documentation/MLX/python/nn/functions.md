# Functions

Layers without parameters (e.g. activation functions) are also provided as
simple functions.

| [elu](_autosummary_functions/mlx.nn.elu.md#mlx.nn.elu)(x[, alpha]) | Applies the Exponential Linear Unit. |
| --- | --- |
| [celu](_autosummary_functions/mlx.nn.celu.md#mlx.nn.celu)(x[, alpha]) | Applies the Continuously Differentiable Exponential Linear Unit. |
| [gelu](_autosummary_functions/mlx.nn.gelu.md#mlx.nn.gelu)(x) | Applies the Gaussian Error Linear Units function. |
| [gelu_approx](_autosummary_functions/mlx.nn.gelu_approx.md#mlx.nn.gelu_approx)(x) | An approximation to Gaussian Error Linear Unit. |
| [gelu_fast_approx](_autosummary_functions/mlx.nn.gelu_fast_approx.md#mlx.nn.gelu_fast_approx)(x) | A fast approximation to Gaussian Error Linear Unit. |
| [glu](_autosummary_functions/mlx.nn.glu.md#mlx.nn.glu)(x[, axis]) | Applies the gated linear unit function. |
| [hard_shrink](_autosummary_functions/mlx.nn.hard_shrink.md#mlx.nn.hard_shrink)(x[, lambd]) | Applies the HardShrink activation function. |
| [hard_tanh](_autosummary_functions/mlx.nn.hard_tanh.md#mlx.nn.hard_tanh)(x[, min_val, max_val]) | Applies the HardTanh function. |
| [hardswish](_autosummary_functions/mlx.nn.hardswish.md#mlx.nn.hardswish)(x) | Applies the hardswish function, element-wise. |

| [log_sigmoid](_autosummary_functions/mlx.nn.log_sigmoid.md#mlx.nn.log_sigmoid)(x) | Applies the Log Sigmoid function. |
| [log_softmax](_autosummary_functions/mlx.nn.log_softmax.md#mlx.nn.log_softmax)(x[, axis]) | Applies the Log Softmax function. |
| [mish](_autosummary_functions/mlx.nn.mish.md#mlx.nn.mish)(x) | Applies the Mish function, element-wise. |
| [prelu](_autosummary_functions/mlx.nn.prelu.md#mlx.nn.prelu)(x, alpha) | Applies the element-wise parametric ReLU. |
| [relu](_autosummary_functions/mlx.nn.relu.md#mlx.nn.relu)(x) | Applies the Rectified Linear Unit. |
| [relu2](_autosummary_functions/mlx.nn.relu2.md#mlx.nn.relu2)(x) | Applies the ReLU² activation function. |
| [relu6](_autosummary_functions/mlx.nn.relu6.md#mlx.nn.relu6)(x) | Applies the Rectified Linear Unit 6. |
| [selu](_autosummary_functions/mlx.nn.selu.md#mlx.nn.selu)(x) | Applies the Scaled Exponential Linear Unit. |
| [sigmoid](_autosummary_functions/mlx.nn.sigmoid.md#mlx.nn.sigmoid)(x) | Applies the sigmoid function. |
| [silu](_autosummary_functions/mlx.nn.silu.md#mlx.nn.silu)(x) | Applies the Sigmoid Linear Unit. |
| [softmax](_autosummary_functions/mlx.nn.softmax.md#mlx.nn.softmax)(x[, axis]) | Applies the Softmax function. |
| [softmin](_autosummary_functions/mlx.nn.softmin.md#mlx.nn.softmin)(x[, axis]) | Applies the Softmin function. |
