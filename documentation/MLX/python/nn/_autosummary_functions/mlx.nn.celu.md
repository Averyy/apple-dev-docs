# mlx.nn.celu

**class celu(*x*, *alpha=1.0*)**
: Applies the Continuously Differentiable Exponential Linear Unit.
Applies \(\max(0, x) + \min(0, \alpha * (\exp(x / \alpha) - 1))\)
element wise.
