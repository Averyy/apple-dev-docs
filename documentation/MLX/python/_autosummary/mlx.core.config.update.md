# mlx.core.config.update

```python
update(name: str, value: int) → None
```

Set the value of a process-wide configuration.

See [Environment Variables](../../usage/environment_variables.md#environment-variables) for available configurations.

**Parameters:**

- **name** ([str](https://docs.python.org/3/builtins/stdtypes.html#str)) – Name of configuration.
- **value** ([int](https://docs.python.org/3/builtins/functions.html#int)) – Value of configuration.
