# mlx.core.vecdot

```python
vecdot(a: array, b: array, /, *, axis: int = -1, stream: StreamOrDevice = None) → array
```

Compute the vector dot product of two arrays along an axis.

**Parameters:**

- **a** ([array](mlx.core.array.md#mlx.core.array)) – Input array
- **b** ([array](mlx.core.array.md#mlx.core.array)) – Input array
- **axis** ([int](https://docs.python.org/3/builtins/functions.html#int), *optional*) – Axis over which to compute the dot product. Default: `-1`.

**Returns:**
: The vector dot product.

**Return type:**
: [array](mlx.core.array.md#mlx.core.array)
