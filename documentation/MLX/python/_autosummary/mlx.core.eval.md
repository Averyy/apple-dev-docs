# mlx.core.eval

**eval(**args*) → [None](https://docs.python.org/3/library/constants.html#None)**
: Evaluate an [array](mlx.core.array.html#mlx.core.array) or tree of [array](mlx.core.array.html#mlx.core.array).

Parameters:
***args** (*arrays** or **trees** of **arrays*) – Each argument can be a single array
or a tree of arrays. If a tree is given the nodes can be a Python
[list](https://docs.python.org/3/library/stdtypes.html#list), [tuple](https://docs.python.org/3/library/stdtypes.html#tuple) or [dict](https://docs.python.org/3/library/stdtypes.html#dict). Leaves which are not
arrays are ignored.
