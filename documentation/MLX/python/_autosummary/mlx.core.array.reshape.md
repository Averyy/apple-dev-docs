# mlx.core.array.reshape

**array.reshape(*self*, **shape*, *stream: Stream | ThreadLocalStream | Device | mlx.core.DeviceType | None = None*) → [array](mlx.core.array.md#mlx.core.array)**
: Equivalent to [reshape()](mlx.core.reshape.md#mlx.core.reshape) but the shape can be passed either as a
[tuple](https://docs.python.org/3/builtins/stdtypes.html#tuple) or as separate arguments.
See [reshape()](mlx.core.reshape.md#mlx.core.reshape) for full documentation.
