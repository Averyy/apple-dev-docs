# handle

**Framework**: PermissionKit  
**Kind**: property  
**Role**: Instance Property

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- visionOS 26.0+

## Declaration

```swift

```

## Discussion

A handle can be an email address, phone number, username, or any other person identifier.
