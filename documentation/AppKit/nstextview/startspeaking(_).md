# startSpeaking(_:)

**Framework**: AppKit  
**Kind**: method  
**Role**: Instance Method

Speaks the selected text, or all text if no selection.

**Availability**:
- macOS

## Declaration

```swift
func startSpeaking(_ sender: Any?)
```

```objc
- (void) startSpeaking:(id) sender;
```

## Parameters

- `sender`: The control sending the message; can be `nil`.
