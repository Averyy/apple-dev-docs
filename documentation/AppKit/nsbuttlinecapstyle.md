# NSButtLineCapStyle

**Framework**: AppKit  
**Kind**: var  
**Role**: Global Variable

Specifies a butt line cap style for endpoints for an open path when stroked.

**Availability**:
- macOS 10.0+ - Deprecated in 11.0

> **Deprecated**: Use [`NSBezierPath.LineCapStyle.butt`](./nsbezierpath/linecapstyle-swift.enum/butt.md) instead.

## Declaration

```c
static const NSLineCapStyle NSButtLineCapStyle;
```
