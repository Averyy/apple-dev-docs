# init()

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Creates a new toolbar with an empty identifier string.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- macOS 10.13+

## Declaration

```swift
convenience init()
```

```objc
- (instancetype) init;
```

## Return Value

The initialized toolbar object.
