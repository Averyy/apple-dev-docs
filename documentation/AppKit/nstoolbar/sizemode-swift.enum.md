# NSToolbar.SizeMode

**Framework**: AppKit  
**Kind**: enum  
**Role**: Enumeration

Constants that specify toolbar display modes.

**Availability**:
- Mac Catalyst 13.1+ - Deprecated in 27.2
- macOS 10.0+ - Deprecated in 27.0

> **Deprecated**: The toolbar no longer uses this type.

## Topics

### Constants
- [NSToolbar.SizeMode.default](./sizemode-swift.enum/default.md)

- [NSToolbar.SizeMode.regular](./sizemode-swift.enum/regular.md)
  The toolbar uses regular-sized controls and 32 by 32 pixel icons.
- [NSToolbar.SizeMode.small](./sizemode-swift.enum/small.md)
  The toolbar uses small-sized controls and 24 by 24 pixel icons.
