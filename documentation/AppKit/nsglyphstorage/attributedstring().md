# attributedString()

**Framework**: AppKit  
**Kind**: method  
**Required**: Yes

Returns the text storage object from which the `NSGlyphGenerator` object procures characters for glyph generation.

**Availability**:
- macOS 10.0+

## Declaration

```swift
func attributedString() -> NSAttributedString
```

#### Return Value

The receiver’s text storage object.
