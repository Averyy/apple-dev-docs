# init()

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Creates a Touch Bar object.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- macOS 10.12.2+

## Declaration

```swift
init()
```

```objc
- (instancetype) init;
```

## Return Value

A fully initialized Touch Bar object.
