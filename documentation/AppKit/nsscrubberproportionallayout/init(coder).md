# init(coder:)

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Initializes and returns a newly allocated proprotional layout object from a storyboard or nib file.

**Availability**:
- macOS 10.12.2+

## Declaration

```swift
init(coder: NSCoder)
```

```objc
- (instancetype) initWithCoder:(NSCoder *) coder;
```

#### Return Value

A properly initialized proportional layout object.
