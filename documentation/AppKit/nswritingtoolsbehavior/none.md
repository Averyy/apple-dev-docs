# NSWritingToolsBehavior.none

**Framework**: AppKit  
**Kind**: case  
**Role**: Case

An option to prevent Writing Tools from modifying the text in the view.

**Availability**:
- macOS 15.0+

## Declaration

```swift
case none
```

```c
NSWritingToolsBehaviorNone
```
