# Deprecated symbols

**Framework**: AppKit  
**Role**: API Collection

Review symbols that are no longer in active development, and their recommended replacements.

#### Overview

Although these symbols are available for use, Apple is no longer actively developing them, and may remove them in a future release. Apple recommends moving away from these symbols and using their indicated replacements instead. Check the individual symbol pages for the recommended replacements.

## Topics

### Deprecated methods
- [- jobStyleHint](./nsprintoperation/jobstylehint.md)
  The type of content that the print job is printing.
- [- setJobStyleHint:](./nsprintoperation/setjobstylehint_.md)
  Sets the type of content that the print job is printing.
- [- accessoryView](./nsprintoperation/accessoryview.md)
  Returns the accessory view used by the print operation’s print panel.
- [- setAccessoryView:](./nsprintoperation/setaccessoryview_.md)
  Sets the custom accessory view to be displayed by the print operation’s print panel.
- [- showPanels](./nsprintoperation/showpanels.md)
  Returns a Boolean value that indicates whether the print panel is to be displayed.
- [- setShowPanels:](./nsprintoperation/setshowpanels_.md)
  Sets whether the print operation should display a print panel.
