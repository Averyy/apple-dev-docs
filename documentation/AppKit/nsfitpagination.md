# NSFitPagination

**Framework**: AppKit  
**Kind**: var  
**Role**: Global Variable

The image is scaled to produce one column or one row of pages.

**Availability**:
- macOS 10.0+ - Deprecated in 11.0

## Declaration

```c
static const NSPrintingPaginationMode NSFitPagination;
```

### Deprecated
