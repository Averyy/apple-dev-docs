# NSLayoutConstraint.Attribute.firstBaseline

**Framework**: AppKit  
**Kind**: case  
**Role**: Case

The object’s baseline.

**Availability**:
- macOS 10.11+

## Declaration

```swift
case firstBaseline
```

```c
NSLayoutAttributeFirstBaseline
```

#### Discussion

For objects with more than one line of text, this is the baseline for the topmost line of text.
