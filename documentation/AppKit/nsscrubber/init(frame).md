# init(frame:)

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Initializes and returns a newly allocated scrubber object with the specified frame rectangle.

**Availability**:
- macOS 10.12.2+

## Declaration

```swift
init(frame frameRect: NSRect)
```

```objc
- (instancetype) initWithFrame:(NSRect) frameRect;
```
