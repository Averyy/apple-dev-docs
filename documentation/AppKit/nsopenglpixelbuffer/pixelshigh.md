# pixelsHigh

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

The height of the OpenGL pixel buffer’s texture (in pixels).

**Availability**:
- macOS 10.2+ - Deprecated in 10.7

## Declaration

```objc
@property (readonly) GLsizei pixelsHigh;
```

## Return Value

The height of the texture (in pixels).
