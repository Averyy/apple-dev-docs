# NSLightGray

**Framework**: AppKit  
**Kind**: var  
**Role**: Global Variable

A constant that specifies the light gray shade in the 2-bit deep grayscale color space.

**Availability**:
- macOS

## Declaration

```c
extern const CGFloat NSLightGray;
```
