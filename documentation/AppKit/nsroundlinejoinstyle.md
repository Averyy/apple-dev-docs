# NSRoundLineJoinStyle

**Framework**: AppKit  
**Kind**: var  
**Role**: Global Variable

Specifies a round line shape of the joints between connected segments of a stroked path.

**Availability**:
- macOS 10.0+ - Deprecated in 11.0

> **Deprecated**: Use [`NSBezierPath.LineJoinStyle.round`](./nsbezierpath/linejoinstyle-swift.enum/round.md) instead.

## Declaration

```c
static const NSLineJoinStyle NSRoundLineJoinStyle;
```
