# NSSpellingState

**Framework**: AppKit  
**Kind**: enum  
**Role**: Enumeration

Constants for the spelling state attribute key.

**Availability**:
- macOS

## Declaration

```c
enum NSSpellingState : NSInteger;
```

#### Overview

Use these constants as the values for the [`NSSpellingStateAttributeName`](./nsspellingstateattributename.md) key.
