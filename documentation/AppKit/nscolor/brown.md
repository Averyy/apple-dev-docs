# brown

**Framework**: AppKit  
**Kind**: property  
**Role**: Type Property

Returns a color object whose RGB value is `0.6`, `0.4`, `0.2` and whose alpha value is `1.0`.

**Availability**:
- macOS

## Declaration

```swift
class var brown: NSColor { get }
```

```objc
@property (class, strong, readonly) NSColor * brownColor;
```

#### Return Value

The `NSColor` object.
