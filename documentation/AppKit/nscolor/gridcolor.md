# gridColor

**Framework**: AppKit  
**Kind**: property  
**Role**: Type Property

The color to use for the optional gridlines, such as those in a table view.

**Availability**:
- macOS

## Declaration

```swift
class var gridColor: NSColor { get }
```

```objc
@property (class, strong, readonly) NSColor * gridColor;
```

#### Return Value

The system color used for gridlines. For more information, see [`NSColor`](../nscolor.md).
