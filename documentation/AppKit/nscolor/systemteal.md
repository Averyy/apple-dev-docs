# systemTeal

**Framework**: AppKit  
**Kind**: property  
**Role**: Type Property

Returns a color object for teal that automatically adapts to vibrancy and accessibility settings.

**Availability**:
- macOS 10.12+

## Declaration

```swift
class var systemTeal: NSColor { get }
```

```objc
@property (class, strong, readonly) NSColor * systemTealColor;
```

#### Discussion

Use this color when you want a tint color that looks great on both light and dark backgrounds.
