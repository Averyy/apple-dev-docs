# selectedControlColor

**Framework**: AppKit  
**Kind**: property  
**Role**: Type Property

The color to use for the face of a selected control—that is, a control that has been clicked or is being dragged.

**Availability**:
- macOS

```swift
class var selectedControlColor: NSColor { get }
```
