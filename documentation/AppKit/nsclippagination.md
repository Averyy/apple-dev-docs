# NSClipPagination

**Framework**: AppKit  
**Kind**: var  
**Role**: Global Variable

The image is clipped to produce one column or row of pages.

**Availability**:
- macOS 10.0+ - Deprecated in 11.0

## Declaration

```c
static const NSPrintingPaginationMode NSClipPagination;
```
