# init()

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Creates a directional edge insets structure that contains default values.

**Availability**:
- macOS 10.15+

## Declaration

```swift
init()
```

## Return Value

An initialized inset structure.

## Discussion

This method sets all inset margins to `0.0`.
