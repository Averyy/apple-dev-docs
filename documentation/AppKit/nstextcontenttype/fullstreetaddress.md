# fullStreetAddress

**Framework**: AppKit  
**Kind**: property  
**Role**: Type Property

A property that defines the content in a text input area as a street address that fully identifies a location.

**Availability**:
- macOS 14.0+

## Declaration

```swift
static let fullStreetAddress: NSTextContentType
```
