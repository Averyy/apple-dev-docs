# init(coder:)

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Initializes and returns a new item from a storyboard or nib file.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- macOS 10.12.2+
