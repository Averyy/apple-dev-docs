# NSPickerTouchBarItem.SelectionMode.selectOne

**Framework**: AppKit  
**Kind**: case  
**Role**: Case

A mode in which a person can only select one option in the control at a time.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
