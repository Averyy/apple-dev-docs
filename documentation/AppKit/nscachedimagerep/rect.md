# rect

**Framework**: AppKit  
**Kind**: method  
**Role**: Instance Method

Returns the rectangle where the representation is cached.

**Availability**:
- macOS 10.0+ - Deprecated in 10.6

## Declaration

```objc
- (NSRect) rect;
```

#### Return Value

The rectangle in the associated offscreen window where the receiver’s image is located.
