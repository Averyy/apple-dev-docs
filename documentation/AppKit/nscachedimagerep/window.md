# window

**Framework**: AppKit  
**Kind**: method  
**Role**: Instance Method

Returns the window where the representation is cached.

**Availability**:
- macOS 10.0+ - Deprecated in 10.6

## Declaration

```objc
- (NSWindow *) window;
```

#### Return Value

The window (typically offscreen) used to store the image.
