# tag

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

The integer tag of the selected menu item.

**Availability**:
- macOS

## Declaration

```swift
var tag: Int { get set }
```

```objc
@property NSInteger tag;
```

#### Discussion

If no item is selected, the value in this property is `0`.
