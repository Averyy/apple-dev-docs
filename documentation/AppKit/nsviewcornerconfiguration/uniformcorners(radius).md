# uniformCorners(radius:)

**Framework**: AppKit  
**Kind**: method  
**Role**: Type Method

A configuration that applies the given radius uniformly to all corners, using the largest of the resolved corner radii when they differ.

**Availability**:
- macOS 27.0+
