# allowsCharacterPickerTouchBarItem

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that controls whether the Touch Bar displays the character picker item for rich text fields.

**Availability**:
- macOS 10.12.2+
