# init(string:)

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Creates a badge with the provided custom string.

**Availability**:
- macOS 14.0+

## Declaration

```swift
init(string: String)
```

```objc
- (instancetype) initWithString:(NSString *) string;
```

## Parameters

- `string`: The string label that displays when the badge appears.
