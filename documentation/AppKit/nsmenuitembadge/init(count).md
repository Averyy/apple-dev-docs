# init(count:)

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Creates a badge with a count and an empty string.

**Availability**:
- macOS 14.0+

## Declaration

```swift
init(count itemCount: Int)
```

```objc
- (instancetype) initWithCount:(NSInteger) itemCount;
```

## Parameters

- `itemCount`: The badge count.
