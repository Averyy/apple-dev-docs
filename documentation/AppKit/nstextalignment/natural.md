# NSTextAlignment.natural

**Framework**: AppKit  
**Kind**: case  
**Role**: Case

Text uses the default alignment for the current localization of the app.

**Availability**:
- macOS 10.0+

## Declaration

```swift
case natural
```

```c
NSTextAlignmentNatural
```

#### Discussion

The default alignment for left-to-right scripts is [`NSTextAlignment.left`](./left.md), and the default alignment for right-to-left scripts is [`NSTextAlignment.right`](./right.md).
