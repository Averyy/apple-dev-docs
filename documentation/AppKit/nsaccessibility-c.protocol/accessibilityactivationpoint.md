# accessibilityActivationPoint

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

The activation point for the user interface element.

**Availability**:
- macOS 10.10+

## Declaration

```objc
@property NSPoint accessibilityActivationPoint;
```

## Discussion

The activation point in screen coordinates.
