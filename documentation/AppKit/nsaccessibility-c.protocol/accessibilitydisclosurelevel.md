# accessibilityDisclosureLevel

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

The indention level for the row.

**Availability**:
- macOS 10.10+

## Declaration

```objc
@property NSInteger accessibilityDisclosureLevel;
```

#### Discussion

Use this property in the elements representing an outline’s row.
