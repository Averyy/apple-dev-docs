# accessibilityDisclosedByRow

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

The row disclosing the current row.

**Availability**:
- macOS 10.10+

## Declaration

```objc
@property (weak, nullable) id accessibilityDisclosedByRow;
```

## Discussion

Use this property in the elements representing an outline’s row.
