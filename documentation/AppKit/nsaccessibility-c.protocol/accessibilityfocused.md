# accessibilityFocused

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that determines whether the accessibility element has the keyboard focus.

**Availability**:
- macOS 10.10+

## Declaration

```objc
@property (getter=isAccessibilityFocused) BOOL accessibilityFocused;
```
