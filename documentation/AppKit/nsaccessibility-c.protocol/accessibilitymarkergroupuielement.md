# accessibilityMarkerGroupUIElement

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

The user interface element that functions as a marker group for the ruler accessibility element.

**Availability**:
- macOS 10.10+

## Declaration

```objc
@property (strong, nullable) id accessibilityMarkerGroupUIElement;
```

#### Discussion

Use this property on a ruler element.
