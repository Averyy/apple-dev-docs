# columnSpan

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

Returns the number of table columns spanned by this text table block.

**Availability**:
- macOS 10.0+

## Declaration

```swift
var columnSpan: Int { get }
```

```objc
@property (readonly) NSInteger columnSpan;
```

#### Return Value

The number of table columns spanned by this text table block.
