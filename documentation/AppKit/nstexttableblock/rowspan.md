# rowSpan

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

Returns the number of table rows spanned by this text table block.

**Availability**:
- macOS 10.0+

## Declaration

```swift
var rowSpan: Int { get }
```

```objc
@property (readonly) NSInteger rowSpan;
```

#### Return Value

The number of table rows spanned by this text table block.
