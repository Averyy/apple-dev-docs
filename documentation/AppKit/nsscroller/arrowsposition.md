# arrowsPosition

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

The location of the scroll buttons within the scroller, as described in [`NSScroller.ArrowPosition`](./arrowposition.md).

**Availability**:
- macOS 10.0+ - Deprecated in 10.14

> **Deprecated**: Has had no effect since 10.7

## Declaration

```swift
var arrowsPosition: NSScroller.ArrowPosition { get set }
```

```objc
@property NSScrollArrowPosition arrowsPosition;
```

## Discussion

See [`NSScroller.ArrowPosition`](./arrowposition.md) for a list of possible values for `location`.

> **Note**:  This property has no effect in macOS 10.7 and later.
