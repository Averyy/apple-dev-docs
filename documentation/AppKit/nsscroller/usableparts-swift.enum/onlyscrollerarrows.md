# NSScroller.UsableParts.onlyScrollerArrows

**Framework**: AppKit  
**Kind**: case  
**Role**: Case

Specifies that the scroller has only scroll buttons, no knob.

**Availability**:
- macOS 10.0+ - Deprecated in 10.14

> **Deprecated**: Scroller arrows are not used anymore.
