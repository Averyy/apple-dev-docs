# init(coder:)

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Initializes a scrubber selection style when included from a nib or Storyboard.

**Availability**:
- macOS 10.12.2+

## Declaration

```swift
init(coder: NSCoder)
```

```objc
- (instancetype) initWithCoder:(NSCoder *) coder;
```

## Return Value

A properly initialized scrubber selection style object.
