# increment

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

The amount by which the receiver changes with each increment or decrement.

**Availability**:
- macOS

## Declaration

```swift
var increment: Double { get set }
```

```objc
@property double increment;
```

## Discussion

The default is 1.
