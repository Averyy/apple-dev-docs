# NSSmallControlSize

**Framework**: AppKit  
**Kind**: var  
**Role**: Global Variable

A size that is smaller than the default control size.

**Availability**:
- macOS 10.0+ - Deprecated in 10.12

## Declaration

```c
static const NSControlSize NSSmallControlSize;
```
