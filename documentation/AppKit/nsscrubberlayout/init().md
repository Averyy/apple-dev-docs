# init()

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Initializes and returns a newly allocated scrubber layout object from code.

**Availability**:
- macOS 10.12.2+

## Declaration

```swift
init()
```

```objc
- (instancetype) init;
```

## Return Value

A properly initialized scrubber layout object.
