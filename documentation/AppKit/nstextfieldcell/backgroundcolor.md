# backgroundColor

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

The color of the cell’s background.

**Availability**:
- macOS

## Declaration

```swift
@NSCopying
var backgroundColor: NSColor? { get set }
```

```objc
@property (copy, nullable) NSColor * backgroundColor;
```

#### Discussion

The background color is drawn behind the cell’s text.
