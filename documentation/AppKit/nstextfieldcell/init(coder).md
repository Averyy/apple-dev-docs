# init(coder:)

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Initializes a text field cell from data in the provided unarchiver.

**Availability**:
- macOS

## Declaration

```swift
init(coder: NSCoder)
```

```objc
- (instancetype) initWithCoder:(NSCoder *) coder;
```

#### Return Value

A text field cell that displays a string.

## Parameters

- `coder`: An unarchiver object.
