# NSMenuItem.ImageVisibility.hidden

**Framework**: AppKit  
**Kind**: case

The item image should not be visible.

**Availability**:
- macOS 27.0+ (Beta)

## Declaration

```swift
case hidden
```

## See Also

- [NSMenuItem.ImageVisibility.visible](nsmenuitem/imagevisibility/visible.md)
