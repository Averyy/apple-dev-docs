# init(coder:)

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Creates a new content manager object from data in an unarchiver.

**Availability**:
- macOS 12.0+

## Declaration

```swift
init?(coder: NSCoder)
```

```objc
- (instancetype) initWithCoder:(NSCoder *) coder;
```

## Parameters

- `coder`: An unachiver that conforms to the [`NSCoder`](../../Foundation/nscoder.md) class.
