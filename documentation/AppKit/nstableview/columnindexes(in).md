# columnIndexes(in:)

**Framework**: AppKit  
**Kind**: method  
**Role**: Instance Method

Returns the indexes of the table view’s columns that intersect the specified rectangle.

**Availability**:
- macOS 10.5+

## Declaration

```swift
func columnIndexes(in rect: NSRect) -> IndexSet
```

```objc
- (NSIndexSet *) columnIndexesInRect:(NSRect) rect;
```

#### Return Value

New [`NSIndexSet`](../../Foundation/nsindexset.md) object containing the indexes of the table view’s columns that intersect with `rect`.

#### Discussion

Columns that return [`true`](../../Swift/true.md) for the `NSTableColumn` method [`isHidden`](../nstablecolumn/ishidden.md) are excluded from the results.

## Parameters

- `rect`: The rectangle in the table view’s coordinate system to test for column enclosure.
