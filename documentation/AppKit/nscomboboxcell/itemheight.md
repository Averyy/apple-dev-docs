# itemHeight

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

The height of each item in the combo box’s pop-up list.

**Availability**:
- macOS

## Declaration

```swift
var itemHeight: CGFloat { get set }
```

```objc
@property CGFloat itemHeight;
```

## Discussion

The default item height is 16.0.
