# Deprecated symbols

**Framework**: AppKit  
**Role**: API Collection

Review symbols that are no longer in active development, and their recommended replacements.

#### Overview

Although these symbols are available for use, Apple is no longer actively developing them, and may remove them in a future release. Apple recommends moving away from these symbols and using their indicated replacements instead. Check the individual symbol pages for the recommended replacements.

## Topics

### Deprecated methods
- [func beginGesture(with: NSEvent)](./nsresponder/begingesture%28with%29.md)
  Informs the receiver that the user has begun a touch gesture.
- [func endGesture(with: NSEvent)](./nsresponder/endgesture%28with%29.md)
  Informs the receiver that the user has ended a touch gesture.
- [- performMnemonic:](./nsresponder/performmnemonic_.md)
  Handle a mnemonic.
- [- setInterfaceStyle:](./nsresponder/setinterfacestyle_.md)
  Sets the receiver’s style to the style specified by `interfaceStyle`, such as `NSMacintoshInterfaceStyle` or `NSWindows95InterfaceStyle`.
- [- interfaceStyle](./nsresponder/interfacestyle.md)
  Returns the receiver’s interface style.
### Deprecated constants
- [NSInterfaceStyleDefault](./nsinterfacestyledefault.md)
  For more information, see the function [`NSInterfaceStyleForKey`](./nsinterfacestyleforkey.md).
