# isAnyApplicationSpeaking

**Framework**: AppKit  
**Kind**: property  
**Role**: Type Property

A Boolean value indicating whether any application is currently speaking through the sound output device.

**Availability**:
- macOS 10.3+ - Deprecated in 14.0

> **Deprecated**: Use AVSpeechSynthesizer in AVFoundation instead

## Declaration

```swift
class var isAnyApplicationSpeaking: Bool { get }
```

```objc
@property (class, readonly, getter=isAnyApplicationSpeaking) BOOL anyApplicationSpeaking;
```

## Discussion

This property is [`true`](../../Swift/true.md) when another application is producing speech through the sound output device. You usually invoke this method to prevent your application from speaking over speech being generated by another application or system component.
