# init()

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Initializes and returns an instance of the `NSSpeechRecognizer` class.

**Availability**:
- macOS

## Declaration

```swift
init?()
```

```objc
- (instancetype) init;
```

## Discussion

Returns `nil` if initialization did not succeed.
