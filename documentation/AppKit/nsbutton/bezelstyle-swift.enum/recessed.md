# recessed

**Framework**: AppKit  
**Kind**: property  
**Role**: Type Property

A bezel style appropriate for use in scope bars and title bar accessories, similar to the bookmarks bar in Safari.

**Availability**:
- macOS 10.0+ - Deprecated in 27.0 (renamed: NSButton.BezelStyle.accessoryBar)
