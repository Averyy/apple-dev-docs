# NSButton.GradientType.convexWeak

**Framework**: AppKit  
**Kind**: case  
**Role**: Case

The top-left corner is dark gray, and the bottom-right corner is light gray, so the button appears to be sticking out.

**Availability**:
- macOS 10.0+ - Deprecated in 10.12

## Declaration

```swift
case convexWeak
```

```c
NSGradientConvexWeak
```
