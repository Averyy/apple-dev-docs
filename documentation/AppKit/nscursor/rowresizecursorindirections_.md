# rowResizeCursorInDirections:

**Framework**: AppKit  
**Kind**: method  
**Role**: Type Method

Returns the cursor for resizing a row (horizontal divider) in the specified directions.

**Availability**:
- Mac Catalyst 18.0+
- macOS 15.0+

## Declaration

```objc
+ (NSCursor *) rowResizeCursorInDirections:(NSVerticalDirections) directions;
```

## Parameters

- `directions`: The direction in which a row can be resized.
