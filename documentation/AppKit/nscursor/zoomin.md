# zoomIn

**Framework**: AppKit  
**Kind**: property  
**Role**: Type Property

Returns the zoom-in cursor.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 18.0+
- macOS 15.0+

## Declaration

```swift
class var zoomIn: NSCursor { get }
```

```objc
@property (class, strong, readonly) NSCursor * zoomInCursor;
```

#### Discussion

> **Note**: This cursor is used to indicate zooming in on (magnifying) a canvas or object.
