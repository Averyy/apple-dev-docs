# isCancellableByScrollGesture

**Framework**: AppKit  
**Kind**: property

Causes the receiver to be cancelled when its enclosing scroll view’s gesture recognizer begins.

**Availability**:
- macOS 27.0+ (Beta)

## Declaration

```swift
var isCancellableByScrollGesture: Bool { get set }
```

#### Discussion

Defaults to `false`.
