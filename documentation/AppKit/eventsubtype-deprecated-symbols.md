# Deprecated symbols

**Framework**: AppKit  
**Role**: API Collection

Review symbols that are no longer in active development, and their recommended replacements.

## Overview

Although these symbols are available for use, Apple is no longer actively developing them, and may remove them in a future release. Apple recommends moving away from these symbols and using their indicated replacements instead. Check the individual symbol pages for the recommended replacements.

## Topics

### Deprecated constants
- [NSAWTEventType](./nsawteventtype.md)
  An event type used to support Java applications.
- [NSApplicationActivatedEventType](./nsapplicationactivatedeventtype.md)
  The application has been activated.
- [NSApplicationDeactivatedEventType](./nsapplicationdeactivatedeventtype.md)
  The application has been deactivated.
- [NSMouseEventSubtype](./nsmouseeventsubtype.md)
  Indicates a purely mouse event.
- [NSPowerOffEventType](./nspoweroffeventtype.md)
  Specifies that the user is turning off the computer.
- [NSScreenChangedEventType](./nsscreenchangedeventtype.md)
  An NSWindow has changed screens.
- [NSTabletPointEventSubtype](./nstabletpointeventsubtype.md)
  Indicates a tablet-pointer event; see description of `NSTabletPoint`.
- [NSTabletProximityEventSubtype](./nstabletproximityeventsubtype.md)
  Indicates a tablet-proximity event; see description of `NSTabletProximity`.
- [NSTouchEventSubtype](./nstoucheventsubtype.md)
  Indicates a touch event subtype.
- [NSWindowExposedEventType](./nswindowexposedeventtype.md)
  A non-retained NSWindow has been exposed.
- [NSWindowMovedEventType](./nswindowmovedeventtype.md)
  An NSWindow has moved.
