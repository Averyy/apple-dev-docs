# NSMiniControlSize

**Framework**: AppKit  
**Kind**: var  
**Role**: Global Variable

The control has a smaller size than `NSSmallControlSize`.

**Availability**:
- macOS 10.0+ - Deprecated in 10.12

## Declaration

```c
static const NSControlSize NSMiniControlSize;
```
