# init(target:action:)

**Framework**: AppKit  
**Kind**: init

The action is sent to the target on interaction.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- macOS 10.12+

## Declaration

```swift
init(target: Any?, action: Selector)
```

## Parameters

- `target`: An optional `NSSliderAccessory`.
