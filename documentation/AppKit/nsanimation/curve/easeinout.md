# NSAnimation.Curve.easeInOut

**Framework**: AppKit  
**Kind**: case  
**Role**: Case

Describes an S-curve in which the animation slowly speeds up and then slows down near the end of the animation. This constant is the default.

**Availability**:
- macOS

## Declaration

```swift
case easeInOut
```

```c
NSAnimationEaseInOut
```
