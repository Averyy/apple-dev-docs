# progressMarkUserInfoKey

**Framework**: AppKit  
**Kind**: property  
**Role**: Type Property

## Declaration

```swift
class let progressMarkUserInfoKey: String
```


## Discussion

Contains the value of an [`NSAnimation.Progress`](./progress.md) as an [`NSNumber`](../../Foundation/nsnumber.md) instance that indicates the current animation progress. The value will be between `0.0` and `1.0`.
