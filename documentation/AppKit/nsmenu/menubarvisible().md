# menuBarVisible()

**Framework**: AppKit  
**Kind**: method  
**Role**: Type Method

Returns a Boolean value that indicates whether the menu bar is visible.

**Availability**:
- macOS

```swift
class func menuBarVisible() -> Bool
```


#### Return Value

[`true`](../../Swift/true.md) if the menu bar is visible and selectable, otherwise [`false`](../../Swift/false.md).
