# init(key:)

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Initializes and returns a dragging image component with the specified key.

**Availability**:
- macOS 10.7+

## Declaration

```swift
init(key: NSDraggingItem.ImageComponentKey)
```

```objc
- (instancetype) initWithKey:(NSDraggingImageComponentKey) key;
```

#### Return Value

An initialized dragging image component with the specified key.

#### Discussion

This method is the designated initializer.

## Parameters

- `key`: The key.
