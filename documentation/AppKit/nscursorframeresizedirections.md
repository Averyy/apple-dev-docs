# NSCursorFrameResizeDirections

**Framework**: AppKit  
**Kind**: enum  
**Role**: Enumeration

The directions in which a rectangular frame can be resized.

**Availability**:
- Mac Catalyst 18.0+
- macOS 15.0+

## Declaration

```c
enum NSCursorFrameResizeDirections : NSUInteger;
```

## Topics

### Enumeration Cases
- [NSCursorFrameResizeDirectionsAll](./nscursorframeresizedirections/nscursorframeresizedirectionsall.md)
  Indicates that the shape can be resized inwards or wards to be either smaller or larger, respectively.
- [NSCursorFrameResizeDirectionsInward](./nscursorframeresizedirections/nscursorframeresizedirectionsinward.md)
  Indicates that the shape can be resized inwards to be smaller.
- [NSCursorFrameResizeDirectionsOutward](./nscursorframeresizedirections/nscursorframeresizedirectionsoutward.md)
  Indicates that the shape can be resized outwards to be larger.
