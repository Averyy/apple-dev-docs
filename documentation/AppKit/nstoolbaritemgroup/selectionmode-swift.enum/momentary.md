# NSToolbarItemGroup.SelectionMode.momentary

**Framework**: AppKit  
**Kind**: case  
**Role**: Case

The system temporarily highlights the select group item when the user selects the item.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- macOS 10.15+
