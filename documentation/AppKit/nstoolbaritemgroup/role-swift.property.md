# role

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

The semantic role of the item. Defaults to `NSToolbarItemGroupRoleAutomatic`.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 27.0+
- macOS 27.0+
