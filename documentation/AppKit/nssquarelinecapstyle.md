# NSSquareLineCapStyle

**Framework**: AppKit  
**Kind**: var  
**Role**: Global Variable

Specifies a square line cap style for endpoints for an open path when stroked.

**Availability**:
- macOS 10.0+ - Deprecated in 11.0

> **Deprecated**: Use [`NSBezierPath.LineCapStyle.square`](./nsbezierpath/linecapstyle-swift.enum/square.md) instead.

## Declaration

```c
static const NSLineCapStyle NSSquareLineCapStyle;
```
