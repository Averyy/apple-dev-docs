# Deprecated symbols

**Framework**: AppKit  
**Role**: API Collection

Review symbols that are no longer in active development, and their recommended replacements.

## Overview

Although these symbols are available for use, Apple is no longer actively developing them, and may remove them in a future release. Apple recommends moving away from these symbols and using their indicated replacements instead. Check the individual symbol pages for the recommended replacements.

## Topics

  The progress indicator’s control tint.
- [var isBezeled: Bool](./nsprogressindicator/isbezeled.md)
  A Boolean that indicates whether the progress indicator’s frame has a three-dimensional bezel.
### Deprecated methods
- [- animate:](./nsprogressindicator/animate_.md)
  This action method advances the progress animation of an indeterminate progress animator by one step.
- [- animationDelay](./nsprogressindicator/animationdelay.md)
  Returns the delay, in seconds, between animation steps for an indeterminate progress indicator.
- [- setAnimationDelay:](./nsprogressindicator/setanimationdelay_.md)
  Sets the delay, in seconds, between animation steps for an indeterminate progress indicator.
### Deprecated enumerations
- [NSProgressIndicatorThickness](./nsprogressindicatorthickness.md)
  Specify the height of a progress indicator.
