# label

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

The text displayed alongside the slider.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- macOS 10.12.2+

## Declaration

```swift
var label: String? { get set }
```

```objc
@property (copy, nullable) NSString * label;
```

## Discussion

Set this property to `nil` to hide the label.
