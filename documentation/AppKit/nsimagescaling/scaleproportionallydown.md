# NSImageScaling.scaleProportionallyDown

**Framework**: AppKit  
**Kind**: case  
**Role**: Case

If it is too large for the destination, scale the image down while preserving the aspect ratio.

**Availability**:
- macOS 10.5+

```swift
case scaleProportionallyDown
```
