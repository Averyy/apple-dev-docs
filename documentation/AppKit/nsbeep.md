# NSBeep

**Framework**: AppKit  
**Kind**: func  
**Role**: Function

Plays the system beep.

**Availability**:
- macOS

## Declaration

```c
extern void NSBeep();
```

## Discussion

Plays the system beep. Users can select a sound to be played as the system beep. On a Macintosh computer, for example, you can change sounds with the Sound pane of System Preferences.
