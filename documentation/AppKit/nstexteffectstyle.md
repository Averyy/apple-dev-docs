# NSTextEffectStyle

**Framework**: AppKit  
**Kind**: typealias  
**Role**: Type Alias

Constants for the type of effect to apply to the text.

**Availability**:
- macOS 10.10+

## Declaration

```c
typedef NSString * NSTextEffectStyle;
```

#### Discussion

Use this constant as the value for the [`NSTextEffectAttributeName`](./nstexteffectattributename.md) key.
