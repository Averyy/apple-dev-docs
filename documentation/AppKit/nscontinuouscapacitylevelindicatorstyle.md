# NSContinuousCapacityLevelIndicatorStyle

**Framework**: AppKit  
**Kind**: var  
**Role**: Global Variable

A style that indicates the capacity of something, such as how much data is on a hard disk.

**Availability**:
- macOS 10.0+ - Deprecated in 10.14

> **Deprecated**: Use [`NSLevelIndicator.Style.continuousCapacity`](./nslevelindicator/style/continuouscapacity.md) instead.

## Declaration

static const NSLevelIndicatorStyle NSContinuousCapacityLevelIndicatorStyle;
