# NSViewCornerRadii

**Framework**: AppKit  
**Kind**: class  
**Role**: Class

Provides a structured way to define custom corner radii for each corner of a view, along with a corner curve.

**Availability**:
- macOS 27.0+

class NSViewCornerRadii
