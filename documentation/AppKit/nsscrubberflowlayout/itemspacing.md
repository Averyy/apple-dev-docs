# itemSpacing

**Framework**: AppKit  
**Kind**: property  
**Role**: Instance Property

The horizontal spacing between items, specified in points.

**Availability**:
- macOS 10.12.2+

## Declaration

```swift
var itemSpacing: CGFloat { get set }
```

```objc
@property CGFloat itemSpacing;
```

#### Discussion

The default value of this property is `0.0`.
