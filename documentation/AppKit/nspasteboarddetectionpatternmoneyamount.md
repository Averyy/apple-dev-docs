# NSPasteboardDetectionPatternMoneyAmount

**Framework**: AppKit  
**Kind**: var  
**Role**: Global Variable

A pattern that indicates the pasteboard detects a string that contains an amount of money.

**Availability**:
- macOS 15.4+
