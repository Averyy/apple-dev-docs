# Deprecated symbols

**Framework**: AppKit  
**Role**: API Collection

Review symbols that are no longer in active development, and their recommended replacements.

#### Overview

Although these symbols are available for use, Apple is no longer actively developing them, and may remove them in a future release. Apple recommends moving away from these symbols and using their indicated replacements instead. Check the individual symbol pages for the recommended replacements.

## Topics

### Deprecated symbols
- [NSIntType](./nsinttype.md)
  Must be between `INT_MIN` and `INT_MAX`.
- [NSPositiveIntType](./nspositiveinttype.md)
  Must be between 1 and `INT_MAX`.
- [NSFloatType](./nsfloattype.md)
  Must be between `–FLT_MAX` and `FLT_MAX`.
- [NSPositiveFloatType](./nspositivefloattype.md)
  Must be between `FLT_MIN` and `FLT_MAX`.
- [NSDoubleType](./nsdoubletype.md)
  Must be between `–FLT_MAX` and `FLT_MAX`.
- [NSPositiveDoubleType](./nspositivedoubletype.md)
  Must be between `FLT_MIN` and `FLT_MAX`.
- [NSAnyType](./nsanytype.md)
  Any value is allowed.
