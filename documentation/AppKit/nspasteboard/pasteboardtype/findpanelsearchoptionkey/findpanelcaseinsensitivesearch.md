# findPanelCaseInsensitiveSearch

**Framework**: AppKit  
**Kind**: property  
**Role**: Type Property

**Availability**:
- macOS 10.5+

## Discussion

The value [`true`](../../../../Swift/true.md) indicates a case-insensitive search; [`false`](../../../../Swift/false.md) indicates a case-sensitive search.
