# formFeed

**Framework**: AppKit  
**Kind**: property  
**Role**: Type Property

The form feed key.

**Availability**:
- macOS 10.9+

## Declaration

```swift
static let formFeed: NSEvent.SpecialKey
```

## Discussion

This key is unavailable on most Macintosh keyboards.
