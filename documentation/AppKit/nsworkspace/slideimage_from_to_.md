# slideImage:from:to:

**Framework**: AppKit  
**Kind**: method  
**Role**: Instance Method

Animates a sliding image from one point to another.

**Availability**:
- macOS 10.0+ - Deprecated in 10.6

> **Deprecated**: Do not use.

## Declaration

```objc
- (void) slideImage:(NSImage *) image from:(NSPoint) fromPoint to:(NSPoint) toPoint;
```

## Discussion

Currently unimplemented.

## Parameters

- `image`: The image to animate.
- `fromPoint`: The starting point, in screen coordinates.
- `toPoint`: The ending point, in screen coordinates.
