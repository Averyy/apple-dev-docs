# applicationUserInfoKey

**Framework**: AppKit  
**Kind**: property  
**Role**: Type Property

The value corresponding to this key is an instance of [`NSRunningApplication`](../nsrunningapplication.md) that reflects the affected app.

**Availability**:
- macOS 10.6+
