# isFilePackage(atPath:)

**Framework**: AppKit  
**Kind**: method  
**Role**: Instance Method

Determines whether the specified path is a file package.

**Availability**:
- macOS

## Declaration

```swift
func isFilePackage(atPath fullPath: String) -> Bool
```

```objc
- (BOOL) isFilePackageAtPath:(NSString *) fullPath;
```

#### Return Value

[`true`](../../Swift/true.md) if the path identifies a file package; otherwise, [`false`](../../Swift/false.md) if the path does not exist, is not a directory, or is not a file package.

#### Discussion

You can safely call this method from any thread of your app.

## Parameters

- `fullPath`: The full path to examine.
