# init()

**Framework**: AppKit  
**Kind**: init  
**Role**: Initializer

Creates an option object containing no options.

**Availability**:
- macOS 10.13+

## Declaration

```swift
init()
```

```objc
- (instancetype) init;
```

#### Discussion

Use this initializer to create the empty option set.
