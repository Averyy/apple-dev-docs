# NSPasteboardDetectionPatternLink

**Framework**: AppKit  
**Kind**: var  
**Role**: Global Variable

A pattern that indicates the pasteboard detects a string that contains a URL.

**Availability**:
- macOS 15.4+

## Declaration

```c
extern NSPasteboardDetectionPattern const NSPasteboardDetectionPatternLink;
```

#### Return Value

Array of DDMatchLink values
