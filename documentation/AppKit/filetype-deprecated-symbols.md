# Deprecated symbols

**Framework**: AppKit  
**Role**: API Collection

Review symbols that are no longer in active development, and their recommended replacements.

## Overview

Although these symbols are available for use, Apple is no longer actively developing them, and may remove them in a future release. Apple recommends moving away from these symbols and using their indicated replacements instead. Check the individual symbol pages for the recommended replacements.

## Topics

### Deprecated constants
- [NSTIFFFileType](./nstifffiletype.md)
  Tagged Image File Format (TIFF).
- [NSBMPFileType](./nsbmpfiletype.md)
  Windows bitmap image (BMP) format.
- [NSGIFFileType](./nsgiffiletype.md)
  Graphics Image Format (GIF), originally created by CompuServe for online downloads.
- [NSJPEGFileType](./nsjpegfiletype.md)
  JPEG format.
- [NSPNGFileType](./nspngfiletype.md)
  Portable Network Graphics (PNG) format.
- [NSJPEG2000FileType](./nsjpeg2000filetype.md)
  JPEG 2000 file format.
