# NSMiterLineJoinStyle

**Framework**: AppKit  
**Kind**: var  
**Role**: Global Variable

Specifies a miter line shape of the joints between connected segments of a stroked path.

**Availability**:
- macOS 10.0+ - Deprecated in 11.0

> **Deprecated**: Use [`NSBezierPath.LineJoinStyle.miter`](./nsbezierpath/linejoinstyle-swift.enum/miter.md) instead.

## Declaration
