# init()

**Framework**: SecureElementCredential  
**Kind**: init  
**Role**: Initializer

Creates an empty credential session.

**Availability**:
- iOS 18.1+
- iPadOS 18.1+

## Declaration

```swift
init()
```

## Discussion

Don’t use this initializer to create a session. Use [`startSession()`](./startsession%28%29.md) to request and start a session.
