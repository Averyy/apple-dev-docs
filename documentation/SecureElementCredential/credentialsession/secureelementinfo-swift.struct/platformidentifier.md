# platformIdentifier

**Framework**: SecureElementCredential  
**Kind**: property

A unique identifier that describes the hardware and operating system combination of a device, along with its version information.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)

## Declaration

```swift
let platformIdentifier: String
```

#### Discussion

Use this string to verify any Secure Element OS and hardware composite certification requirements.
