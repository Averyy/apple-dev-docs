# SecurityMessage.CipherSuite.p256

**Framework**: Accessory Transport Extension  
**Kind**: case

A cipher suite that uses NIST P-256 elliptic curve cryptography.

**Availability**:
- iOS 26.5+
- iPadOS 26.5+
- Mac Catalyst 26.5+

## Declaration

```swift
case p256
```

## Mentions

- [Receiving iOS notifications on an accessory](receiving-ios-notifications-on-an-accessory.md)

#### Discussion

Use this cipher suite as a fallback for Bluetooth only. The [`AccessoryTransport.internet`](accessorytransport/internet.md) or [`AccessoryTransport.localNetwork`](accessorytransport/localnetwork.md) transport types require [`SecurityMessage.CipherSuite.xWing`](securitymessage/ciphersuite-swift.enum/xwing.md) instead.
