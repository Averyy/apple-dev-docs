# XPC_SESSION_CREATE_NONE

**Framework**: XPC  
**Kind**: case  
**Role**: Enumeration Case

Configures a new session with default settings.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS
