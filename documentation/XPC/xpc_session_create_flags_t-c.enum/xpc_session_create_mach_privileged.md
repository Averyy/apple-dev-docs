# XPC_SESSION_CREATE_MACH_PRIVILEGED

**Framework**: XPC  
**Kind**: case  
**Role**: Enumeration Case

Indicates the session is connecting to a service in the privileged Mach bootstrap.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS
