# XPC_LISTENER_CREATE_INACTIVE

**Framework**: XPC  
**Kind**: case  
**Role**: Enumeration Case

Prevents the system from automatically activating the listener after creation.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- watchOS

## Declaration

```c
XPC_LISTENER_CREATE_INACTIVE
```
