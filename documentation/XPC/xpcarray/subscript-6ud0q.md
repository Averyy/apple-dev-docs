# subscript(_:)

**Framework**: XPC  
**Kind**: subscript

Get or set a value in this array as an XPCArray.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- watchOS 27.0+ (Beta)

## Declaration

```swift
subscript(index: Int) -> XPCArray? { get set }
```

#### Return Value

A XPCArray value or `nil` if no such value was found.

## Parameters

- `index`: The index at which to get or set the XPCArray.
