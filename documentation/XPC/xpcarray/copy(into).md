# copy(into:)

**Framework**: XPC  
**Kind**: method  
**Role**: Instance Method

Copies the elements of the array to a different array.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
- tvOS 16.0+
- visionOS
- watchOS 9.0+

## Declaration

```swift
func copy(into destination: XPCArray)
```

## Parameters

- `destination`: The array to copy the elements into.
