# modelIdentifier

**Framework**: Natural Language  
**Kind**: property  
**Role**: Instance Property

A string that uniquely identifies the embedding model.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```swift
var modelIdentifier: String { get }
```

```objc
@property (copy, readonly) NSString * modelIdentifier;
```

## Discussion

Use the same model identifier that you developed and tested your app with to maintain consistent results.
