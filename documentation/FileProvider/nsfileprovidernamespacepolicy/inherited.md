# NSFileProviderNamespacePolicy.inherited

**Framework**: File Provider  
**Kind**: case

Inherit the namespace policy of the parent folder.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- visionOS 27.0+

## Declaration

```swift
case inherited
```

#### Discussion

This is the default namespace policy on every item other than the root.
