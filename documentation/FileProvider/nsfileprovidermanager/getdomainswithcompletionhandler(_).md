# getDomainsWithCompletionHandler(_:)

**Framework**: File Provider  
**Kind**: method  
**Role**: Type Method

Returns all of the File Provider extension’s domains.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- Mac Catalyst 11.0+
- macOS 11.0+
- visionOS 1.0+
