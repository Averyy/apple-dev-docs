# NSFileProviderErrorPageExpired

**Framework**: File Provider  
**Kind**: case  
**Role**: Enumeration Case

An error indicating that the page is too old, and that the system must restart the enumeration operation from the beginning.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- macOS 11.0+
- visionOS 1.0+
