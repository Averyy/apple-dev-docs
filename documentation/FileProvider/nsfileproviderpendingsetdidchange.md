# NSFileProviderPendingSetDidChange

**Framework**: File Provider  
**Kind**: var  
**Role**: Global Variable

A notification that the system posts when the set of pending items changes for your file provider extension.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- macOS 11.3+
- visionOS 1.0+
