# init()

**Framework**: File Provider  
**Kind**: init  
**Role**: Initializer

Returns a new type and creator structure with both codes set to `0`.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- macOS 12.0+
- visionOS 1.0+
