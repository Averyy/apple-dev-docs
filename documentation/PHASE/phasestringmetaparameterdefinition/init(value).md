# init(value:)

**Framework**: PHASE  
**Kind**: init  
**Role**: Initializer

Creates a specification for a textual metaparameter with the given value.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```swift
init(value: String)
```

```objc
- (instancetype) initWithValue:(NSString *) value;
```

## Parameters

- `value`: The default text for the metaparameter specification.
