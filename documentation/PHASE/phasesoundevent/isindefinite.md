# isIndefinite

**Framework**: PHASE  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the sound loops or stops on its own.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 17.0+
- visionOS 1.0+
