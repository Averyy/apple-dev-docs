# cullDistance

**Framework**: PHASE  
**Kind**: property  
**Role**: Instance Property

The distance beyond which the framework doesn’t process the sound.

**Availability**:

- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
