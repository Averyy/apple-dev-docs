# init(identifier:)

**Framework**: PHASE  
**Kind**: init  
**Role**: Initializer

Creates a random node with the name you specify.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```swift
convenience init(identifier: String)
```

```objc
- (instancetype) initWithIdentifier:(NSString *) identifier;
```

## Parameters

- `identifier`: A unique name for the node.
