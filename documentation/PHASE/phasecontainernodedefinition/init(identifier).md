# init(identifier:)

**Framework**: PHASE  
**Kind**: init  
**Role**: Initializer

Creates a container node with the given name.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```swift

```

```objc
- (instancetype) initWithIdentifier:(NSString *) identifier;
```

## Parameters

- `identifier`: A unique name for the node.
