# FxDrawingCoordinates

**Framework**: Professional Video Applications  
**Kind**: typealias  
**Role**: Type Alias

Constants used to identify coordinate spaces.

**Availability**:
- FxPlug 3.1+

## Declaration

```swift
typealias FxDrawingCoordinates = Int
```

```c
typedef NSUInteger FxDrawingCoordinates;
```

## Discussion

The `Y` coordinate component increases upwardly in all coordinate spaces.
