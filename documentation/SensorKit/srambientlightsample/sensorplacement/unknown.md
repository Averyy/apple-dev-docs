# SRAmbientLightSample.SensorPlacement.unknown

**Framework**: SensorKit  
**Kind**: case  
**Role**: Case

Indicates that the sensor can’t determine the light source’s location.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
