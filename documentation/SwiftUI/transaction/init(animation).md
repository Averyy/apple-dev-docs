# init(animation:)

**Framework**: SwiftUI  
**Kind**: init  
**Role**: Initializer

Creates a transaction and assigns its animation property.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- macOS 10.15+
- tvOS 13.0+
- visionOS 1.0+
- watchOS 6.0+

## Declaration

```swift
init(animation: Animation?)
```

## Parameters

- `animation`: The animation to perform when the current state changes.
