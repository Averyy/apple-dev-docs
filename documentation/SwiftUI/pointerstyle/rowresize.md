# rowResize

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

The pointer style for resizing a row, or horizontal division, in either direction.

**Availability**:
- macOS 15.0+

## Declaration

```swift
static let rowResize: PointerStyle
```

## Discussion

The following image shows the row resize pointer:

![A horizontal bar with arrows pointing up and](https://developer.apple.com/tutorials/images/com.apple.SwiftUI/PointerStyle-rowResize@2x.png)

You may apply this pointer style to a single view or a view hierarchy using the [`pointerStyle(_:)`](../view/pointerstyle%28_%29.md) modifier.
