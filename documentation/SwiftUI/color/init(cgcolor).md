# init(cgColor:)

**Framework**: SwiftUI  
**Kind**: init  
**Role**: Initializer

Creates a color from a Core Graphics color.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
init(cgColor: CGColor)
```

## Parameters

- `cgColor`: A [`CGColor`](../../CoreGraphics/cgcolor.md) instance from which to create a color.
