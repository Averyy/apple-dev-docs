# baseline

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Instance Property

The distance from the top of the image to its baseline.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
let baseline: CGFloat
```

## Discussion

If the image has no baseline, this value is equivalent to the image’s height.
