# disablesGroup

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

An option that causes the filter to composite the object and its shadow separately in the current layer.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
static var disablesGroup: GraphicsContext.ShadowOptions { get }
```
