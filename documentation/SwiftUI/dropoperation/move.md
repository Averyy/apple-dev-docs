# DropOperation.move

**Framework**: SwiftUI  
**Kind**: case  
**Role**: Case

Move the data represented by the drag items instead of copying it.

**Availability**:
- iOS 13.4+
- iPadOS 13.4+
- Mac Catalyst 13.4+
- macOS 10.15+
- visionOS 1.0+
