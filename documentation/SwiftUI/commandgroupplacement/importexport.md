# importExport

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

Placement for commands that relate to importing and exporting data using formats that the app doesn’t natively support.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- visionOS 1.0+

## Declaration

```swift
static let importExport: CommandGroupPlacement
```

#### Discussion

Empty by default in macOS.
