# Text.TruncationMode.tail

**Framework**: SwiftUI  
**Kind**: case  
**Role**: Case

Truncate at the end of the line.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- macOS 10.15+
- tvOS 13.0+
- visionOS 1.0+
- watchOS 6.0+

## Declaration

```swift
case tail
```

#### Discussion

Use this kind of truncation to omit characters from the end of the string. For example, you could truncate the English alphabet as “abcd…”.
