# Text.Case

**Framework**: SwiftUI  
**Kind**: enum  
**Role**: Enumeration

A scheme for transforming the capitalization of characters within text.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 7.0+
