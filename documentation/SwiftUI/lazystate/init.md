# init()

**Framework**: SwiftUI  
**Kind**: init

Creates a state property without an initial value.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```swift
init()
```

#### Discussion

This initializer behaves like the `init(wrappedValue:)` initializer with an input of `nil`. See that initializer for more information.
