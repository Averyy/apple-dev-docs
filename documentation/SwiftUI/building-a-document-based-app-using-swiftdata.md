# Building a document-based app using SwiftData

**Framework**: SwiftUI  
**Role**: Sample Code  
**Download**: [BuildingADocumentBasedAppUsingSwiftData.zip](https://docs-assets.developer.apple.com/published/a378001f6c52/BuildingADocumentBasedAppUsingSwiftData.zip)

Code along with the WWDC presenter to transform an app with SwiftData.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- Xcode 15.0+

#### Overview

Learn how to use [`@Query`](../SwiftData/query.md), [`@Bindable`](./bindable.md), [`.modelContainer`](./view/modelcontainer%28_%29.md), the [`.modelContext`](./environmentvalues/modelcontext.md) environment variable, and [`DocumentGroup`](./documentgroup.md) to integrate with the [`SwiftData`](../SwiftData/SwiftData.md) framework.

> **Note**: This sample code project is associated with WWDC23 session 10154: [Build an app with SwiftData](https://developer.apple.com/wwdc23/10154/).
