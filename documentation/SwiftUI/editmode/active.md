# EditMode.active

**Framework**: SwiftUI  
**Kind**: case  
**Role**: Case

The user can edit the view content.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- tvOS 13.0+
- visionOS 1.0+

## Declaration

```swift
case active
```

#### Discussion

The [`isEditing`](./isediting.md) property is `true` in this state.
