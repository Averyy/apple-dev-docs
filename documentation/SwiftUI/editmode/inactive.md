# EditMode.inactive

**Framework**: SwiftUI  
**Kind**: case  
**Role**: Case

The user can’t edit the view content.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- tvOS 13.0+
- visionOS 1.0+

## Declaration

```swift
case inactive
```

## Discussion

The [`isEditing`](./isediting.md) property is `false` in this state.

## See Also

### Getting edit modes
- [EditMode.active](./active.md)
  The user can edit the view content.
- [EditMode.transient](./transient.md)
