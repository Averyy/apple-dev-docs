# resetSectionOrder(for:)

**Framework**: SwiftUI  
**Kind**: method  
**Role**: Instance Method

Resets ordering back to the default for the section with `sectionID`, preserving any customized tab visibilities.

**Availability**:
- iOS 18.0+ - Deprecated in 27.2
- iPadOS 18.0+ - Deprecated in 27.2
- Mac Catalyst 18.0+ - Deprecated in 27.2
- macOS 15.0+ - Deprecated in 27.2
- visionOS 2.0+ - Deprecated in 27.2

> **Deprecated**: Use the `section` subscript and call `resetTabOrder` instead.

## Declaration

```swift
mutating func resetSectionOrder(for sectionID: String)
```
