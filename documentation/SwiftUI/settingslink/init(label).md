# init(label:)

**Framework**: SwiftUI  
**Kind**: init  
**Role**: Initializer

Creates a settings link with a custom label.

**Availability**:
- macOS 14.0+

## Declaration

```swift
nonisolated
init(@ContentBuilder label: () -> Label)
```

## Parameters

- `label`: A view to use as the label for this settings link.
