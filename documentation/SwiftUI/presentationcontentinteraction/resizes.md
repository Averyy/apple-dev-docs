# resizes

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

A behavior that prioritizes resizing a presentation when swiping, rather than scrolling the content of the presentation.

**Availability**:
- iOS 16.4+
- iPadOS 16.4+
- Mac Catalyst 16.4+
- macOS 13.3+
- tvOS 16.4+
- visionOS 1.0+
- watchOS 9.4+

## Declaration
