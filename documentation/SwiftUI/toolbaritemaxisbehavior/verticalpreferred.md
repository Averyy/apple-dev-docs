# verticalPreferred

**Framework**: SwiftUI  
**Kind**: property

The item supports both horizontal and vertical bars, and prefers a vertical placement when both horizontal and vertical bars are present.

**Availability**:
- iOS 27.1+ (Beta)
- iPadOS 27.1+ (Beta)

## Declaration

```swift
static let verticalPreferred: ToolbarItemAxisBehavior
```
