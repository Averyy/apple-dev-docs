# horizontalOnly

**Framework**: SwiftUI  
**Kind**: property

The item only supports horizontal bars. If an item only supports horizontal bars and no horizontal bars are present, the item is not shown.

**Availability**:
- iOS 27.1+ (Beta)
- iPadOS 27.1+ (Beta)

## Declaration

```swift
static let horizontalOnly: ToolbarItemAxisBehavior
```
