# indigo

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

A context-dependent indigo color suitable for use in UI elements.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
@export(implementation)
static var indigo: Color { get }
```

Available when `Self` is `Color`.
