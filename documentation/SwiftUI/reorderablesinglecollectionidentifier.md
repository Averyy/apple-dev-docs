# ReorderableSingleCollectionIdentifier

**Framework**: SwiftUI  
**Kind**: struct

An opaque, empty type used to identify reorderable containers and modifiers with only a single collection.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
