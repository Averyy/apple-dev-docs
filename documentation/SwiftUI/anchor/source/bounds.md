# bounds

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

An anchor source rect defined as the entire bounding rect of the current view.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- macOS 10.15+
- tvOS 13.0+
- visionOS 1.0+
- watchOS 6.0+

## Declaration

```swift
static var bounds: Anchor<CGRect>.Source { get }
```

Available when `Value` is `CGRect`.
