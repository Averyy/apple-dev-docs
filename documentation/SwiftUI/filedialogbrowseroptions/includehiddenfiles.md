# includeHiddenFiles

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

Displays the files that are hidden by default.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- visionOS 1.0+

## Declaration

```swift
static let includeHiddenFiles: FileDialogBrowserOptions
```
