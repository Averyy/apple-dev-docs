# interaction

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

The kind for hit-testing and accessibility.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
static let interaction: ContentShapeKinds
```

#### Discussion

Setting a content shape with this kind causes the view to hit-test using the specified shape.
