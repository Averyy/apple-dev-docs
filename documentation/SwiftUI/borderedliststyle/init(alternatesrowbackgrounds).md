# init(alternatesRowBackgrounds:)

**Framework**: SwiftUI  
**Kind**: init  
**Role**: Initializer

Creates a bordered list style with optional alternating row backgrounds.

**Availability**:
- macOS 12.0+ - Deprecated in 27.2

> **Deprecated**: Use the [`bordered`](../liststyle/bordered.md) style and add the [`alternatingRowBackgrounds(_:)`](../view/alternatingrowbackgrounds%28_%29.md) view modifier instead.

## Declaration

```swift
init(alternatesRowBackgrounds: Bool)
```
