# division

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

A region that splits your view into separate parts.

**Availability**:
- iOS 27.1+
- iPadOS 27.1+
- Mac Catalyst 27.1+
- macOS 27.1+
- tvOS 27.1+
- visionOS 27.1+
- watchOS 27.1+

## Declaration

```swift
static var division: ReservedRegion.Kind { get }
```

#### Discussion

A division region is an area, such as the fold of iPhone Duo, that splits your view. Place your content on both sides of the region instead of across it.
