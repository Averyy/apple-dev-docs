# margins

**Framework**: SwiftUI  
**Kind**: property

The extra space around the reserved area that keeps interactive content clear of it.

**Availability**:
- iOS 27.1+
- iPadOS 27.1+
- Mac Catalyst 27.1+
- macOS 27.1+
- tvOS 27.1+
- visionOS 27.1+
- watchOS 27.1+
