# axes(_:)

**Framework**: SwiftUI  
**Kind**: method  
**Role**: Instance Method

Creates a split arrangement that lays out its views along the axes you provide.

**Availability**:
- iOS 27.1+
- iPadOS 27.1+
- Mac Catalyst 27.1+
- macOS 27.1+
- tvOS 27.1+
- visionOS 27.1+
- watchOS 27.1+

## Declaration

```swift
nonisolated
func axes(_ axes: Axis.Set) -> SplitArrangementViewStyle
```

## Discussion

For axes that you don’t include, the arrangement only displays the primary view.
