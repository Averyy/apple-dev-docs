# empty

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

An effect that applies no changes when hovered.

**Availability**:
- visionOS 2.0+

## Declaration

```swift
static var empty: EmptyHoverEffect { get }
```

Available when `Self` is `EmptyHoverEffect`.
