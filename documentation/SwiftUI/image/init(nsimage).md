# init(nsImage:)

**Framework**: SwiftUI  
**Kind**: init  
**Role**: Initializer

Creates a SwiftUI image from an AppKit image instance.

**Availability**:
- macOS 10.15+

## Declaration

```swift
nonisolated
init(nsImage: NSImage)
```

## Parameters

- `nsImage`: The AppKit image to wrap with a SwiftUI [`Image`](../image.md). instance.
