# Image.Interpolation.none

**Framework**: SwiftUI  
**Kind**: case  
**Role**: Case

A value that indicates SwiftUI doesn’t interpolate image data.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- macOS 10.15+
- tvOS 13.0+
- visionOS 1.0+
- watchOS 6.0+
