# Image.Interpolation.low

**Framework**: SwiftUI  
**Kind**: case  
**Role**: Case

A value that indicates a low level of interpolation quality, which may speed up image rendering.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.0+
- macOS 10.15+
- tvOS 13.0+
- visionOS 1.0+
- watchOS 6.0+

