# photosPickerAutomaticDismissDisabled(_:)

**Framework**: SwiftUI  
**Kind**: method  
**Role**: Instance Method

Conditionally prevents automatic dismissal of the Photos picker.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- macOS 27.3+ (Beta)
- visionOS 27.3+ (Beta)

## Declaration

```swift
nonisolated
func photosPickerAutomaticDismissDisabled(_ isDisabled: Bool = true) -> some View
```

## Return Value

A Photos picker with automatic dismissal configured.

## Parameters

- `isDisabled`: Boolean value to determine whether to prevent automatic dismissal or not.
