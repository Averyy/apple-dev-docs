# padding3D(_:)

**Framework**: SwiftUI  
**Kind**: method  
**Role**: Instance Method

Pads this view along all edge insets by the amount you specify.

**Availability**:
- visionOS 1.0+

## Declaration

```swift
@export(implementation)
nonisolated func padding3D(_ length: CGFloat) -> some View
```

**Other overloads**:

## Return Value

## Parameters
