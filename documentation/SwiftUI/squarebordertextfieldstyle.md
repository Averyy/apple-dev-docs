# SquareBorderTextFieldStyle

**Framework**: SwiftUI  
**Kind**: struct  
**Role**: Structure

A text field style with a system-defined square border.

**Availability**:
- macOS 10.15+ - Deprecated in 27.2

> **Deprecated**: Use BorderedTextField instead. As of macOS 26, text fields no longer have a rectangular border.

## Declaration

```swift
struct SquareBorderTextFieldStyle
```

#### Overview

You can also use [`squareBorder`](./textfieldstyle/squareborder.md) to construct this style.
