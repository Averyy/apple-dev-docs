# circularEaseIn

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

A curve that starts out slowly, then speeds up as it finishes.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 10.0+

## Declaration

```swift
static let circularEaseIn: UnitCurve
```

#### Discussion

The shape of the curve is equal to the fourth (bottom right) quadrant of a unit circle.
