# init()

**Framework**: SwiftUI  
**Kind**: init  
**Role**: Initializer

Creates a new accessibility focus state for a Boolean value.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- macOS 12.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
init() where Value == Bool
```

**Other overloads**:

```swift
init<T>() where Value == T?, T : Hashable
```
