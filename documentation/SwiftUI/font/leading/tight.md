# Font.Leading.tight

**Framework**: SwiftUI  
**Kind**: case  
**Role**: Case

Reduced line spacing.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 7.0+

## Declaration

```swift
case tight
```

#### Discussion

This value typically reduces line spacing by 1 point for watchOS and 2 points on other platforms.
