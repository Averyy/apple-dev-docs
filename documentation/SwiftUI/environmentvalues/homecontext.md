# homeContext

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Instance Property

The context that the Home app provides to your extension’s views.

**Availability**:
- iOS 27.2+
- iPadOS 27.2+

## Declaration

```swift
var homeContext: HomeContext? { get set }
```

## Discussion

This value is `nil` outside your extension’s content.
