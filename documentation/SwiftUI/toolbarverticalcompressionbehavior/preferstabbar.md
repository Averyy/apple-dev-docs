# prefersTabBar

**Framework**: SwiftUI  
**Kind**: property

A compression behavior that prefers keeping the tab bar visible.

**Availability**:
- iOS 27.1+ (Beta)
- iPadOS 27.1+ (Beta)

## Declaration

```swift
static let prefersTabBar: ToolbarVerticalCompressionBehavior
```

#### Discussion

Toolbar items will compress before tab bar items when space is constrained.
