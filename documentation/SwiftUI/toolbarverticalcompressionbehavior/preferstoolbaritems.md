# prefersToolbarItems

**Framework**: SwiftUI  
**Kind**: property

A compression behavior that prefers keeping toolbar items visible.

**Availability**:
- iOS 27.1+ (Beta)
- iPadOS 27.1+ (Beta)

## Declaration

```swift
static let prefersToolbarItems: ToolbarVerticalCompressionBehavior
```

#### Discussion

The tab bar will compress before toolbar items when space is constrained.
