# linear

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

A progress view that visually indicates its progress using a horizontal bar.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 7.0+

## Declaration

```swift
@export(implementation)
nonisolated static var linear: LinearProgressViewStyle { get }
```

Available when `Self` is `LinearProgressViewStyle`.
