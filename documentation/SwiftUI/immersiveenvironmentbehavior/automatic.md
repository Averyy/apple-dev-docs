# automatic

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

A behavior that matches the system default behavior.

**Availability**:
- visionOS 26.0+

## Declaration

```swift
static var automatic: ImmersiveEnvironmentBehavior { get }
```

## Discussion

Use this value with the [`immersiveEnvironmentBehavior(_:)`](../scene/immersiveenvironmentbehavior%28_%29.md) scene modifier to define that the system follows a default behavior regarding the system’s immersive environment when your app opens a scene.
