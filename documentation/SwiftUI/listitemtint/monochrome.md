# monochrome

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

A standard grayscale tint effect.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS 1.0+
- watchOS 7.0+

## Declaration

```swift
static let monochrome: ListItemTint
```

#### Discussion

The system doesn’t override monochrome tints.
