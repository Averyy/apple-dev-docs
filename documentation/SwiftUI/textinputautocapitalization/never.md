# never

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

Defines an autocapitalizing behavior that will not capitalize anything.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- tvOS 15.0+
- visionOS 1.0+
- watchOS 8.0+

## Declaration

```swift
static var never: TextInputAutocapitalization { get }
```
