# standardBounds

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

The hosting view creates constraints for its minimum, ideal, and maximum sizes.

**Availability**:
- macOS 13.0+

## Declaration

```swift
static let standardBounds: NSHostingSizingOptions
```
