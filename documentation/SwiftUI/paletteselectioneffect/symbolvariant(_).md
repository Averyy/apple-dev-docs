# symbolVariant(_:)

**Framework**: SwiftUI  
**Kind**: method  
**Role**: Type Method

Applies the specified symbol variant when selected.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
- visionOS 1.0+

## Declaration

```swift
static func symbolVariant(_ variant: SymbolVariants) -> PaletteSelectionEffect
```

#### Discussion

> **Note**: This effect only applies to SF Symbols.
