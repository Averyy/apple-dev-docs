# CircularGaugeStyle

**Framework**: SwiftUI  
**Kind**: struct  
**Role**: Structure

A gauge style that displays an open ring with a marker that appears at a point along the ring to indicate the gauge’s current value.

**Availability**:
- watchOS 7.0+

## Declaration

```swift
nonisolated
struct CircularGaugeStyle
```
