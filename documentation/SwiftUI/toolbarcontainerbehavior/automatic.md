# automatic

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

The system decides whether this container renders the toolbar, or whether its toolbar content integrates into a parent container’s bar.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- macOS 27.3+ (Beta)
- tvOS 27.3+ (Beta)
- visionOS 27.3+ (Beta)
- watchOS 27.3+ (Beta)

## Declaration

```swift
static let automatic: ToolbarContainerBehavior
```

## Discussion

By default, the system allows integration in contexts where it is supported.
