# form

**Framework**: SwiftUI  
**Kind**: property  
**Role**: Type Property

The size is appropriate for forms and slightly less wide than`.page`

**Availability**:

- iPadOS 18.0+
- Mac Catalyst 18.0+
- macOS 15.0+
- tvOS 18.0+
- visionOS 2.0+
- watchOS 11.0+
