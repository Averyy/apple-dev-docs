# automatic

**Framework**: SwiftUI  
**Kind**: property

The system determines the restoration behavior.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+
- tvOS 27.0+
- visionOS 27.0+
- watchOS 27.0+

## Declaration

```swift
static let automatic: ToolbarMinimizationRestoration
```

#### Discussion

By default, the toolbar restores when the user reverses scroll direction.
