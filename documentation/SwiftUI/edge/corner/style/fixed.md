# fixed(_:)

**Framework**: SwiftUI  
**Kind**: method

A rounded corner style where the corner’s radius is the value you provide.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- tvOS 26.0+
- visionOS 26.0+
- watchOS 26.0+

## Declaration

```swift
static func fixed(_ radius: CGFloat) -> Edge.Corner.Style
```

#### Discussion

Provide a value of zero for a square corner.
