# ZeroOrMore

**Framework**: RegexBuilder  
**Kind**: struct  
**Role**: Structure

A regex component that matches zero or more occurrences of its underlying component.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
- tvOS 16.0+
- visionOS
- watchOS 9.0+
