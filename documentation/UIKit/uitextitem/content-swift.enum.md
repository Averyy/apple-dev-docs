# UITextItem.Content

**Framework**: UIKit  
**Kind**: enum  
**Role**: Enumeration

Constants that describe and capture the type of content a text item represents along with a specific related value.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- visionOS

## Declaration
