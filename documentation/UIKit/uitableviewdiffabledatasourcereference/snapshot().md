# snapshot()

**Framework**: UIKit  
**Kind**: method  
**Role**: Instance Method

Returns a representation of the current state of the data in the table view.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 13.0+
- visionOS 1.0+
