# UIArrangement

**Framework**: UIKit  
**Kind**: class  
**Role**: Class

A type that describes how an arrangement view controller lays out its view controllers.

**Availability**:
- iOS 27.1+
- iPadOS 27.1+
- Mac Catalyst 27.1+
- tvOS 27.1+
- visionOS 27.1+
