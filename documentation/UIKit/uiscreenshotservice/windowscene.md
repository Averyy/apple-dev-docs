# windowScene

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The window scene that contains the windows to capture in your PDF data.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 13.0+

## Declaration

```swift
weak var windowScene: UIWindowScene? { get }
```

```objc
@property (nonatomic, weak, readonly, nullable) UIWindowScene * windowScene;
```

#### Discussion

Use this property to access the window scene containing the relevant content.
