# isAbsoluteOffset

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the anchor’s offset is expressed as an absolute value.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 13.0+
- visionOS 1.0+

## Declaration

```swift
var isAbsoluteOffset: Bool { get }
```

```objc
@property (nonatomic, readonly) BOOL isAbsoluteOffset;
```
