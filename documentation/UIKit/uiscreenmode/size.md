# size

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The screen size, measured in pixels.

**Availability**:
- iOS 3.2+
- iPadOS 3.2+
- Mac Catalyst 13.1+
- tvOS

## Declaration

```swift
var size: CGSize { get }
```

```objc
@property (nonatomic, readonly) CGSize size;
```

## Discussion

The value in this property represents the size of the underlying display buffer.
