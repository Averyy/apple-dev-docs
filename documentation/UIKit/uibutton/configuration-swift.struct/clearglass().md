# clearGlass()

**Framework**: UIKit  
**Kind**: method  
**Role**: Type Method

Creates a configuration for a button that has a clear Liquid Glass style.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- tvOS 26.0+

## Declaration

```swift
static func clearGlass() -> UIButton.Configuration
```

#### Discussion

In tvOS, this button style applies a Liquid Glass effect regardless of whether the button has focus.
