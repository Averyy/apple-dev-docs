# currentTitleShadowColor

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+
