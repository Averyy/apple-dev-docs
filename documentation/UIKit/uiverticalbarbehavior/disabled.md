# UIVerticalBarBehavior.disabled

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

The vertical bar is disabled.

**Availability**:
- iOS 27.1+
- iPadOS 27.1+
- Mac Catalyst 27.1+
- tvOS 27.1+
- visionOS 27.1+

## Declaration

```swift
case disabled
```

```c
UIVerticalBarBehaviorDisabled
```

## Discussion

Bar content falls back to the standard horizontal top and bottom bars, and the vertical status bar reverts to the horizontal axis.
