# UICellConfigurationState.DropState.notTargeted

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

A drag session is active and can perform a drop in the cell’s container, but the cell itself isn’t the drop target.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
- visionOS
