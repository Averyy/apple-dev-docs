# landscapePhone

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

Specifies metrics for landscape orientation using the phone idiom.

**Availability**:
- iOS 5.0+ - Deprecated in 8.0 (renamed: UIBarMetrics.compact)
- iPadOS 5.0+ - Deprecated in 8.0 (renamed: UIBarMetrics.compact)
- Mac Catalyst 13.1+ - Deprecated in 13.1 (renamed: UIBarMetrics.compact)
- tvOS

> **Deprecated**: Use [`UIBarMetrics.compact`](./compact.md) instead.
