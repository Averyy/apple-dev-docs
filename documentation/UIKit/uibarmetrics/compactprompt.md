# UIBarMetrics.compactPrompt

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

Specifies metrics for bars with the prompt property when using the phone idiom, such as [`UINavigationBar`](../uinavigationbar.md) and [`UISearchBar`](../uisearchbar.md).
