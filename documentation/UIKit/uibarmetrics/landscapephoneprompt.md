# landscapePhonePrompt

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

Specifies metrics for landscape orientation using the phone idiom for bars with the prompt property, such as [`UINavigationBar`](../uinavigationbar.md) and [`UISearchBar`](../uisearchbar.md).

**Availability**:
- iOS 7.0+ - Deprecated in 8.0 (renamed: UIBarMetrics.compactPrompt)
- iPadOS 7.0+ - Deprecated in 8.0 (renamed: UIBarMetrics.compactPrompt)
- Mac Catalyst 13.1+ - Deprecated in 13.1 (renamed: UIBarMetrics.compactPrompt)
- tvOS

> **Deprecated**: Use [`UIBarMetrics.compactPrompt`](./compactprompt.md) instead.
