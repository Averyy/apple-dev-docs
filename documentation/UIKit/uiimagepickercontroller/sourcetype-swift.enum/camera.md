# UIImagePickerController.SourceType.camera

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

Specifies the device’s built-in camera as the source for the image picker controller.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst

## Declaration

```swift
case camera
```

```c
UIImagePickerControllerSourceTypeCamera
```

## Discussion

Indicate the specific camera you want (front or rear, as available) by using the [`cameraDevice`](../cameradevice-swift.property.md) property.
