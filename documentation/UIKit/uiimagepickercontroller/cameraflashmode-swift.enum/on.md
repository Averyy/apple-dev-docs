# UIImagePickerController.CameraFlashMode.on

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

Specifies that flash illumination is always on, no matter what the ambient light conditions are.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst

## Declaration

```swift
case on
```

```c
UIImagePickerControllerCameraFlashModeOn
```
