# UIImagePickerController.CameraFlashMode.off

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

Specifies that flash illumination is always off, no matter what the ambient light conditions are.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst

## Declaration

```swift
case off
```

```c
UIImagePickerControllerCameraFlashModeOff
```
