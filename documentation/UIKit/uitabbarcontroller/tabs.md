# tabs

**Framework**: UIKit  
**Kind**: property

An array of tabs that the tab bar displays.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- tvOS 18.0+
- visionOS 2.0+

```swift
var tabs: [UITab] { get set }
```
