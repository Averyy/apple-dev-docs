# preferredLayout

**Framework**: UIKit  
**Kind**: property

The preferred layout for how the sidebar lays out with the tab bar controller’s content. Default is `.automatic`

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- visionOS 2.0+

## Declaration

```swift
var preferredLayout: UITabBarController.Sidebar.Layout { get set }
```
