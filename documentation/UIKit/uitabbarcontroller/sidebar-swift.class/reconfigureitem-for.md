# reconfigureItem(for:)

**Framework**: UIKit  
**Kind**: method

Requests the sidebar reconfigure the item representing the specified tab. This method has no effect if the `tab` is not currently displayed in the sidebar.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- visionOS 2.0+

## Declaration

```swift
func reconfigureItem(for tab: UITab)
```
