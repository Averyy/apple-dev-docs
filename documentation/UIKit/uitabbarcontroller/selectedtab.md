# selectedTab

**Framework**: UIKit  
**Kind**: property

The currently selected tab, which can be a root tab or any of their descendants.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- tvOS 18.0+
- visionOS 2.0+

## Declaration

```swift
var selectedTab: UITab? { get set }
```

#### Discussion

The default value for this property is `nil`.
