# setTabBarHidden(_:animated:)

**Framework**: UIKit  
**Kind**: method

Changes the active tab bar’s visibility with an option to animate the change.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- tvOS 18.0+
- visionOS 2.0+
