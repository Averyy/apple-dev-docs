# UIBarStyle

**Framework**: UIKit  
**Kind**: enum  
**Role**: Enumeration

Defines the stylistic appearance of different types of views.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- visionOS

## Declaration

