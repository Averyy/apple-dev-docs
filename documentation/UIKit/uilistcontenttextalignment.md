# UIListContentTextAlignment

**Framework**: UIKit  
**Kind**: enum  
**Role**: Enumeration

Constants that specify the visual alignment of the text.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
- visionOS 1.0+

## Declaration

```c
enum UIListContentTextAlignment : NSInteger;
```

## Topics

### Text alignment
- [UIListContentTextAlignmentCenter](./uilistcontenttextalignment/uilistcontenttextalignmentcenter.md)
  The text has centered alignment.
- [UIListContentTextAlignmentJustified](./uilistcontenttextalignment/uilistcontenttextalignmentjustified.md)
  The text has justified alignment.
- [UIListContentTextAlignmentNatural](./uilistcontenttextalignment/uilistcontenttextalignmentnatural.md)
  The text uses the default alignment that the system associates with the current localization of the app.
