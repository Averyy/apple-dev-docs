# shape

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The shape to use for the hover effect.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic, strong, nullable) UIShape * shape;
```

## Discussion

If the value of this property is `nil`, the system chooses a default shape based on the view.
