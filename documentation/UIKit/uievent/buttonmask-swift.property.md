# buttonMask

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A bit mask that represents which input-device buttons are pressed for the current event.

**Availability**:
- iOS 13.4+
- iPadOS 13.4+
- Mac Catalyst 13.4+
- visionOS 1.0+
