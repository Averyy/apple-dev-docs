# alert

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS

## Declaration

```swift
static let alert: UIWindow.Level
```


## Discussion
