# statusBar

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

The level for a status window.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- visionOS

## Declaration

```swift
static let statusBar: UIWindow.Level
```

```c
extern const UIWindowLevel UIWindowLevelStatusBar;
```

#### Discussion

Windows at this level appear on top of your app’s main window, but below alerts.
