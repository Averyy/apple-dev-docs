# UIPointerLiftEffect

**Framework**: UIKit  
**Kind**: class  
**Role**: Class

An effect where the pointer slides under the given view and disappears as the view scales up and gains a shadow.

**Availability**:
- iOS 13.4+
- iPadOS 13.4+
- Mac Catalyst 13.4+
- visionOS 1.0+

## Declaration

```objc
@interface UIPointerLiftEffect : UIPointerEffect
```
