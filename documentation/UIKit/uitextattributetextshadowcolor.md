# UITextAttributeTextShadowColor

**Framework**: UIKit  
**Kind**: var  
**Role**: Global Variable

The key to the text shadow color in a text attributes dictionary.

**Availability**:
- iOS 5.0+ - Deprecated in 7.0
- iPadOS 5.0+ - Deprecated in 7.0
- Mac Catalyst 13.1+ - Deprecated in 13.1

> **Deprecated**: Instead, use [`NSShadowAttributeName`](./nsshadowattributename.md) with an [`NSShadow`](./nsshadow.md) object as the value.

## Declaration

```c
extern NSString * const UITextAttributeTextShadowColor;
```

#### Discussion

The corresponding value is an instance of [`UIColor`](./uicolor.md).
