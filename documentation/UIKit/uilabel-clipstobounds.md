# clipsToBounds

**Framework**: UIKit  
**Role**: Article

A Boolean value that determines whether subviews are confined to the bounds of the view.

## Overview

`UILabel` inherits this property from the `UIView` parent class. This class changes the default value of this property to [`true`](../Swift/true.md).
