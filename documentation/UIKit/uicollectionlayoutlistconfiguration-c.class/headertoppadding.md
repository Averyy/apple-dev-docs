# headerTopPadding

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The amount of padding above each section header.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- tvOS 15.0+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic) CGFloat headerTopPadding;
```

#### Discussion

The default value is [`UICollectionViewLayoutAutomaticDimension`](../uicollectionviewlayoutautomaticdimension.md).
