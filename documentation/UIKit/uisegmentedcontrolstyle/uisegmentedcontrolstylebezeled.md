# UISegmentedControlStyleBezeled

**Framework**: UIKit  
**Kind**: case  
**Role**: Enumeration Case

The large bezeled style for segmented controls.

**Availability**:
- iOS 2.0+ - Deprecated in 7.0
- iPadOS 2.0+ - Deprecated in 7.0
- Mac Catalyst 13.1+ - Deprecated in 13.1

> **Deprecated**: This control style is deprecated and shouldn’t be used.

## Declaration

```c
UISegmentedControlStyleBezeled
```

#### Discussion

Segmented controls in this style can have a tint color (see `tintColor`).
