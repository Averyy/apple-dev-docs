# effect

**Framework**: UIKit  
**Kind**: method  
**Role**: Type Method

Provides a convenience initializer to create a system-default hover effect that automatically selects the appropriate effect based on the view to which it applies.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- visionOS 1.0+
