# primaryLanguage

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The primary language, if any, of the input mode.

**Availability**:
- iOS 4.2+
- iPadOS 4.2+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+

## Declaration

```swift
var primaryLanguage: String? { get }
```

```objc
@property (nonatomic, strong, readonly, nullable) NSString * primaryLanguage;
```

## Discussion

The value of this property is a BCP 47 language code such as “es”, “en-US”, or “fr-CA”.
