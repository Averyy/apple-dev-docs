# capsuleConfigurationWithMaximumRadius:

**Framework**: UIKit  
**Kind**: method  
**Role**: Type Method

A configuration that rounds the corners into a capsule shape, scaling with the view’s size and clamped to the `maximumRadius`.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- tvOS 26.0+
- visionOS 26.0+
