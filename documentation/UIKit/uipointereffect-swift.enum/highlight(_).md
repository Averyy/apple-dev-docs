# UIPointerEffect.highlight(_:)

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

An effect where the pointer slides under the given view and morphs into the view’s shape.

**Availability**:
- iOS 13.4+
- iPadOS 13.4+
- Mac Catalyst 13.4+
- visionOS
