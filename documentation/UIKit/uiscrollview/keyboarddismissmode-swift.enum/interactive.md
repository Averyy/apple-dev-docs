# UIScrollView.KeyboardDismissMode.interactive

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

A mode in which the keyboard follows the dragging touch offscreen, and can be pulled upward again to cancel the dismiss.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- tvOS
