# UIScrollView.KeyboardDismissMode.interactiveWithAccessory

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

A mode in which the keyboard and accessory view both follow the dragging touch offscreen, and can be pulled upward again to cancel the dismiss.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- tvOS
