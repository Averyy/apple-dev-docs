# font

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

Any font that may be associated with the change. For example, this property will be available in case of font typography settings change or new font selection.

**Availability**:

- iPadOS 18.0+
- visionOS 26.0+
