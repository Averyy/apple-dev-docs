# numberValue

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

Any number value that may be associated with the change. For example, if case of font point size change, this property will reflect new point size.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- visionOS 26.0+

## Declaration

```objc
@property (nonatomic, copy, readonly, nullable) NSNumber * numberValue;
```
