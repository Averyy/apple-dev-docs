# isScrollEnabled

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that determines whether the view content can scroll.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```swift
var isScrollEnabled: Bool { get set }
```

```objc
@property (nonatomic, getter=isScrollEnabled) BOOL scrollEnabled;
```

#### Discussion

The default is `NO`.
