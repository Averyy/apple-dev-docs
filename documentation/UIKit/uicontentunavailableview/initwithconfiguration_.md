# initWithConfiguration:

**Framework**: UIKit  
**Kind**: method  
**Role**: Instance Method

Creates a new content-unavailable view with the specified configuration.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```objc
- (instancetype) initWithConfiguration:(UIContentUnavailableConfiguration *) configuration;
```

## Parameters

- `configuration`: The configuration describing the view’s appearance and behavior.
