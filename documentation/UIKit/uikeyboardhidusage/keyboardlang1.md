# UIKeyboardHIDUsage.keyboardLANG1

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

The raw usage code 144 (decimal)/90 (hexadecimal).

**Availability**:
- iOS 13.4+
- iPadOS 13.4+
- Mac Catalyst 13.4+
- tvOS 13.4+
- visionOS 1.0+

## Declaration

```swift
case keyboardLANG1
```

```c
UIKeyboardHIDUsageKeyboardLANG1
```

## Discussion

On Japanese language keyboards from Apple, the [`UIKeyboardHIDUsage.keyboardLANG1`](./keyboardlang1.md) key is the Kana switch (かな) key. On Korean language keyboards, it’s the Hangul/English toggle key.
