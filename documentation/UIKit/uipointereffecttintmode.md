# UIPointerEffectTintMode

**Framework**: UIKit  
**Kind**: enum  
**Role**: Enumeration

An effect that defines how to apply a tint to a view during a pointer interaction.

**Availability**:
- iOS 13.4+
- iPadOS 13.4+
- Mac Catalyst 13.4+
- visionOS 1.0+

## Declaration

```c
enum UIPointerEffectTintMode : NSInteger;
```
