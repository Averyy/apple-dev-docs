# init(coder:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a view controller with data in an unarchiver.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+
