# font

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The font to use for the badge. A `nil` value will be treated as an indication to use the system default.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+

## Declaration

```objc
@property (nonatomic, strong, nullable) UIFont * font;
```
