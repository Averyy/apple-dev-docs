# foregroundColor

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The badge’s foreground color. A `nil` value will be treated as an indication to use the system default.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+

## Declaration

@property (nonatomic, strong, nullable) UIColor * foregroundColor;
