# init(frame:zIndex:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a custom item with the specified frame and vertical stacking order in relation to other items in the group.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 13.0+
- visionOS 1.0+

## Declaration

