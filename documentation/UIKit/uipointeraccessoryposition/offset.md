# offset

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The offset of the accessory from the primary pointer.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS

## Declaration

```c
CGFloat offset;
```

## Discussion

This property only supports positive values.
