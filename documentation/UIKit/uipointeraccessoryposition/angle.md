# angle

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The angle of the accessory’s position, measured in radians clockwise from the top of the primary pointer.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS

CGFloat angle;
