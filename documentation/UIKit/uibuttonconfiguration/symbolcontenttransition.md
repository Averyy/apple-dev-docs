# symbolContentTransition

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The symbol content transition to use when transitioning across symbol images. Defaults to `nil`, meaning no symbol content transition should occur.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- tvOS 26.0+
- visionOS 26.0+

## Declaration

```objc
@property (nonatomic, strong, readwrite, nullable) UISymbolContentTransition * symbolContentTransition;
```
