# titlePadding

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The distance between the title and subtitle labels.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- tvOS 15.0+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic, assign, readwrite) CGFloat titlePadding;
```

#### Discussion

The title padding adjusts the distance between the title and subtitle labels.
