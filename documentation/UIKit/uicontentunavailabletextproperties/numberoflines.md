# numberOfLines

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The maximum number of lines for the text.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic) NSInteger numberOfLines;
```

## Discussion

A value of 0 indicates an unlimited number of lines.
