# preferredImageDynamicRange

**Framework**: UIKit  
**Kind**: property

The preferred treatment to use for HDR images. By default the image view will defer to the value from its traitCollection.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+
