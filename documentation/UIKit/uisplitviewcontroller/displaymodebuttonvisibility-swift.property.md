# displayModeButtonVisibility

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A setting that determines whether the display mode button is visible in the interface.

**Availability**:
- iOS 14.5+
- iPadOS 14.5+
- Mac Catalyst 14.5+
- tvOS 14.5+
