# UICollectionLayoutListContentHuggingElements

**Framework**: UIKit  
**Kind**: enum  
**Role**: Enumeration

Constants that determine which types of items in a collection view tightly hug their content.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- tvOS 18.0+
- visionOS 2.0+
