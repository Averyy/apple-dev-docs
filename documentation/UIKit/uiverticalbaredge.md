# UIVerticalBarEdge

**Framework**: UIKit  
**Kind**: enum

The edge where the system places the vertical bar.

**Availability**:
- iOS 27.1+ (Beta)
- iPadOS 27.1+ (Beta)

## Declaration

```swift
enum UIVerticalBarEdge
```

  The vertical bar is on the trailing edge.
- [UIVerticalBarEdge.unspecified](uiverticalbaredge/unspecified.md)
