# UIBarStyle.blackTranslucent

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

A deprecated translucent style.

**Availability**:
- iOS 2.0+ - Deprecated in 13.0
- iPadOS 2.0+ - Deprecated in 13.0
- Mac Catalyst 13.1+ - Deprecated in 13.1

> **Deprecated**: Use [`UIBarStyle.black`](./black.md) and set the [`isTranslucent`](../uinavigationbar/istranslucent.md) property to [`true`](../../Swift/true.md) instead.
