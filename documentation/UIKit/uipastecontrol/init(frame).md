# init(frame:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a paste button with the specified size and position.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- visionOS 1.0+

## Declaration

```swift
init(frame: CGRect)
```

```objc
- (instancetype) initWithFrame:(CGRect) frame;
```

## Parameters

- `frame`: A structure that determines the paste button’s size and position within the parent view’s frame.
