# displayMode

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

An option that determines whether the paste button composes an icon, textual label, or both.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- visionOS 1.0+
