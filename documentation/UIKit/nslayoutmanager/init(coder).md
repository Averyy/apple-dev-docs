# init(coder:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a layout manager from data in an unarchiver.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+
