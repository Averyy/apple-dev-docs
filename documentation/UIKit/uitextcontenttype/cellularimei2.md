# cellularIMEI2

**Framework**: UIKit  
**Kind**: property

A property that defines the content in a text input area to contain the second International Mobile Equipment Identity (IMEI) for an eSIM.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- tvOS 27.0+
- visionOS 27.0+

## Declaration

```swift
static let cellularIMEI2: UITextContentType
```

#### Discussion

> **Note**: This property isn’t present on single-SIM devices.
