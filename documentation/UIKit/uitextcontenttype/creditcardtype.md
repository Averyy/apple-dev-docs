# creditCardType

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

A property that defines the content in a text input area as a credit card type.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+
