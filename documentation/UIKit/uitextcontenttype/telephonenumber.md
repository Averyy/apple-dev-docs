# telephoneNumber

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

A property that defines the content in a text input area as a telephone number.

**Availability**:
- iOS 10.0+
- iPadOS 10.0+
- Mac Catalyst 13.1+
- tvOS 10.0+
- visionOS 1.0+

## Declaration

```swift
static let telephoneNumber: UITextContentType
```

```c
extern UITextContentType const UITextContentTypeTelephoneNumber;
```
