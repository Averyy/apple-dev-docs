# UIUserNotificationActionResponseTypedTextKey

**Framework**: UIKit  
**Kind**: var  
**Role**: Global Variable

The response text selected by the user.

**Availability**:
- iOS 9.0+ - Deprecated in 10.0
- iPadOS 9.0+ - Deprecated in 10.0
- Mac Catalyst 13.1+ - Deprecated in 13.1

> **Deprecated**: Use [`userText`](../UserNotifications/untextinputnotificationresponse/usertext.md) instead.

## Declaration

```swift
let UIUserNotificationActionResponseTypedTextKey: String
```

```c
extern NSString * const UIUserNotificationActionResponseTypedTextKey;
```

#### Discussion

The value of this key is an [`NSString`](../Foundation/nsstring.md) containing the user’s text response.
