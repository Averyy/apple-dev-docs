# UIGraphicsImageRendererFormat.Range.automatic

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

The system automatically chooses the image renderer context’s pixel format according to the color range of its content.

**Availability**:
- iOS 12.0+
- iPadOS 12.0+
- Mac Catalyst 13.1+
- tvOS 12.0+
- visionOS 1.0+
