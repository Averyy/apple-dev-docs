# UIView.TintAdjustmentMode.normal

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

The view’s tint color property returns the completely unmodified tint color of the view.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+
