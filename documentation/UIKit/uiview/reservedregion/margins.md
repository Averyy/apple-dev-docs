# margins

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The extra space around the reserved area that keeps interactive content clear of it.

**Availability**:
- iOS 27.1+
- iPadOS 27.1+
- Mac Catalyst 27.1+
- tvOS 27.1+
- visionOS 27.1+

## Declaration

```swift
let margins: UIEdgeInsets
```

## Discussion

The region’s [`frame`](./frame.md) already includes these margins.
