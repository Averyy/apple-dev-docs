# appliedContentSizeCategoryLimitsDescription

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A string that lists each of the view’s superviews, its content size category, and whether that view has content size category limits.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- tvOS 15.0+
- visionOS 1.0+
