# init(windowScene:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Initializes and returns a new text-formatting coordinator for the specified window scene.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 13.0+
- visionOS 1.0+

## Declaration

