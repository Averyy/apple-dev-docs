# isFontPanelVisible

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

A Boolean value that indicates whether the font panel is visible.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 13.0+
- visionOS 1.0+
