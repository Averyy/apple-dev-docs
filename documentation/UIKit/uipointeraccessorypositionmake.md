# UIPointerAccessoryPositionMake

**Framework**: UIKit  
**Kind**: func  
**Role**: Function

Creates a custom accessory position with the specified offset and angle.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- visionOS 1.0+

## Declaration

```c
static UIPointerAccessoryPosition UIPointerAccessoryPositionMake(CGFloat offset, CGFloat angle);
```

## See Also

### Creating a custom accessory position
- [angle](./uipointeraccessoryposition/angle.md)
  The angle of the accessory’s position, measured in radians clockwise from the top of the primary pointer.
- [offset](./uipointeraccessoryposition/offset.md)
  The offset of the accessory from the primary pointer.
