# hideShowBarDuration

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

A variable that specifies the duration when animating the navigation bar.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS

## Declaration

```swift
class let hideShowBarDuration: CGFloat
```

```c
extern const CGFloat UINavigationControllerHideShowBarDuration;
```

#### Discussion

Note that this is a constant value, so it can’t be set.
