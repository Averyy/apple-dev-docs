# UIButtonConfigurationCornerStyleFixed

**Framework**: UIKit  
**Kind**: case  
**Role**: Enumeration Case

A style that uses the background corner radius without modification.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- tvOS 15.0+
- visionOS 1.0+

## Declaration

```c
UIButtonConfigurationCornerStyleFixed
```
