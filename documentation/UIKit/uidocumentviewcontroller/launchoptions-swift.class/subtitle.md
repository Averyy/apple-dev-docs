# subtitle

**Framework**: UIKit  
**Kind**: property

The subtitle of the view. Default is `nil`. If `nil`, no subtitle will be displayed.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- visionOS 27.0+ (Beta)
