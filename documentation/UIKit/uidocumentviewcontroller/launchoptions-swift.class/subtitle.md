# subtitle

**Framework**: UIKit  
**Kind**: property

The subtitle of the launch view. Default is `nil`. If `nil`, no subtitle will be displayed.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- visionOS 27.0+

## Declaration

```swift
var subtitle: String? { get set }
```
