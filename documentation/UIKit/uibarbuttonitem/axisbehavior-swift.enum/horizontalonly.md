# UIBarButtonItem.AxisBehavior.horizontalOnly

**Framework**: UIKit  
**Kind**: case

The item only supports horizontal bars. If an item only supports horizontal bars and no horizontal bars are present, the item is not shown.

**Availability**:
- iOS 27.1+ (Beta)
- iPadOS 27.1+ (Beta)
