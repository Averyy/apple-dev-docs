# UIBarButtonItem.SystemItem.pageCurl

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

The system page curl button.

**Availability**:
- iOS 4.0+ - Deprecated in 11.0
- iPadOS 4.0+ - Deprecated in 11.0
- Mac Catalyst 13.1+ - Deprecated in 13.1
- tvOS - Deprecated in 11.0

> **Deprecated**: [`UIBarButtonItem.SystemItem.pageCurl`](./pagecurl.md) isn’t recommended for apps that run in iOS 7 and later.

## Declaration

```swift
case pageCurl
```

```c
UIBarButtonSystemItemPageCurl
```

## Discussion

This bar button image can be used only for bar button items placed on toolbars.
