# axisBehavior

**Framework**: UIKit  
**Kind**: property

The bar axis behavior of the item.

**Availability**:
- iOS 27.1+ (Beta)
- iPadOS 27.1+ (Beta)

## Declaration

```swift
var axisBehavior: UIBarButtonItem.AxisBehavior { get set }
```

#### Discussion

The default value is `UIBarButtonItemAxisBehaviorAutomatic`.
