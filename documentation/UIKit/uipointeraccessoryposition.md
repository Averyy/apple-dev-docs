# UIPointerAccessoryPosition

**Framework**: UIKit  
**Kind**: struct  
**Role**: Structure

A structure that specifies the position of the accessory relative to the primary pointer.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS

## Declaration

```c
typedef struct { ... } UIPointerAccessoryPosition;
```
