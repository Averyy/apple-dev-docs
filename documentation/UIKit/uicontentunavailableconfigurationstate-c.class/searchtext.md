# searchText

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The search text.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic, strong, nullable) NSString * searchText;
```

## Discussion

By default, this property returns the search bar text from the view controller’s search controller.
