# NSTextWritingDirection.embedding

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

Text is embedded in text with another writing direction.

**Availability**:
- iOS 7.0+ - Deprecated in 9.0 (renamed: NSWritingDirectionFormatType)
- iPadOS 7.0+ - Deprecated in 9.0 (renamed: NSWritingDirectionFormatType)
- Mac Catalyst 13.1+ - Deprecated in 13.1 (renamed: NSWritingDirectionFormatType)
- watchOS 2.0+ - Deprecated in 2.0 (renamed: NSWritingDirectionFormatType)

> **Deprecated**: Use [`NSWritingDirectionFormatType.embedding`](../nswritingdirectionformattype/embedding.md) instead.

## Declaration

```swift
case embedding
```

```c
NSTextWritingDirectionEmbedding
```

## Overview

For example, an English quotation in the middle of an Arabic sentence could be marked as being embedded left-to-right text.
