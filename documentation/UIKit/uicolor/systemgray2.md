# systemGray2

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

A second-level shade of gray that adapts to the environment.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- visionOS 1.0+

## Declaration

```swift
class var systemGray2: UIColor { get }
```

```objc
@property (class, nonatomic, readonly) UIColor * systemGray2Color;
```

#### Discussion

This color adapts to the current environment. In light environments, this gray is slightly lighter than [`systemGray`](./systemgray.md). In dark environments, this gray is slightly darker than [`systemGray`](./systemgray.md).
