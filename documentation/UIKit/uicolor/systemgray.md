# systemGray

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

The standard base gray color that adapts to the environment.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- tvOS 9.0+
- visionOS 1.0+

## Declaration

```swift
class var systemGray: UIColor { get }
```

```objc
@property (class, nonatomic, readonly) UIColor * systemGrayColor;
```

## Discussion

This color represents the standard system gray. It adapts to the current environment.
