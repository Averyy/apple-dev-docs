# lightText

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

The nonadaptable system color for text on a dark background.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- visionOS

## Declaration

```swift
class var lightText: UIColor { get }
```

```objc
@property (class, nonatomic, readonly) UIColor * lightTextColor;
```

#### Return Value

The `UIColor` object.

#### Discussion

This color doesn’t adapt to changes in the underlying trait environment.
