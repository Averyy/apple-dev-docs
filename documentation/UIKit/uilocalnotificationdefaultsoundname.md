# UILocalNotificationDefaultSoundName

**Framework**: UIKit  
**Kind**: var  
**Role**: Global Variable

Identifies the default system sound to play when a notification alert is displayed.

**Availability**:
- iOS 4.0+ - Deprecated in 10.0
- iPadOS 4.0+ - Deprecated in 10.0
- Mac Catalyst 13.1+ - Deprecated in 13.1
- watchOS 2.0+ - Deprecated in 3.0

> **Deprecated**: For more information, see [`UILocalNotification`](./uilocalnotification.md).

## Declaration

```swift
let UILocalNotificationDefaultSoundName: String
```

```c
extern NSString * const UILocalNotificationDefaultSoundName;
```

#### Discussion

You assign this value to the [`soundName`](./uilocalnotification/soundname.md) property.
