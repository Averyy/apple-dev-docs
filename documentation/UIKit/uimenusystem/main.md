# main

**Framework**: UIKit  
**Kind**: property

**Availability**:
- iOS 13.0+

- tvOS 13.0+
- visionOS 1.0+

## Discussion

In Mac apps built with Mac Catalyst, the main menu system is the app’s menu bar.
