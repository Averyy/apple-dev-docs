# whenValues

**Framework**: UIKit  
**Kind**: property

Time periods mentioned in the text that can be used to filter photos.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)

## Declaration

```swift
var whenValues: [String] { get }
```

#### Discussion

For example, if the user types “photos from last summer,” this array might contain `@[@"last summer"]`.
