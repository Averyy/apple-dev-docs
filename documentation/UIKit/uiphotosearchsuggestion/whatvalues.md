# whatValues

**Framework**: UIKit  
**Kind**: property

Subjects or topics mentioned in the text that can be used to filter photos.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)

## Declaration

```swift
var whatValues: [String] { get }
```

#### Discussion

For example, if the user types “photos of food,” this array might contain `@[@"food"]`.
