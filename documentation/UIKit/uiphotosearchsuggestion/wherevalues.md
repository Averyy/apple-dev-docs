# whereValues

**Framework**: UIKit  
**Kind**: property

Locations mentioned in the text that can be used to filter photos.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+

## Declaration

```swift
var whereValues: [String] { get }
```

#### Discussion

For example, if the user types “pictures from Paris,” this array might contain `@[@"Paris"]`.
