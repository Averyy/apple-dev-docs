# rollAngle

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A value that represents the barrel-roll angle of Apple Pencil.

**Availability**:
- iOS 17.5+
- iPadOS 17.5+
- Mac Catalyst 17.5+
- visionOS 26.2+
