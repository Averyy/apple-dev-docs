# decorationItems

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

An array of the decoration items that are anchored to the section, such as background decoration views.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 13.0+
- visionOS 1.0+

## Declaration


```objc
@property (nonatomic, copy) NSArray<NSCollectionLayoutDecorationItem *> * decorationItems;
```
