# UICellAccessoryStandardDimension

**Framework**: UIKit  
**Kind**: var  
**Role**: Global Variable

The system standard layout dimension for accessories.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
- visionOS 1.0+

## Declaration

```c
extern const CGFloat UICellAccessoryStandardDimension;
```
