# init(horizontal:vertical:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Returns an offset structure from the given components.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS
- watchOS 2.0+

## Declaration

```swift
init(horizontal: CGFloat, vertical: CGFloat)
```

```c
static UIOffset UIOffsetMake(CGFloat horizontal, CGFloat vertical);
```

#### Return Value

An offset structure with offsets `horizontal` and `vertical`.

## Parameters

- `horizontal`: The horizontal offset.
- `vertical`: The vertical offset.
