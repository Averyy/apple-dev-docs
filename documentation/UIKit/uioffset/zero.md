# zero

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

An offset structure with no offset in the horizontal and vertical directions.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS
- watchOS 2.0+

## Declaration

```swift
static let zero: UIOffset
```

```c
extern const UIOffset UIOffsetZero;
```

#### Discussion

This constant represents a [`UIOffset`](../uioffset.md) structure whose [`horizontal`](./horizontal.md) and [`vertical`](./vertical.md) fields are `0`.
