# vertical

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The amount of vertical offset from a position.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS
- watchOS 2.0+

## Declaration

```swift
var vertical: CGFloat
```

```c
CGFloat vertical;
```

## Discussion

Positive values indicate an offset downward, and negative values indicate an offset upward.
