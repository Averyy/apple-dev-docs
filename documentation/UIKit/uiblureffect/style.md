# UIBlurEffect.Style

**Framework**: UIKit  
**Kind**: enum  
**Role**: Enumeration

Blur styles available for blur effect objects.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+
