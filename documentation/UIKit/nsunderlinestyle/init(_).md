# init(_:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a [`NSUnderlineStyle`](../nsunderlinestyle.md) from `Text.LineStyle`.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- tvOS 15.0+
- visionOS
- watchOS 8.0+

## Declaration

```swift
init(_ lineStyle: Text.LineStyle)
```

## Return Value

A new [`NSUnderlineStyle`](../nsunderlinestyle.md).

## Parameters

- `lineStyle`: A value of `Text.LineStyle` to wrap with [`NSUnderlineStyle`](../nsunderlinestyle.md).
