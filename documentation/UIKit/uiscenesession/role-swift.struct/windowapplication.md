# windowApplication

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

A scene that displays interactive windows on the device’s built-in display or an externally connected display.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 13.0+
- visionOS 1.0+
