# UITextAutocapitalizationType.allCharacters

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

Specifies automatic capitalization of all characters, such as for entry of two-character state abbreviations for the United States.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS

```swift
case allCharacters
```
