# init(color:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a color effect with the specified color.

**Availability**:
- iOS 26.1+
- iPadOS 26.1+
- Mac Catalyst 26.1+
- tvOS 26.1+
- visionOS 26.0+

## Declaration

```swift
convenience init(color: UIColor?)
```

```objc
+ (instancetype) effectWithColor:(UIColor *) color;
```

## Parameters

- `color`: The color to use for the background.
