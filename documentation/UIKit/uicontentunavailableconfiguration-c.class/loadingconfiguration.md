# loadingConfiguration

**Framework**: UIKit  
**Kind**: method  
**Role**: Type Method

**Availability**:

- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+

