# extraExtraLarge

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

A font that is larger than the extra-large font but smaller than the largest font size available.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+
