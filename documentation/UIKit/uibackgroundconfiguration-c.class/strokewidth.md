# strokeWidth

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The width of the stroke.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic) CGFloat strokeWidth;
```

## Discussion

The default value is `0.0`.
