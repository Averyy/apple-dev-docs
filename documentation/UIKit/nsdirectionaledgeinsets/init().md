# init()

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a directional edge insets structure that contains default values.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- Mac Catalyst 13.1+
- tvOS 11.0+
- visionOS 1.0+
- watchOS 4.0+

## Declaration

```swift
init()
```

## Return Value

An initialized inset structure.

## Discussion

This method sets all inset margins to `0.0`.
