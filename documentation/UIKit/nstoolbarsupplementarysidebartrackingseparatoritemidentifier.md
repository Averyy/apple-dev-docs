# NSToolbarSupplementarySidebarTrackingSeparatorItemIdentifier

**Framework**: UIKit  
**Kind**: var  
**Role**: Global Variable

The identifier for a toolbar item that displays a tracking separator aligned with the secondary divider in a split view.

**Availability**:
- Mac Catalyst 14.0+

## Declaration

```c
extern NSToolbarItemIdentifier NSToolbarSupplementarySidebarTrackingSeparatorItemIdentifier;
```

## Overview

The item’s tracking separator visually aligns itself with the second divider of a vertical split view in the same window.
