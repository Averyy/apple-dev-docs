# UIVerticalBarCompressionBehavior.prefersBarItems

**Framework**: UIKit  
**Kind**: case

A compression behavior that prefers keeping bar items visible.

**Availability**:
- iOS 27.1+ (Beta)
- iPadOS 27.1+ (Beta)

## Declaration

```swift
case prefersBarItems
```

#### Discussion

The tab bar will compress before bar items when space is constrained.
