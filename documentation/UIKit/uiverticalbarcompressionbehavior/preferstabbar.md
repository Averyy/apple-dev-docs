# UIVerticalBarCompressionBehavior.prefersTabBar

**Framework**: UIKit  
**Kind**: case

A compression behavior that prefers keeping the tab bar visible.

**Availability**:
- iOS 27.1+ (Beta)
- iPadOS 27.1+ (Beta)

## Declaration

```swift
case prefersTabBar
```

#### Discussion

Bar items will compress before the tab bar when space is constrained.
