# enabled

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that enables and disables the button.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic, getter=isEnabled) BOOL enabled;
```

#### Discussion

The default value is `YES`.
