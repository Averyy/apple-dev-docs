# UICellAccessoryCheckmark

**Framework**: UIKit  
**Kind**: class  
**Role**: Class

The checkmark system accessory.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
- visionOS 1.0+

## Declaration

```objc
@interface UICellAccessoryCheckmark : UICellAccessory
```

## Overview

A checkmark accessory is a checkmark with the default system green color. This accessory appears on the trailing edge of the cell.
