# preferredTapAction

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

A person’s preferred double-tap action for Apple Pencil, as specified in the Settings app.

**Availability**:
- iOS 12.1+
- iPadOS 12.1+
- Mac Catalyst 13.1+
- visionOS 26.2+
