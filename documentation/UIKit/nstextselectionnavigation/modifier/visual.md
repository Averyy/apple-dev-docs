# visual

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

The value that indicates the framework extends the selection visually inside the rectangular area defined by the anchor and drag positions.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- tvOS 15.0+
- visionOS 1.0+
