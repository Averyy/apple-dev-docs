# position

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The index position of the cell accessory in relation to the other accessories in the accessories array.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic, copy, null_resettable) UICellAccessoryPosition position;
```
