# NSTextContentStorageUnsupportedAttributeAddedNotification

**Framework**: UIKit  
**Kind**: var  
**Role**: Global Variable

Posted by `NSTextContentStorage` when a text attribute unsupported by `NSTextContentStorage` is added to the underlying text storage.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- tvOS 15.0+
- visionOS 1.0+

## Declaration

```c
extern NSNotificationName NSTextContentStorageUnsupportedAttributeAddedNotification;
```
