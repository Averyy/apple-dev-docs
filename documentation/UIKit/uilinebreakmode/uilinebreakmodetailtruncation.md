# UILineBreakModeTailTruncation

**Framework**: UIKit  
**Kind**: case  
**Role**: Enumeration Case

Truncate text (as necessary) from the end of the line.

**Availability**:
- iOS 2.0+ - Deprecated in 6.0
- iPadOS 2.0+ - Deprecated in 6.0
- Mac Catalyst 13.1+ - Deprecated in 13.1

> **Deprecated**: Use [`NSLineBreakMode.byTruncatingTail`](../nslinebreakmode/bytruncatingtail.md) instead.

## Declaration

```c
UILineBreakModeTailTruncation
```

## Discussion

For multiple lines of text, only text on the last line truncates.
