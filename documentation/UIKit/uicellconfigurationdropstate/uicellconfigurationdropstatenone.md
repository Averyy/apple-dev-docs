# UICellConfigurationDropStateNone

**Framework**: UIKit  
**Kind**: case  
**Role**: Enumeration Case

The system hasn’t associated the cell with a drag session.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- visionOS 1.0+

## Declaration

```c
UICellConfigurationDropStateNone
```

## See Also

### Drop states
- [UICellConfigurationDropStateNotTargeted](./uicellconfigurationdropstatenottargeted.md)
  A drag session is active and can perform a drop in the cell’s container, but the cell itself isn’t the drop target.
- [UICellConfigurationDropStateTargeted](./uicellconfigurationdropstatetargeted.md)
  The cell is the drop target for a drag session.
