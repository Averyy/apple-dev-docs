# UICellConfigurationDropStateNotTargeted

**Framework**: UIKit  
**Kind**: case  
**Role**: Enumeration Case

A drag session is active and can perform a drop in the cell’s container, but the cell itself isn’t the drop target.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- visionOS 1.0+

## Declaration

```c
UICellConfigurationDropStateNotTargeted
```
