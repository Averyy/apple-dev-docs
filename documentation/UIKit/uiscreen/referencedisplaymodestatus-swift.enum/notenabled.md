# UIScreen.ReferenceDisplayModeStatus.notEnabled

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

A status that indicates the screen provides a reference display mode but it’s in a disabled state.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- tvOS 16.0+
