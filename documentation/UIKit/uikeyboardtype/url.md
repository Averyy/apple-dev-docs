# UIKeyboardType.URL

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

Specifies a keyboard for URL entry.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS

## Declaration

```swift
case URL
```

```c
UIKeyboardTypeURL
```

## Discussion

This keyboard type prominently features the period (”`.`”) and slash (”/”) characters and the “`.com`” string.
