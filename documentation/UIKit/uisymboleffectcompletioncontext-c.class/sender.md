# sender

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The object, an image view or bar button item, that received the symbol effect.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic, weak, readonly, nullable) id sender;
```
