# currentProgress

**Framework**: UIKit  
**Kind**: property

The current progress value of the active page control indicator, between 0 and 1. Values outside of [0…1] will be clamped.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+
