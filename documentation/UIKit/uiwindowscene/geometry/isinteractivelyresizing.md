# isInteractivelyResizing

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

Returns true when the scene is being resized interactively, otherwise false.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- tvOS 26.0+
