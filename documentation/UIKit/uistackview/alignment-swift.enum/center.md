# UIStackView.Alignment.center

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

A layout where the stack view aligns the center of its arranged views with its center along its axis.

**Availability**:
- iOS 9.0+
- iPadOS 9.0+
- Mac Catalyst 13.1+
- tvOS 9.0+
- visionOS 1.0+

## Declaration

```swift
case center
```

```c
UIStackViewAlignmentCenter
```
