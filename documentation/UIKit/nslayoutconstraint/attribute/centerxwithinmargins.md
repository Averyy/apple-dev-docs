# NSLayoutConstraint.Attribute.centerXWithinMargins

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

The center along the x-axis between the object’s left and right margin.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+

## Declaration

```swift
case centerXWithinMargins
```

```c
NSLayoutAttributeCenterXWithinMargins
```

#### Discussion

For [`UIView`](../../uiview.md) objects, the margins are defined by their [`layoutMargins`](../../uiview/layoutmargins.md) property.
