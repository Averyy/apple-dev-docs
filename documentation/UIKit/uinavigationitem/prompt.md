# prompt

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A single line of text that displays at the top of the navigation bar.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- visionOS 1.0+

## Declaration

```swift
var prompt: String? { get set }
```

```objc
@property (nonatomic, copy, readwrite, nullable) NSString * prompt;
```

#### Discussion

The default value is `nil`.
