# displayAsPalette

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

An option indicating the menu displays as a row of menu elements for choosing from a collection of items.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+
