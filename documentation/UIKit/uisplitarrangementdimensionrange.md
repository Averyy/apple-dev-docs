# UISplitArrangementDimensionRange

**Framework**: UIKit  
**Kind**: class  
**Role**: Class

A range of dimensions defining the minimum, preferred, and maximum size for a view within a split arrangement.

**Availability**:
- iOS 27.1+
- iPadOS 27.1+
- Mac Catalyst 27.1+
- tvOS 27.1+
- visionOS 27.1+
