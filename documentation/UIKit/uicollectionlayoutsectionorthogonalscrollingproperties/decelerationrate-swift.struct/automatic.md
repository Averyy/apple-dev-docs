# automatic

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

A deceleration rate that matches the parent scroll view’s deceleration rate for the orthogonal scrolling section.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+
