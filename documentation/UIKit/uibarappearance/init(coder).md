# init(coder:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates an appearance object from data in an unarchiver.

**Availability**:

- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 13.0+
- visionOS 1.0+
