# init()

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a new bar appearance object containing default values.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 13.0+
- visionOS 1.0+

## Declaration

```swift
convenience init()
```

```objc
- (instancetype) init;
```

#### Return Value

A new bar appearance object containing default values for the current device idiom.
