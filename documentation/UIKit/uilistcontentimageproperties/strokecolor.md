# strokeColor

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

Configures the color of the stroke. A nil value uses the view’s tint color; use `clearColor` for no color (transparent).

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- tvOS 18.0+
- visionOS 2.0+

## Declaration

```objc
@property (nonatomic, strong, nullable) UIColor * strokeColor;
```
