# viewController

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The view controller that the system presents when someone selects a tab.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- tvOS 18.0+
- visionOS 2.0+
