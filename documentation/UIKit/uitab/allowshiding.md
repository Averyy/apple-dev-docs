# allowsHiding

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether people can hide a tab in a sidebar.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- tvOS 18.0+
- visionOS 2.0+

## Declaration

```swift
var allowsHiding: Bool { get set }
```

```objc
@property (nonatomic, assign) BOOL allowsHiding;
```
