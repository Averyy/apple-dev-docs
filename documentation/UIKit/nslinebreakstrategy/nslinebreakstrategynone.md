# NSLineBreakStrategyNone

**Framework**: UIKit  
**Kind**: case  
**Role**: Enumeration Case

The text system doesn’t use any line-break strategies.

**Availability**:
- iOS 9.0+
- iPadOS 9.0+
- Mac Catalyst 13.1+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```c
NSLineBreakStrategyNone
```
