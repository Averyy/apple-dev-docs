# includesTextListMarkers

**Framework**: UIKit  
**Kind**: property

A Boolean value that indicates whether TextKit includes text list markers in the contents.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- tvOS 26.0+
- visionOS 26.0+
- watchOS 26.0+

## Declaration

```swift
class var includesTextListMarkers: Bool { get }
```

#### Discussion

The default value is `false`.
