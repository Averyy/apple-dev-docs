# hyphen

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

The value that represents a hyphen-shaped marker that you can apply to a text list item.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift

```
