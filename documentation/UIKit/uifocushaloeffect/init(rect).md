# init(rect:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a rectangular halo effect using the specified rectangle.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- visionOS 1.0+
