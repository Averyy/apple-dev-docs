# init(groups:)

**Framework**: UIKit  
**Kind**: init

Creates a configuration object with provided component groups.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- visionOS 26.0+

## Declaration

```swift
convenience init(groups: [UITextFormattingViewController.ComponentGroup])
```

## Parameters

- `groups`: Component groups displayed in text formatting view.
