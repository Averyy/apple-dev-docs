# UITableView.ScrollPosition.middle

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

The table view scrolls the row of interest to the middle of the visible table view.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS
