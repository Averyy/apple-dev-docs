# selfSizingInvalidation

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The mode that the table view uses for invalidating the size of self-sizing cells.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- tvOS 16.0+
- visionOS 1.0+
