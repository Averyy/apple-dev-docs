# separatorColor

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The color of separator rows in the table view.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- visionOS 1.0+

## Declaration

```swift
var separatorColor: UIColor? { get set }
```

```objc
@property (nonatomic, strong, nullable) UIColor * separatorColor;
```

## Discussion

The default color is gray.
