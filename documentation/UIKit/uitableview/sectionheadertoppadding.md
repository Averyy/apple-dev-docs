# sectionHeaderTopPadding

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The amount of padding above each section header.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- tvOS 15.0+
- visionOS 1.0+

## Declaration

```swift
var sectionHeaderTopPadding: CGFloat { get set }
```

```objc
@property (nonatomic) CGFloat sectionHeaderTopPadding;
```

## Discussion

The default value is [`automaticDimension`](./automaticdimension.md).
