# top

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

Scroll so that the item is positioned at the top of the collection view’s bounds.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS

## Declaration

```swift
static var top: UICollectionView.ScrollPosition { get }
```

```c
UICollectionViewScrollPositionTop
```

#### Discussion

This option is mutually exclusive with the [`centeredVertically`](./centeredvertically.md) and [`bottom`](./bottom.md) options.
