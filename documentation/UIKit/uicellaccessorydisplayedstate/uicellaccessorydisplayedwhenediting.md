# UICellAccessoryDisplayedWhenEditing

**Framework**: UIKit  
**Kind**: case  
**Role**: Enumeration Case

The accessory displays only when the cell is in editing mode.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
- visionOS 1.0+

## Declaration

```c
UICellAccessoryDisplayedWhenEditing
```

## See Also

### States
- [UICellAccessoryDisplayedAlways](./uicellaccessorydisplayedalways.md)
  The accessory always displays.
- [UICellAccessoryDisplayedWhenNotEditing](./uicellaccessorydisplayedwhennotediting.md)
  The accessory displays only when the cell isn’t in editing mode.
