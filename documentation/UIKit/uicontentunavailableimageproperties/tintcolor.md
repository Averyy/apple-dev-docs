# tintColor

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The tint color applied to the image view.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic, strong, nullable) UIColor * tintColor;
```

#### Discussion

Setting the value to `nil` makes the image view use its inherited tint color.
