# UIPreferredPresentationStyle

**Framework**: UIKit  
**Kind**: enum  
**Role**: Enumeration

The presentation styles that determine how a view shows an item provider’s data.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS
- watchOS 4.0+

## Declaration

```c
enum UIPreferredPresentationStyle : NSInteger;
```

## Topics

### Presentation styles
- [UIPreferredPresentationStyleUnspecified](./uipreferredpresentationstyle/uipreferredpresentationstyleunspecified.md)
  A presentation style indicating that no preferred style is specified.
- [UIPreferredPresentationStyleInline](./uipreferredpresentationstyle/uipreferredpresentationstyleinline.md)
  A presentation style indicating that the item provider data should be presented inline.
- [UIPreferredPresentationStyleAttachment](./uipreferredpresentationstyle/uipreferredpresentationstyleattachment.md)
  A presentation style indicating that the item provider data should be presented as an attachment.
