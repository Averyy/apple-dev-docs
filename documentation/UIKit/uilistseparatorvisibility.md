# UIListSeparatorVisibility

**Framework**: UIKit  
**Kind**: enum  
**Role**: Enumeration

An enumeration that defines the visibility of list separators.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS

## Declaration

```c
enum UIListSeparatorVisibility : NSInteger;
```

- [UIListSeparatorVisibilityVisible](./uilistseparatorvisibility/uilistseparatorvisibilityvisible.md)
