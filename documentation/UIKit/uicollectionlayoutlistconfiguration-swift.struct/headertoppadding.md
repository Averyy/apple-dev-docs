# headerTopPadding

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The amount of padding above each section header.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- tvOS 15.0+
- visionOS

## Declaration

```swift
var headerTopPadding: CGFloat? { get set }
```

#### Discussion

The default value is `nil`, which indicates automatic padding.
