# UIUserNotificationActionContext.default

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

The default context for displaying the alert.

**Availability**:
- iOS 8.0+ - Deprecated in 10.0
- iPadOS 8.0+ - Deprecated in 10.0
- Mac Catalyst 13.1+ - Deprecated in 13.1

> **Deprecated**: For more information, see [`UIUserNotificationCategory`](../uiusernotificationcategory.md).

## Declaration

```swift
case `default`
```

```c
UIUserNotificationActionContextDefault
```

#### Discussion

In this context, the full UI is displayed for the notification’s alert. You may specify up to four custom actions in this context.
