# UIUserNotificationActionContext.minimal

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

A notification where space is minimal.

**Availability**:
- iOS 8.0+ - Deprecated in 10.0
- iPadOS 8.0+ - Deprecated in 10.0
- Mac Catalyst 13.1+ - Deprecated in 13.1

> **Deprecated**: For more information, see [`UIUserNotificationCategory`](../uiusernotificationcategory.md).

## Declaration

```swift
case minimal
```

```c
UIUserNotificationActionContextMinimal
```

#### Discussion

In this context, a minimal UI is displayed for the notification’s alert. You may specify up to two custom actions in this context.
