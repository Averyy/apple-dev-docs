# shapeWithRoundedRect:

**Framework**: UIKit  
**Kind**: method  
**Role**: Type Method

**Availability**:
- iOS 13.4+
- iPadOS 13.4+
- Mac Catalyst 13.4+
- visionOS 1.0+
