# errorDomain

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

A string that indicates that an error happened when the system attempted to determine if your app is the default in a category.

**Availability**:
- iOS 18.2+
- iPadOS 18.2+

## Declaration
