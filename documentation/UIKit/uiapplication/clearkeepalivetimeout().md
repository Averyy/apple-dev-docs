# clearKeepAliveTimeout()

**Framework**: UIKit  
**Kind**: method  
**Role**: Instance Method

Removes a previously installed periodic handler block.

**Availability**:
- iOS 4.0+ - Deprecated in 9.0
- iPadOS 4.0+ - Deprecated in 9.0
- Mac Catalyst 13.1+ - Deprecated in 13.1

> **Deprecated**: Use [PushKit](../../PushKit/PushKit.md) for VoIP apps instead.

## Declaration

```swift
func clearKeepAliveTimeout()
```

```objc
- (void) clearKeepAliveTimeout;
```

## Discussion

If your VoIP app no longer needs to be woken up at periodic intervals, you can use this method to remove any previously installed handler.
