# prefersShadow

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that determines whether to add a shadow.

**Availability**:
- iOS 13.4+
- iPadOS 13.4+
- Mac Catalyst 13.4+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic) BOOL prefersShadow;
```

#### Discussion

The default value of this property is [`false`](../../Swift/false.md).
