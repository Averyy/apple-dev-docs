# prefersScaledContent

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that determines whether to scale the content.

**Availability**:
- iOS 13.4+
- iPadOS 13.4+
- Mac Catalyst 13.4+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic) BOOL prefersScaledContent;
```

## Discussion

The default value of this property is [`true`](../../Swift/true.md).
