# UIPreferredPresentationStyleAttachment

**Framework**: UIKit  
**Kind**: case  
**Role**: Enumeration Case

A presentation style indicating that the item provider data should be presented as an attachment.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS
- watchOS 4.0+

## Declaration

```c
UIPreferredPresentationStyleAttachment
```
