# UIImage.RenderingMode.alwaysOriginal

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

Always draw the original image, without treating it as a template.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+
- watchOS 2.0+
