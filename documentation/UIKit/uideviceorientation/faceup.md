# UIDeviceOrientation.faceUp

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

The device is held parallel to the ground with the screen facing upwards.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- visionOS

## Declaration

```swift
case faceUp
```

```c
UIDeviceOrientationFaceUp
```
