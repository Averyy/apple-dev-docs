# isValidInterfaceOrientation

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the specified orientation is one of the portrait or landscape orientations.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst

## Declaration

```swift
var isValidInterfaceOrientation: Bool { get }
```

