# UIBarMinimizationSafeAreaAdjustment.enabled

**Framework**: UIKit  
**Kind**: case

The safe area adjusts as bars minimize, allowing content to reflow.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
