# NSToolbarItemIdentifier

**Framework**: UIKit  
**Role**: API Collection

UIKit-specific constants for the standard toolbar items that the system provides.

#### Overview

UIKit defines these constants that you use to configure an [`NSToolbarItem`](../AppKit/nstoolbaritem.md). For more information, see [`NSToolbarItem.Identifier`](../AppKit/nstoolbaritem/identifier.md).

## Topics

### Getting the standard item identifiers
- [NSToolbarPrimarySidebarTrackingSeparatorItemIdentifier](./nstoolbarprimarysidebartrackingseparatoritemidentifier.md)
  The identifier for a toolbar item that displays a tracking separator aligned with the primary divider in a split view.
- [NSToolbarSupplementarySidebarTrackingSeparatorItemIdentifier](./nstoolbarsupplementarysidebartrackingseparatoritemidentifier.md)
  The identifier for a toolbar item that displays a tracking separator aligned with the secondary divider in a split view.
