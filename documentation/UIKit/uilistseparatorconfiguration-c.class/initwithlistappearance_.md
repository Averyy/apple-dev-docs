# initWithListAppearance:

**Framework**: UIKit  
**Kind**: method  
**Role**: Instance Method

Creates a list separator configuration with default values according to the specified list appearance.

**Availability**:
- iOS 14.5+
- iPadOS 14.5+
- Mac Catalyst 14.5+
- visionOS 1.0+

## Declaration

```objc
- (instancetype) initWithListAppearance:(UICollectionLayoutListAppearance) listAppearance;
```

## Parameters

- `listAppearance`: The appearance of the list using this separator configuration.
