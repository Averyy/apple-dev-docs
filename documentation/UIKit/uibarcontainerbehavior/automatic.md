# UIBarContainerBehavior.automatic

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

The system decides whether this navigation controller renders the bar, or whether its bar content should be integrated into a single bar in a parent container view controller, like a split view controller.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- tvOS 27.3+ (Beta)
- visionOS 27.3+ (Beta)

## Declaration

```swift
case automatic
```

```c
UIBarContainerBehaviorAutomatic
```

## Discussion

By default, the system allows integration in contexts where it is supported.
