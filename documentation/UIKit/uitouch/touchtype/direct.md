# UITouch.TouchType.direct

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

A touch resulting from direct contact with the screen.

**Availability**:
- iOS 9.0+
- iPadOS 9.0+
- Mac Catalyst 13.1+
- tvOS 9.0+
- visionOS 1.0+

## Declaration

```swift
case direct
```

```c
UITouchTypeDirect
```

#### Discussion

Direct touches occur when the user’s finger touches the screen.
