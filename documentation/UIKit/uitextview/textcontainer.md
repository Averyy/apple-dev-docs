# textContainer

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The text container object that defines the area where text displays in the text view.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+
