# threadIdentifier

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A string that uniquely identifies a conversation. This identifier is persistent for the life of the conversation.

**Availability**:
- iOS 18.4+
- iPadOS 18.4+
- Mac Catalyst 18.4+
