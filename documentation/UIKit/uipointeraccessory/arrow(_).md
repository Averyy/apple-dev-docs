# arrow(_:)

**Framework**: UIKit  
**Kind**: method  
**Role**: Type Method

Creates a pointer accessory with an arrow shape at the specified position.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- visionOS

## Declaration

```swift
@MainActor
@preconcurrency class func arrow(_ position: UIPointerAccessory.Position) -> Self
```

## Parameters

- `position`: One of the available [`UIPointerAccessory.Position`](./position-swift.struct.md) positions.
