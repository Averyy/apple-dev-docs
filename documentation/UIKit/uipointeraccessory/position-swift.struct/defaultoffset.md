# defaultOffset

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

A constant that specifies the default offset of an accessory from the primary pointer shape.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- visionOS
