# overlay

**Framework**: UIKit  
**Kind**: property

An arrangement that layers the primary view over the secondary view, or places the views side by side on a folded display.

**Availability**:
- iOS 27.1+
- iPadOS 27.1+
- Mac Catalyst 27.1+
