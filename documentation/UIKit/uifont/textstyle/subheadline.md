# subheadline

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

The font for subheadings.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
static let subheadline: UIFont.TextStyle
```

```c
extern UIFontTextStyle const UIFontTextStyleSubheadline;
```

## Discussion

> ❗ **Important**:  On tvOS, text used for subheadings should be in an all-caps format.
