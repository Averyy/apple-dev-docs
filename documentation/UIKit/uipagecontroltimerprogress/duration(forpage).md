# duration(forPage:)

**Framework**: UIKit  
**Kind**: method  
**Role**: Instance Method

Returns the duration for the specified page, and `preferredDuration` when there is no custom duration set for the specified page.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+
