# UISegmentedControl.Segment.center

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

Any segment between the left and rightmost segments.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS

## Declaration

```swift
case center
```

```c
UISegmentedControlSegmentCenter
```

#### Discussion

Applies only when [`numberOfSegments`](../numberofsegments.md) is greater than 2.
