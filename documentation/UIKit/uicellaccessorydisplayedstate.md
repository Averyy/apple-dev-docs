# UICellAccessoryDisplayedState

**Framework**: UIKit  
**Kind**: enum  
**Role**: Enumeration

Constants that describe the cell-editing states that the accessory appears in.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
- visionOS 1.0+

## Declaration

```c
enum UICellAccessoryDisplayedState : NSInteger;
```

## Topics

### States
- [UICellAccessoryDisplayedAlways](./uicellaccessorydisplayedstate/uicellaccessorydisplayedalways.md)
  The accessory always displays.
- [UICellAccessoryDisplayedWhenEditing](./uicellaccessorydisplayedstate/uicellaccessorydisplayedwhenediting.md)
  The accessory displays only when the cell is in editing mode.
- [UICellAccessoryDisplayedWhenNotEditing](./uicellaccessorydisplayedstate/uicellaccessorydisplayedwhennotediting.md)
  The accessory displays only when the cell isn’t in editing mode.
