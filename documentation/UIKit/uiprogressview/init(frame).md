# init(frame:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a progress view with the specified frame rectangle.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+

## Declaration

```swift
init(frame: CGRect)
```

```objc
- (instancetype) initWithFrame:(CGRect) frame;
```
