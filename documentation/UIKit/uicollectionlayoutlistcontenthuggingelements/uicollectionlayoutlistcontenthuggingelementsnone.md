# UICollectionLayoutListContentHuggingElementsNone

**Framework**: UIKit  
**Kind**: case  
**Role**: Enumeration Case

A mode where none of the items in the collection view tightly hug their content.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- tvOS 18.0+
- visionOS 2.0+

## Declaration

```c
UICollectionLayoutListContentHuggingElementsNone
```
