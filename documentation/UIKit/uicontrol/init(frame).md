# init(frame:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a control with the specified frame.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+
