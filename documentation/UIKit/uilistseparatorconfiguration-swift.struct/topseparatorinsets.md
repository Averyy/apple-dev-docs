# topSeparatorInsets

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

Insets to apply to the top separator of the item the configuration applies to.

**Availability**:
- iOS 14.5+
- iPadOS 14.5+
- Mac Catalyst 14.5+
- visionOS

## Declaration

var topSeparatorInsets: NSDirectionalEdgeInsets { get set }
