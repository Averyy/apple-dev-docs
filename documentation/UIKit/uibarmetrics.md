# UIBarMetrics

**Framework**: UIKit  
**Kind**: enum  
**Role**: Enumeration

Constants to specify metrics to use for appearance.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS

## Declaration

```swift
enum UIBarMetrics
```

```c
enum UIBarMetrics : NSInteger;
```

## Topics

### Constants
- [UIBarMetrics.default](./uibarmetrics/default.md)
  Specifies default metrics for the device.
- [UIBarMetrics.compact](./uibarmetrics/compact.md)
  Specifies metrics when using the phone idiom.
- [UIBarMetrics.defaultPrompt](./uibarmetrics/defaultprompt.md)
  Specifies default metrics for the device for bars with the prompt property, such as [`UINavigationBar`](./uinavigationbar.md) and [`UISearchBar`](./uisearchbar.md).
- [UIBarMetrics.compactPrompt](./uibarmetrics/compactprompt.md)
  Specifies metrics for bars with the prompt property when using the phone idiom, such as [`UINavigationBar`](./uinavigationbar.md) and [`UISearchBar`](./uisearchbar.md).
- [static var landscapePhone: UIBarMetrics](./uibarmetrics/landscapephone.md)
  Specifies metrics for landscape orientation using the phone idiom.
- [static var landscapePhonePrompt: UIBarMetrics](./uibarmetrics/landscapephoneprompt.md)
  Specifies metrics for landscape orientation using the phone idiom for bars with the prompt property, such as [`UINavigationBar`](./uinavigationbar.md) and [`UISearchBar`](./uisearchbar.md).
