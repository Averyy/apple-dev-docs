# configurationWithMenu:

**Framework**: UIKit  
**Kind**: method  
**Role**: Type Method

Creates a menu configuration with the specified menu and a default preview.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- visionOS 1.0+

## Declaration

```objc
+ (instancetype) configurationWithMenu:(UIMenu *) menu;
```

## Parameters

- `menu`: The menu to be presented.
