# supportsEyedropper

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

If set to `NO` the eyedropper functionality is not supported for this color well.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- visionOS 26.0+

## Declaration

```swift
var supportsEyedropper: Bool { get set }
```

```objc
@property (nonatomic) BOOL supportsEyedropper;
```
