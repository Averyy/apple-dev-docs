# UITraitSplitViewControllerLayoutEnvironment

**Framework**: UIKit  
**Kind**: class  
**Role**: Class

A class that represents the split view controller layout environment trait.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- tvOS 26.0+
- visionOS 26.0+

## Declaration

```objc
@interface UITraitSplitViewControllerLayoutEnvironment : NSObject
```

## Overview

The trait specifies whether an ancestor split view controller, if any, is expanded or collapsed.
