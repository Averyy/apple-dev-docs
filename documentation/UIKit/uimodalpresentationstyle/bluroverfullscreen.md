# UIModalPresentationStyle.blurOverFullScreen

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

A presentation style that blurs the underlying content before displaying new content in a full-screen presentation.

**Availability**:
- tvOS 11.0+
