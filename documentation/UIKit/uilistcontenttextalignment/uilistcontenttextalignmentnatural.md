# UIListContentTextAlignmentNatural

**Framework**: UIKit  
**Kind**: case  
**Role**: Enumeration Case

The text uses the default alignment that the system associates with the current localization of the app.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
