# traits

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

The font traits dictionary attribute.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+
- watchOS 2.0+

## Declaration

```swift
static let traits: UIFontDescriptor.AttributeName
```

```c
extern UIFontDescriptorAttributeName const UIFontDescriptorTraitsAttribute;
```

## Discussion

The value is an [`NSDictionary`](../../../Foundation/nsdictionary.md) instance that fully describes the font traits. The font supplies the default value.
