# UIContentUnavailableButtonProperties

**Framework**: UIKit  
**Kind**: class  
**Role**: Class

Properties configuring the appearance and behavior of a button in a content-unavailable view.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```objc
@interface UIContentUnavailableButtonProperties : NSObject
```

## Topics

### Instance Properties
- [enabled](./uicontentunavailablebuttonproperties/enabled.md)
  A Boolean value that enables and disables the button.
- [menu](./uicontentunavailablebuttonproperties/menu.md)
  A menu that the button displays.
- [primaryAction](./uicontentunavailablebuttonproperties/primaryaction.md)
  The action to perform for the primary action control event.
- [role](./uicontentunavailablebuttonproperties/role.md)
  The role of the button.
