# init()

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Initializes the edge insets structure to default values.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS
- watchOS 2.0+

## Declaration

```swift
init()
```

## Return Value

An initialized inset structure.

## Discussion

This initializer sets all inset margins to `0.0`.
