# UIDocumentPickerMode

**Framework**: UIKit  
**Kind**: enum

Modes that define the type of file transfer operation that the document picker uses.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- Mac Catalyst 13.1+
- visionOS 1.0+
