# font

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The font for the label.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic, strong) UIFont * font;
```

## Discussion

The default value of this property is the preferred font for [`body`](../uifont/textstyle/body.md).
