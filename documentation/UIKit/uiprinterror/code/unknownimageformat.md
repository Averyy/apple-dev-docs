# UIPrintError.Code.unknownImageFormat

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

An image is in a format that UIKit doesn’t recognize for printing.

**Availability**:
- iOS 4.2+
- iPadOS 4.2+
- Mac Catalyst 13.1+
- visionOS 1.0+

