# UIPrintError.Code.noContent

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

UIKit hasn’t assigned a print formatter, page renderer, or printing item to print.

**Availability**:
- iOS 4.2+
- iPadOS 4.2+
- Mac Catalyst 13.1+
- visionOS 1.0+
