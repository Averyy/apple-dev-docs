# init(frame:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a search bar with a specified frame.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- visionOS 1.0+

## Declaration

```swift
init(frame: CGRect)
```

```objc
- (instancetype) initWithFrame:(CGRect) frame;
```

## Parameters

- `frame`: A rectangle that specifies the initial location and size of the search bar in its superview’s coordinates.
