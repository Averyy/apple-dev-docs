# placeholder

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The string to display when there’s no other text in the text field.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+

## Declaration

```swift
var placeholder: String? { get set }
```

```objc
@property (nonatomic, copy, nullable) NSString * placeholder;
```

#### Discussion

The default value is `nil`.
