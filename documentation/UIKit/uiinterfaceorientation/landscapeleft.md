# UIInterfaceOrientation.landscapeLeft

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

The device is in landscape mode, with the device upright and the Home button on the left.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- visionOS

## Declaration

```swift
case landscapeLeft
```

```c
UIInterfaceOrientationLandscapeLeft
```
