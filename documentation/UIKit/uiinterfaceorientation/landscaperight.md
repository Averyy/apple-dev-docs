# UIInterfaceOrientation.landscapeRight

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

The device is in landscape mode, with the device upright and the Home button on the right.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- visionOS
