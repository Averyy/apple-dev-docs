# UICellAccessoryOutlineDisclosureStyleAutomatic

**Framework**: UIKit  
**Kind**: case  
**Role**: Enumeration Case

The system automatically determines the style depending on whether the cell’s configuration is as a section header.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- visionOS 1.0+
