# UITableViewCell.SelectionStyle.blue

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

The cell has a default background color when it’s selected.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- tvOS
- visionOS

## Declaration

```swift
case blue
```

```c
UITableViewCellSelectionStyleBlue
```

#### Discussion

In iOS 7, the selection color is no longer blue. Use [`UITableViewCell.SelectionStyle.default`](./default.md) instead.
