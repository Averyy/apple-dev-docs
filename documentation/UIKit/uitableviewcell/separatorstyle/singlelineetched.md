# UITableViewCell.SeparatorStyle.singleLineEtched

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

The separator cell has double lines running across its width, giving it an etched look.

**Availability**:
- iOS 2.0+ - Deprecated in 11.0
- iPadOS 2.0+ - Deprecated in 11.0
- Mac Catalyst 13.1+ - Deprecated in 13.1

> **Deprecated**: Use [`UITableViewCell.SeparatorStyle.singleLine`](./singleline.md) instead.

## Declaration

```swift
case singleLineEtched
```

```c
UITableViewCellSeparatorStyleSingleLineEtched
```

#### Discussion

This style is currently only supported for grouped-style table views.
