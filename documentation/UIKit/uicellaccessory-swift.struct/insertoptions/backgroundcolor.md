# backgroundColor

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The background color to apply to the accessory.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
- visionOS

## Declaration

```swift
var backgroundColor: UIColor?
```

#### Discussion

The default value of this property is `nil`, which uses the system default.
