# showsVerticalSeparator

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that determines whether a vertical separator displays before the accessory when it appears after another accessory.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
- visionOS

## Declaration

```swift
var showsVerticalSeparator: Bool
```

## Discussion

The default value of this property is [`true`](../../../Swift/true.md).
