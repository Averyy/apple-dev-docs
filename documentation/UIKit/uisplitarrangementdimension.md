# UISplitArrangementDimension

**Framework**: UIKit  
**Kind**: class  
**Role**: Class

A dimension that indicates how to size a view in a split arrangement.

**Availability**:
- iOS 27.1+
- iPadOS 27.1+
- Mac Catalyst 27.1+
- tvOS 27.1+
- visionOS 27.1+

## Declaration

```objc
@interface UISplitArrangementDimension : NSObject
```

## Topics

### Getting a dimension
- [+ automaticDimension](./uisplitarrangementdimension/automaticdimension.md)
  A dimension that indicates sizing for a view in a split arrangement follows automatic rules.
- [+ intrinsicDimension](./uisplitarrangementdimension/intrinsicdimension.md)
  A dimension that indicates sizing for a view in a split arrangement uses intrinsic content size.
- [+ absoluteDimension:](./uisplitarrangementdimension/absolutedimension_.md)
  A dimension that indicates sizing for a view in a split arrangement uses the float value you provide, expressed in points.
- [+ fractionalDimension:](./uisplitarrangementdimension/fractionaldimension_.md)
  A dimension that indicates sizing for a view in a split arrangement uses the float value you provide as a fraction.
