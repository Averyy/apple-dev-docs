# radius

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The blur radius, in points, used to render the shadow. Defaults to `0.0`.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- tvOS 18.0+
- visionOS 2.0+
