# offset

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The offset, in points, of the layer’s shadow. Defaults to `CGSizeZero`.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- tvOS 18.0+
- visionOS 2.0+
