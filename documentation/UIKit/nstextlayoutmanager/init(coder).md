# init(coder:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a new text layout manager with the coder you provide.

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- Mac Catalyst 15.0+
- tvOS 15.0+
- visionOS 1.0+

## Declaration

```swift
init?(coder: NSCoder)
```

```objc
- (instancetype) initWithCoder:(NSCoder *) coder;
```

## Parameters

- `coder`: A coder that implements [`NSCoder`](../../Foundation/nscoder.md).
