# init(coder:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a text container from data in an unarchiver.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- Mac Catalyst 13.1+
- tvOS 9.0+
- visionOS 1.0+

```swift
init(coder: NSCoder)
```

```objc
- (instancetype) initWithCoder:(NSCoder *) coder;
```

## Parameters

- `coder`: A coder that implements [`NSCoder`](../../Foundation/nscoder.md).
