# UICellAccessoryOutlineDisclosureStyle

**Framework**: UIKit  
**Kind**: enum  
**Role**: Enumeration

Constants that describe the style of the outline disclosure accessory.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- visionOS 1.0+

## Declaration

```c
enum UICellAccessoryOutlineDisclosureStyle : NSInteger;
```

- [UICellAccessoryOutlineDisclosureStyleCell](./uicellaccessoryoutlinedisclosurestyle/uicellaccessoryoutlinedisclosurestylecell.md)

  The style to use for a section header.
