# accessories

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

Cell accessories to use when displaying this item. Some accessories may not be shown if it conflicts with system default accessories.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
