# init(request:)

**Framework**: UIKit  
**Kind**: init

Creates a sidebar item from the specified request. The sidebar item will be preconfigured with the appropriate defaults for its content.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- visionOS 2.0+

## Declaration

```swift
convenience init(request: UITabSidebarItem.Request)
```
