# lift

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

An effect that can visually lift the view on hover where appropriate.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- visionOS 1.0+

## Declaration

```swift
static var lift: UIHoverLiftEffect { get }
```

Available when `Self` is `UIHoverLiftEffect`.
