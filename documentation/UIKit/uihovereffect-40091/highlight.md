# highlight

**Framework**: UIKit  
**Kind**: property  
**Role**: Type Property

An effect that applies a highlight to the view on hover.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- visionOS 1.0+

## Declaration

```swift
static var highlight: UIHoverHighlightEffect { get }
```

Available when `Self` is `UIHoverHighlightEffect`.
