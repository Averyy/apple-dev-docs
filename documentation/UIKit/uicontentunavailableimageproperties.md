# UIContentUnavailableImageProperties

**Framework**: UIKit  
**Kind**: class  
**Role**: Class

Properties configuring the appearance of images in a content-unavailable view.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- tvOS 17.0+
- visionOS 1.0+

## Declaration

```objc
@interface UIContentUnavailableImageProperties : NSObject
```

## Topics

### Instance Properties
- [accessibilityIgnoresInvertColors](./uicontentunavailableimageproperties/accessibilityignoresinvertcolors.md)
  A Boolean value that determines whether the image inverts its colors with the Invert Colors accessibility feature enabled.
- [cornerRadius](./uicontentunavailableimageproperties/cornerradius.md)
  The preferred corner radius for the image.
- [maximumSize](./uicontentunavailableimageproperties/maximumsize.md)
  A maximum size for the image.
- [preferredSymbolConfiguration](./uicontentunavailableimageproperties/preferredsymbolconfiguration.md)
  The symbol configuration for the image.
- [tintColor](./uicontentunavailableimageproperties/tintcolor.md)
  The tint color applied to the image view.
