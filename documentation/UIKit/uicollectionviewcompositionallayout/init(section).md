# init(section:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a compositional layout object with a single section.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- tvOS 13.0+
- visionOS 1.0+
