# hinge

**Framework**: UIKit  
**Kind**: property

The current hinge state for the interaction, or `nil` when the interaction leaves a hierarchy that provides hinge updates.

**Availability**:
- iOS 27.1+ (Beta)
- iPadOS 27.1+ (Beta)
