# flipHorizontalTransition

**Framework**: UIKit  
**Kind**: method  
**Role**: Type Method

A transition where the current view flips horizontally to reveal the new view.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- tvOS 18.0+
- visionOS 2.0+

## Declaration

