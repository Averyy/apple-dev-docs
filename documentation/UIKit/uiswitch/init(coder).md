# init(coder:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Creates a switch control from data in an unarchiver.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.1+
- visionOS 1.0+

## Declaration

```swift
init?(coder: NSCoder)
```

```objc
- (instancetype) initWithCoder:(NSCoder *) coder;
```

## Parameters

- `coder`: An object containing data used to initialize the switch control.
