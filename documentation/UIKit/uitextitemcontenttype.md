# UITextItemContentType

**Framework**: UIKit  
**Kind**: enum  
**Role**: Enumeration

Constants that describe and capture the type of content a text item represents along with a specific related value.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- visionOS 1.0+

## Declaration

```c
enum UITextItemContentType : NSInteger;
```

## Topics

### Getting the content type
- [UITextItemContentTypeLink](./uitextitemcontenttype/uitextitemcontenttypelink.md)
  A link to a resource, such as an item on a remote server or the path to a local file.
- [UITextItemContentTypeTag](./uitextitemcontenttype/uitextitemcontenttypetag.md)
  A string that represents a custom tag for a topic.
- [UITextItemContentTypeTextAttachment](./uitextitemcontenttype/uitextitemcontenttypetextattachment.md)
  A text attachment, such as an image or view.
