# UIPencilPreferredAction.showInkAttributes

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

An action that toggles the display of the selected tool’s ink attributes.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- visionOS 26.2+
