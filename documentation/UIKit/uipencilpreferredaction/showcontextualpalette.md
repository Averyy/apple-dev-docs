# UIPencilPreferredAction.showContextualPalette

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

An action that toggles shows a contextual palette of markup tools, or undo and redo options if tools aren’t available.

**Availability**:
- iOS 17.5+
- iPadOS 17.5+
- Mac Catalyst 17.5+
- visionOS 26.2+
