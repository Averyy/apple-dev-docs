# layoutRegionForBarOnEdge:extent:

**Framework**: UIKit  
**Kind**: method  
**Role**: Type Method

Returns a bar layout region of a given extent on a given edge.

**Availability**:
- iOS 27.1+
- iPadOS 27.1+
- Mac Catalyst 27.1+
- tvOS 27.1+
- visionOS 27.1+

## Declaration

```objc
+ (UIViewLayoutRegion *) layoutRegionForBarOnEdge:(UIRectEdge) edge extent:(CGFloat) extent;
```

## Discussion

> **Note**: Only a single edge is allowed per region.
