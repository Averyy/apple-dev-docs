# layoutRegionForBarOnDirectionalEdge:

**Framework**: UIKit  
**Kind**: method  
**Role**: Type Method

Returns a bar layout region on a given directional edge using the default system bar extent.

**Availability**:
- iOS 27.2+
- iPadOS 27.2+

## Declaration

```objc
+ (UIViewLayoutRegion *) layoutRegionForBarOnDirectionalEdge:(NSDirectionalRectEdge) edge;
```

## Discussion

> **Note**: Only a single edge is allowed per region.
