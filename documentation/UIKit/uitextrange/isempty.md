# isEmpty

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the range of text represented by the receiver is zero-length.

**Availability**:
- iOS 3.2+
- iPadOS 3.2+
- Mac Catalyst 13.1+
- tvOS
- visionOS 1.0+

## Declaration

```swift
var isEmpty: Bool { get }
```

```objc
@property (nonatomic, readonly, getter=isEmpty) BOOL empty;
```
