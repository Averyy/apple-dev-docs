# defaultViewProperties

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

**Availability**:
- iOS 27.1+
- iPadOS 27.1+
- Mac Catalyst 27.1+
- tvOS 27.1+
- visionOS 27.1+
