# imageToTextPadding

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

The padding between the image and text.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- tvOS 14.0+
- visionOS 1.0+

## Declaration

```objc
@property (nonatomic) CGFloat imageToTextPadding;
```

## Discussion

This value only applies when there’s both an image and text.
