# init(itemProviders:)

**Framework**: UIKit  
**Kind**: init  
**Role**: Initializer

Initializes and returns an activity items configuration with the specified item providers.

**Availability**:
- iOS 13.0+
- iPadOS 13.0+
- Mac Catalyst 13.1+
- visionOS 1.0+
