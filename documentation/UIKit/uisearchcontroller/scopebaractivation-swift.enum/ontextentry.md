# UISearchController.ScopeBarActivation.onTextEntry

**Framework**: UIKit  
**Kind**: case  
**Role**: Case

A mode in which the search controller shows the scope bar when typing begins in the search field, and hides it after search cancellation.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- visionOS 1.0+
