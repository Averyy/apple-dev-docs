# displayOrder

**Framework**: UIKit  
**Kind**: property  
**Role**: Instance Property

An array that contains instances of subitems in their display order.

**Availability**:
- iOS 18.0+
- iPadOS 18.0+
- Mac Catalyst 18.0+
- tvOS 18.0+
- visionOS 2.0+

## Declaration

```swift
var displayOrder: [UITab] { get }
```

```objc
@property (nonatomic, strong, readonly) NSArray<UITab *> * displayOrder;
```
