# UIApplicationCategoryDefaultStatusLastProvidedDateErrorKey

**Framework**: UIKit  
**Kind**: var  
**Role**: Global Variable

A dictionary key, with a value that’s the date your app last received a successful result.

**Availability**:
- iOS 18.2+
- iPadOS 18.2+

## Declaration
