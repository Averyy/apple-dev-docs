# osVersion

**Framework**: MetricKit  
**Kind**: property

The version of the OS on the device including the type of OS, version number, and build number.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
