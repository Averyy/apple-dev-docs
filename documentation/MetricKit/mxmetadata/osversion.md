# osVersion

**Framework**: MetricKit  
**Kind**: property  
**Role**: Instance Property

The version of the OS on the device including the type of OS, version number, and build number.

**Availability**:
- iOS 13.0+ - Deprecated in 27.2
- iPadOS 13.0+ - Deprecated in 27.2
- Mac Catalyst 13.1+ - Deprecated in 27.0
- macOS 12.0+ - Deprecated in 27.2
- visionOS 1.0+ - Deprecated in 27.2

> **Deprecated**: Use [`osVersion`](../metricreport/environment-swift.struct/osversion.md) or [`osVersion`](../diagnosticreport/environment-swift.struct/osversion.md) instead.

## Declaration

```swift
var osVersion: String { get }
```

```objc
@property (strong, readonly, nonnull) NSString * osVersion;
```

#### Discussion

The OS version is the same as the one used in crash reports.
