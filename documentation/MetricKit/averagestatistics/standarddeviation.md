# standardDeviation

**Framework**: MetricKit  
**Kind**: property  
**Role**: Instance Property

The standard deviation of the distribution of values used to calculate the average.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+
- Mac Catalyst 27.0+
- macOS 27.0+

## Declaration

```swift
let standardDeviation: Double?
```

This value is `nil` when the standard deviation is not available.
