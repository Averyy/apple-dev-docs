# locationMap

**Framework**: Accessibility  
**Kind**: property  
**Role**: Instance Property

An array of integers that has the same length as the resultString. locationMap[i]-th character in the input string corresponds to resultString[i].

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
