# init(_:)

**Framework**: CarKey  
**Kind**: init  
**Role**: Initializer

Creates and returns a new function identifier with the specified value.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.3+
- watchOS 9.0+

## Declaration

```swift
init(_ rawValue: Int)
```

#### Return Value

A new function identifier type.

## Parameters

- `rawValue`: The value for the new type.
