# Resolution Results

**Framework**: SiriKit  
**Role**: API Collection

Resolve common types of data like strings and dates into specific values that your app recognizes.

## Topics

- [class INIntentResolutionResult](https://developer.apple.com/documentation/intents/inintentresolutionresult)

- [class INObjectResolutionResult](https://developer.apple.com/documentation/intents/inobjectresolutionresult)
