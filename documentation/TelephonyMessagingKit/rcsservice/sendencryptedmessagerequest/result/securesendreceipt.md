# secureSendReceipt

**Framework**: TelephonyMessagingKit  
**Kind**: property

The send receipt of the message.

**Availability**:
- iOS 26.5+ (Beta)
- iPadOS 26.5+ (Beta)

## Declaration

```swift
let secureSendReceipt: RCSMessage.SecureSendReceipt?
```

#### Discussion

Use this to re-send a message when the recipient device fails to decrypt the message.
