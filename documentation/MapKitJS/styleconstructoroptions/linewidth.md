# lineWidth

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

The width of a line’s stroke, in CSS pixels.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
lineWidth?: number;
```

#### Discussion

The default line width is `1`.
