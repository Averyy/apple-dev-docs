# arrivalDate

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

The arrival date for the trip.

**Availability**:
- MapKit JS 5.46+

## Declaration

```
arrivalDate?: Date;
```

## Discussion

Specify either a [`departureDate`](./departuredate.md) or an `arrivalDate`, but don’t set both. If you send both values, MapKit JS logs a warning.
