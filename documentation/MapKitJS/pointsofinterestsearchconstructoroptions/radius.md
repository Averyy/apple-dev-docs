# radius

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

Sets the distance provided in meters, or the longest distance derived from the center point to the region’s bounding box.

**Availability**:
- MapKit JS 5.45+

## Declaration

```
radius?: number;
```
