# pointOfInterestFilter

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

Sets a filter that lists points of interest categories to include or exclude.

**Availability**:
- MapKit JS 5.45+

## Declaration

```
pointOfInterestFilter?: PointOfInterestFilter;
```
