# data

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

Custom data to associate with the overlay.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
get data(): {};
set data(data: {});
```

#### Discussion

You choose the data to assign to the overlay. It can be any JavaScript value.
