# size

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The dimensions of the annotation, in CSS pixels.

**Availability**:
- MapKit JS 5.78.1+

## Declaration

```
get size(): Size;
```

#### Discussion

You can’t change the size of a [`PlaceAnnotation`](../placeannotation.md).
