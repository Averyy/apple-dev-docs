# draggable

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the place annotation is draggable.

**Availability**:
- MapKit JS 5.78.1+

## Declaration

```
get draggable(): boolean;
```

## Discussion

You can’t set the draggable property of the place annotation. This property always returns `false`.
