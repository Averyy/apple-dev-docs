# color

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The color of the place.

**Availability**:
- MapKit JS 5.74+

## Declaration

```
get color(): string;
```

#### Discussion

Not all places have a color. You can’t set the color property of the place annotation.
