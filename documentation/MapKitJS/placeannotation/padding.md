# padding

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The amount of spacing to add around the annotation when showing items.

**Availability**:
- MapKit JS 5.78.1+

## Declaration

```
get padding(): Padding;
```

#### Discussion

You can’t set the padding property of the place annotation.
