# rotation

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

The map’s rotation, in degrees.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
rotation?: number;
```

#### Discussion

The default value is `0.`
