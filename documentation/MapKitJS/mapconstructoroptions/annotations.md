# annotations

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

An array holding all the annotations on the map.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
annotations?: Annotation[];
```

#### Discussion

The default value is `[]` (empty array).
