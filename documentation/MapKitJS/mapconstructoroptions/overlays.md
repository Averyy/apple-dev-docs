# overlays

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

An array that contains all of the map’s overlays.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
overlays?: Overlay[];
```

#### Discussion

The default value is `[]` (empty array).
