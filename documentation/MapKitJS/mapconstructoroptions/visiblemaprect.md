# visibleMapRect

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

The visible area of the map, in map units.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
visibleMapRect?: MapRectData;
```

#### Discussion

The default value is `new mapkit.MapRect(0, 0, 1, 1).`
