# selectedOverlay

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

The selected overlay on the map.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
selectedOverlay?: Overlay;
```

#### Discussion

The default value is `null.`
