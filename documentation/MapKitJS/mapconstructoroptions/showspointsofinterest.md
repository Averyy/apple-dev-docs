# showsPointsOfInterest

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

A Boolean value that determines whether the map displays points of interest.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
showsPointsOfInterest?: boolean;
```

## Discussion

The default value is `true.`
