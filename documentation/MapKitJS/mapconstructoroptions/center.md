# center

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

The map coordinate at the center of the map view.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
center?: CoordinateData;
```

#### Discussion

There’s no default value.
