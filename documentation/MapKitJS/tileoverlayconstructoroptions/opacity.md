# opacity

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

The opacity level of the overlay.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
opacity: number;
```

## Discussion

The default value is `1`.
