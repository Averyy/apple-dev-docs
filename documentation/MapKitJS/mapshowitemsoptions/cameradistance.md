# cameraDistance

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

The distance from the center of the map to the camera, when showing the items.

**Availability**:
- MapKit JS 5.23+

## Declaration

```
cameraDistance?: number;
```
