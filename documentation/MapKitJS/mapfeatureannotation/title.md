# title

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The title of the feature.

**Availability**:
- MapKit JS 5.74.1+

## Declaration

```
get title(): string | null;
```

#### Discussion

You can’t set the title property of the map feature annotation.
