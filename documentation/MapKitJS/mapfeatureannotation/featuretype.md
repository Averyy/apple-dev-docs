# featureType

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

A value that describes the type of place the feature represents.

**Availability**:
- MapKit JS 5.74.1+

## Declaration

```
get featureType(): "" | MapFeatureType;
```

#### Discussion

This is one of the possible [`MapFeatureType`](../mapfeaturetype.md) values.
