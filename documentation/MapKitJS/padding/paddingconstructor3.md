# new Padding(top, right)

**Framework**: MapKit JS  
**Kind**: init  
**Role**: Constructor

Creates a padding object and initializes it with the provided top and right side values.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
constructor(top: number, right: number);
```

#### Discussion

The framework sets the left and bottom padding values to `0`.

## Parameters

- `top`: The top inset margin.
- `right`: The right inset margin.
