# copy()

**Framework**: MapKit JS  
**Kind**: method  
**Role**: Instance Method

Returns a copy of the padding object.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
copy(): Padding;
```

## Return Value

A [`Padding`](../padding.md) object that is a copy of the original.
