# defaultPrevented

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the app canceled the event.

**Availability**:
- MapKit JS 5.0+ - Deprecated in 6.0

> **Deprecated**: Removed in MapKit JS 6.0.0. Use standard `Event` instead.
