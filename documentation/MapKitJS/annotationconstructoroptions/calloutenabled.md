# calloutEnabled

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

A Boolean value that determines whether the map shows a callout.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
calloutEnabled?: boolean;
```

## Discussion

The default value is `true`.
