# subtitle

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

The text to display as a subtitle on the second line of an annotation’s callout.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
subtitle?: string;
```

## Discussion

The default value is `null`.
