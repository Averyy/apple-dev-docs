# accessibilityLabel

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

Accessibility text for the annotation.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
accessibilityLabel?: string;
```

#### Discussion

The default value is `null`.
