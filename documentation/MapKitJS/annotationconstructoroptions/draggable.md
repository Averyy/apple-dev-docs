# draggable

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

A Boolean value that determines whether the user can drag the annotation.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
draggable?: boolean;
```

#### Discussion

The default value is `false`.
