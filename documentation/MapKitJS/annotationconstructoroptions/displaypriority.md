# displayPriority

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

A hint the map uses to prioritize displaying the annotation.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
displayPriority?: AnnotationDisplayPriority;
```

## Mentions

- [MapKit JS 5](../mapkit-js-5.md)

#### Discussion

The default value is [`Required`](../annotationdisplaypriority/required.md)
