# size

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The dimensions of the annotation, in CSS pixels.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
get size(): Size;
set size(_: Size);
```

#### Discussion

You can’t change the size of an [`MarkerAnnotation`](../markerannotation.md).
