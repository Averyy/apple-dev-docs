# includeAddresses

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

A Boolean value that indicates whether the search results should include addresses.

**Availability**:
- MapKit JS 5.32.2+

## Declaration

```
includeAddresses?: boolean;
```

## Discussion

The default value is `true`.
