# copy()

**Framework**: MapKit JS  
**Kind**: method  
**Role**: Instance Method

Returns a copy of the map size object.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
copy(): MapSize;
```

## Return Value

A MapSize object that is a copy of the original.
