# boundingRegion

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

The region that encloses the places from the search results.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
boundingRegion: CoordinateRegion | null;
```

## Discussion

This property isn’t present if there aren’t any results.
