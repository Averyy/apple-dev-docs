# fillColor

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The fill color of a shape.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
get fillColor(): string;
set fillColor(fillColor: string);
```

## Discussion

This can be any valid CSS color value. Set to `null` for no fill. The default fill color is `rgb(0, 122, 255)`.
