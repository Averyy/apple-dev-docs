# size

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The size of the user location annotation.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
get size(): Size;
set size(_: Size);
```

## Discussion

You can’t set the size of the user-location annotation.
