# copy()

**Framework**: MapKit JS  
**Kind**: method  
**Role**: Instance Method

Returns a copy of the location.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
copy(): MapPoint;
```

## Return Value

A MapPoint object that is a copy of the map location.
