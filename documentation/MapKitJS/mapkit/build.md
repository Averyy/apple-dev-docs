# build

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The build string.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
get build(): string;
```

## Discussion

A build string that describes the MapKit JS version. It’s helpful to include this in bug reports.
