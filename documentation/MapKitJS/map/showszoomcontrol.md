# showsZoomControl

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

A Boolean value that determines whether to display a control for zooming in and zooming out on a map.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
get showsZoomControl(): boolean;
set showsZoomControl(showsZoomControl: boolean);
```
