# removeOverlay(overlay)

**Framework**: MapKit JS  
**Kind**: method  
**Role**: Instance Method

Removes an overlay from the map.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
removeOverlay(overlay: Overlay): Overlay;
```

## Return Value

Returns the overlay.

## Parameters

- `overlay`: The overlay to remove.
