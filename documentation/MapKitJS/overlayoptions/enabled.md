# enabled

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

A Boolean value that determines whether the overlay responds to user interaction.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
enabled?: boolean;
```

#### Discussion

The default value is `true`.
