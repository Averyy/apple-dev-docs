# BottomTrailing

**Framework**: MapKit JS  
**Kind**: case  
**Role**: Enumeration Case

Places the badge on the bottom trailing corner of the Look Around preview.

**Availability**:
- MapKit JS 5.79+

## Declaration

```
readonly BottomTrailing: "bottomTrailing";
```

## See Also

### Possible badge positions

- [TopTrailing](./toptrailing.md)
