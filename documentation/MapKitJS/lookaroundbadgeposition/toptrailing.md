# TopTrailing

**Framework**: MapKit JS  
**Kind**: case  
**Role**: Enumeration Case

Places the badge on the top trailing corner of the Look Around preview.

**Availability**:
- MapKit JS 5.79+

## Declaration

```
readonly TopTrailing: "topTrailing";
```
