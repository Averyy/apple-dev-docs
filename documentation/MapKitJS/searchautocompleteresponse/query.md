# query

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

The query string used to perform the autocomplete request.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
query: string;
```

#### Discussion

The search query that corresponds to the [`results`](./results.md).

  The results from an autocomplete request.
