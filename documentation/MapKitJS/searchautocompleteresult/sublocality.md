# subLocality

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The name of the area within the locality.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
subLocality: string | null;
```

## Discussion

For example, the [`subLocality`](./sublocality.md) for the Golden Gate Park is `"Golden Gate Park"`.
