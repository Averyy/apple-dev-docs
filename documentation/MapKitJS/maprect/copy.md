# copy()

**Framework**: MapKit JS  
**Kind**: method  
**Role**: Instance Method

Returns a copy of a map rectangle.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
copy(): MapRect;
```

#### Return Value

A MapRect object that is a copy of the original.
