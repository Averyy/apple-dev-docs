# Rectangle

**Framework**: MapKit JS  
**Kind**: case

Uses the full collision frame rectangle to detect collisions.

**Availability**:
- MapKit JS 5.0+

## Declaration

```swift
readonly Rectangle: "rectangle";
```

#### Discussion

The bounding box of the annotation is used for collision detection.

  Uses a circle inscribed in the collision frame rectangle to detect collisions.
