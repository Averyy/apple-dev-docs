# message

**Framework**: MapKit JS  
**Kind**: property

The error message describing the request failure.

**Availability**:
- MapKit JS 6.0+

## Declaration

```swift
message: ConfigurationErrorStatus;
```

#### Discussion

The value is a [`ConfigurationErrorStatus`](configurationerrorstatus.md) string that indicates why the request failed.
