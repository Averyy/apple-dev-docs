# subLocality

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The name of the area within the locality.

**Availability**:
- MapKit JS 5.41.1+

## Declaration

```
subLocality: string | null;
```

## Discussion

For example, the [`subLocality`](./sublocality.md) for Golden Gate Park in San Francisco, California, is `"Golden Gate Park"`.
