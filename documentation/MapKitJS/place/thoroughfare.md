# thoroughfare

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The street name at the place.

**Availability**:
- MapKit JS 5.41.1+

## Declaration

```
thoroughfare: string | null;
```

#### Discussion

For example, one possible [`thoroughfare`](./thoroughfare.md) in Golden Gate Park in San Francisco, California, is `"John F Kennedy Dr"`.
