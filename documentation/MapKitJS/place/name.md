# name

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The name of the place.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
name: string | null;
```

#### Discussion

For example, the name for a specific place in Golden Gate Park in San Francisco, California, is `"Lindley Meadow"`.
