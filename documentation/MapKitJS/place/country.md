# country

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The country or region of the place.

**Availability**:
- MapKit JS 5.41.1+

## Declaration

```
country: string | null;
```

#### Discussion

For example, the [`country`](./country.md) for Golden Gate Park in San Francisco, California, is `"United States"`.
