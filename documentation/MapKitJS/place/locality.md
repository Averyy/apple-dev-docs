# locality

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The city of the place.

**Availability**:
- MapKit JS 5.41.1+

## Declaration

```
locality: string | null;
```

#### Discussion

For example, the [`locality`](./locality.md) for Golden Gate Park in San Francisco, California, is `"San Francisco"`.
