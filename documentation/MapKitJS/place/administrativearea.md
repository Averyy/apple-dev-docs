# administrativeArea

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

The state or province of the place.

**Availability**:
- MapKit JS 5.41.1+

## Declaration

```
administrativeArea: string | null;
```

## Discussion

For example, the [`administrativeArea`](./administrativearea.md) for Golden Gate Park in San Francisco, CA is “`California"`.
