# Complete

**Framework**: MapKit JS  
**Kind**: case  
**Role**: Enumeration Case

A value that indicates the Look Around view has completed loading.

**Availability**:
- MapKit JS 5.79+

## Declaration

```
readonly Complete: "complete";
```
