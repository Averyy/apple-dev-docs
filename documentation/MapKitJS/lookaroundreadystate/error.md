# Error

**Framework**: MapKit JS  
**Kind**: case  
**Role**: Enumeration Case

A value that indicates the Look Around view encountered an error while loading.

**Availability**:
- MapKit JS 5.79+

## Declaration

```
readonly Error: "error";
```
