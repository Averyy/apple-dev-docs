# Adaptive

**Framework**: MapKit JS  
**Kind**: case

A measurement system that adapts to the map’s language.

**Availability**:
- MapKit JS 5.13+

## Declaration

```swift
readonly Adaptive: "adaptive";
```

#### Discussion

MapKit JS chooses the measurement system — either metric or imperial — based on the map’s language.
