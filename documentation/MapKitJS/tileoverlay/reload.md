# reload()

**Framework**: MapKit JS  
**Kind**: method  
**Role**: Instance Method

Reloads the tile overlay for the displayed map region with the latest data values.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
reload(): void;
```
