# accessibilityLabel

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

**Availability**:
- MapKit JS 5.0+

## Declaration

```
get accessibilityLabel(): string | null;
set accessibilityLabel(value: string | null);
```

## Discussion
