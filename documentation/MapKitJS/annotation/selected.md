# selected

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether the map shows the annotation in a selected state.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
get selected(): boolean;
set selected(value: boolean);
```
