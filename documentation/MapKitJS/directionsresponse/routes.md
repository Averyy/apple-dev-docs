# routes

**Framework**: MapKit JS  
**Kind**: property  
**Role**: Interface Property

An array of route objects.

**Availability**:
- MapKit JS 5.0+

## Declaration

```
routes: Route[];
```

#### Discussion

The server returns up to three [`Route`](../route.md) objects in the array.
