# play()

**Framework**: WatchKit  
**Kind**: method  
**Role**: Instance Method

Plays the movie.

**Availability**:
- watchOS 3.0+

## Declaration

```swift
func play()
```

```objc
- (void) play;
```

## Discussion

If the movie is currently paused, this resumes playback from the current position.
