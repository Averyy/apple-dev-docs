# WatchKitError.Code.mediaPlayerFailed

**Framework**: WatchKit  
**Kind**: case  
**Role**: Case

A media player error.

**Availability**:
- watchOS

## Declaration

```swift
case mediaPlayerFailed
```

```c
WatchKitMediaPlayerError
```

## Discussion

WatchKit reports this error when it’s unable to play a media file.
