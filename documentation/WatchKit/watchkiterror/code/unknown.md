# WatchKitError.Code.unknown

**Framework**: WatchKit  
**Kind**: case  
**Role**: Case

An unknown error.

**Availability**:
- watchOS

## Declaration

```swift
case unknown
```

```c
WatchKitUnknownError
```

#### Discussion

WatchKit reports this error when it can’t determine the precise reason for the failure.
