# WatchKitError.Code.downloadFailed

**Framework**: WatchKit  
**Kind**: case  
**Role**: Case

A download error.

**Availability**:
- watchOS

## Declaration

```swift
case downloadFailed
```

```c
WatchKitDownloadError
```

#### Discussion

WatchKit reports this error when it can’t download a media file.
