# Model I/O Data Types

**Framework**: Model I/O  
**Role**: API Collection

## Topics

### Data Types
- [struct MDLAxisAlignedBoundingBox](./mdlaxisalignedboundingbox.md)
  The minimal volume containing an object, used by the [`boundingBox(atTime:)`](./mdlobject/boundingbox%28attime%29.md) method.
- [typealias MDLVoxelIndex](./mdlvoxelindex.md)
  A 4-component vector encoding the location of a voxel in a voxel array and describing its relation to an object’s volume.
