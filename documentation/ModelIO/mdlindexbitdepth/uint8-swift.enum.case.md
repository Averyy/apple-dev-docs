# MDLIndexBitDepth.uInt8

**Framework**: Model I/O  
**Kind**: case  
**Role**: Case

Each index in the submesh’s index buffer is an 8-bit integer.

**Availability**:
- iOS 9.0+
- iPadOS 9.0+
- Mac Catalyst 13.0+
- macOS 10.11+
- tvOS 9.0+
- visionOS 1.0+

## Declaration

```swift
case uInt8
```

```c
MDLIndexBitDepthUInt8
```

#### Discussion

An index buffer with this data type can contain a maximum of 256 indices.
