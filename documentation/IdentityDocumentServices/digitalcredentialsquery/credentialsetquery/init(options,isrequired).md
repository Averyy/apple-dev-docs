# init(options:isRequired:)

**Framework**: IdentityDocumentServices  
**Kind**: init  
**Role**: Initializer

Initializes a credential set query.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst
- macOS 27.3+ (Beta)

## Declaration

```swift
init(options: [Set<String>], isRequired: Bool = true)
```

## Parameters

- `options`: Sets of credential query identifiers, any one of which satisfies a grouping.
- `isRequired`: A Boolean that specifies whether a grouping must be satisfied.
