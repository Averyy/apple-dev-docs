# ~=(_:_:)

**Framework**: IdentityDocumentServices  
**Kind**: op  
**Role**: Operator

Pattern matching operator for matching error codes directly. This enables traditional switch/case pattern matching on error codes.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst
- macOS 26.0+
