# init(exchangeProtocol:responseData:)

**Framework**: IdentityDocumentServices  
**Kind**: init  
**Role**: Initializer

Initializes an OpenID4VP response.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst
- macOS 27.3+ (Beta)

## Declaration

```swift
init(exchangeProtocol: OpenID4VPExchangeProtocolIdentifier, responseData: Data)
```

## Parameters

- `exchangeProtocol`: The exchange protocol the response answers.
- `responseData`: The OpenID4VP authorization response.
