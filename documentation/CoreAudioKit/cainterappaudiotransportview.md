# CAInterAppAudioTransportView

**Framework**: CoreAudioKit  
**Kind**: class  
**Role**: Class

A view that provides an audio transport user interface.

**Availability**:
- iOS 8.0+ - Deprecated in 13.0
- iPadOS 8.0+ - Deprecated in 13.0
- Mac Catalyst 14.0+ - Deprecated in 14.0
- visionOS 1.0+ - Deprecated in 1.0

> **Deprecated**: This symbol is no longer recommended. Inter-App Audio is deprecated in iOS 13 and is unavailable when running iPad apps in macOS.
