# InsightEvaluator.OperationCategory.other

**Framework**: Trust Insights  
**Kind**: case  
**Role**: Case

A value that represents action types that don’t fall into other available categories.

**Availability**:
- iOS 27.0+
- iPadOS 27.0+

## Declaration

```swift
case other
```

#### Discussion

If the available action types aren’t appropriate for your use case, please consider filing a Feedback Report with the details relating to your category of interest.
