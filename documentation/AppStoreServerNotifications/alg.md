# alg

**Framework**: App Store Server Notifications  
**Kind**: typealias  
**Role**: Type

The JSON Web Signature (JWS) header parameter that identifies the cryptographic algorithm used to secure the JWS.

**Availability**:
- App Store Server Notifications 2.0+

string alg
