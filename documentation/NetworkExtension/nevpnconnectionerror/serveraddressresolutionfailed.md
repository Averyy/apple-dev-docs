# NEVPNConnectionError.serverAddressResolutionFailed

**Framework**: Network Extension  
**Kind**: case  
**Role**: Case

An error code that indicates the VPN connection failed because the system couldn’t determine the VPN server address.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
- tvOS 17.0+
- visionOS 1.0+
