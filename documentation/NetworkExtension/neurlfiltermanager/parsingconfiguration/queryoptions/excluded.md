# excluded

**Framework**: Network Extension  
**Kind**: property

A Boolean value that indicates whether to exclude the query component from URL parsing.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)

## Declaration

```swift
var excluded: Bool
```

#### Discussion

When this value is `true`, parsing ignores all other query options.
