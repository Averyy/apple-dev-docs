# NEHotspotConfigurationError.pending

**Framework**: Network Extension  
**Kind**: case  
**Role**: Case

The network configuration action has not completed.

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- Mac Catalyst 13.1+
- visionOS 1.0+
- watchOS 7.0+
