# kMIDIPropertyUMPEnabled

**Framework**: Core MIDI  
**Kind**: var  
**Role**: Global Variable

kMIDIPropertyUMPEnabled

## Declaration

```c
extern CFStringRef const kMIDIPropertyUMPEnabled;
```

#### Discussion

Device property, MIDIUniqueID. If this property is present and set to 1 then the device is UMP capable.
