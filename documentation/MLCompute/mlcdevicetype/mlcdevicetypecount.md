# MLCDeviceTypeCount

**Framework**: ML Compute  
**Kind**: case  
**Role**: Enumeration Case

A number that represents the number of device types.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
