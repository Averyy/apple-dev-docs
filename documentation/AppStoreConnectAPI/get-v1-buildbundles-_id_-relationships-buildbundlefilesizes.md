# List file size IDs for a build bundle

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/buildBundles/{id}/relationships/buildBundleFileSizes`

## Parameters

- `limit` (integer)
