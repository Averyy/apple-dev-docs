# List offer code IDs for an auto-renewable subscription

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/subscriptions/{id}/relationships/offerCodes`

## Parameters

- `limit` (integer)
