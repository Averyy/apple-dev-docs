# List app info localization IDs for an app info

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/appInfos/{id}/relationships/appInfoLocalizations`

## Parameters

- `limit` (integer)
