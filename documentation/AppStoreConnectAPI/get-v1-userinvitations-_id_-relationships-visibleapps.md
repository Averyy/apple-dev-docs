# List visible app IDs for a user invitation

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/userInvitations/{id}/relationships/visibleApps`

## Parameters

- `limit` (integer)
