# List Git reference IDs for an SCM repository

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/scmRepositories/{id}/relationships/gitReferences`

## Parameters

- `limit` (integer)
