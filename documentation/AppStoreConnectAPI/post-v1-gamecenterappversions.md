# Create an app version

**Framework**: App Store Connect API  
**Kind**: httpRequest

Add a new Game Center app version.

**Availability**:
- App Store Connect API 3.0+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/gameCenterAppVersions`
