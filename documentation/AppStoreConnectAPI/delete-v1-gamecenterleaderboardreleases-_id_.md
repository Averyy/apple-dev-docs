# Delete a Leaderboard Release

**Framework**: App Store Connect API  
**Kind**: httpRequest

Delete a new leaderboard release.

**Availability**:
- App Store Connect API 3.0+

## Endpoint

`DELETE https://api.appstoreconnect.apple.com/v1/gameCenterLeaderboardReleases/{id}`

## Parameters

- `id` (string) *(required)*
