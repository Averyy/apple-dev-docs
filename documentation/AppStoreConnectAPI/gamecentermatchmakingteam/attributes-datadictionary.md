# GameCenterMatchmakingTeam.Attributes

**Framework**: App Store Connect API  
**Kind**: dictionary

The attributes of a game-specific team.

**Availability**:
- App Store Connect API 3.1+

## Declaration

```swift
object GameCenterMatchmakingTeam.Attributes
```

## Properties

- `maxPlayers` (integer): The maximum number of players on the team.
- `minPlayers` (integer): The minimum number of players on the team.
- `referenceName` (string): A name for the team that’s unique within the scope of its rule set.
