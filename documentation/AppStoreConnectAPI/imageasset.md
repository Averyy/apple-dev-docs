# ImageAsset

**Framework**: App Store Connect API  
**Kind**: dictionary  
**Role**: Object

An image asset, including its height, width, and template URL.

**Availability**:
- App Store Connect API 1.0+

## Declaration

```
object ImageAsset
```

## Properties

- `templateUrl` (string)
- `height` (integer)
- `width` (integer)
