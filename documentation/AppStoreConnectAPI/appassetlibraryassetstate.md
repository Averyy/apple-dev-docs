# AppAssetLibraryAssetState

**Framework**: App Store Connect API  
**Kind**: typealias  
**Role**: Type

String that represents the state of an app asset library asset.

**Availability**:
- App Store Connect API 4.5+

## Declaration

```
string AppAssetLibraryAssetState
```

## Possible Values

- `AWAITING_UPLOAD`
- `UPLOAD_COMPLETE`
- `FAILED`
- `COMPLETE`
- `PREPARE_FOR_SUBMISSION`
- `READY_FOR_REVIEW`
- `WAITING_FOR_REVIEW`
- `IN_REVIEW`
- `ACCEPTED`
- `APPROVED`
- `REJECTED`
- `ARCHIVED`
