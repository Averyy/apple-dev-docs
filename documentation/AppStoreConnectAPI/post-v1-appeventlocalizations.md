# Create an app event localization

**Framework**: App Store Connect API  
**Kind**: httpRequest

Add a new localization for an in-app event.

**Availability**:
- App Store Connect API 1.7+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/appEventLocalizations`
