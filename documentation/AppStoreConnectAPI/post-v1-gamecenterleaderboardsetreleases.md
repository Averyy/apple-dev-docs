# Create a Leaderboard Set Release

**Framework**: App Store Connect API  
**Kind**: httpRequest

Add a new leaderboard set release.

**Availability**:
- App Store Connect API 3.0+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/gameCenterLeaderboardSetReleases`
