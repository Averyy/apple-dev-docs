# List device IDs for a profile

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/profiles/{id}/relationships/devices`

## Parameters

- `limit` (integer)
