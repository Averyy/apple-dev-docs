# App Store Connect API 4.6 release notes

**Framework**: App Store Connect API  
**Role**: Article

Update your server-side code to use new features, and test your code against API changes.

## Overview

App Store Connect API version 4.6 provides resources that enable you to automate actions you take in App Store Connect.

## Added

- Give people a reason to stay subscribed when they start to cancel an auto-renewable subscription. Create a retention message with [`Create a retention message`](./post-v1-retentionmessages.md), add localized text to its versions with [`Create a retention message localization`](./post-v1-retentionmessagelocalizations.md), and present a discount alongside the message with [`Create a retention offer`](./post-v1-retentionoffers.md). Assign the message to a subscription with [`Replace the retention message for a subscription`](./patch-v1-subscriptions-_id_-relationships-retentionmessage.md). For more information, see [Setting up retention messaging for auto-renewable subscriptions](./setting-up-retention-messaging.md).

## Deprecated

- The `INSTALLS` report type for [`Download sales and trends reports`](./get-v1-salesreports.md) is deprecated. As of November 4, 2026, Apple no longer generates new reports of this type, but you can still download historical reports.
