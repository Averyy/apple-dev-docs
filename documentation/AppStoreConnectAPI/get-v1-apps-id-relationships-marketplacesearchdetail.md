# Get the marketplace search detail ID for an app

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/apps/{id}/relationships/marketplaceSearchDetail`

## Parameters

- `id` (string) *(required)*
