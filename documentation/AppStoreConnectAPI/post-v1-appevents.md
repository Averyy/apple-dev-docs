# Create an in-app event

**Framework**: App Store Connect API  
**Kind**: httpRequest

Create a new in-app event for your app.

**Availability**:
- App Store Connect API 1.7+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/appEvents`
