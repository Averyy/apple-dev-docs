# AppAssetLibraryPlacementState

**Framework**: App Store Connect API  
**Kind**: typealias  
**Role**: Type

String that represents the state of an app asset library placement.

**Availability**:
- App Store Connect API 4.5+

## Declaration

```
string AppAssetLibraryPlacementState
```

## Possible Values

- `ASSET_PROCESSING`
- `FAILED`
- `PARENT_PREPARE_FOR_SUBMISSION`
- `PARENT_READY_FOR_REVIEW`
- `PARENT_WAITING_FOR_REVIEW`
- `PARENT_IN_REVIEW`
- `PARENT_APPROVED`
