# List repository IDs for an SCM provider

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/scmProviders/{id}/relationships/repositories`

## Parameters

- `limit` (integer)
