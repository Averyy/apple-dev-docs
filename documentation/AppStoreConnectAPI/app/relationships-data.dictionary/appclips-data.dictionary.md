# App.Relationships.AppClips

**Framework**: App Store Connect API  
**Kind**: dictionary  
**Role**: Object

The data and links that describe the relationship between the Apps and the App Clips resources.

**Availability**:
- App Store Connect API 1.6+

## Declaration

```
object App.Relationships.AppClips
```

## Topics

### Objects
- [object App.Relationships.AppClips.Data](./appclips-data.dictionary/data-data.dictionary.md)
  The type and ID of a related App Clips resource.

## Properties

- `data` ([App.Relationships.AppClips.Data]): The ID and type of the related App Clips resource.
- `links` (RelationshipLinks): Navigational links that include the self-link.
- `meta` (PagingInformation): The paging information.
