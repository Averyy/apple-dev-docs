# Create an app preview

**Framework**: App Store Connect API  
**Kind**: httpRequest

Add a new app preview to a preview set.

**Availability**:
- App Store Connect API 1.2+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/appPreviews`
