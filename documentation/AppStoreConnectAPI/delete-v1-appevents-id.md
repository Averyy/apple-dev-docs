# Delete an App Event

**Framework**: App Store Connect API  
**Kind**: httpRequest

Delete an in-app event and its related metadata.

**Availability**:
- App Store Connect API 1.7+

## Endpoint

`DELETE https://api.appstoreconnect.apple.com/v1/appEvents/{id}`

## Parameters

- `id` (string) *(required)*
