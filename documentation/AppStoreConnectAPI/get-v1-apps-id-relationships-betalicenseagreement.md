# Get the beta license agreement ID for an app

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/apps/{id}/relationships/betaLicenseAgreement`

## Parameters

- `id` (string) *(required)*
