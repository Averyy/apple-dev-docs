# Create a profile

**Framework**: App Store Connect API  
**Kind**: httpRequest

Create a new provisioning profile.

**Availability**:
- App Store Connect API 1.1+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/profiles`
