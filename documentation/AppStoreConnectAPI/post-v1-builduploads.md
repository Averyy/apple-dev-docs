# Create a Build Upload

**Framework**: App Store Connect API  
**Kind**: httpRequest

Add a new build upload to an app.

**Availability**:
- App Store Connect API 4.1+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/buildUploads`
