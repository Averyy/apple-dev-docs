# Get the beta app review submission ID for a build

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/builds/{id}/relationships/betaAppReviewSubmission`

## Parameters

- `id` (string) *(required)*
