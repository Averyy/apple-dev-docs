# Create a Featuring Nomination

**Framework**: App Store Connect API  
**Kind**: httpRequest

Tell Apple about your upcoming app or feature.

**Availability**:
- App Store Connect API 3.8+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/nominations`
