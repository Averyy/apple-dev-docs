# Delete a subscription group localization

**Framework**: App Store Connect API  
**Kind**: httpRequest

Delete a localized custom name for a subscription group configured with the v2 API.

**Availability**:
- App Store Connect API 4.4.1+

## Mentions

- [App Store Connect API 4.4.1 release notes](app-store-connect-api-4-4-1-release-notes.md)

## Endpoint

`DELETE https://api.appstoreconnect.apple.com/v2/subscriptionGroupLocalizations/{id}`

## Parameters

- `id` (string) *(required)*
