# Create an app screenshot

**Framework**: App Store Connect API  
**Kind**: httpRequest

Add a new screenshot to a screenshot set.

**Availability**:
- App Store Connect API 1.2+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/appScreenshots`
