# Create a Leaderboard Set Image

**Framework**: App Store Connect API  
**Kind**: httpRequest

Add a new leaderboard set image.

**Availability**:
- App Store Connect API 3.0+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/gameCenterLeaderboardSetImages`
