# AppAssetLibraryFeature

**Framework**: App Store Connect API  
**Kind**: typealias  
**Role**: Type

String that represents the App Store feature an app asset library asset supports.

**Availability**:
- App Store Connect API 4.5+

## Declaration

```
string AppAssetLibraryFeature
```

## Possible Values

- `APP_STORE_VERSIONS`
- `CUSTOM_PRODUCT_PAGES`
- `PRODUCT_PAGE_OPTIMIZATIONS`
- `IN_APP_EVENTS`
- `IN_APP_PURCHASES`
- `SUBSCRIPTIONS`
- `RETENTION_MESSAGING`
- `GAME_CENTER`
- `APP_CLIPS`
- `APPLE_ADS`
