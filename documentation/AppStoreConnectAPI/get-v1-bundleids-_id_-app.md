# Read the app information of a bundle id

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 1.2+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/bundleIds/{id}/app`

## Parameters

- `fields[apps]` ([string])
