# AppAssetLibraryPlacementType

**Framework**: App Store Connect API  
**Kind**: typealias  
**Role**: Type

String that represents the type of an app asset library placement.

**Availability**:
- App Store Connect API 4.5+

## Declaration

```
string AppAssetLibraryPlacementType
```

## Possible Values

- `APP_SCREENSHOT`
- `IMESSAGE_APP_SCREENSHOT`
- `APP_PREVIEW`
- `PRODUCT_PAGE_HEADER_ASSET`
- `APP_STORE_SEARCH_RESULTS_ASSET`
- `SEARCH_RESULTS_ADS_ASSET`
- `TODAY_TAB_ADS_ASSET`
- `EVENT_CARD_ASSET`
- `EVENT_DETAILS_PAGE_ASSET`
- `RETENTION_MESSAGE_ASSET`
