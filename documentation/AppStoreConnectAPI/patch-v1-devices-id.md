# Modify a Registered Device

**Framework**: App Store Connect API  
**Kind**: httpRequest

Update the name or status of a specific device.

**Availability**:
- App Store Connect API 1.1+

## Endpoint

`PATCH https://api.appstoreconnect.apple.com/v1/devices/{id}`

## Parameters

- `id` (string) *(required)*
