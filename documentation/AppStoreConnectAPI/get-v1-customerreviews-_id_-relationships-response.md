# Get the response ID for a customer review

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/customerReviews/{id}/relationships/response`

## Parameters

- `id` (string) *(required)*
