# Get the build ID for a build beta detail

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/buildBetaDetails/{id}/relationships/build`

## Parameters

- `id` (string) *(required)*
