# Create a beta build localization

**Framework**: App Store Connect API  
**Kind**: httpRequest

Create localized What’s New text for a build.

**Availability**:
- App Store Connect API 1.0+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/betaBuildLocalizations`
