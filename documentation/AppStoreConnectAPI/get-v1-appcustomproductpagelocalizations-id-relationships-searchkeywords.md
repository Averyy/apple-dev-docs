# List All Search Keywords for a Customer Product Page Localization

**Framework**: App Store Connect API  
**Kind**: httpRequest

Get a list of search keyword IDs for a customer product page localization.

**Availability**:
- App Store Connect API 4.1+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/appCustomProductPageLocalizations/{id}/relationships/searchKeywords`

## Parameters

- `limit` (integer)
