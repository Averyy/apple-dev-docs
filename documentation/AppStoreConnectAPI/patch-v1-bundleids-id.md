# Modify a Bundle ID

**Framework**: App Store Connect API  
**Kind**: httpRequest

Update a specific bundle ID’s name.

**Availability**:
- App Store Connect API 1.1+

## Endpoint

`PATCH https://api.appstoreconnect.apple.com/v1/bundleIds/{id}`

## Parameters

- `id` (string) *(required)*
