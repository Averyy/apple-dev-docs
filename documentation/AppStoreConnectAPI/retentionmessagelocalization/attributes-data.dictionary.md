# RetentionMessageLocalization.Attributes

**Framework**: App Store Connect API  
**Kind**: dictionary  
**Role**: Object

Attributes that describe a retention message localization resource.

**Availability**:
- App Store Connect API 4.6+

## Declaration

```
object RetentionMessageLocalization.Attributes
```

## Properties

- `locale` (string): The locale of the header and body text. For more information, see [Managing metadata in your app by using locale shortcodes](../managing-metadata-in-your-app-by-using-locale-shortcodes.md).
- `header` (string): The heading of the retention message, up to 66 characters.
- `body` (string): The body text of the retention message, up to 144 characters.
