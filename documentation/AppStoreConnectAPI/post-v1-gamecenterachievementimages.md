# Create an Achievement Image

**Framework**: App Store Connect API  
**Kind**: httpRequest

Add a new achievement image.

**Availability**:
- App Store Connect API 3.0+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/gameCenterAchievementImages`
