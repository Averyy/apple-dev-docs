# Get the second primary subcategory ID for an app info

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/appInfos/{id}/relationships/primarySubcategoryTwo`

## Parameters

- `id` (string) *(required)*
