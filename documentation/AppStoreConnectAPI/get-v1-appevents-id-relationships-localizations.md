# List localization IDs for an app event

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/appEvents/{id}/relationships/localizations`

## Parameters

- `limit` (integer)
