# List certificate IDs for a merchant ID

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/merchantIds/{id}/relationships/certificates`

## Parameters

- `limit` (integer)
