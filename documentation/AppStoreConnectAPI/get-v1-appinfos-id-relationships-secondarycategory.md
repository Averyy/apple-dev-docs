# Get the secondary category ID for an app info

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/appInfos/{id}/relationships/secondaryCategory`

## Parameters

- `id` (string) *(required)*
