# Delete a Group

**Framework**: App Store Connect API  
**Kind**: httpRequest

Remove a group.

**Availability**:
- App Store Connect API 3.0+

## Endpoint

`DELETE https://api.appstoreconnect.apple.com/v1/gameCenterGroups/{id}`

## Parameters

- `id` (string) *(required)*
