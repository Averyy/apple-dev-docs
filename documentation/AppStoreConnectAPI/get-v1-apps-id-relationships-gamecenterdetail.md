# Get the Game Center detail ID for an app

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/apps/{id}/relationships/gameCenterDetail`

## Parameters

- `id` (string) *(required)*
