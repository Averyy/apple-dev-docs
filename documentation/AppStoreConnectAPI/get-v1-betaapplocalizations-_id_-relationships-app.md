# Get the app ID for a beta app localization

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/betaAppLocalizations/{id}/relationships/app`

## Parameters

- `id` (string) *(required)*
