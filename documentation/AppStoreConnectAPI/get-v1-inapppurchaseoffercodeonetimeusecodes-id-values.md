# List All Values for an In-App Purchase Offer Code One-Time Use Code

**Framework**: App Store Connect API  
**Kind**: httpRequest

Get a list of values for a specific In-App Purchase offer code one-time use code.

**Availability**:
- App Store Connect API 4.2+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/inAppPurchaseOfferCodeOneTimeUseCodes/{id}/values`

## Parameters

- `id` (string) *(required)*
