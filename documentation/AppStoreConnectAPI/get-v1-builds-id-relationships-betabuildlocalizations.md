# List beta build localization IDs for a build

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/builds/{id}/relationships/betaBuildLocalizations`

## Parameters

- `limit` (integer)
