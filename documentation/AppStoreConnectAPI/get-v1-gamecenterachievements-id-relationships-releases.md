# List release IDs for a Game Center achievement

**Framework**: App Store Connect API  
**Kind**: httpRequest

**Availability**:
- App Store Connect API 4.0+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/gameCenterAchievements/{id}/relationships/releases`

## Parameters

- `limit` (integer)
