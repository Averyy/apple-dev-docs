# Modify a Review Submission Item

**Framework**: App Store Connect API  
**Kind**: httpRequest

Update a specific review submission item.

**Availability**:
- App Store Connect API 1.7+

## Endpoint

`PATCH https://api.appstoreconnect.apple.com/v1/reviewSubmissionItems/{id}`

## Parameters

- `id` (string) *(required)*
