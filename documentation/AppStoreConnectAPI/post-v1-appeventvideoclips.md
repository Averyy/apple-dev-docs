# Create an app event video clip

**Framework**: App Store Connect API  
**Kind**: httpRequest

Reserve a video clip asset for an in-app event.

**Availability**:
- App Store Connect API 1.7+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/appEventVideoClips`
