# List Territory IDs for an App Tag

**Framework**: App Store Connect API  
**Kind**: httpRequest

List territory IDs for an app tag.

**Availability**:
- App Store Connect API 4.1+

## Endpoint

`GET https://api.appstoreconnect.apple.com/v1/appTags/{id}/relationships/territories`

## Parameters

- `limit` (integer)
