# Modify a Background Asset

**Framework**: App Store Connect API  
**Kind**: httpRequest

Update a specific background asset.

**Availability**:
- App Store Connect API 3.6+

## Endpoint

`PATCH https://api.appstoreconnect.apple.com/v1/backgroundAssets/{id}`

## Parameters

- `id` (string) *(required)*
