# InAppPurchaseType

**Framework**: App Store Connect API  
**Kind**: typealias  
**Role**: Type

A string that represents the type of an In-App Purchase.

**Availability**:
- App Store Connect API 2.0+

## Declaration

```
string InAppPurchaseType
```

## Possible Values

- `CONSUMABLE`
- `NON_CONSUMABLE`
- `NON_RENEWING_SUBSCRIPTION`
