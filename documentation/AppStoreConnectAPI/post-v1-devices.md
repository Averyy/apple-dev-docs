# Register a New Device

**Framework**: App Store Connect API  
**Kind**: httpRequest

Register a new device for app development.

**Availability**:
- App Store Connect API 1.1+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/devices`
