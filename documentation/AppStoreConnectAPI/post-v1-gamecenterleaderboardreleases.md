# Create a Leaderboard Release

**Framework**: App Store Connect API  
**Kind**: httpRequest

Add a new leaderboard release.

**Availability**:
- App Store Connect API 3.0+

## Endpoint

`POST https://api.appstoreconnect.apple.com/v1/gameCenterLeaderboardReleases`
