# contains(edge:)

**Framework**: Compute Graph  
**Kind**: method

Returns whether the graph contains the given edge.

## Declaration

```swift
func contains(edge: ComputeNodeGraph.Edge) -> Bool
```

#### Return Value

`true` if the graph contains the edge; otherwise, `false`.

## Parameters

- `edge`: The edge to look up.
