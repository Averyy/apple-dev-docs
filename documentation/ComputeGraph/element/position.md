# element::position

**Framework**: ComputeGraph  
**Kind**: func

Returns the current position of the element, in the graph’s coordinate space.

**Availability**:
- macOS 27.0+ (Beta)
- Reality Composer Pro 27.0+ (Beta)

## Declaration

```swift
float3 element::position()
```

#### Return Value

The position as a 3D vector (x, y, z)
