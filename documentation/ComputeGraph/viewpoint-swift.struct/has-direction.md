# has_direction

**Framework**: ComputeGraph  
**Kind**: property

Indicates whether a valid direction is available.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- Reality Composer Pro 27.0+ (Beta)

## Declaration

```swift
var has_direction: Bool
```

#### Discussion

When `false`, the `direction` value should not be used.
