# has_direction

**Framework**: Compute Graph  
**Kind**: property  
**Role**: Instance Property

Indicates whether a valid direction is available.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS
- tvOS
- visionOS
- Reality Composer Pro

## Declaration

```swift
var has_direction: Bool
```

```c
bool has_direction;
```

#### Discussion

When `false`, the `direction` value should not be used.
