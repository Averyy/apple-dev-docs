# has_position

**Framework**: Compute Graph  
**Kind**: property  
**Role**: Instance Property

Indicates whether a valid position is available.

**Availability**:
- iOS
- iPadOS
- Mac Catalyst
- macOS

- visionOS
- Reality Composer Pro

## Declaration

```swift
var has_position: Bool
```


## Discussion

When `false`, the `position` value should not be used.
