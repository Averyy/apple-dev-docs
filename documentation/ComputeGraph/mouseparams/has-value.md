# has_value

**Framework**: ComputeGraph  
**Kind**: property

Indicates whether valid mouse parameters are available.

**Availability**:
- iOS 27.0+ (Beta)
- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- tvOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- Reality Composer Pro 27.0+ (Beta)

## Declaration

```swift
var has_value: Bool
```

#### Discussion

When `false`, the `position` and `direction` values should not be used.
