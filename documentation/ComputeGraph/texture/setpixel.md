# texture::setPixel

**Framework**: ComputeGraph  
**Kind**: func

In the context of a texture stage, sets the current pixels’ value.

**Availability**:
- macOS 27.0+ (Beta)
- Reality Composer Pro 27.0+ (Beta)

## Declaration

```swift
void texture::setPixel(float4 value)
```
