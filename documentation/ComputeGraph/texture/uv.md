# texture::uv

**Framework**: ComputeGraph  
**Kind**: func

Current pixel’s position, in UV [0.0, 1.0] coordinates.

**Availability**:
- macOS 27.0+ (Beta)
- Reality Composer Pro 27.0+ (Beta)

## Declaration

```swift
float2 texture::uv()
```

#### Discussion

In the context of a texture stage, returns the current pixel position, in UV coordinates.
