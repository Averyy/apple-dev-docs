# texture::position

**Framework**: ComputeGraph  
**Kind**: func

Current pixel’s position

**Availability**:
- macOS 27.0+ (Beta)
- Reality Composer Pro 27.0+ (Beta)

## Declaration


In the context of a texture stage, returns the current pixel position, in integer coordinates.
