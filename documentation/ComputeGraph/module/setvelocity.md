# module::setVelocity

**Framework**: ComputeGraph  
**Kind**: func

Sets the velocity of an element to the specified value.

**Availability**:
- macOS 27.0+ (Beta)
- Reality Composer Pro 27.0+ (Beta)

## Declaration

```swift
void module::setVelocity(float3 velocity)
```

#### Discussion

Use this function to assign a new velocity vector to an element, replacing its current velocity.

> **Note**: ![Graph](https://docs-assets.developer.apple.com/published/54c6ced8fde7ed5ad81798ee739731e2/module__setVelocity.svg)

## Parameters

- `velocity`: The new velocity vector
