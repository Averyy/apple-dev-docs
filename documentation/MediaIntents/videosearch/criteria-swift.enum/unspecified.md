# VideoSearch.Criteria.unspecified

**Framework**: Media Intents  
**Kind**: case  
**Role**: Case

The request includes a vague search query or no specific search criteria.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- tvOS 27.3+ (Beta)
- visionOS 27.3+ (Beta)

## Declaration

```swift
case unspecified
```

## Discussion

The person says something like “Play something” without specifying particular content. Provide recommended or recently watched content in your response.
