# init(criteria:)

**Framework**: Media Intents  
**Kind**: init  
**Role**: Initializer

Creates a video search with a person’s search criteria.

**Availability**:
- iOS 27.3+ (Beta)
- iPadOS 27.3+ (Beta)
- Mac Catalyst 27.3+ (Beta)
- tvOS 27.3+ (Beta)
- visionOS 27.3+ (Beta)

## Declaration

```swift
init(criteria: VideoSearch.Criteria)
```

## Parameters

- `criteria`: The search criteria for the video request.
