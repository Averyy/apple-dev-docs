# CFNetServiceGetPortNumber(_:)

**Framework**: CFNetwork  
**Kind**: func  
**Role**: Function

This function gets the port number from a CFNetService.

**Availability**:
- iOS 2.0+ - Deprecated in 27.0
- iPadOS 2.0+ - Deprecated in 27.0
- Mac Catalyst 13.1+ - Deprecated in 27.0
- macOS 10.5+ - Deprecated in 27.0
- tvOS 9.0+ - Deprecated in 27.0
- visionOS 1.0+ - Deprecated in 27.0

> **Deprecated**: Use nw_browser_t or nw_listener_t in Network framework instead

## Declaration

```swift
func CFNetServiceGetPortNumber(_ theService: CFNetService) -> Int32
```

```c
extern SInt32 CFNetServiceGetPortNumber(CFNetServiceRef theService);
```

## Return Value

The port number of the service.

## Parameters

- `theService`: The CFNetService whose protocol-specific information is to be obtained; cannot be `NULL`. Note that in order to get protocol-specific information, you must resolve `theService` by calling [`CFNetServiceResolve`](./cfnetserviceresolve.md) or [`CFNetServiceResolveWithTimeout(_:_:_:)`](./cfnetserviceresolvewithtimeout%28_,_,_%29.md) before calling this function.
