# CFNetServiceGetTypeID()

**Framework**: CFNetwork  
**Kind**: func  
**Role**: Function

Gets the Core Foundation type identifier for the Network Service object.

**Availability**:
- iOS 2.0+ - Deprecated in 27.0
- iPadOS 2.0+ - Deprecated in 27.0
- Mac Catalyst 13.1+ - Deprecated in 27.0
- macOS 10.2+ - Deprecated in 27.0
- tvOS 9.0+ - Deprecated in 27.0
- visionOS 1.0+ - Deprecated in 27.0

> **Deprecated**: Use nw_browser_t or nw_listener_t in Network framework instead

## Declaration

```swift
func CFNetServiceGetTypeID() -> CFTypeID
```

```c
extern CFTypeID CFNetServiceGetTypeID();
```

## Return Value

The type ID.

## Discussion

This function is thread safe.
