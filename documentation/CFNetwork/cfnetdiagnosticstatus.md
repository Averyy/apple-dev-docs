# CFNetDiagnosticStatus

**Framework**: CFNetwork  
**Kind**: typealias  
**Role**: Type Alias

A CFIndex type that is used to return status values from `CFNetDiagnostic` status and diagnostic functions. For a list of possible values, see [`CFNetDiagnosticStatusValues`](./cfnetdiagnosticstatusvalues.md).

**Availability**:
- iOS 2.0+ - Deprecated in 11.0
- iPadOS 2.0+ - Deprecated in 11.0
- Mac Catalyst 13.1+ - Deprecated in 13.1
- macOS 10.4+ - Deprecated in 10.13
- tvOS 9.0+ - Deprecated in 11.0
- visionOS 1.0+ - Deprecated in 1.0

## Declaration

```swift
typealias CFNetDiagnosticStatus = CFIndex
```

typedef CFIndex CFNetDiagnosticStatus;
