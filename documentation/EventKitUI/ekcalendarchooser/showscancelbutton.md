# showsCancelButton

**Framework**: EventKit UI  
**Kind**: property  
**Role**: Instance Property

A Boolean that determines whether to display a Cancel button.

**Availability**:
- iOS 4.0+
- iPadOS 4.0+
- Mac Catalyst 13.0+
- visionOS 1.0+

## Declaration

```swift
var showsCancelButton: Bool { get set }
```

```objc
@property (nonatomic) BOOL showsCancelButton;
```

#### Discussion

Use [`true`](../../Swift/true.md) to show a Cancel button; otherwise, [`false`](../../Swift/false.md).
