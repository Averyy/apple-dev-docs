# monitoredIdentifiers

**Framework**: Core Location  
**Kind**: property  
**Role**: Instance Property

An array that contains all the identifiers for each condition that the monitor is monitoring.

**Availability**:
- iOS 17.0+
- iPadOS 17.0+
- Mac Catalyst 17.0+
- macOS 14.0+
