# CLDeviceOrientation.faceDown

**Framework**: Core Location  
**Kind**: case  
**Role**: Case

The device is held parallel to the ground with the screen facing downwards.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- Mac Catalyst 13.0+
- macOS 10.6+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+
