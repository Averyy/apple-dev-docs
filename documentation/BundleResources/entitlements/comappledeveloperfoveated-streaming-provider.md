# Foveated Streaming Provider

**Framework**: Bundle Resources  
**Kind**: typealias

An entitlement that allows other apps to use privacy-sensitive foveation data for streaming from remote endpoints to Apple Vision Pro.

**Availability**:
- visionOS 27.0+ (Beta)



**Type**: boolean

#### Discussion

Allow apps to use your protocol with the Foveated Streaming framework to connect and stream immersive content. Use of this entitlement requires Apple approval; complete the [`entitlement request form`](https://developer.apple.comhttps://developer.apple.com/contact/request/foveated-streaming-provider/).
