# iCloud Key-Value Store Entitlement

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The container identifier to use for iCloud key-value storage.

**Availability**:
- iOS 3.0+
- iPadOS 3.0+
- macOS 10.7+
- tvOS 9.0+
- watchOS 2.0+

## Details

- **Name**: `com.apple.developer.ubiquity-kvstore-identifier` (iCloud Key-Value Store)
- **Type**: string

## Discussion

To add this entitlement to your app, enable the iCloud capability and “Key-value storage” service in Xcode.
