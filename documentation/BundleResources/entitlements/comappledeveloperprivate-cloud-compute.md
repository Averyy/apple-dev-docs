# com.apple.developer.private-cloud-compute

**Framework**: Bundle Resources  
**Kind**: typealias

**Availability**:

- iPadOS 27.0+ (Beta)
- Mac Catalyst 27.0+ (Beta)
- macOS 27.0+ (Beta)
- visionOS 27.0+ (Beta)
- watchOS 27.0+ (Beta)



**Type**: boolean

**Default**: `NO`
