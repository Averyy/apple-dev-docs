# iCloud Container Identifiers Entitlement

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The container identifiers for the iCloud production environment.

**Availability**:
- iOS 3.0+
- iPadOS 3.0+
- macOS 10.7+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Details

- **Name**: `com.apple.developer.icloud-container-identifiers` (iCloud Container Identifiers)
- **Type**: array of string 

## Discussion

To add this entitlement to your app, enable the iCloud capability in Xcode.
