# WeatherKit Entitlement

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A Boolean value that indicates whether the app may use WeatherKit.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
- tvOS 16.0+
- watchOS 9.0+

## Details

- **Name**: `com.apple.developer.weatherkit` (WeatherKit)
- **Type**: boolean



**Default**: `NO`

#### Discussion

To add this entitlement to your app, enable the WeatherKit capability in Xcode.
