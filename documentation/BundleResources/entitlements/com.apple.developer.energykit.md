# EnergyKit Entitlement

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The entitlement the system requires for an app to use the EnergyKit framework.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+

## Details

- **Name**: `com.apple.developer.energykit`
- **Type**: boolean



**Default**: `NO`

#### Discussion

This entitlement works with the [EnergyKit](../../EnergyKit/EnergyKit.md) framework, which provides insights and suggestions to manage home device electricity usage.

To use EnergyKit, add this entitlement to your app by enabling the EnergyKit capability on your target in Xcode. For more information, see [Adding capabilities to your app](../../Xcode/adding-capabilities-to-your-app.md).
