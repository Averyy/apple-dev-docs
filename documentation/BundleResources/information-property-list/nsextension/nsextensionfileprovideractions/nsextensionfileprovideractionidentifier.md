# NSExtensionFileProviderActionIdentifier

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

**Availability**:
- iOS 11.0+
- iPadOS 11.0+
- visionOS 1.0+

## Details

- **Name**: `NSExtensionFileProviderActionIdentifier`
