# NSExtensionServiceRoleType

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The type of task an Action extension performs.

**Availability**:
- macOS 10.10+

## Details

- **Name**: `NSExtensionServiceRoleType`
- **Type**: string

## Possible Values

- `NSExtensionServiceRoleTypeEditor`
- `NSExtensionServiceRoleTypeViewer`
