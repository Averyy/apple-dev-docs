# PHSupportedMediaTypes

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The types of assets a Photo Editing extension can edit.

**Availability**:
- iOS 8.0+
- iPadOS 8.0+

## Details

- **Name**: `PHSupportedMediaTypes`
- **Type**: array of string 

## Possible Values

- `Image`
- `Video`
