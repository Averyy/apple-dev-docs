# NSExtensionServiceAllowsFinderPreviewItem

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

**Availability**:
- macOS 10.14+

## Details

- **Name**: `NSExtensionServiceAllowsFinderPreviewItem`
