# NSExtensionJavaScriptPreprocessingFile

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

**Availability**:
- iOS 8.0+
- iPadOS 8.0+
- macOS 10.10+
- visionOS 1.0+
