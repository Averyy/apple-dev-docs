# CFBundleIconFile

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The file containing the bundle’s icon.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Details

- **Name**: `CFBundleIconFile` (Icon file)
- **Type**: string
