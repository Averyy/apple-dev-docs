# CFBundleLocalizations

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The localizations handled manually by your app.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Details

- **Name**: `CFBundleLocalizations` (Localizations)
- **Type**: array of string 



**Default**: `en`
