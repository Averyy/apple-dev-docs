# LSRequiresIPhoneOS

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A Boolean value indicating whether the app must run in iOS.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+

## Details

- **Name**: `LSRequiresIPhoneOS` (Application requires iPhone environment)
- **Type**: boolean
