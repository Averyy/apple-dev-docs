# UTTypeIconFiles

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

One or more bundle icon resources to associate with this type.

**Availability**:
- iOS 5.0+
- iPadOS 5.0+
- macOS 10.7+
- visionOS 1.0+

## Details

- **Name**: `UTTypeIconFiles` (Icon file names)
- **Type**: array of string
