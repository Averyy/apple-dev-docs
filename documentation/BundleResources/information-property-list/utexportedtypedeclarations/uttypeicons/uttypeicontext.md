# UTTypeIconText

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A short string the system renders at the bottom edge of the document icon.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- macOS 11.0+
- visionOS 1.0+

## Details

- **Name**: `UTTypeIconText` (Text)
- **Type**: string

## Discussion

This key is optional.

The system automatically scales the text to fit and capitalizes every letter. Keep the string short enough to remain legible at the smallest icon sizes.
