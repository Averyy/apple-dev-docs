# NSSupportsLiveActivitiesFrequentUpdates

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A Boolean value that indicates whether an app can update its Live Activities frequently.

**Availability**:
- iOS 16.2+
- iPadOS 16.2+

## Details

- **Name**: `NSSupportsLiveActivitiesFrequentUpdates` (Supports Live Activities Frequent Updates)
- **Type**: boolean

## Discussion

Set the corresponding value to `true` to enable your Live Activities to receive frequent updates with remote push notifications. For more information, see `Updating and ending your Live Activity with ActivityKit push notifications`.
