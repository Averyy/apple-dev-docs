# GKGameCenterBadgingDisabled

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A Boolean value indicating whether GameKit can add badges to a turn-based game icon.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- visionOS 1.0+

## Details

- **Name**: `GKGameCenterBadgingDisabled`
- **Type**: boolean
