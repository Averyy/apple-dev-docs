# CFBundleTypeRole

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The app’s role with respect to the type.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Details

- **Name**: `CFBundleTypeRole` (Document Role)
- **Type**: string

## Possible Values

- `Editor`
- `Viewer`
- `Shell`
- `QLGenerator`
- `None`



**Default**: `None`
