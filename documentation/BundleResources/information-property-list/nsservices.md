# NSServices

**Framework**: Bundle Resources  
**Kind**: dictionary  
**Role**: Property List Key

The services provided by an app.

**Availability**:
- macOS 10.0+

## Details

- **Name**: `NSServices` (Services)
- **Type**: array of dictionary
