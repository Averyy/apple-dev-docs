# GCSupportsGameMode

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A Boolean value indicating whether the app supports game mode.

**Availability**:
- iOS 18.0+ - Deprecated in 18.6
- iPadOS 18.0+ - Deprecated in 18.6

> **Deprecated**: Use [`LSSupportsGameMode`](./lssupportsgamemode.md) instead.

## Details

- **Name**: `GCSupportsGameMode` (Supports Game Mode (deprecated))
- **Type**: boolean
