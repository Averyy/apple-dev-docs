# LSUIPresentationMode

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The initial user-interface mode for the app.

**Availability**:
- macOS 10.0+

## Details

- **Name**: `LSUIPresentationMode` (Application UI Presentation Mode)
- **Type**: number

## Possible Values

- `0`
- `1`
- `2`
- `3`
- `4`



**Default**: `0`
