# CFPlugInFactories

**Framework**: Bundle Resources  
**Kind**: dictionary  
**Role**: Property List Key

The interfaces supported by the plug-in for static registration.

**Availability**:
- macOS 10.0+

## Details

- **Name**: `CFPlugInFactories` (Plug-in factory interfaces)
- **Type**: dictionary
