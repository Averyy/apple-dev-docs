# LSBackgroundOnly

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A Boolean value indicating whether the app runs only in the background.

**Availability**:
- macOS 10.0+

## Details

- **Name**: `LSBackgroundOnly` (Application is background only)
- **Type**: boolean
