# NSFinancialDataUsageDescription

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A message that tells people why the app is requesting access to financial data stored in Wallet.

**Availability**:
- iOS 17.4+
- iPadOS 17.4+

## Details

- **Name**: `NSFinancialDataUsageDescription` (Privacy - Financial Data Usage Description)
- **Type**: string
