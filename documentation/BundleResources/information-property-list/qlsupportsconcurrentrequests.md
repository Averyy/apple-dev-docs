# QLSupportsConcurrentRequests

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A Boolean value indicating whether a Quick Look app’s  generator can handle concurrent thumbnail and preview requests.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- macOS 10.0+
- visionOS 1.0+

## Details

- **Name**: `QLSupportsConcurrentRequests` (Quick Look supports concurrent requests)
- **Type**: boolean



**Default**: `NO`
