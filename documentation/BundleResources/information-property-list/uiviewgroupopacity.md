# UIViewGroupOpacity

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A Boolean value that indicates whether Core Animation sublayers inherit the opacity of their superlayer.

**Availability**:
- iOS 3.0+
- iPadOS 3.0+
- tvOS 9.0+
- watchOS 2.0+

## Details

- **Name**: `UIViewGroupOpacity` (Renders with group opacity)
- **Type**: boolean

#### Discussion

If `YES`, sublayers inherit from the superlayer; otherwise, they don’t.
