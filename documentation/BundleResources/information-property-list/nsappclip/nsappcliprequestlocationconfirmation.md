# NSAppClipRequestLocationConfirmation

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A Boolean value that indicates whether an App Clip can confirm the user’s location.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+

## Details

- **Name**: `NSAppClipRequestLocationConfirmation` (Requests location confirmation)
- **Type**: boolean

#### Discussion

Set the value to `true` to allow your App Clip to confirm the user’s location. For more information, see [Responding to invocations](../../../AppClip/responding-to-invocations.md).
