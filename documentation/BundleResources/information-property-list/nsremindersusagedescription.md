# NSRemindersUsageDescription

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A message that tells people why the app is requesting access to their reminders.

**Availability**:
- iOS 6.0+ - Deprecated in 17.0
- iPadOS 6.0+ - Deprecated in 17.0
- Mac Catalyst 13.0+ - Deprecated in 17.0
- macOS 10.14+ - Deprecated in 14.0
- watchOS 6.0+ - Deprecated in 10.0

> **Deprecated**: NSRemindersUsageDescription has been deprecated; use [`NSRemindersFullAccessUsageDescription`](./nsremindersfullaccessusagedescription.md) instead.

## Details

- **Name**: `NSRemindersUsageDescription` (Privacy - Reminders Usage Description)
- **Type**: string

## Discussion

> ❗ **Important**:  This key is required if your app uses APIs that access the person’s reminders.
