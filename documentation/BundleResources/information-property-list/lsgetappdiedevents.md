# LSGetAppDiedEvents

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A Boolean value indicating whether the app is notified when a child process dies.

**Availability**:
- macOS 10.0+

## Details

- **Name**: `LSGetAppDiedEvents` (Application should get App Died events)
- **Type**: boolean
