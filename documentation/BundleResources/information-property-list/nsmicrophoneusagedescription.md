# NSMicrophoneUsageDescription

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A message that tells people why the app is requesting access to the device’s microphone.

**Availability**:
- iOS 7.0+
- iPadOS 7.0+
- macOS 10.14+
- tvOS 17.0+
- visionOS 1.0+
- watchOS 4.0+

## Details

- **Name**: `NSMicrophoneUsageDescription` (Privacy - Microphone Usage Description)
- **Type**: string

## Mentions

- [Requesting Authorization for Media Capture on macOS](../requesting-authorization-for-media-capture-on-macos.md)

#### Discussion

> ❗ **Important**:  This key is required if your app uses APIs that access the device’s microphone.
