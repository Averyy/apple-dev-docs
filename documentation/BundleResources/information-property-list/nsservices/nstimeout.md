# NSTimeout

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The amount of time, in milliseconds, that the system waits for a response from the service.

**Availability**:
- macOS 10.0+

## Details

- **Name**: `NSTimeout` (Timeout value (in milliseconds))
- **Type**: string
