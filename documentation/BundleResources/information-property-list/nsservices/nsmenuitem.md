# NSMenuItem

**Framework**: Bundle Resources  
**Kind**: dictionary  
**Role**: Property List Key

Text for a Services menu item.

**Availability**:
- macOS 10.0+

## Details

- **Name**: `NSMenuItem` (Menu)
- **Type**: dictionary

## Discussion

The dictionary key is `default` with a string value.

## Properties

- `default` (string) *(required)*
