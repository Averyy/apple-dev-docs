# CFBundleHelpBookName

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The name of the help file that will be opened in Help Viewer.

**Availability**:
- macOS 10.0+

## Details

- **Name**: `CFBundleHelpBookName` (Help Book identifier)
- **Type**: string
