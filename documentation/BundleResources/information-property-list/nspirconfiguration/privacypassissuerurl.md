# PrivacyPassIssuerURL

**Framework**: Bundle Resources  
**Kind**: typealias

The URL of the Privacy Pass issuer.

**Availability**:
- iOS 27.2+
- iPadOS 27.2+
- macOS 27.2+



**Type**: string

#### Discussion

This field is required for Live Caller ID extensions and optional for URL filter extensions.
