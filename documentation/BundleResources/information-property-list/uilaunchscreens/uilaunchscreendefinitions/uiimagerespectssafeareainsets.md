# UIImageRespectsSafeAreaInsets

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A Boolean that specifies whether the launch image should respect the safe area insets.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+

## Details

- **Name**: `UIImageRespectsSafeAreaInsets`
- **Type**: boolean
