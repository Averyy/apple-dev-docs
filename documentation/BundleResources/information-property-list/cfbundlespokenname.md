# CFBundleSpokenName

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

A replacement for the app name in text-to-speech operations.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Details

- **Name**: `CFBundleSpokenName` (Accessibility Bundle Name)
- **Type**: string
