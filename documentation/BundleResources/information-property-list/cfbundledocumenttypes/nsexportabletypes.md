# NSExportableTypes

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The file types that this document can be exported to.

**Availability**:
- iOS 2.0+
- iPadOS 2.0+
- macOS 10.0+
- tvOS 9.0+
- visionOS 1.0+
- watchOS 2.0+

## Details

- **Name**: `NSExportableTypes` (Exportable Type UTIs)
- **Type**: array of string
