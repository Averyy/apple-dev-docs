# APFileSourcePath

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The path to the file or folder in the app package, relative to the installer path.

**Availability**:
- macOS 10.0+

## Details

- **Name**: `APFileSourcePath` (Install file source path)
- **Type**: string
