# CoreSpotlightActionSymbolImage

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

**Availability**:
- iOS 15.0+
- iPadOS 15.0+
- visionOS 1.0+

## Details

- **Name**: `CoreSpotlightActionSymbolImage`
- **Type**: string
