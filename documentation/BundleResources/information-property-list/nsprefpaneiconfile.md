# NSPrefPaneIconFile

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The name of an image file used to represent a preference pane in the System Preferences app.

**Availability**:
- macOS 10.0+

## Details

- **Name**: `NSPrefPaneIconFile` (Preference Pane icon file)
- **Type**: string
