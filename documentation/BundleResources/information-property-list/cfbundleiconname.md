# CFBundleIconName

**Framework**: Bundle Resources  
**Kind**: typealias  
**Role**: Property List Key

The name of the asset that represents the app icon.

**Availability**:
- macOS 10.13+

## Details

- **Name**: `CFBundleIconName` (Icon Name)
- **Type**: string
