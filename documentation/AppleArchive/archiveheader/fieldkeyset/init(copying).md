# init(copying:)

**Framework**: Apple Archive  
**Kind**: init  
**Role**: Initializer

Creates a copy of the specified field key set.

**Availability**:
- iOS 14.0+
- iPadOS 14.0+
- Mac Catalyst 14.0+
- macOS 11.0+
- tvOS 14.0+
- visionOS
- watchOS 7.0+

## Declaration

```swift
init(copying s: ArchiveHeader.FieldKeySet)
```

## Parameters

- `s`: The source field key set.
