# selectedOptionIdentifier

**Framework**: SharedWithYouCore  
**Kind**: property  
**Role**: Instance Property

The identifier of the selected option in the group.

**Availability**:
- iOS 16.0+
- iPadOS 16.0+
- Mac Catalyst 16.0+
- macOS 13.0+
- visionOS 1.0+

## Declaration

```swift
var selectedOptionIdentifier: String { get set }
```

```objc
@property (nonatomic, strong, readwrite) NSString * selectedOptionIdentifier;
```

#### Discussion

The system defaults this value to the first [`SWCollaborationOption`](../swcollaborationoption.md) identifier.
