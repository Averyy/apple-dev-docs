# highlightDuration

**Framework**: Touch Controller  
**Kind**: property  
**Role**: Instance Property

The time it takes for a highlight to fade away, in seconds.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+

