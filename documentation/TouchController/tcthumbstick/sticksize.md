# stickSize

**Framework**: Touch Controller  
**Kind**: property  
**Role**: Instance Property

The size (width, height) of the thumbstick stick itself in points.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+

## Declaration

```swift
var stickSize: CGSize { get set }
```

```objc
@property (nonatomic, assign) CGSize stickSize;
```
