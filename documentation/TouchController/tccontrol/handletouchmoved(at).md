# handleTouchMoved(at:)

**Framework**: Touch Controller  
**Kind**: method  
**Role**: Instance Method  
**Required**: Yes

Handles a touch moved event at the specified point.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+

## Declaration

```swift

```


## Parameters

- `point`: The point where the touch moved to.
