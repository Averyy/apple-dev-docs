# zIndex

**Framework**: Touch Controller  
**Kind**: property  
**Role**: Instance Property

The z-index of the button. A lower z-index is drawn first.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+

## Declaration

```swift
var zIndex: Int { get set }
```

```objc
@property (nonatomic, assign) NSInteger zIndex;
```
