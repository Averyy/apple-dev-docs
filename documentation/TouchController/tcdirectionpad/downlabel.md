# downLabel

**Framework**: Touch Controller  
**Kind**: property  
**Role**: Instance Property

The label for the down button, if the control isn’t a composite direction pad.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
