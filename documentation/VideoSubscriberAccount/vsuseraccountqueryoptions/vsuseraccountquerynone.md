# VSUserAccountQueryNone

**Framework**: Video Subscriber Account  
**Kind**: case  
**Role**: Enumeration Case

A constant that indicates fetching user accounts from the user’s current device only.

**Availability**:
- iOS 16.4+
- iPadOS 16.4+
- macOS 13.3+
- tvOS 16.4+
- visionOS 1.0+
