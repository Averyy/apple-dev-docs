# includeAccountProviderIdentifier

**Framework**: Video Subscriber Account  
**Kind**: property  
**Role**: Instance Property

A Boolean value that indicates whether your app requests the identifier of the account provider.

**Availability**:
- iOS 10.0+
- iPadOS 10.0+
- Mac Catalyst 10.0+
- macOS
- tvOS 10.0+
- visionOS 1.0+
