# VSAutoSignInAuthorizationDenied

**Framework**: Video Subscriber Account  
**Kind**: case  
**Role**: Enumeration Case

A state that indicates the person denied authorization.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- macOS 26.0+
- tvOS 26.0+
- visionOS 26.0+
