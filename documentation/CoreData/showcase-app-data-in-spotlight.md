# Showcase App Data in Spotlight

**Framework**: Core Data  
**Role**: Sample Code  
**Download**: [ShowcaseAppDataInSpotlight.zip](https://docs-assets.developer.apple.com/published/f08acd44c6ed/ShowcaseAppDataInSpotlight.zip)
