# init()

**Framework**: Messages  
**Kind**: init  
**Role**: Initializer

Creates an instance of the critical messenger object.

**Availability**:
- iOS 18.2+
- iPadOS 18.2+

## Declaration

```swift
override dynamic init()
```

## Discussion

Don’t use this initializer directly, create an instance of [`MSCriticalSMSMessenger`](../mscriticalsmsmessenger.md) instead.
