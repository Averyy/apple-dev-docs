# isAnimating()

**Framework**: Messages  
**Kind**: method  
**Role**: Instance Method

Returns a Boolean value that indicates whether the sticker is animating.

**Availability**:
- iOS 10.0+
- iPadOS 10.0+
- Mac Catalyst 13.1+

## Declaration

```swift
func isAnimating() -> Bool
```

```objc
- (BOOL) isAnimating;
```

#### Return Value

Returns [`true`](../../Swift/true.md) if the sticker is animating; otherwise, [`false`](../../Swift/false.md).
