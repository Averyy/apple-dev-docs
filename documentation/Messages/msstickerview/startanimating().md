# startAnimating()

**Framework**: Messages  
**Kind**: method  
**Role**: Instance Method

Starts the sticker’s animation, beginning with the first frame.

**Availability**:
- iOS 10.0+
- iPadOS 10.0+
- Mac Catalyst 13.1+
