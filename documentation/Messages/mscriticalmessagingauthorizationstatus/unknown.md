# MSCriticalMessagingAuthorizationStatus.unknown

**Framework**: Messages  
**Kind**: case  
**Role**: Case

The authorization status is unknown.

**Availability**:
- iOS 18.2+
- iPadOS 18.2+

## Declaration

```swift
case unknown
```

## Discussion

A person hasn’t either explicitly authorized or denied authorization to use the framework.
