# FSExtentType.readOnly

**Framework**: FSKit  
**Kind**: case

An extent type to indicate read-only data.

**Availability**:
- macOS 27.0+ (Beta)

## Declaration

```swift
case readOnly
```

#### Discussion

Use this type to represent ranges in the file that data can be read but not written to.
