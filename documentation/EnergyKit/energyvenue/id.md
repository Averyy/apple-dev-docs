# id

**Framework**: EnergyKit  
**Kind**: property  
**Role**: Instance Property

A unique identifier for the venue.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst

## Declaration

```swift
let id: UUID
```

#### Discussion

Use this identifier to submit `ElectricalLoadEvent`s for [`ElectricityGuidance`](../electricityguidance.md).
