# EnergyKitError.venueUnavailable

**Framework**: EnergyKit  
**Kind**: case  
**Role**: Case

An error that indicates a referenced venue is invalid, nonexistent, or restricted by the person.

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst
