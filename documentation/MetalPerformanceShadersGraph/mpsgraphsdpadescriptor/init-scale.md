# init(scale:)

**Framework**: Metal Performance Shaders Graph  
**Kind**: init

Creates a descriptor with the given scale and all other properties set to their defaults (no mask, isCausal = NO, no sinks).

**Availability**:
- iOS 26.0+
- iPadOS 26.0+
- Mac Catalyst 26.0+
- macOS 26.0+
- tvOS 26.0+
