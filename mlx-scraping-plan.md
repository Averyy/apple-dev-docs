## Notes

### Why not everything?
- mlx-framework.org (10 stars) - Just the landing page source, no docs
- Most apple/ml-* repos - Research paper code, not documentation

### Rate Limiting
- GitHub Pages: Be respectful, 100-200ms between requests
- GitHub API (for README fetching): 5000 req/hr with token

### Incremental Updates
Each source tracks content hashes. Only changed pages are re-processed on subsequent runs.
